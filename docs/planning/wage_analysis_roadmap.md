# Real Wage Dashboard：賃金変動要因の分析ロードマップ

作成日：2026-08-19
最終更新：2026-08-28

---

## 1. この文書の目的

本プロジェクトでは、

> **日本の名目賃金・実質賃金は、なぜそのように変化したのか**

を、複数の公的統計を用いて段階的に検証する。

この文書は、個別分析の詳細を記録するためのものではなく、

- 分析全体をどのような構造で進めるか
- どこまで分析が完了しているか
- 次に何を検証するか
- どの時点で分析全体を一区切りとするか

を管理するロードマップとする。

確定した分析結果・数値・方法については、

- `docs/analysis/00_overview.md`
- `docs/analysis/01_*.md` 以降の個別分析文書

を正本とする。

## 2. 現在地

現在の分析体系は次の段階まで進んでいる。

```text
Phase 1. 賃金そのものの構造
  ✅ 雇用形態比較
  ✅ 給与構成
  ✅ 労働投入
  ✅ 産業別賃金・労働時間
  ✅ 産業構成効果

Phase 2. 賃金決定を取り巻く環境
  ✅ 労働需給
  ✅ 企業業績・生産性・付加価値・分配

Phase 3. 実際の賃金改定メカニズム
  ▶ 賃金改定行動
  ○ 春闘
  ○ 最低賃金

Phase 4. 実質購買力
  ○ 名目賃金要因と物価要因の分解
  ○ 費目別CPI

Phase 5. 平均値の背後
  ○ 賃金分布
  ○ 年齢・勤続年数
  ○ 企業・事業所規模別賃金

Phase 6. 外部環境・発展分析
  △ 為替・輸入物価・交易条件
  △ 国際比較
```

記号：

- `✅` 完了
- `▶` 次に実施する有力候補
- `○` 未実施
- `△` 将来候補

## 3. 分析全体の考え方

実質賃金は、単一要因で説明するのではなく、次の構造として捉える。

```text
実質賃金・購買力
│
├─ 名目賃金
│  │
│  ├─ 給与構成
│  │  ├─ 所定内給与
│  │  ├─ 所定外給与
│  │  └─ 特別給与
│  │
│  ├─ 労働投入
│  │  ├─ 時間当たり賃金
│  │  ├─ 労働時間
│  │  └─ 出勤日数
│  │
│  └─ 労働者構成
│     ├─ 雇用形態
│     ├─ 産業
│     ├─ 企業・事業所規模
│     └─ 年齢・勤続年数等
│
├─ 賃金決定環境
│  │
│  ├─ 労働需給
│  │  ├─ 求人倍率
│  │  ├─ 失業率
│  │  └─ 企業の人手不足感
│  │
│  ├─ 企業側の賃上げ余力
│  │  ├─ 付加価値
│  │  ├─ 労働生産性
│  │  └─ 企業収益
│  │
│  ├─ 分配
│  │  ├─ 人件費
│  │  └─ 労働分配率
│  │
│  └─ 賃金改定制度・行動
│     ├─ 企業の賃金改定
│     ├─ 春闘
│     └─ 最低賃金
│
└─ 物価
   ├─ 総合CPI
   ├─ 各種CPI系列
   └─ 費目別CPI
```

分析では、

```text
賃上げ圧力 + 賃上げ余力 + 付加価値の配分 + 賃金改定制度・行動 + 物価
```

を区別して考える。

## 4. 分析上の基本原則

### 4.1 分解・関連・因果を区別する

#### 恒等的・機械的分解

例：

```text
月額賃金 ≈ 時間当たり賃金 × 労働時間
現金給与総額 = きまって支給する給与 + 特別給与
```

全体変化を構成した要素を示す。

ただし、その構成要素が変化した原因までは示さない。

#### 記述的比較

例：

- 一般労働者とパートタイム労働者
- 産業別
- 企業規模別
- 時期別

対象間で観察された違いを示す。

#### 統計的関連

例：

```text
人手不足感 ↔ 所定内給与上昇率
労働生産性 ↔ 月額賃金上昇率
```

相関やラグ相関は因果関係を示さない。

#### 経済的仮説

例：

```text
人手不足
↓
賃上げ圧力
↓
企業の賃金改定
↓
名目賃金
```

データとの整合性を検証するが、観察データのみで因果効果を断定しない。

## 5. 完了済み分析

### 5.1 雇用形態比較

**問い**: 一般労働者とパートタイム労働者で、名目賃金・実質賃金・労働時間の変化はどう異なるか。

**主な位置づけ**: 実質賃金を単一の平均値ではなく、雇用形態別・月額・時間当たりで区別する。

**詳細**: `docs/analysis/01_employment_comparison.md`

---

### 5.2 給与構成の要因分解

**問い**: 現金給与総額の変化は、所定内給与・所定外給与・特別給与のどこから生じたか。

**主な結論**: 2015～2025年の現金給与総額上昇では、所定内給与の寄与が最大だった。所定外給与の長期的な寄与は小さく、近年の賃金上昇を残業増だけでは説明できない。

**詳細**: `docs/analysis/02_wage_composition.md`

---

### 5.3 労働投入の要因分解

**問い**: 月額賃金の変化は、時間当たり賃金と労働時間のどこから生じたか。

**主な結論**: 概算時間当たり賃金は上昇した一方、総実労働時間は減少し、月額賃金上昇の一部を相殺した。労働時間減少の中心は所定内労働時間であり、さらにその中心は出勤日数の減少だった。

**詳細**: `docs/analysis/03_labor_input.md`

---

### 5.4 産業別賃金・労働時間

**問い**: 賃金上昇は一部産業だけで起きたのか。

**主な結論**: 主要16産業すべてで月額賃金と概算時間当たり賃金が上昇し、総実労働時間が減少した。ただし、変化幅には大きな産業差がある。

**詳細**: `docs/analysis/04_industry_wage.md`

---

### 5.5 産業構成効果

**問い**: 全国平均賃金の上昇は、高賃金産業への雇用移動によって生じたのか。

**主な結論**: 2015～2025年の平均賃金上昇の中心は産業内賃金効果であり、産業構成効果はわずかにマイナスだった。したがって、高賃金産業への雇用移動が平均賃金上昇の主因ではない。

**詳細**: `docs/analysis/05_industry_composition.md`

---

### 5.6 労働需給と賃金

**問い**: 人手不足が強まると、その後の賃金上昇率は高まるか。

**主な結論**: 求人倍率、失業率、人手不足感と所定内給与上昇率には一定の正の関連がある。一方、その関係の強さや時間差は時期によって異なり、固定的な賃金反応期間は確認できなかった。労働需給だけで近年の賃金上昇を説明することはできない。

**詳細**: `docs/analysis/06_labor_market.md`

---

### 5.7 企業業績・生産性・付加価値・分配

**問い**: 企業が生み出す付加価値と、その労働側への配分は、賃金上昇とどのように関係しているか。

**主な結論**

2015～2024年度では、

- 労働生産性：+12.69%
- 1人当たり人件費：+7.29%
- 労働分配率：-3.27pt

となった。

企業側の付加価値創出力・収益力は改善したが、その伸びが同じ割合で人件費へ反映されたわけではない。

企業規模別では、大企業ほど生産性・収益性の改善が大きかった。
一方、中小企業では労働分配率が高いものの、生産性と1人当たり人件費の水準が低かった。

また、2000～2024年度の長期時系列分析では、生産性と月額賃金の関係は時期によって大きく異なり、2020年代に特に強い正相関がみられた。

したがって、

> 生産性が上昇すれば自動的に賃金も上昇する

という固定的な関係とはいえない。

**詳細**: `docs/analysis/07_corporate_performance.md`

## 6. 現時点で分かったこと

ここまでの分析を統合すると、日本の賃金変動は次のように整理できる。

```text
労働需給の逼迫 → 賃上げ圧力

企業収益・生産性 → 賃上げ余力

付加価値の配分 → 人件費への反映

企業の賃金改定・春闘・最低賃金 → 実際の名目賃金

名目賃金 × 労働時間・雇用構成 → 月額賃金

名目賃金 ÷ 物価 → 実質購買力
```

現時点では、

- 賃金上昇の内部構造
- 労働時間との関係
- 雇用形態差
- 産業差
- 産業構成変化
- 労働需給
- 企業側の付加価値・生産性・収益・分配

まで分析できている。

一方、

> **企業が実際にどのような理由で、どの程度賃金を改定したのか**

という「賃金決定行動」の部分がまだ直接観察できていない。

ここが現在の分析体系で最も大きな空白である。

## 7. 次に実施する分析

### 7.1 最優先：企業の賃金改定行動

#### 問い

**企業はなぜ賃金を引き上げたのか。また、賃上げを行わなかった企業では何が制約になったのか。**

#### 使用候補データ

厚生労働省「賃金引上げ等の実態に関する調査」

#### 確認したいこと

- 賃金改定を実施した企業割合
- 1人平均賃金改定額・改定率
- 賃金改定の決定要素
- 企業業績
- 労働力の確保・定着
- 物価
- 世間相場
- 労使関係
- 企業規模別差
- 時系列変化

#### 分析上の位置づけ

既存分析では、

```text
人手不足 → 賃上げ圧力
企業業績 → 賃上げ余力
```

まで確認した。

本分析では、その先の、

```text
賃上げ圧力・余力
↓
企業の意思決定
↓
実際の賃金改定
```

を検証する。

#### 優先度

## 11. 分析を追加する判断基準

今後は、分析テーマを無制限に追加しない。

新しい分析は、少なくとも次のいずれかを満たす場合に実施する。

1. 現在の全体結論で「説明できない」としている重要な空白を埋める。
2. 既存の仮説を別統計から検証できる。
3. 既存分析の解釈を大きく変える可能性がある。
4. 実質賃金がなぜ上がりにくかったかという中心問いへの説明力が高い。

単に、

- 分類を細かくできる
- データが存在する
- グラフを追加できる

という理由だけでは新規分析を追加しない。

## 12. 実装前の探索手順

各テーマについて、いきなりStreamlitページを作成しない。

### Step 1. 問いを1文で定義する

例：

> 企業は、どのような理由で賃金を引き上げているのか。

### Step 2. 必要な統計を確認する

- 統計名
- 調査対象
- 指標定義
- 利用可能期間
- データ形式
- API・CSV等の取得方法

を確認する。

### Step 3. 小規模な確認スクリプトを作る

`scripts/check_*.py` で、

- データ取得
- 欠損
- 年度・月
- 分類コード
- 単位
- 指標定義

を確認する。

### Step 4. 分析ロジックを実装する

分析処理は可能な限り、

```text
src/real_wage_dashboard/
```

へ分離する。

Streamlitページに分析ロジックを直接書き込まない。

### Step 5. 結果を確認する

まず表・標準出力等で結果を確認し、

> この結果は中心問いへの説明力があるか

を判断する。

### Step 6. 分析文書を作成する

採用する分析について、

```text
docs/analysis/
```

に、

- 問い
- 使用データ
- 分析条件
- 方法
- 結果
- 考察
- 言えること
- 言えないこと
- 制約

を記録する。

### Step 7. 必要な場合のみUI化する

分析価値が確認できたものだけアプリへ追加する。

すべての分析をStreamlitページにする必要はない。

## 13. 分析完了の基準

本プロジェクトの分析は、すべての候補テーマを実施した時点ではなく、

> **実質賃金がなぜ上がりにくかったのかについて、主要な経路を公的統計から説明できる状態**

を一区切りとする。

最低限、次の経路が整理できていればよい。

```text
1. 名目賃金は何によって変化したか
        ✅

2. 労働時間・雇用構成はどう影響したか
        ✅

3. 人手不足は賃上げと関係していたか
        ✅

4. 企業側に賃上げ余力はあったか
        ✅

5. 企業は実際になぜ賃金を改定したか
        未完

6. 物価上昇が実質賃金をどの程度押し下げたか
        未完
```

したがって、現時点では、

> **5. 賃金改定行動**
>
> **6. 名目賃金と物価の直接分解**

が分析全体を完成に近づける最重要テーマである。

これらが完了した後は、賃金分布、最低賃金、企業規模、費目別CPI等を、

> 結論を補強するために本当に必要か

という観点から追加する。
