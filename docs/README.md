# ドキュメント案内

このディレクトリには、Real Wage Dashboard の分析結果、分析計画、共通参照情報、過去の開発仕様を収録しています。

アプリの機能、セットアップ、実行方法は [プロジェクトREADME](../README.md) を参照してください。

## 最初に読む文書

[実質賃金関連分析：全体像と結論](analysis/00_overview.md) は、本プロジェクトで実施した分析を統合した正本文書です。

次の内容を確認できます。

- 分析全体の問いと対象範囲
- 2015年から2025年を中心とした名目賃金・労働時間・実質賃金の主要結果
- 雇用形態、給与構成、労働投入、産業差、産業構成の分析
- 労働需給と賃金の関係
- 企業収益・生産性・付加価値・労働分配と賃金の関係
- 分析から言えること、言えないこと
- 現時点で残されている分析課題

個別の数式、データ検証、詳細結果、実装・テスト情報は、各個別分析文書を参照してください。

## 分析体系

現在の分析は、大きく次の領域に分かれています。

```text
実質賃金・購買力
│
├─ 名目賃金の内部構造
│  ├─ 雇用形態
│  ├─ 給与構成
│  ├─ 労働投入
│  └─ 産業・雇用構成
│
├─ 賃金決定を取り巻く環境
│  ├─ 労働需給
│  └─ 企業収益・生産性・分配
│
└─ 物価
   └─ CPI
```

現時点では、名目賃金の内部構造と、労働需給・企業側の賃上げ余力まで分析済みです。

今後は、

```text
賃上げ圧力・余力
↓
企業の実際の賃金改定行動
↓
名目賃金
↓
物価との関係
↓
実質賃金
```

という残りの経路を中心に分析します。

## 文書の役割と優先順位

同じ内容が複数文書に現れる場合は、次の基準で参照します。

1. **個別分析の詳細値・方法**
   `analysis/01_*.md` から `analysis/07_*.md`

2. **分析全体の結論**
   `analysis/00_overview.md`

3. **現在の機能・実行方法**
   ルート `README.md`

4. **データ・指標・共通分析方法**
   `reference/`

5. **将来の分析候補・優先順位**
   `planning/wage_analysis_roadmap.md`

6. **過去バージョンの仕様・作業記録**
   `history/`

個別分析文書と `00_overview.md` は上下関係ではなく、役割が異なります。

- 数値の根拠や分析方法を確認する場合：個別分析文書
- 分析全体として何が分かったかを確認する場合：`00_overview.md`

を参照します。

## 更新ルール

- 新しい分析を追加した場合は、個別分析文書を `analysis/` へ追加する。
- 確定した主要結果が変わった場合は、個別分析文書と `analysis/00_overview.md` を更新する。
- 新しい個別分析文書を追加した場合は、この `docs/README.md` の読み順・一覧も更新する。
- ルートREADMEには分析の要約だけを掲載し、詳細な数値・方法を重複させない。
- 将来の分析候補と実施状況は `planning/wage_analysis_roadmap.md` で管理する。
- 分析結果の詳細をロードマップへ重複して蓄積しない。
- 分解結果、記述的比較、統計的関連、因果的主張を区別して記述する。
- 入力データ、取得方法、統計表ID、読み込み条件を変更した場合は、`reference/data_sources.md` を更新する。
- 指標、計算式、単位、列の意味を変更した場合は、`reference/metric_definitions.md` を更新する。
- 共通分析条件、比較期間、集計・分解・相関の方針を変更した場合は、`reference/methodology.md` を更新する。
- ページ、処理モジュール、テスト、分析文書の対応関係を変更した場合は、`reference/implementation_map.md` を更新する。
- リリースノートは既存履歴を上書きせず、変更履歴として追記する。
