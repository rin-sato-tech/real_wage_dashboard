# ドキュメント案内

このディレクトリには、Real Wage Dashboardの分析結果、分析計画、過去の開発仕様を収録しています。

アプリの機能、セットアップ、実行方法は[プロジェクトREADME](../README.md)を参照してください。

---

## 最初に読む文書

[実質賃金関連分析：全体像と結論](analysis/00_overview.md)は、本プロジェクトで実施した分析を統合した正本文書です。

次の内容を確認できます。

- 分析全体の問いと対象範囲
- 2015年平均から2025年平均までの主要結果
- 給与構成、労働投入、産業構成、労働需給、物価の関係
- 分析から言えること、言えないこと
- 残された分析課題

個別の数式、データ検証、詳細結果、実装・テスト情報は、各個別分析文書を参照してください。

## 文書の役割と優先順位

同じ内容が複数文書に現れる場合は、次の順序で参照します。

1. **個別分析の詳細値・方法**：対応する`analysis/01`から`analysis/06`
2. **分析全体の結論**：`analysis/00_overview.md`
3. **現在の機能・実行方法**：ルートの`README.md`
4. **将来の分析候補・優先順位**：`planning/wage_analysis_roadmap.md`
5. **過去バージョンの仕様・作業記録**：`history/v2_*.md`

個別分析文書は詳細な根拠、`00_overview.md`は複数分析を横断した結論を扱うため、両者は上下関係ではなく役割が異なります。数値の根拠を確認する場合は個別分析文書を優先し、分析全体の意味を確認する場合は概要文書を優先します。

## 更新ルール

- 新しい分析を追加した場合は、個別分析文書を`analysis/`へ追加する。
- 確定した主要結果が変わった場合は、個別分析文書と`analysis/00_overview.md`を更新する。
- ルートREADMEには要約だけを掲載し、詳細な数値・方法を重複させない。
- 将来の分析候補と実施状況は`planning/wage_analysis_roadmap.md`で管理する。
- リリースノートは既存履歴を上書きせず、変更履歴として追記する。
- 分解結果、記述的比較、統計的関連、因果的主張を区別して記述する。
- 入力データ、取得方法、統計表ID、読み込み条件を変更した場合は、`reference/data_sources.md`を更新する。
- 指標、計算式、単位、列の意味を変更した場合は、`reference/metric_definitions.md`を更新する。
