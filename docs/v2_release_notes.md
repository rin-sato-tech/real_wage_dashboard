# Real Wage Dashboard v2.0.0 Release Notes

## 概要

v2.0.0では、v1で固定していた賃金分析条件を選択可能にし、
名目賃金・実質賃金を複数条件から比較できるようにしました。

また、月次変動を把握しやすくするため、12か月移動平均を追加しました。

---

## 主な変更

### 賃金条件の選択

以下を選択可能にしました。

- 賃金項目
  - 現金給与総額
  - きまって支給する給与
- 就業形態
  - 就業形態計
  - 一般労働者
  - パートタイム労働者
- 事業所規模
  - 5人以上
  - 30人以上

産業分類は調査産業計に固定しています。

### 12か月移動平均

以下に12か月移動平均を追加しました。

- 名目賃金
- 実質賃金
- 実質賃金指数

移動平均は連続した12暦月が存在する場合のみ算出します。

実質賃金については、

```text
月次名目賃金
→ CPIで実質化
→ 月次実質賃金
→ 12か月移動平均
```

の順で計算します。

### 実質賃金分析

実質賃金ページでは以下を表示します。

- 名目賃金指数とCPIの比較
- 実質賃金指数（月次・12か月移動平均）
- 実質賃金前年同月比

名目賃金指数・実質賃金指数は、
それぞれ2020年平均=100としてアプリ内で算出します。

### CSV出力

CSVに画面で選択した分析条件を保存するようにしました。

名目賃金CSV：

- wage_item
- employment_type
- establishment_size

実質賃金CSV：

- wage_item
- employment_type
- establishment_size
- cpi_series

移動平均等の分析列も出力します。

### データ処理

- 元の賃金CSV読込と条件抽出処理を分離
- 元CSVのみStreamlitでキャッシュ
- CPI取得は既存のAPIキャッシュを継続
- CPIと賃金の結合をone-to-oneで検証
- 2020年の12か月分の基準データが不足する場合は指数化を停止

### テスト・品質

以下を確認済みです。

- 賃金条件の組み合わせ
- 12か月移動平均
- 欠損月処理
- 実質化と移動平均の計算順序
- 基準年データ検証
- one-to-one結合
- UI手動確認
- CSV出力
- v1相当条件の回帰確認

```bash

```

すべて通過しています。

## v1から維持した仕様

- CPI 4系列
- 産業分類：調査産業計
- 実質賃金額 = 名目賃金 ÷ CPI × 100
- 2020年平均=100による指数化
- e-Stat APIによるCPI取得

---

## 注意事項

実質賃金および実質賃金指数は本アプリ内で独自に算出しています。

公的機関が公表する公式の実質賃金指数とは、
使用する指数・算出条件・丸め処理等により一致しない場合があります。
