# 産業構成効果分析

作成日：2026-08-21
最終更新日：2026-08-23
分析ステータス：分析完了

---

## 1. 分析目的

### 1.1 問い

本分析では、以下を主な問いとする。

> 2015年から2025年にかけての平均賃金上昇は、**各産業の中で賃金が上昇した効果**と、**産業別の雇用シェアが変化した効果**にどの程度分けられるか。

具体的には、以下を確認する。

1. 2015年から2025年にかけて**産業別の雇用シェア**はどのように変化したか
2. 平均賃金上昇のうち、**産業内賃金上昇**による部分はどの程度か
3. **高賃金・低賃金産業の雇用シェア変化**は平均賃金を押し上げたか、押し下げたか
4. 賃金変化と雇用シェア変化が同時に起きた交差効果はどの程度か
5. どの産業が平均賃金変化に大きく寄与したか

### 1.2 分析上の位置付け

これまでの産業別賃金分析では、2015年平均から2025年平均にかけて、**主要16産業すべてで月額賃金と概算時間当たり賃金が上昇し、総実労働時間は減少した**ことを確認した。
一方で、産業ごとの賃金上昇率には大きな差が存在した。

そのため、全国平均賃金の変化について、

```text
全国平均賃金
├─ 各産業の中で賃金が変化した効果
└─ 各産業の雇用シェアが変化した効果
```

を分けて確認する必要がある。

本分析は、産業別賃金分析の第2段階として位置付ける。

## 2. この分析で説明すること

本分析では、以下を説明対象とする。

- 産業別雇用者数または常用労働者数
- 産業別雇用シェア
- 2015年から2025年までの雇用シェア変化
- 主要産業の加重平均賃金
- 産業内賃金効果
- 産業構成効果
- 交差効果
- 各産業の平均賃金変化への寄与
- 再構築した平均賃金と調査産業計との整合性

---

## 3. この分析だけでは説明しないこと

本分析は、平均賃金変化を構成要素へ機械的に分解するものであり、
因果関係そのものを示すものではない。

したがって、以下については本分析単独では判断しない。

- なぜ特定産業の雇用者数が増減したのか
- 労働者が実際に産業間を移動したのか
- 産業構成変化が因果的に賃金を変化させたのか
- 同一人物の転職によって平均賃金が変化したのか
- 産業内の年齢・性別・職種構成変化の影響
- 一般労働者・パートタイム労働者構成変化の影響
- 生産性、人手不足、企業収益等の影響

これらは別の分析テーマとして扱う。

## 4. 使用データ

### 4.1 賃金データ

厚生労働省「毎月勤労統計調査」

使用ファイル：`data/raw/hon-maikin-k-jissu.csv`

主に使用する系列：`きまって支給する給与`

基本条件：

| 項目         | 条件                    |
| ------------ | ----------------------- |
| 事業所規模   | 5人以上（T）            |
| 就業形態     | 就業形態計（0）         |
| 主比較期間   | 2015年平均 → 2025年平均 |
| 産業         | C～Rの主要16産業        |
| ベンチマーク | 調査産業計（TL）        |

### 4.2 雇用ウェイトデータ

雇用ウェイトには、毎月勤労統計調査に収録されている産業別労働者数を使用する。

月次の雇用ウェイトは、

$$N_{i,t,m}　=　\frac{前月末労働者数_{i,t,m}　+　本月末労働者数_{i,t,m}}{2}$$

と定義する。

年次雇用者数は、各年12か月の月次雇用ウェイトの平均とする。

賃金データと同じ毎月勤労統計を使用することで、

- 事業所規模：5人以上
- 就業形態：就業形態計
- 産業分類：C～R

を揃えて分析できる。

このため、当初候補としていた労働力調査の産業別雇用者数は使用しない。

### 4.3 雇用ウェイトデータ選定基準

以下の条件を優先する。

1. 2015年・2025年の両方が利用可能
2. 主要16産業に対応できる
3. 産業分類が賃金データと対応可能
4. 雇用者数の定義が明確
5. 年次比較が可能
6. 可能であれば毎月勤労統計と同一母集団

## 5. 分析前のデータ検証

### 5.1 雇用者数系列の確認

毎月勤労統計の元CSVには、以下の労働者数系列が収録されていることを確認した。

- 前月末労働者数
- 増加労働者数
- 減少労働者数
- 本月末労働者数
- パートタイム労働者数

本分析では、前月末労働者数と本月末労働者数の平均を月次雇用ウェイトとして使用する。

対象系列の「種別」は実数であり、指数ではない。

### 5.2 産業分類の対応

賃金データと雇用ウェイトの双方について、C～Rの主要16産業を同一の産業コードで取得できることを確認した。

TL（調査産業計）は構成比計算には含めず、再構築平均賃金との比較用ベンチマークとして使用する。

### 5.3 データ完全性

2015年・2025年について、主要16産業すべてで以下を確認した。

- 各年12か月のデータが存在
- 前月末労働者数の欠損なし
- 本月末労働者数の欠損なし
- 0以下の労働者数なし
- industry × date の重複なし

したがって、2015年から2025年の産業構成比較に必要なデータは完全に揃っている。

## 6. 基本指標

### 6.1 産業別平均賃金

産業 $i$、年 $t$ の平均賃金を$w_{i,t}$とする。

使用する賃金は、月額の「きまって支給する給与」の年平均とする。

### 6.2 産業別雇用者数

産業 $i$、年 $t$ の雇用者数を$N_{i,t}$とする。

### 6.3 産業別雇用シェア

主要16産業内の雇用シェアを、$s_{i,t}=\frac{N_{i,t}}{\Sigma_j N_{j,t}}$とする。

各年について、$\Sigma_i s_{i,t} = 1$となることを確認する。

---

## 7. 再構築平均賃金

主要16産業の賃金と雇用シェアから、$\hat W_t = \Sigma_i s_{i,t}w_{i,t}$を算出する。

これを本分析における「再構築平均賃金」とする。

### 7.1 調査産業計との比較

再構築平均賃金と、毎月勤労統計の調査産業計（TL）の平均賃金を比較する。

確認する項目：

- 2015年の差
- 2025年の差
- 水準差
- 変化率差

目的は、

> 主要16産業の加重平均によって調査産業計の賃金変化をどの程度再現できるか

を確認することである。

完全一致しない場合は、分解対象を「主要16産業の再構築平均賃金」と明示する。

---

## 8. 産業構成効果の分解

2015年を0、2025年を1とする。

再構築平均賃金の変化は、$\Delta \hat W = \hat W_1 - \hat W_0$である。

これを以下の3つに分解する。

### 8.1 産業内賃金効果

$$Within = \Sigma_i s_{i,0} (w_{i,1} - w_{i,0})$$

2015年の産業別雇用シェアを固定し、各産業の賃金のみが変化した場合の効果を表す。

### 8.2 産業構成効果

$$Composition = \Sigma_i w_{i,0} (s_{i,1} - s_{i,0})$$

2015年の産業別賃金を固定し、雇用シェアのみが変化した場合の効果を表す。

### 8.3 交差効果

$$Interaction = \Sigma_i (w_{i,1} - w_{i,0})(s_{i,1} - s_{i,0})$$

賃金変化と雇用シェア変化が同時に生じた部分を表す。

### 8.4 恒等関係

以下が成立することを確認する。

$$\Delta \hat W = Within+Composition+Interaction$$

数値誤差以外の残差が生じないことを検証する。

#### 産業別構成寄与の解釈

全体の産業構成効果は、$Composition = \Sigma_i w_{i,0}(s_{i,1}-s_{i,0})$で算出する。

一方、産業別に「その産業のシェア変化が平均賃金を押し上げたか、
押し下げたか」を解釈する際には、基準年の再構築平均賃金を用いて中心化する。

$$CenteredComposition_i = (w_{i,0}-\hat W_0)(s_{i,1}-s_{i,0})$$

雇用シェア変化の合計は0であるため、

$$\Sigma_i CenteredComposition_i = Composition$$

となり、全体の構成効果は変化しない。

この中心化により、

- 平均以上の賃金 × シェア上昇 → 平均賃金を押し上げる
- 平均未満の賃金 × シェア上昇 → 平均賃金を押し下げる
- 平均以上の賃金 × シェア低下 → 平均賃金を押し下げる
- 平均未満の賃金 × シェア低下 → 平均賃金を押し上げる

と解釈できる。

---

## 9. 産業別寄与

全体の分解だけでなく、産業ごとの寄与も算出する。

出力項目：

| 産業 | 産業内賃金効果 | 産業構成効果 | 交差効果 | 合計寄与 |
| ---- | -------------: | -----------: | -------: | -------: |
|      |                |              |          |          |

各産業について、

$$Contribution_i = Within_i + Composition_i + Interaction_i$$
​

とする。

## 10. 表示単位

### 10.1 主分析

主分析では「円」で表示する。

例：

```text
平均賃金変化 +30,000円
├─ 産業内賃金効果 +32,000円
├─ 産業構成効果 -3,000円
└─ 交差効果 +1,000円
```

### 10.2 補助指標

2015年の再構築平均賃金を分母として、各寄与を%ptに変換する。

$$Effect^{pt} = \frac{Effect}{\hat W_{2015}} \times 100$$

円表示を主とし、%ptは比較しやすさのための補助指標とする。

## 12. 時期別補助分析

2015→2025の結果だけでは、2020年の影響と長期的な構造変化が混在する可能性がある。

データが利用可能であれば、

```text
2015 → 2019
2019 → 2020
2020 → 2025
```

について同じ分解を行う。

目的：

- コロナ期の一時的な産業構成変化
- コロナ後の回復
- 長期的な産業構造変化

を区別する。

## 13. 分析結果

2015年・2025年とも主要16産業すべてについて12か月のデータが揃っており、欠損・重複は確認されなかった。

年次雇用者数は月次雇用ウェイトの12か月平均とした。

したがって、本分析のshift-share分解は、実質的に調査産業計の賃金変化を分解したものとして解釈できる。

### 13.5 産業内賃金効果

2015→2025の産業内賃金効果は、$+27,785.05 \text {円} (+10.663 \text {pt})$だった。

実際の平均賃金上昇率+10.298%を上回っており、
各産業内の賃金上昇だけでみれば、平均賃金を約10.66%押し上げる効果があった。

産業内賃金効果が最も大きかった産業は製造業（E）だった。

| 生活関連サービス等（N）   | +0.191pt |

主な押し下げ要因は以下だった。

| 産業                    | 構成寄与 |
| ----------------------- | -------: |
| 製造業（E）             | -0.304pt |

### 13.7 交差効果

2015→2025の交差効果は、$-395.85 \text {円} (-0.152 \text {pt})$だった。

産業内賃金効果と比較すると小さく、平均賃金変化の主要因ではなかった。

これらの産業では産業内賃金は上昇していたものの、雇用シェア低下による効果がそれを上回った。

### 13.9 時期別分解

2015→2025を3期間に分けて同じ分解を行った。

| 期間      | 平均賃金変化 | 産業内賃金効果 | 産業構成効果 | 交差効果 |
| --------- | -----------: | -------------: | -----------: | -------: |
| 2015→2019 |      +1.379% |       +1.953pt |     -0.502pt | -0.073pt |
| 2019→2020 |      -0.697% |       -0.695pt |     -0.006pt | +0.004pt |
| 2020→2025 |      +9.562% |       +9.251pt |     +0.288pt | +0.024pt |

2015→2019には産業構成変化が平均賃金を約0.50pt押し下げていた。

2019→2020の産業構成効果はほぼゼロであり、2020年の平均賃金低下は産業構成の変化ではなく、
主として各産業内の平均賃金低下によって生じていた。

2020→2025には産業構成効果が+0.29ptへ転じた。

したがって、2015→2025全体の産業構成効果が小幅なマイナスだったのは、産業構成がほとんど変わらなかったためではなく、
前半の押し下げ効果と後半の押し上げ効果が相殺されたためである。

## 14. 考察

### 14.1 平均賃金上昇の中心は産業内賃金上昇

2015→2025の平均賃金上昇率は約10.30%だった。

これに対して産業内賃金効果は+10.66ptであり、平均賃金上昇の大部分は各産業の中で賃金が上昇したことによって説明される。

産業構成効果は-0.21pt、交差効果は-0.15ptであり、産業構成の変化が平均賃金上昇を牽引したとはいえない。

---

### 14.2 産業構成変化は全体としてわずかに賃金を押し下げた

雇用構成そのものは大きく変化している。

医療・福祉やその他のサービス業の雇用シェアが上昇する一方、製造業、運輸業・郵便業、建設業などではシェアが低下した。

ただし、構成効果は各産業の賃金水準との組み合わせによって決まる。

例えば、医療・福祉は雇用シェア上昇幅が最大だったものの、2015年時点では全体平均より賃金水準が低かったため、
そのシェア上昇は平均賃金を押し下げる方向に作用した。

一方、情報通信業や学術研究等では、平均以上の賃金水準と雇用シェア上昇が組み合わさり、平均賃金を押し上げた。

---

### 14.3 産業の規模と賃金上昇の双方が総寄与を左右する

平均賃金変化への総寄与が最も大きかったのは医療・福祉だった。

これは産業構成効果そのものが大きくプラスだったことを意味するわけではない。

医療・福祉は雇用規模が大きく、産業内での賃金上昇もあったため、全体平均賃金上昇への総寄与が大きくなった。

したがって、

- 産業内賃金効果
- 産業構成効果
- 総寄与

は区別して解釈する必要がある。

---

### 14.4 2020年の賃金低下は産業構成変化では説明されない

2019→2020の平均賃金変化は-0.70%だったが、産業構成効果は-0.006ptにとどまった。

このため、2020年の平均賃金低下を、コロナ禍による産業別雇用構成の変化だけで説明することはできない。

主因は各産業内での平均賃金低下だった。

また、産業構成効果は、

- 2015→2019：マイナス
- 2019→2020：ほぼゼロ
- 2020→2025：プラス

と時期によって方向が異なった。

2015→2025全体の構成効果が小さいことは、産業構成の変化自体が小さかったことを意味しない。

## 16. 分析上の限界

### 16.1 雇用ウェイトの定義

本分析では、毎月勤労統計の前月末労働者数と本月末労働者数の平均を月次雇用ウェイトとして使用した。

したがって、賃金側と雇用ウェイト側で、

- 統計
- 事業所規模
- 就業形態
- 産業分類

を揃えている。

ただし、本分析の雇用ウェイトは毎月勤労統計の対象事業所に基づくものであり、日本の全就業者を直接表すものではない。

### 16.2 産業内構成変化

各産業の平均賃金には、

- 雇用形態
- 年齢
- 性別
- 職種
- 事業所規模

などの構成変化が含まれる。

したがって、産業内賃金効果を純粋な賃金率上昇と解釈しない。

### 16.3 産業間移動

雇用シェア変化は、必ずしも同一労働者が産業間を移動したことを意味しない。

新規就業、退職、人口構成変化なども含まれる。

### 16.4 因果関係

本分析はshift-share型の恒等的分解であり、
産業構成変化が賃金変化を因果的に生じさせたことを示すものではない。

### 16.5 分類・時系列接続

産業分類の変更や統計系列の接続性に注意する。

2015→2025について比較可能であることを事前に確認する。

## 18. 現時点での分析結果まとめ

主要16産業について、

```text
産業別賃金 × 産業別雇用シェア
↓
再構築平均賃金
↓
2015 → 2025 の変化 +10.30%
├─ 産業内賃金効果 +10.66pt
├─ 産業構成効果   -0.21pt
└─ 交差効果       -0.15pt
```

となった。

再構築平均賃金は調査産業計とほぼ完全に一致した。

したがって、2015→2025の平均賃金上昇は、主として各産業内の賃金上昇によって生じたと評価できる。

産業構成の変化は全体として平均賃金をわずかに押し下げたが、その効果は時期によって異なり、

2015→2019：押し下げ
2019→2020：ほぼ影響なし
2020→2025：押し上げ

となった。

次の段階では、この結果を過不足なく伝えるUI・可視化を実装する。
