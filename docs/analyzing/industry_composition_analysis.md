# 産業構成効果分析

作成日：2026-08-21
最終更新日：2026-08-21
分析ステータス：設計中

---

## 1. 分析目的

### 1.1 問い

本分析では、以下を主な問いとする。

> 2015年から2025年にかけての平均賃金上昇は、
> 各産業の中で賃金が上昇した効果と、産業別の雇用シェアが変化した効果にどの程度分けられるか。

具体的には、以下を確認する。

1. 2015年から2025年にかけて産業別の雇用シェアはどのように変化したか
2. 平均賃金上昇のうち、産業内賃金上昇による部分はどの程度か
3. 高賃金・低賃金産業の雇用シェア変化は平均賃金を押し上げたか、押し下げたか
4. 賃金変化と雇用シェア変化が同時に起きた交差効果はどの程度か
5. どの産業が平均賃金変化に大きく寄与したか

### 1.2 分析上の位置付け

これまでの産業別賃金分析では、2015年平均から2025年平均にかけて、
主要16産業すべてで月額賃金と概算時間当たり賃金が上昇し、総実労働時間は減少したことを確認した。
一方で、産業ごとの賃金上昇率には大きな差が存在した。

そのため、全国平均賃金の変化について、

```text
全国平均賃金
├─ 各産業の中で賃金が変化した効果
└─ 各産業の雇用シェアが変化した効果
```

を分けて確認する必要がある。

本分析は、産業別賃金分析の第2段階として位置付ける。

## 2. この分析で説明すること

本分析では、以下を説明対象とする。

- 産業別雇用者数または常用労働者数
- 産業別雇用シェア
- 2015年から2025年までの雇用シェア変化
- 主要産業の加重平均賃金
- 産業内賃金効果
- 産業構成効果
- 交差効果
- 各産業の平均賃金変化への寄与
- 再構築した平均賃金と調査産業計との整合性

---

## 3. この分析だけでは説明しないこと

本分析は、平均賃金変化を構成要素へ機械的に分解するものであり、
因果関係そのものを示すものではない。

したがって、以下については本分析単独では判断しない。

- なぜ特定産業の雇用者数が増減したのか
- 労働者が実際に産業間を移動したのか
- 産業構成変化が因果的に賃金を変化させたのか
- 同一人物の転職によって平均賃金が変化したのか
- 産業内の年齢・性別・職種構成変化の影響
- 一般労働者・パートタイム労働者構成変化の影響
- 生産性、人手不足、企業収益等の影響

これらは別の分析テーマとして扱う。

## 4. 使用データ

### 4.1 賃金データ

厚生労働省「毎月勤労統計調査」

使用ファイル：`data/raw/hon-maikin-k-jissu.csv`

主に使用する系列：`きまって支給する給与`

基本条件：

| 項目         | 条件                    |
| ------------ | ----------------------- |
| 事業所規模   | 5人以上（T）            |
| 就業形態     | 就業形態計（0）         |
| 主比較期間   | 2015年平均 → 2025年平均 |
| 産業         | C～Rの主要16産業        |
| ベンチマーク | 調査産業計（TL）        |

### 4.2 雇用ウェイトデータ

第一候補として、
毎月勤労統計調査の産業別常用労働者数を使用できるか確認する。

同一統計内で、

```text
産業別賃金 + 産業別常用労働者数
```

を組み合わせられる場合、母集団・産業分類の整合性が比較的高いため優先する。

利用困難な場合は、労働力調査の産業別雇用者数を候補とする。

### 4.3 雇用ウェイトデータ選定基準

以下の条件を優先する。

1. 2015年・2025年の両方が利用可能
2. 主要16産業に対応できる
3. 産業分類が賃金データと対応可能
4. 雇用者数の定義が明確
5. 年次比較が可能
6. 可能であれば毎月勤労統計と同一母集団

|      |                |                |      |          |

確認項目：

- 欠損
- 重複
- 0または負値
- 産業コード不一致
- 2015年・2025年の完全性

## 6. 基本指標

### 6.1 産業別平均賃金

産業 $i$、年 $t$ の平均賃金を$w_{i,t}$とする。

使用する賃金は、月額の「きまって支給する給与」の年平均とする。

### 6.2 産業別雇用者数

産業 $i$、年 $t$ の雇用者数を$N_{i,t}$とする。

### 6.3 産業別雇用シェア

主要16産業内の雇用シェアを、$s_{i,t}=\frac{N_{i,t}}{\Sigma_j N_{j,t}}$とする。

各年について、$\Sigma_i s_{i,t} = 1$となることを確認する。

---

## 7. 再構築平均賃金

主要16産業の賃金と雇用シェアから、$\hat W_t = \Sigma_i s_{i,t}w_{i,t}$を算出する。

これを本分析における「再構築平均賃金」とする。

### 7.1 調査産業計との比較

再構築平均賃金と、毎月勤労統計の調査産業計（TL）の平均賃金を比較する。

確認する項目：

- 2015年の差
- 2025年の差
- 水準差
- 変化率差

目的は、

> 主要16産業の加重平均によって調査産業計の賃金変化をどの程度再現できるか

を確認することである。

完全一致しない場合は、分解対象を「主要16産業の再構築平均賃金」と明示する。

---

## 8. 産業構成効果の分解

2015年を0、2025年を1とする。

再構築平均賃金の変化は、$\Delta \hat W = \hat W_1 - \hat W_0$である。

これを以下の3つに分解する。

### 8.1 産業内賃金効果

$$Within = \Sigma_i s_{i,0} (w_{i,1} - w_{i,0})$$

2015年の産業別雇用シェアを固定し、各産業の賃金のみが変化した場合の効果を表す。

### 8.2 産業構成効果

$$Composition = \Sigma_i w_{i,0} (s_{i,1} - s_{i,0})$$

2015年の産業別賃金を固定し、雇用シェアのみが変化した場合の効果を表す。

### 8.3 交差効果

$$Interaction = \Sigma_i (w_{i,1} - w_{i,0})(s_{i,1} - s_{i,0})$$

賃金変化と雇用シェア変化が同時に生じた部分を表す。

### 8.4 恒等関係

以下が成立することを確認する。

$$\Delta \hat W = Within+Composition+Interaction$$

数値誤差以外の残差が生じないことを検証する。

---

## 9. 産業別寄与

全体の分解だけでなく、産業ごとの寄与も算出する。

出力項目：

| 産業 | 産業内賃金効果 | 産業構成効果 | 交差効果 | 合計寄与 |
| ---- | -------------: | -----------: | -------: | -------: |
|      |                |              |          |          |

各産業について、

$$Contribution_i = Within_i + Composition_i + Interaction_i$$
​

とする。

## 10. 表示単位

### 10.1 主分析

主分析では「円」で表示する。

例：

```text
平均賃金変化 +30,000円
├─ 産業内賃金効果 +32,000円
├─ 産業構成効果 -3,000円
└─ 交差効果 +1,000円
```

### 10.2 補助指標

2015年の再構築平均賃金を分母として、各寄与を%ptに変換する。

$$Effect^{pt} = \frac{Effect}{\hat W_{2015}} \times 100$$

円表示を主とし、%ptは比較しやすさのための補助指標とする。

## 16. 分析上の限界

### 16.1 雇用ウェイトの定義

毎月勤労統計の常用労働者数を使用できない場合、労働力調査等の別統計を使用する可能性がある。

その場合、

- 母集団
- 雇用者の定義
- 産業分類

が完全には一致しない可能性がある。

### 16.2 産業内構成変化

各産業の平均賃金には、

- 雇用形態
- 年齢
- 性別
- 職種
- 事業所規模

などの構成変化が含まれる。

したがって、産業内賃金効果を純粋な賃金率上昇と解釈しない。

### 16.3 産業間移動

雇用シェア変化は、必ずしも同一労働者が産業間を移動したことを意味しない。

新規就業、退職、人口構成変化なども含まれる。

### 16.4 因果関係

本分析はshift-share型の恒等的分解であり、
産業構成変化が賃金変化を因果的に生じさせたことを示すものではない。

### 16.5 分類・時系列接続

産業分類の変更や統計系列の接続性に注意する。

2015→2025について比較可能であることを事前に確認する。

## 18. 現時点での分析方針まとめ

本分析では、

```text
主要16産業
↓
産業別賃金 × 産業別雇用シェア
↓
再構築平均賃金
↓
2015 → 2025 の変化
├─ 産業内賃金効果
├─ 産業構成効果
└─ 交差効果
```

という順序で分析する。

主分析は複雑な回帰分析ではなく、加重平均の恒等関係に基づくshift-share型の分解とする。

最初に雇用ウェイトとして利用可能なデータを確認し、賃金側と定義・産業分類を揃えられるかを検証したうえで、
具体的な実装に進む。
