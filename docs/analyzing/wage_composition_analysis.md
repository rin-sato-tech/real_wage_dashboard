## 1. 分析目的

### 1.1 問い

現金給与総額の変動は、所定内給与・所定外給与・特別給与のどの要素によって生じたのか。

特に、近年の名目賃金上昇について、

- **所定内給与**の持続的な上昇によるものか
- **所定外給与**の増加によるものか
- 賞与等の**特別給与**による一時的な変動なのか

を区別する。

### 1.2 この分析で説明すること

- 現金給与総額の変化額
- 各給与項目の変化額
- 現金給与総額の前年比に対する各給与項目の寄与度
- 給与構成の長期的変化
- 時期による寄与構造の違い

### 1.3 この分析だけでは説明しないこと

この分析は給与項目間の**恒等的・機械的な分解**を目的とする。

したがって、以下の因果関係そのものは本分析からは判断しない。

- なぜ所定内給与が上昇したのか
- なぜ賞与が増減したのか
- 人手不足が賃金を押し上げたのか
- 春闘が実際の賃金をどの程度押し上げたのか
- 生産性や企業収益が賃金に与えた影響

これらは別の分析テーマで検証する。

## 4. 給与項目間の整合性確認

給与構成について、以下の3つの関係を1990年1月から2026年5月までの437か月について検証した。

```text
現金給与総額 = きまって支給する給与 + 特別給与
きまって支給する給与 = 所定内給与 + 所定外給与
```

したがって、

```text
現金給与総額 = 所定内給与 + 所定外給与 + 特別給与
```

と表せる。

### 4.1 検算方法

月 $(t)$ の残差を、$`e_t = Total_t-(In_t+Out_t+Bonus_t)`$とする。

- $Total_t$：現金給与総額
- $In_t$：所定内給与
- $Out_t$：所定外給与
- $Bonus_t$：特別給与

確認する指標：

- 残差の最大絶対値
- 残差の平均絶対値
- 完全一致した月数
- 全観測数

### 4.2 検証結果

| 検証式                                            | 観測数 | 完全一致 | 誤差発生 | 最大絶対誤差 | 平均絶対誤差 |
| ------------------------------------------------- | -----: | -------: | -------: | -----------: | -----------: |
| 現金給与総額 = きまって支給する給与 + 特別給与    |    437 |      437 |        0 |          0円 |          0円 |
| きまって支給する給与 = 所定内給与 + 所定外給与    |    437 |      437 |        0 |          0円 |          0円 |
| 現金給与総額 = 所定内給与 + 所定外給与 + 特別給与 |    437 |      437 |        0 |          0円 |          0円 |

### 4.3 判断

対象となる437か月すべてについて3つの関係が完全一致し、最大絶対誤差・平均絶対誤差ともに0円であった。

したがって、本分析では、

```text
現金給与総額 = 所定内給与 + 所定外給与 + 特別給与
```

を恒等式として採用し、残差項を設けずに現金給与総額の変動を3要素へ完全に分解する。

## 5. 分析方法

### 5.1 前年差

各系列 $(X)$ について、$`\Delta X_t=X_t-X_{t-12}`$を計算する。

現金給与総額について、$`\Delta Total_t =\Delta In_t + \Delta Out_t + \Delta Bonus_t`$として前年差を分解する。

### 5.2 前年比

各系列について、$`YoY_t = \frac{X_t-X_{t-12}}{X_{t-12}} \times100`$を計算する。

これは各給与項目自身が前年から何％変化したかを表す。

### 5.3 現金給与総額前年比への寄与度

現金給与総額の前年比を、$`g_t = \frac{Total_t-Total_{t-12}}{Total_{t-12}}\times100`$とする。

| 項目               | 寄与度式                                                                  |
| ------------------ | ------------------------------------------------------------------------- |
| 所定内給与の寄与度 | $`Cont^{In}_t=\frac{{In}_t-{In}_{t-12}}{Total_{t-12}}\times100`$          |
| 所定外給与の寄与度 | $`Cont^{Out}_t=\frac{{Out}_t-{Out}_{t-12}}{Total_{t-12}}\times100`$       |
| 特別給与の寄与度   | $`Cont^{Bonus}_t=\frac{{Bonus}_t-{Bonus}_{t-12}}{Total_{t-12}}\times100`$ |

恒等式が成立する場合、$`g_t=Cont^{In}_t+Cont^{Out}_t+Cont^{Bonus}_t`$となる。

単位は **%ポイント（pt）** とする。

### 5.4 給与構成比

$`S^{In}_t=\frac{In_t}{Total_t}\times100`$

$`S^{Out}_t=\frac{Out_t}{Total_t}\times100`$

$`S^{Bonus}_t=\frac{Bonus_t}{Total_t}\times100`$

月次では賞与月による変動が大きいため、主として年平均または年間集計値で評価する。

### 5.5 12か月移動平均

給与の基調を確認するため、$`MA12_t=\frac{1}{12}\sum_{j=0}^{11}X_{t-j}`$を計算する。

連続した12暦月が存在する場合のみ算出する。

### 5.6 長期比較

基本比較期間：

- 2015年
- 2025年

各年の12か月平均を使用する。

現金給与総額の長期変化：$`\Delta\bar{T}=\bar{T}_{2025}-\bar{T}_{2015}`$

所定内給与の寄与度：$`Cont^{In}_{2015\rightarrow2025}=\frac{\bar{In}_{2025}-\bar{In}_{2015}}{\bar{Total}_{2015}}\times100`$

所定外給与・特別給与についても同様に計算する。

## 6. 分析結果

### 6.1 現金給与総額と給与構成の長期推移

#### 結果

**現金給与総額**は長期的には緩やかな増加傾向を示しているが、その構成要因は時期によって異なる。

- **所定内給与**は現金給与総額の大部分を占める主要項目であり、近年はその水準が上昇している。

- 一方、**所定外給与**は長期的な変化が比較的小さく、現金給与総額の変動への寄与も限定的である。

- **特別給与**は賞与等を含むため月ごとの変動が大きく、現金給与総額の短期的な上下を大きく左右する月がある。

2026年5月時点の12か月移動平均は以下のとおりである。

| 項目         | 12か月移動平均 |
| ------------ | -------------: |
| 現金給与総額 |      359,595円 |
| 所定内給与   |      271,047円 |
| 所定外給与   |       20,172円 |
| 特別給与     |       68,377円 |

#### 確認された特徴

- 現金給与総額の長期的な上昇では、所定内給与の増加が主要な要因となっている。
- 所定外給与は長期的にはほぼ横ばいであり、総額の上昇への寄与は小さい。
- 特別給与は季節性と月ごとの変動が大きいため、単月ではなく年平均や12か月移動平均を併用して評価する必要がある。

- 所定外給与
- 特別給与

の月次推移および12か月移動平均を表示し、給与総額の基調と構成要素の違いを確認できるようにする。

### 6.3 現金給与総額の前年差分解

対象年月：2026-05

| 項目         |   前年差 |
| ------------ | -------: |
| 現金給与総額 | +9,856円 |
| 所定内給与   | +8,241円 |
| 所定外給与   |   +549円 |
| 特別給与     | +1,066円 |

検算：

$8,241+549+1,066=9,856円$

したがって、

$\Delta Total=\Delta In+\Delta Out+\Delta Bonus=9,856円$

となり、現金給与総額の前年差と3要素の前年差合計は完全に一致する。

#### 結果

2026年5月の現金給与総額は、前年同月から9,856円増加した。

このうち、

- 所定内給与：+8,241円
- 所定外給与：+549円
- 特別給与：+1,066円

であり、増加額の大部分を所定内給与が占めた。

所定内給与は現金給与総額の増加額9,856円のうち約83.6%を占めている。

したがって、2026年5月の現金給与総額上昇は、金額ベースでも所定内給与の増加が中心だった。

### 7.1 年平均

| 項目         |    2015年 |    2025年 |      差額 |  変化率 |

### 7.2 現金給与総額の変化への寄与

| 項目       |    寄与額 |    寄与度 |
| ---------- | --------: | --------: |
| 所定内給与 | +26,697円 |  +8.46 pt |
| 所定外給与 |    +137円 |  +0.04 pt |
| 特別給与   | +13,298円 |  +4.22 pt |
| 合計       | +40,131円 | +12.72 pt |

3要素の寄与度合計と現金給与総額の変化率との差は
約 $3.6 \times 10^{-15}\text{pt}$ であり、浮動小数点誤差の範囲である。

### 7.3 結果

2015年から2025年にかけて、現金給与総額の年平均は
315,505円から355,636円へ**40,131円（12.72%）増加**した。

この増加に対する寄与は、所定内給与が+8.46ptと最大であり、
特別給与が+4.22pt、所定外給与が+0.04ptであった。

したがって、**この10年間の現金給与総額の上昇は主として
所定内給与の増加によって構成されていた**。

一方、**特別給与**自体は24.21%増加しており、現金給与総額に占める構成比も17.41%から19.18%へ上昇した。
そのため、給与構成そのものが所定内給与中心へ変化したとはいえない。

**所定外給与**は10年間で0.69%しか増加しておらず、現金給与総額の長期上昇への寄与はほぼなかった。

### 7.4 解釈

2015年から2025年までの現金給与総額の上昇は、一時的な賞与増加だけで説明されるものではなく、**所定内給与の増加が最大の構成要因**だった。

一方、特別給与の伸び率は所定内給与を上回っており、給与総額に占める特別給与の比率も上昇している。

したがって、

- 長期的な給与総額上昇の最大要因は所定内給与である
- しかし給与構成そのものが所定内給与へ一方向にシフトしたわけではない

という2点を区別する必要がある。

給与総額の変動構造は時期によって異なる。

コロナ期の給与総額減少は所定内給与の低下ではなく、
主として所定外給与と特別給与の減少によって構成されていた。

その後、2022年以降は所定内給与が主要な上昇要因となり、特に2024年にはその寄与が大きく拡大した。

したがって、近年の現金給与総額上昇は残業等の所定外給与増加によるものではなく、
主として所定内給与の上昇と特別給与の増加によって構成されている。

ただし、本分析は各給与項目の寄与を分解したものであり、所定内給与が上昇した原因そのものを示すものではない。

## 10. 分析から分かったこと

### 10.1 主な結果

1. **2015～2025年の現金給与総額上昇の最大要因は所定内給与だった。**
   現金給与総額は12.72%増加し、そのうち所定内給与が+8.46pt、特別給与が+4.22pt寄与した。

2. **所定外給与の長期的寄与は極めて小さい。**
   2015～2025年の所定外給与増加率は0.69%にとどまり、現金給与総額への寄与は+0.04ptだった。

3. **2020年の給与総額低下は所定内給与の低下によるものではなかった。**
   所定内給与はプラス寄与を保った一方、所定外給与と特別給与が大きくマイナス寄与した。

4. **2022年以降、特に2024年から所定内給与の寄与が大きくなった。**

5. **直近2026年にも所定内給与中心の上昇構造が続いている。**
   2026年1～5月の所定内給与寄与は、おおむね+2.6～+3.0ptで推移している。

### 10.2 問いへの暫定回答

**現金給与総額の変動は、所定内給与・所定外給与・特別給与のどの要素によって生じたのか。**

2015年以降の長期的な現金給与総額の上昇は、主として所定内給与の増加によって構成されていた。

特別給与も無視できない寄与を持ち、特に特定の年・月では給与総額の変動を大きく左右している。

一方、所定外給与の長期的な寄与は小さい。

また、寄与構造は時期によって異なる。2020年の給与総額低下は所定外給与と特別給与の減少によって生じた一方、2022年以降は所定内給与が主要な上昇要因となり、特に2024年以降その寄与が大きくなっている。

## 11. 分析から分からないこと

本分析では給与総額の変化を構成項目に分解できるが、それぞれの給与項目が変化した原因までは特定できない。

特に、

- 所定内給与上昇の原因
- 所定外給与変化の原因
- 賞与変化の原因
- 労働需給の影響
- 春闘の影響
- 最低賃金の影響
- 生産性の影響
- 企業収益・労働分配率の影響

については別途検証が必要である。

## 12. 限界・注意点

### 12.1 恒等式と因果関係

寄与度分解によって、

> 「どの給与項目の変化が現金給与総額の変化を構成していたか」

は説明できる。

一方で、

> 「なぜその給与項目が変化したのか」

について因果的な説明はできない。

### 12.2 特別給与の季節性

特別給与は賞与月に集中するため、月次値・月次前年比の変動が大きい。

長期的な給与構造を評価する場合は年平均・12か月移動平均も併用する。

### 12.3 毎月勤労統計の平均値

本分析は集計された平均賃金を分析している。

個人の賃金分布や、同一人物の賃金変化を表すものではない。

### 12.4 その他

主分析では就業形態計を使用している。

そのため、一般労働者とパートタイム労働者の賃金水準や給与構成の違い、および両者の構成比変化が平均値に与える影響を分離していない。

必要に応じて雇用形態別分析を追加する。

## 13. 統計的処理について

本分析の主要な問いは給与構成の恒等的分解で回答できるため、回帰分析・仮説検定は主分析として使用しない。

使用する処理：

- 前年差
- 前年比
- 寄与度
- 構成比
- 年平均
- 12か月移動平均
- 期間別比較

必要性が生じた場合のみ、補助的な記述統計を追加する。

## 17. 最終結論

現金給与総額の変動を所定内給与・所定外給与・特別給与に分解した結果、2015年から2025年の**現金給与総額は12.72%増加**し、
そのうち**所定内給与が+8.46ptと最大の寄与**を示した。特別給与は+4.22pt、所定外給与は+0.04ptであった。

したがって、この10年間の現金給与総額上昇は、**主として所定内給与の増加**によって構成されていた。
一方、特別給与の増加も無視できず、給与構成そのものが所定内給与中心へ一方向に変化したとはいえない。

また、寄与構造は時期によって異なる。
2020年の給与総額低下は主として所定外給与と特別給与の減少によって構成され、2022年以降は所定内給与が主要なプラス寄与となった。特に2024年は所定内給与と特別給与の寄与が大きかった。

本分析によって「何が給与総額の変化を構成したか」は定量的に説明できたが、所定内給与がなぜ上昇したのかまでは説明できない。
労働需給、春闘、最低賃金、生産性、企業収益等との関係は、別の分析テーマとして検証する必要がある。
