作成日：2026-08-20

## 1. 分析目的

### 1.1 問い

月額の賃金変化は、**時間当たり賃金**と**労働時間**のどちらによって生じたのか。

さらに、労働時間の変化について、

- 所定内労働時間
- 所定外労働時間
- 出勤日数
- 1出勤日当たり所定内労働時間

のどの要素によって生じたのかを分解する。

分析全体を以下の3段階で捉える。

```text
月額のきまって支給する給与
├─ 概算時間当たり賃金
└─ 総実労働時間
   ├─ 所定内労働時間
   │  ├─ 出勤日数
   │  └─ 1出勤日当たり所定内労働時間
   └─ 所定外労働時間
```

### 1.2 この分析で説明すること

- 月額賃金の変化と時間当たり賃金の変化の違い
- 労働時間変化が月額賃金に与えた機械的な寄与
- 総実労働時間の変化に対する所定内・所定外労働時間の寄与
- 所定内労働時間の変化が、出勤日数と1出勤日当たり労働時間のどちらから生じたか
- コロナ期など特殊局面と長期的な変化の違い

### 1.3 この分析だけでは説明しないこと

本分析は、労働投入量と賃金の関係を**恒等的・機械的に分解すること**を目的とする。

したがって、以下の因果関係そのものは本分析からは判断しない。

- なぜ労働時間が短縮したのか
- 働き方改革が労働時間をどの程度短縮したのか
- 有給休暇取得増加が出勤日数に与えた影響
- 景気変動が所定外労働時間に与えた因果効果
- 人手不足が労働時間や賃金に与えた影響
- 生産性向上によって労働時間が減少したのか

これらは別の分析テーマとして検証する。

## 4. 労働時間系列の整合性確認

### 4.1 検証する関係

以下の関係を1990年1月～2026年5月の437か月について検証した。

$Hour^{Total}_t=Hour^{In}_t + Hour^{Out}_t$

すなわち、

```text
総実労働時間 = 所定内労働時間 + 所定外労働時間
```

### 4.2 検算方法

月 $(t)$ の残差を、$e_t = Hour^{Total}_t -(Hour^{In}_t + Hour^{Out}_t)$とする。

浮動小数点演算による丸め誤差を考慮し、絶対誤差 $1×10^{−10}$以内を一致と判定する。

確認する指標：

- 最大絶対誤差
- 平均絶対誤差
- 完全一致した月数
- 全観測数

### 4.3 検証結果

| 観測数 | 許容誤差内で一致 | 不一致 |        最大絶対誤差 |        平均絶対誤差 |
| -----: | ---------------: | -----: | ------------------: | ------------------: |
|    437 |              437 |      0 | $2.31×10^{-14}$時間 | $9.36×10^{-15}$時間 |

### 4.4 判断

437か月すべてについて、

```text
総実労働時間 = 所定内労働時間 + 所定外労働時間
```

が数値的に成立した。

観測された最大絶対誤差は約 $2.31×10^{−14}$時間であり、Pythonの浮動小数点演算に由来する丸め誤差と判断できる。

したがって、本分析では、

```text
総実労働時間 = 所定内労働時間 + 所定外労働時間
```

を恒等式として採用し、残差項を設けずに完全な加法分解を行う。

## 5. 分析方法

### 5.1 第1段階：月額賃金の分解

概算時間当たり賃金を、$Wage^{hr}_t =\frac{Wage_t}{Hour^{Total}_t}$と定義する。

したがって、$Wage_t = Wage^{hr}_t \times Hour^{Total}_t$が成り立つ。

#### 対数変化による分解

$\Delta \ln Wage = \Delta \ln Wage^{hr} + \Delta \ln Hour^{Total}$

として、

- 時間当たり賃金の寄与
- 総実労働時間の寄与

に分解する。

#### 分析する指標

- 月額賃金前年比
- 概算時間当たり賃金前年比
- 総実労働時間前年比
- 対数変化による寄与
- 2015年平均→2025年平均の長期変化

---

### 5.2 第2段階：総実労働時間の分解

$Hour^{Total}_t = Hour^{In}_t + Hour^{Out}_t$を用いる。

#### 前年差

$\Delta Hour^{Total}_t = \Delta Hour^{In}_t + \Delta Hour^{Out}_t$

#### 総実労働時間変化への寄与

総実労働時間の前年差に対して、

- 所定内労働時間
- 所定外労働時間

がどの程度寄与したかを確認する。

必要に応じて、前年差だけでなく前年水準を分母とした寄与度も算出する。

---

### 5.3 第3段階：所定内労働時間の分解

1出勤日当たり所定内労働時間を、

$HoursPerDay_t = \frac{Hour^{scheduled}_t}{Days^{Worked}_t}$

と定義する。

したがって、

$Hour^{scheduled}_t = HoursPerDay_t \times Days^{Worked}_t$

となる。

#### 対数変化による分解

$\Delta \ln Hour^{scheduled} = \Delta \ln HoursPerDay_t + \Delta \ln Days^{Worked}_t$

として、

- 出勤日数の寄与
- 1出勤日当たり所定内労働時間の寄与

に分解する。

---

### 5.4 前年比

各系列 (X) について、$YoY_t = \frac{X_t-X_{t-12}}{X_{t-12}} \times100$を計算する。

対象：

- きまって支給する給与
- 概算時間当たり賃金
- 総実労働時間
- 所定内労働時間
- 所定外労働時間
- 出勤日数
- 1出勤日当たり所定内労働時間

---

### 5.5 12か月移動平均

必要に応じて、$MA12_t = \frac{1}{12}\sum_{j=0}^{11}X_{t-j}$を計算する。

連続した12暦月が存在する場合のみ算出する。

主として長期的な方向性を確認するために使用する。

---

### 5.6 長期比較

基本比較期間：

- 2015年
- 2025年

各年の12か月平均を使用する。

#### 第1段階

```text
月額賃金
├─ 時間当たり賃金
└─ 総実労働時間
```

#### 第2段階

```text
総実労働時間
├─ 所定内労働時間
└─ 所定外労働時間
```

#### 第3段階

```text
所定内労働時間
├─ 出勤日数
└─ 1出勤日当たり所定内労働時間
```

についてそれぞれ2015年平均と2025年平均を比較する。

## 6. 分析結果

### 6.1 月額賃金は「単価」と「労働時間」のどちらで変化したか

#### 結果

2015年から2025年にかけて、月額の**きまって支給する給与**は260,575円から287,408円へ増加し、変化率は+10.30%であった。

一方、年間の賃金総額を年間の総実労働時間で除して算出した**年間加重概算時間当たり賃金**は、1,804.12円/時間から2,128.03円/時間へ上昇し、変化率は+17.95%であった。

**総実労働時間**は144.43時間から135.06時間へ減少し、変化率は-6.49%であった。

対数変化による要因分解では、

- 月額賃金の対数変化：+9.80
- 時間当たり賃金の寄与：+16.51
- 総実労働時間の寄与：-6.71

となった。

したがって、2015年から2025年にかけては、**時間当たり賃金の上昇が月額賃金を押し上げた一方、
総実労働時間の減少がその上昇を一部相殺**していた。

#### 分析上の注意

年次の概算時間当たり賃金は、月次の概算時間当たり賃金を単純平均するのではなく、

```text
年間のきまって支給する給与の合計 ÷ 年間の総実労働時間の合計
```

として算出した。

これにより、

```text
年平均月額賃金 = 年間加重概算時間当たり賃金 × 年平均総実労働時間
```

が数値的に成立し、長期変化を完全に分解できる。

### 6.2 総実労働時間はなぜ変化したか

#### 結果

2015年から2025年にかけて、**総実労働時間は144.43時間から135.06時間へ減少**し、
前年差では-9.38時間、変化率では-6.49%となった。

その内訳は、

- 所定内労働時間：133.45時間 → 125.25時間（-8.20時間）
- 所定外労働時間：10.98時間 → 9.81時間（-1.18時間）

であった。

2015年の総実労働時間を基準とした寄与度は、

- 所定内労働時間：-5.68pt
- 所定外労働時間：-0.81pt

となった。

両者の合計は総実労働時間の変化率-6.49%と一致する。

#### 2015年平均と2025年平均

| 指標           | 2015年 | 2025年 | 変化 |
| -------------- | -----: | -----: | ---: |
| 総実労働時間   |        |        |      |
| 所定内労働時間 |        |        |      |
| 所定外労働時間 |        |        |      |

#### 解釈

2015年から2025年にかけた総実労働時間の減少は、**主として所定内労働時間の減少**によって生じている。

総実労働時間の減少幅9.38時間のうち、所定内労働時間の減少は8.20時間であり、減少幅の約87%を占める。

一方、所定外労働時間も減少しているものの、長期的な総実労働時間減少への寄与は比較的小さい。

したがって、この期間の労働時間短縮を「残業時間の減少」だけで説明することはできず、
通常の勤務時間に相当する所定内労働時間の減少がより大きな要因となっている。

### 6.3 所定内労働時間は「日数」と「1日当たり時間」のどちらで変化したか

#### 結果

2015年から2025年にかけて、**所定内労働時間は133.45時間から125.25時間へ減少**し、変化率は-6.14%であった。

同期間に、

- 出勤日数：18.675日 → 17.45日（-6.56%）
- 1出勤日当たり所定内労働時間：7.146時間 → 7.178時間（+0.44%）

となった。

対数変化による要因分解では、

- 所定内労働時間の対数変化：-6.34
- 出勤日数の寄与：-6.78
- 1出勤日当たり所定内労働時間の寄与：+0.44

となり、両寄与の合計は所定内労働時間の変化と一致した。


#### 2015年平均と2025年平均

| 指標                        | 2015年 | 2025年 | 変化率 |
| --------------------------- | -----: | -----: | -----: |
| 所定内労働時間              |        |        |        |
| 出勤日数                    |        |        |        |
| 1出勤日当たり所定内労働時間 |        |        |        |

#### 対数変化による寄与

| 要因                        | 寄与 |
| --------------------------- | ---: |
| 出勤日数                    |      |
| 1出勤日当たり所定内労働時間 |      |
| 所定内労働時間              |      |

#### 解釈

2015年から2025年にかけた所定内労働時間の減少は、主として出勤日数の減少によって生じている。

一方、1出勤日当たり所定内労働時間はわずかに増加しており、所定内労働時間の減少を説明する要因ではなかった。

したがって、この期間の所定内労働時間短縮は、「1日に働く時間が短くなった」というより、
「月間の平均出勤日数が減少した」ことによる影響が大きい。

ただし、毎月勤労統計の出勤日数は実際に出勤した日数であり、有給休暇取得などの影響も受けるため、
出勤日数減少の制度的・行動的な原因までは本分析だけでは特定できない。

### 6.4 時系列で見た寄与構造

以下の局面を中心に確認する。

#### 2015～2019年

コロナ前から、**概算時間当たり賃金の上昇と総実労働時間の減少**が同時に進む局面が確認された。

2016～2018年には時間当たり賃金の上昇が月額賃金を押し上げた一方、総実労働時間の減少がその一部を相殺した。

2019年には、時間当たり賃金の対数寄与が+2.07であった一方、総実労働時間の寄与は-2.22となり、両者がおおむね相殺した。その結果、月額賃金の対数変化は-0.15となった。

したがって、労働時間減少による月額賃金の押下げは2020年だけに生じた特殊な現象ではなく、コロナ前から確認できる。

#### 2020年

2020年は、

- 時間当たり賃金寄与：+2.15
- 総実労働時間寄与：-2.85
- 月額賃金の対数変化：-0.70

となった。

時間当たり賃金は上昇したものの、それを上回る労働時間減少によって、月額賃金は前年を下回った。

コロナ前から存在した労働時間減少の傾向に加え、2020年には労働時間のマイナス寄与がさらに大きくなった。

#### 2021～2022年

2021年には総実労働時間の寄与が+0.69となり、前年の大幅な減少から反動回復した。

一方、時間当たり賃金の寄与は-0.15と小幅なマイナスであり、月額賃金の増加は主として労働時間の回復によるものであった。

2022年には、

- 時間当たり賃金寄与：+1.33
- 総実労働時間寄与：+0.07

となり、月額賃金上昇の中心は再び時間当たり賃金へ移った。

#### 2023年以降

2023年は時間当たり賃金の上昇が月額賃金上昇の主要因となった。

2024年には時間当たり賃金の寄与が+3.78まで拡大し、総実労働時間も+0.46の寄与となったため、
月額賃金は+4.34%と大きく上昇した。

2025年にも時間当たり賃金の寄与は+3.31と高水準を維持したが、総実労働時間の寄与が-1.38となった。
そのため、月額賃金の伸びは+1.94%に抑えられた。

近年は時間当たり賃金の上昇が明確になっている一方、
労働時間の変化によって月額賃金への反映度合いが年によって大きく異なることが確認できる。

## 7. 雇用形態別補助分析

就業形態計で確認された出勤日数減少が、一般労働者とパートタイム労働者の構成比変化だけによるものかを確認するため、
2015年平均と2025年平均を雇用形態別に比較した。

### 一般労働者

- 総実労働時間：-4.80%
- 所定内労働時間：-4.41%
- 出勤日数：-4.63%
- 1出勤日当たり所定内労働時間：+0.23%

### パートタイム労働者

- 総実労働時間：-11.19%
- 所定内労働時間：-10.82%
- 出勤日数：-12.22%
- 1出勤日当たり所定内労働時間：+1.61%

### 解釈

一般労働者・パートタイム労働者の双方で出勤日数が減少しており、
就業形態計で確認された出勤日数減少は、雇用形態構成比の変化だけでは
説明できない。

また、両雇用形態とも1出勤日当たり所定内労働時間は減少しておらず、
所定内労働時間の減少は主として出勤日数の減少によって生じている。

特にパートタイム労働者では、出勤日数および所定内労働時間の
減少幅が一般労働者より大きい。

ただし、本分析では一般労働者とパートタイム労働者の構成比変化を
定量的に分解していないため、就業形態計の変化に対する構成効果の
大きさまでは判断しない。

## 9. 分析上の注意点

### 9.1 概算時間当たり賃金

```text
きまって支給する給与 ÷ 総実労働時間
```

による派生指標であり、公表された時間当たり賃金そのものではない。

そのため、UI・文書上では必ず**概算時間当たり賃金**と表記する。

### 9.2 出勤日数

出勤日数は勤務日数そのものと完全には一致しない。

したがって、

```text
所定内労働時間 ÷ 出勤日数
```

についても、厳密な「1日の所定労働時間」ではなく、**1出勤日当たり所定内労働時間**として扱う。

### 9.3 加法分解と乗法分解

以下を区別する。

#### 加法分解

```text
総実労働時間 = 所定内労働時間 + 所定外労働時間
```

→ 前年差・寄与度を使用する。

#### 乗法分解

```text
月額賃金 = 時間当たり賃金 × 総実労働時間
```

```text
所定内労働時間 = 1出勤日当たり所定内労働時間 × 出勤日数
```

→ 対数変化による寄与を使用する。

両者を同じ「寄与度」として混同しない。

### 9.4 平均値の構成効果

就業形態計の平均値は、

- 一般労働者
- パートタイム労働者

などの構成比変化によっても変化する。

そのため、本分析で確認された労働時間変化が、個々の労働者の勤務時間短縮だけを意味するとは限らない。

必要に応じて雇用形態別分析で確認する。

## 10. この分析から言えること・言えないこと

### 言えること

- 月額賃金変化を、時間当たり賃金と総実労働時間に機械的に分解できる
- 総実労働時間変化を、所定内・所定外労働時間に分解できる
- 所定内労働時間変化を、出勤日数と1出勤日当たり時間に分解できる
- 各要素がどの時期にどの方向へ動いたか確認できる
- 2015年から2025年までの長期変化の構造を比較できる

### 言えないこと

- 労働時間減少の政策的・制度的原因
- 働き方改革の因果効果
- 景気変動の因果効果
- 有給休暇取得の寄与
- 人手不足の因果効果
- 生産性と労働時間の因果関係

## 11. 分析上の主要な問いへの回答

### 問い1

**2015～2025年の月額賃金上昇は、時間当たり賃金上昇と労働時間変化のどちらによって説明されるか。**

2015年から2025年にかけて、月額のきまって支給する給与は260,575円から287,408円へ増加し、変化率は+10.30%であった。

同期間に、年間加重概算時間当たり賃金は1,804.12円/時間から2,128.03円/時間へ上昇し、+17.95%となった。

一方、総実労働時間は144.43時間から135.06時間へ減少し、変化率は-6.49%であった。

対数変化による要因分解では、

- 月額賃金の対数変化：+9.80
- 時間当たり賃金の寄与：+16.51
- 総実労働時間の寄与：-6.71

となった。

したがって、2015～2025年の月額賃金上昇は、**時間当たり賃金の上昇が主な押上げ要因であり、総実労働時間の減少がその一部を相殺していた**と整理できる。

### 問い2

**労働時間の変化は、所定内労働時間と所定外労働時間のどちらによって生じたか。**

2015年から2025年にかけて、総実労働時間は144.43時間から135.06時間へ、9.38時間減少した。

内訳は、

- 所定内労働時間：133.45時間 → 125.25時間（-8.20時間）
- 所定外労働時間：10.98時間 → 9.81時間（-1.18時間）

であった。

2015年の総実労働時間を基準とした寄与度は、

- 所定内労働時間：-5.68pt
- 所定外労働時間：-0.81pt

となった。

したがって、長期的な総実労働時間の減少は、主として**所定内労働時間の減少**によって生じている。

総実労働時間の減少幅の約87%を所定内労働時間の減少が占めており、「残業時間の減少だけ」で長期的な労働時間短縮を説明することはできない。

### 問い3

**所定内労働時間の変化は、出勤日数と1出勤日当たり労働時間のどちらによって生じたか。**

2015年から2025年にかけて、

- 所定内労働時間：133.45時間 → 125.25時間（-6.14%）
- 出勤日数：18.675日 → 17.45日（-6.56%）
- 1出勤日当たり所定内労働時間：7.146時間 → 7.178時間（+0.44%）

となった。

対数変化による分解では、

- 所定内労働時間の対数変化：-6.34
- 出勤日数の寄与：-6.78
- 1出勤日当たり所定内労働時間の寄与：+0.44

であった。

したがって、所定内労働時間の減少は、**1出勤日当たりの勤務時間短縮ではなく、主として月間の出勤日数減少によって生じている**と整理できる。

一般労働者・パートタイム労働者の双方でも同じ方向が確認された。

- 一般労働者：出勤日数 -4.63%、1出勤日当たり時間 +0.23%
- パートタイム労働者：出勤日数 -12.22%、1出勤日当たり時間 +1.61%

このため、就業形態計の出勤日数減少は、雇用形態構成比の変化だけでは説明できない。

### 問い4

**コロナ期の労働時間変化は、長期的傾向とどのように異なっていたか。**

コロナ前の2015～2019年にも、時間当たり賃金の上昇と総実労働時間の減少が同時に進む傾向が確認された。

特に2019年は、

- 時間当たり賃金寄与：+2.07
- 総実労働時間寄与：-2.22

となり、両者がおおむね相殺した。

2020年には、

- 時間当たり賃金寄与：+2.15
- 総実労働時間寄与：-2.85

となり、労働時間減少の影響がさらに拡大した。

総実労働時間の内訳では、

- 所定内労働時間寄与：-1.81pt
- 所定外労働時間寄与：-1.00pt

となり、2019年と比べて所定外労働時間の減少が大きく拡大した。

したがって2020年は、**コロナ前から存在していた所定内労働時間・出勤日数の減少に加えて、所定外労働時間も大きく減少した特殊局面**と整理できる。

2021年には所定内・所定外労働時間がともに反動回復した。

一方、2025年の労働時間減少は2020年とは異なり、

- 所定内労働時間寄与：-1.19pt
- 所定外労働時間寄与：-0.18pt
- 出勤日数寄与：-1.14

となっており、主として所定内労働時間、とりわけ出勤日数の減少によって生じていた。

## 12. 最終的な考察

### 12.1 主要結果

本分析では、月額賃金の変化を労働投入の観点から3段階に分解した。

```text
月額賃金
├─ 時間当たり賃金
└─ 総実労働時間
   ├─ 所定内労働時間
   │  ├─ 出勤日数
   │  └─ 1出勤日当たり所定内労働時間
   └─ 所定外労働時間
```

2015～2025年について確認された主な結果は以下のとおりである。

1. 月額賃金は+10.30%上昇した。
2. 年間加重概算時間当たり賃金は+17.95%上昇した。
3. 総実労働時間は-6.49%減少した。
4. 総実労働時間減少の中心は所定内労働時間であった。
5. 所定内労働時間減少の中心は出勤日数であった。
6. 1出勤日当たり所定内労働時間は減少しておらず、わずかに増加した。
7. 一般労働者・パートタイム労働者の双方で出勤日数減少が確認された。
8. 2020年は所定外労働時間の減少も大きく、長期的傾向とは異なる特殊局面であった。

### 12.2 経済的な意味

月額賃金だけを見ると、2015年から2025年までの上昇率は約10%にとどまる。

しかし、労働時間を考慮すると、時間当たり賃金は約18%上昇している。

したがって、月額賃金の伸びが時間当たり賃金の伸びより弱い理由の一つとして、総実労働時間の減少が確認できる。

さらに、その労働時間減少を分解すると、所定外労働時間、すなわち残業時間の減少だけではなく、
所定内労働時間の減少がより大きな要因であった。

所定内労働時間をさらに分解すると、1出勤日当たりの勤務時間が短縮したのではなく、
平均的な出勤日数が減少したことが主な要因であった。

この結果から、月額賃金の伸びを評価する際には、「賃金単価がどの程度上昇したか」と「労働投入量がどの程度変化したか」を分けて確認する必要がある。

### 12.3 給与構成分析との接続

給与構成分析では、

```text
現金給与総額
├─ 所定内給与
├─ 所定外給与
└─ 特別給与
```

という給与項目側から賃金変化を分解した。

その結果、2015～2025年の現金給与総額上昇では、所定内給与の寄与が最も大きかった。

本分析では、

```text
きまって支給する給与
├─ 時間当たり賃金
└─ 労働時間
```

として、労働投入側から月額賃金を分解した。

両分析を組み合わせることで、

- 給与のどの項目が増減したのか
- 月額給与の変化が賃金単価と労働時間のどちらから生じたのか

を異なる階層から説明できる。

### 12.4 分析上の制約

本分析は恒等式・定義式に基づく機械的な要因分解であり、確認された変化の原因そのものを特定するものではない。

特に、出勤日数の減少については、

- 有給休暇取得の増加
- 休日数の変化
- 労働日数の制度的変化
- 雇用形態や労働者属性の構成変化
- 景気や企業活動の変化

など、複数の要因が考えられる。

また、雇用形態別補助分析では一般労働者・パートタイム労働者の双方で出勤日数減少を確認したが、
両者の構成比変化を定量的に分解していない。

したがって、**出勤日数がなぜ減少したのか**という因果的な問いは、本分析だけでは回答できない。

### 12.5 次の分析への接続

本分析によって、月額賃金の変化を労働投入量まで分解できた。

次の段階では、平均賃金や労働投入を動かす構成要因として、

- 産業構成
- 雇用形態構成
- 企業・事業所規模
- 年齢・勤続年数

などを検討する。

特に、今回確認された出勤日数減少について、労働者構成の変化がどの程度影響しているかは、今後の分析候補となる。
