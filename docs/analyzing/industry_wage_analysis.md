## 1. 分析目的

### 1.1 問い

本分析では、以下を主な問いとする。

> **2015～2025年の賃金上昇は各産業で広く生じたのか。
> また、産業ごとの月額賃金の変化は、時間当たり賃金と労働時間のどちらによって生じたのか。**

具体的には、以下の4点を確認する。

1. 賃金上昇率にはどの程度の産業差があるか
2. 月額賃金と時間当たり賃金では、産業別の評価が異なるか
3. 労働時間の増減が、産業別の月額賃金をどの程度押し上げ・押し下げたか
4. 日本全体の賃金変化は、多くの産業に共通する動きなのか、一部産業の影響が大きいのか

---

### 1.2 分析上の位置付け

本分析は、これまで実施した以下の分析を産業別に拡張するものである。

```text
賃金変動
├─ 給与構成
│  ├─ 所定内給与
│  ├─ 所定外給与
│  └─ 特別給与
│
├─ 労働投入
│  ├─ 時間当たり賃金
│  └─ 労働時間
│
└─ 労働者構成
   ├─ 産業
   ├─ 雇用形態
   ├─ 事業所規模
   └─ 年齢・勤続年数等
```

これまでの分析では調査産業計を中心に、日本全体の賃金・労働時間変化を確認した。

本分析では、

```text
全国平均
    ↓
各産業
    ↓
月額賃金
    ├─ 概算時間当たり賃金
    └─ 総実労働時間
```

という構造で、全国平均の背後に存在する産業差を確認する。

---

## 2. この分析で説明すること

本分析では、以下を説明対象とする。

- 産業別の月額賃金水準・変化率
- 産業別の概算時間当たり賃金の変化率
- 産業別の総実労働時間の変化率
- 月額賃金変化に対する時間当たり賃金と労働時間の機械的寄与
- 賃金上昇が産業横断的に生じているか
- 産業間の賃金上昇率のばらつき
- 月額賃金と時間当たり賃金で産業評価が異なるケース
- 特徴的な産業における年次推移

---

## 3. この分析だけでは説明しないこと

本分析では、産業別の違いを記述・分解するが、その原因について因果的な判断は行わない。

したがって、以下については本分析単独では判断しない。

- なぜ特定産業の賃金が高く上昇したのか
- 人手不足が産業別賃金をどの程度押し上げたのか
- 労働生産性が賃金上昇に与えた因果効果
- 企業利益や付加価値が賃金に与えた影響
- 春闘や最低賃金の影響
- 産業別のパート比率変化が全国平均賃金に与えた影響
- 産業間の労働移動が全国平均賃金に与えた影響

これらは後続分析で検討する。

## 7. 分析方法

### 7.1 第1段階：産業別月額賃金変化

産業ごとに2015年平均と2025年平均を算出し、

$Growth_i = \left(\frac{Wage_{i,2025}}{Wage_{i,2015}} -1 \right) \times 100$

によって変化率を算出する。

確認する項目：

- 2015年平均
- 2025年平均
- 変化額
- 変化率
- 全産業中央値
- 全国平均との比較

---

### 7.2 第2段階：概算時間当たり賃金

産業別に、$`Wage^{hr}_{i,t} = \frac{Wage_{i,t}}{Hours^{total}_{i,t}}`$を算出する。

2015→2025について、

- 月額賃金変化率
- 概算時間当たり賃金変化率

を比較する。

これにより、月額賃金の伸びが弱い産業についても、賃金単価そのものは上昇しているかを確認する。

---

### 7.3 第3段階：総実労働時間

産業ごとに2015年平均・2025年平均を算出し、総実労働時間の変化を確認する。

特に、

- 労働時間が大きく減少した産業
- 労働時間が増加した産業
- 全国平均と異なる動きを示した産業

を確認する。

---

## 8. 月額賃金の要因分解

産業 $(i)$ について、$`Wage_i = Wage^{hr}_i \times Hours_i`$とする。

したがって、

$\Delta \ln Wage_i =\Delta \ln Wage^{hr}_i + \Delta \ln Hours_i$

として、

- 概算時間当たり賃金の寄与
- 総実労働時間の寄与

に分解する。

---

### 8.1 出力例

| 産業  | 月額賃金変化 | 時間当たり賃金寄与 | 労働時間寄与 |
| ----- | -----------: | -----------------: | -----------: |
| 産業A |              |                    |              |
| 産業B |              |                    |              |

この表によって、

```text
月額賃金上昇
├─ 賃金単価上昇によるもの
└─ 労働時間変化によるもの
```

を産業横断的に比較する。

---

## 9. 労働時間の補助分析

総実労働時間については、$`Hour^{total} =Hour^{In} + Hour^{Out}`$の関係を利用する。

ただし、全産業について詳細な労働投入分解を繰り返すことは避ける。

主分析では総実労働時間までとし、以下のような特徴的な産業についてのみ、

- 所定内労働時間
- 所定外労働時間

を補助的に確認する。

対象候補：

- 労働時間減少率が特に大きい産業
- 月額賃金と時間当たり賃金の乖離が大きい産業
- コロナ期に特徴的な変化を示した産業

---

## 10. 就業形態による補助分析

主分析は就業形態計を使用する。

ただし、産業間では一般労働者・パートタイム労働者の構成比が異なるため、産業差には雇用形態構成の影響が含まれる。

この影響を確認するため、必要に応じて一般労働者について同様の比較を行う。

### 基本方針

```text
主分析
└─ 就業形態計

補助分析
└─ 一般労働者

必要な場合のみ
└─ パートタイム労働者
```

全産業×全就業形態を全面的に表示することは避ける。

---

## 11. 産業横断的な記述統計

産業別変化率について、以下を算出する。

- 平均
- 中央値
- 最小値
- 最大値
- 四分位範囲
- 標準偏差
- 賃金上昇産業数
- 分析対象産業数
- 全国平均以上に上昇した産業数

---

### 11.1 賃金上昇産業割合

$Share^{up} =\frac{\text{賃金上昇産業数}}{\text{分析対象産業数}}$

を算出する。

単に全国平均が上昇したかではなく、賃金上昇がどの程度広範だったかを確認する。

---

## 12. 探索的統計分析

統計的推測を本分析の中心には置かない。

本分析では主要産業そのものを比較するため、産業間の平均差についてt検定やANOVA等による有意差検定を主分析として使用しない。

### 12.1 散布図

産業ごとに、

$x_i = \Delta\ln Wage^{hr}_i$

$y_i = \Delta\ln Hours_i$

として散布図を作成する。

以下の4象限として解釈する。

```text
                労働時間増加
                    ↑
                    │
時間単価低下 ←────────┼────────→ 時間単価上昇
                    │
                    ↓
                労働時間減少
```

特に、

```text
時間当たり賃金 ↑
労働時間       ↓
```

となる産業では、賃金単価上昇が月額賃金に完全には反映されていない可能性を確認する。

---

### 12.2 相関係数

必要に応じて、

- Pearson相関係数
- Spearman順位相関係数

を算出する。

ただし、産業数が限られるため、因果関係を示すものではなく探索的な参考値として扱う。

## 17. 分析上の限界

### 17.1 産業内の労働者構成

産業別平均値には、

- 一般労働者・パートタイム労働者比率
- 年齢構成
- 性別構成
- 職種構成
- 企業規模構成

などの違いが含まれる。

したがって、産業別平均賃金の差を「同一属性の労働者に対する産業固有の賃金効果」と解釈しない。

---

### 17.2 概算時間当たり賃金

本分析の時間当たり賃金は、

$月額のきまって支給する給与 ÷ 総実労働時間$

による概算値であり、個人単位の実際の時給ではない。

---

### 17.3 因果関係

産業別賃金上昇と、

- 人手不足
- 生産性
- 企業利益
- 労働分配率

などの関係は、本分析だけでは因果的に判断できない。

## 18. 次段階：産業構成効果

第1段階で明確な産業差が確認された場合、全国平均賃金の変化を、

$\text{全国平均賃金変化} =\simeq \text{産業内賃金変化} + \text{産業構成変化} + \text{交差効果}$

に分解することを検討する。

必要データ候補：

- 毎月勤労統計の産業別常用労働者数
- 労働力調査の産業別雇用者数

---

### 18.1 次段階へ進む判断基準

以下のいずれかが確認された場合、産業構成効果分析の優先度を高める。

- 産業別賃金上昇率のばらつきが大きい
- 雇用規模の大きい産業で特徴的な賃金変化がある
- 月額賃金と時間当たり賃金で評価が大きく異なる
- 産業ごとの雇用シェア変化が全国平均に影響している可能性が高い

一方、産業差が小さい場合は、無理に産業構成効果へ進まず、別の分析テーマを優先する。

## 20. 現時点での分析方針まとめ

本分析では、単純な産業別賃金ランキングではなく、

```text
全国平均
↓
産業別月額賃金
↓
概算時間当たり賃金 × 総実労働時間
↓
産業ごとの賃金上昇構造の違い
```

を明らかにする。

統計処理については、

```text
主分析
├─ 記述統計
├─ 変化率
└─ 恒等的な要因分解

補助分析
├─ 産業間ばらつき
├─ 散布図
└─ 相関係数
```

とし、統計的有意差検定や複雑な回帰分析は本分析の中心には置かない。

最初にデータ品質と産業分類の接続性を確認し、その結果を踏まえて分析対象産業を確定する。
