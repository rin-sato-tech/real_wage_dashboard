# 一般労働者・パートタイム労働者比較分析

## 1. 分析テーマ

一般労働者とパートタイム労働者では、賃金・労働時間・時間当たり賃金・実質購買力がどのように異なる推移をしてきたかを分析する。

---

## 2. 分析目的

月額賃金の変化だけでは、**賃金率そのものの変化と労働時間の変化を区別できない**。

そこで本分析では、

- 月額賃金
- 労働時間
- 概算時間当たり賃金
- 実質月額賃金
- 実質概算時間当たり賃金

を一般労働者とパートタイム労働者で比較し、賃金変化の背景を整理する。

---

## 3. 主な分析問い

1. 一般労働者とパートタイム労働者では、月額賃金の推移にどのような違いがあるか。

2. 総実労働時間はそれぞれどのように変化しているか。

3. 月額賃金の変化は、労働時間の変化によってどの程度説明できるか。

4. 労働時間を考慮した概算時間当たり賃金は、それぞれどのように推移しているか。

5. 物価変動を考慮した実質月額賃金、実質概算時間当たり賃金はどのように変化しているか。

6. 一般労働者とパートタイム労働者では、賃金変化の構造にどのような違いがあるか。

---

## 7. CPI

## 8. 指標定義

### 8.1 月額賃金

```text
regular_wage = きまって支給する給与
```

### 8.2 労働時間

```text

```

```text
approx_hourly_wage = regular_wage / working_hours
```

これは公的統計として公表される正式な時間当たり賃金ではなく、アプリ内で算出する概算値とする。

### 8.4 実質月額賃金

```text
real_regular_wage = regular_wage / CPI * 100
```

### 8.5 実質概算時間当たり賃金

```text
real_approx_hourly_wage = approx_hourly_wage / CPI * 100
```

## 11. 月額賃金変化の分解

定義上、

```text
月額賃金 = 概算時間当たり賃金 × 総実労働時間
```

である。

対数を用いると、

```text
log(月額賃金) = log(概算時間当たり賃金) - log(総実労働時間)
```

となる。

前年同月との対数変化を用いて、

```text
月額賃金変化 = 時間当たり賃金要因 - 労働時間要因
```

として分解する。

### 算出指標

#### 概算時間当たり賃金

概算時間当たり賃金は以下で算出する。

```text
概算時間当たり賃金 = きまって支給する給与 ÷ 総実労働時間
```

これは公表された公式の時給ではなく、本アプリで分析用に算出した概算値である。

#### 実質月額賃金

```text
実質月額賃金 = きまって支給する給与 ÷ CPI × 100
```

#### 実質概算時間当たり賃金

```text
実質概算時間当たり賃金 = 概算時間当たり賃金 ÷ CPI × 100
```

### 2020年基準指数

以下の指標を各就業形態について個別に2020年平均=100として指数化する。

- 月額賃金
- 総実労働時間
- 概算時間当たり賃金
- 実質月額賃金
- 実質概算時間当たり賃金

一般労働者とパートタイム労働者はそれぞれ独立して指数化する。

したがって、指数の水準から両者の絶対的な賃金額や賃金格差を比較することはできない。

### 前年同月比

以下について12か月前との変化率を算出する。

- 月額賃金
- 総実労働時間
- 概算時間当たり賃金
- 実質月額賃金
- 実質概算時間当たり賃金

計算には月次原系列を使用し、移動平均系列から前年比を算出しない。

### 月額賃金変化の要因分解

月額賃金を、

```text
月額賃金 = 概算時間当たり賃金 × 総実労働時間
```

とみなす。

対数を取ると、

```text
log(月額賃金) = log(概算時間当たり賃金) + log(総実労働時間)
```

となるため、前年同月からの対数変化を、

- 時間当たり賃金要因
- 労働時間要因

に分解する。

```text
月額賃金の対数変化 = 時間当たり賃金要因 + 労働時間要因
```

表示値は通常の前年比率ではなく、前年同月からの対数差を100倍した値である。

## 実データから確認された主な傾向

5人以上・CPI総合の年平均では、2015年から2025年にかけて以下の傾向が確認された。

### 一般労働者

- 概算時間当たり賃金は上昇
- 労働時間は長期的には低下
- 名目月額賃金は上昇
- 実質月額賃金の改善は弱い

### パートタイム労働者

- 概算時間当たり賃金の上昇が大きい
- 労働時間は2015年と比べて低下
- 名目月額賃金は上昇
- 実質概算時間当たり賃金は2020年水準を上回る

月額賃金の変化を見る際には、時間当たり賃金だけでなく労働時間の変化も同時に考慮する必要がある。
