# 手取り賃金・実質手取り賃金の長期分析

## 要約

本分析では、厚生労働省「毎月勤労統計調査」の賃金を用いて、1990～2025年の税・社会保険料控除後の「名目手取り賃金」と、物価変動を考慮した「実質手取り賃金」を推計した。対象は事業所規模5人以上・調査産業計・就業形態計とし、各年に同じ属性を持つ35歳・男性・単身・扶養なし・給与所得のみの標準労働者が存在すると仮定した反復横断型のシミュレーションを行った。

1990年から2025年にかけて、年間額面賃金相当額は393.9万円から426.8万円へ8.3%増加した。一方、名目手取り賃金は327.0万円から338.2万円への3.4%増にとどまった。税・社会保険料の実効負担率は17.0%から20.8%へ3.8ポイント上昇しており、額面賃金の伸びの一部が負担増によって相殺された。

同期間に、実質化に用いた「持家の帰属家賃を除く総合」CPIは27.1%上昇した。その結果、実質額面賃金は14.8%、実質手取り賃金は18.6%低下した。1990年の実質手取り364.5万円に対し、2025年は296.6万円相当であり、約67.9万円の減少となった。

実質手取りの1990→2025年の変化を、額面賃金、税制度、社会保険制度、物価の4要因にShapley分解すると、1990年の実質手取りを基準として、額面賃金要因は+6.49%、税制度要因は+1.27%、社会保険制度要因は−4.73%、物価要因は−21.68%の寄与となった。最大の押下げ要因は物価上昇であり、それに社会保険制度による負担増が加わった。一方、税制度の変更は長期では手取りをわずかに押し上げる方向に寄与した。

負担率を項目別にみると、1990→2025年には厚生年金が+3.73ポイント、健康保険が+1.75ポイント、住民税が+1.48ポイント上昇した一方、所得税は−3.19ポイント低下した。したがって、長期的な負担増を単純に「増税」と捉えることは適切ではなく、主として社会保険料負担の上昇によって説明される。

2015→2025年に限ると、額面賃金は12.7%、名目手取りは12.7%増加したが、CPIが16.6%上昇したため、実質手取りは3.4%低下した。この10年間では実効負担率の変化は+0.04ポイントと小さく、実質手取りの低下は主として物価上昇が名目賃金の伸びを上回ったことで生じた。

住民税の計上時期、一時的な税額控除・減税、厚生年金保険料率の男女差、40～64歳に課される介護保険料、毎月勤労統計の賃金系列の断層について感応度分析を行った。1990→2025年の実質手取り変化率は、女性モデルで−18.8%、45歳モデルで−19.3%となり、主分析の−18.6%と大きくは変わらなかった。公表前年比を連鎖した比較可能な賃金系列でも、1990→2025年の実質額面賃金は−14.4%となり、実額系列の−14.8%とほぼ一致した。一方、2015→2025年では実額系列−3.3%に対して連鎖系列−5.9%となり、直近10年間の変化幅には系列選択による不確実性がある。

以上から、1990年以降の標準労働者モデルでは、額面賃金は名目では増加したものの、社会保険料負担の上昇によって手取りの伸びが抑えられ、さらに物価上昇によって実質的な購買力は大きく低下したと整理できる。ただし、本分析は平均的な個人や世帯の実際の手取りを推計したものではなく、一定の属性と給与水準を与えた標準労働者モデルによる制度比較である。

## 1. 分析目的と問い

名目賃金の変化だけでは、労働者が実際に利用できる所得の変化を十分に把握できない。給与からは所得税、個人住民税、厚生年金保険料、健康保険料、雇用保険料などが控除されるため、額面賃金が増えても、税・社会保険料負担が増加すれば手取りの伸びは小さくなる。

さらに、名目手取りが増加しても、同時に物価が上昇すれば、その所得で購入できる財・サービスの量が増えるとは限らない。したがって、労働者の購買力を評価するには、

$$\text{額面賃金} \rightarrow \text{税・社会保険料控除後の手取り} \rightarrow \text{物価調整後の実質手取り}$$

という段階を区別して分析する必要がある。

本分析の中心となる問いは、次のとおりである。

> **1990年以降、額面賃金の変化はどの程度手取り所得の増加につながったのか。また、税・社会保険制度と物価の変化は、手取りの購買力にどの程度影響したのか。**

具体的には、以下を検証する。

1. 額面名目賃金と名目手取り賃金は1990～2025年にどのように変化したか。
2. 額面賃金に対する税・社会保険料の実効負担率はどのように変化したか。
3. 負担率の変化は、所得税、住民税、厚生年金、健康保険、雇用保険のどの項目によって生じたか。
4. 名目手取りを物価調整すると、実質手取りはどのように変化したか。
5. 実質手取りの変化を、額面賃金、税制度、社会保険制度、物価の要因に分解すると、それぞれどの程度寄与したか。
6. 税・社会保険制度そのものの変更による効果と、賃金水準の変化によって税・保険料額が変化した効果を区別できるか。
7. 標準労働者の属性や住民税の計上時期、賃金系列の選択を変更しても、主な結論は維持されるか。

分析期間は1990～2025年とする。また、既存分析との接続のため2015→2025年を独立して確認し、1990年代、2000年代、2010年代、2020→2025年についても期間別に比較する。

本分析の目的は、税・社会保険制度の変更が特定の政策目的を達成したかを因果的に評価することではない。一定の標準労働者モデルを設定し、その給与に各年の制度を機械的に適用することで、賃金・制度・物価の変化が手取りの長期推移とどのように対応しているかを記述することを目的とする。

## 2. データと分析方法

### 2.1 使用データと対象範囲

主分析の対象条件を以下に示す。

| 項目               | 内容                                   |
| ------------------ | -------------------------------------- |
| 賃金               | 厚生労働省「毎月勤労統計調査」         |
| 物価               | 総務省「消費者物価指数」               |
| 分析期間           | 1990～2025年                           |
| 産業               | 調査産業計                             |
| 事業所規模         | 常用労働者5人以上                      |
| 就業形態           | 就業形態計                             |
| 額面賃金           | 現金給与総額                           |
| 月例賃金           | きまって支給する給与                   |
| 賞与               | 特別給与                               |
| CPI                | 持家の帰属家賃を除く総合               |
| 主分析の年齢       | 35歳                                   |
| 性別               | 男性                                   |
| 世帯・扶養         | 単身・扶養親族なし                     |
| 所得               | 給与所得のみ                           |
| 住民税の主計上方法 | income-year                            |
| 税制               | 各年に実際に適用された制度を基本とする |

毎月勤労統計については、各年1～12月の月次実額を単純平均して年平均月額を作成する。年平均の現金給与総額を12倍したものを年間額面給与相当額とする。

この年平均は、毎月勤労統計が公表する労働者数加重の年平均実額とは異なる。本分析では同じ方法で月例賃金と特別給与を年次化し、税・社会保険料計算に必要な給与構成を一貫して作成することを優先する。

### 2.2 標準労働者モデル

税・社会保険料は年齢、性別、扶養人数、加入制度、居住地などによって異なる。そのため、本分析は「平均的な労働者の実際の平均手取り」を直接推計するものではなく、属性を固定した標準労働者モデルを用いる。

主分析では、各年について次の労働者を想定する。

| 属性             | 仮定                                                 |
| ---------------- | ---------------------------------------------------- |
| 年齢             | 35歳                                                 |
| 性別             | 男性                                                 |
| 配偶者           | なし                                                 |
| 扶養親族         | なし                                                 |
| 所得             | 給与所得のみ                                         |
| 勤務先           | 一般の事業                                           |
| 厚生年金         | 一般の厚生年金被保険者                               |
| 健康保険         | 政府管掌健康保険・協会けんぽ相当                     |
| その他の所得控除 | なし                                                 |
| 個別の税額控除   | 原則なし。ただし制度上一般に適用される減税措置は反映 |

これは、35歳の同一人物を1990年から2025年まで追跡するモデルではない。

> **各年に同じ属性を持つ35歳の標準労働者が存在すると仮定した反復横断型シミュレーション**

として解釈する。

年齢を固定することで、加齢そのものによる社会保険制度の変化を除き、賃金水準と制度変更を年次比較しやすくする。40～64歳に課される介護保険料については、45歳モデルを別途計算して感応度を確認する。

### 2.3 年間給与の構築

各年 $t$ の現金給与総額の年平均月額を $\overline{W}_t$ とすると、年間額面給与相当額 $W_t$ を $W_t = 12\overline{W}_t$ とする。同様に、きまって支給する給与の年平均月額を $\overline{M}_t$、特別給与の年平均月額を $\overline{B}_t$ とし、 $Regular_t = 12\overline{M}_t, $ $Bonus_t = 12\overline{B}_t$ とする。

毎月勤労統計の月次データでは、 $\text{現金給与総額} = \text{きまって支給する給与} + \text{特別給与}$ が成立するため、年平均後も $W_t = Regular_t + Bonus_t$ となることを確認した。

社会保険料計算では、各年の「きまって支給する給与」の年平均月額を、その年を通じた標準的な月例報酬の代理値として使用する。年間特別給与は6月と12月に半額ずつ支給されると仮定する。

したがって、本分析の年間給与は個人を12か月追跡した実際の年間給与ではなく、

> **毎月勤労統計の平均月額から構築した標準化された年間給与水準**

である。

### 2.4 税・社会保険料

年間控除額 $D_t$ は、主分析では次の合計とする。

$$D_t = IncomeTax_t + ResidentTax_t + Pension_t + Health_t + EmploymentInsurance_t$$

35歳モデルでは介護保険料は発生しない。45歳感応度分析では、これに介護保険料を加える。

所得税は、各年の給与所得控除、基礎控除、社会保険料控除、税率・速算控除、税額調整を反映して計算する。復興特別所得税の対象期間にはこれを加える。また、1990年代の特別減税、定率減税、2024年の定額減税など、標準労働者モデルに適用される一時的な措置も主分析では反映する。

個人住民税についても、各賦課年度の給与所得控除、基礎控除、所得割、均等割、調整控除、一時的な減税措置等を反映する。自治体独自の超過課税は扱わず、標準的な制度を用いる。

厚生年金・健康保険では、各時点の保険料率に加え、標準報酬月額の等級、賞与に対する保険料、賞与上限等を反映する。2003年の総報酬制導入前後では月例報酬と賞与の取扱いが異なるため、制度変更を区別して計算する。

雇用保険は「一般の事業」の労働者本人負担率を使用し、月例賃金と賞与を含む給与に適用する。

労災保険、子ども・子育て拠出金などの事業主のみが負担する項目は、労働者本人の給与から控除されないため対象外とする。また、消費税等の間接税も名目手取りの控除項目には含めず、物価への影響はCPIを通じて実質化の段階で反映されるものとして扱う。

### 2.5 名目手取りと実効負担率

名目手取り賃金 $N_t$ を、 $N_t = W_t - D_t$ とする。また、額面賃金に対する実効負担率 $d_t$ を、 $d_t = \frac{D_t}{W_t}$ とし、手取り率 $q_t$ を、 $q_t = \frac{N_t}{W_t} = 1-d_t$ とする。

所得税、住民税、厚生年金、健康保険、雇用保険についても、それぞれの控除額を額面賃金で除した項目別負担率を計算する。これにより、合計負担率の変化がどの項目から生じたかを確認する。

### 2.6 住民税の計上時期

個人住民税は前年の所得を基礎として翌年度に課税される。この時間差をどの年に帰属させるかによって、特に制度改正の前後では年次負担率が大きく変化する可能性がある。

主分析では、所得年 $t$ の給与に対して、その所得から生じる賦課年度 $t+1$ の住民税額を対応させる `income_year` 方式を用いる。

この方法は、

> **同じ所得年に対する税・社会保険料負担を比較する**

という分析目的に適している一方、実際の給与からその年に徴収される住民税額とは一致しない。

そこで感応度分析として、年 $t$ に前年所得 $t-1$ に基づく住民税年額を対応させる `cash_flow` 方式も計算する。ただし、これは年税額を年単位でずらした近似であり、実際の特別徴収が原則として6月から翌年5月まで行われる月別キャッシュフローを再現したものではない。

### 2.7 実質手取り賃金

物価調整には、既存の実質賃金分析と同じ「持家の帰属家賃を除く総合」CPIを使用する。実質手取り賃金 $R_t$ を、 $R_t = \frac{N_t}{CPI_t/100}$ とする。同様に、年間額面給与もCPIで除して実質額面賃金を算出する。

長期的な変化を比較するため、1990年を100として、 $I_{R,t} = \frac{R_t}{R_{1990}} \times 100$ を計算する。額面名目賃金、名目手取り、実質額面賃金についても同様の指数を作成する。CPIの基準年は実質額の表示単位を決めるものであり、1990年=100とする時系列指数の基準とは役割が異なる。

### 2.8 期間変化の対数分解

実質手取りは、 $R_t = \frac{W_t(1-d_t)}{P_t}$ と表すことができる。ここで $P_t$ はCPIである。したがって、2時点間の対数変化は、

$$\Delta \ln R = \Delta \ln W + \Delta \ln(1-d) - \Delta \ln P$$

と恒等的に分解できる。

この分解では、実質手取りの変化を、

- 額面賃金の変化
- 手取り率、すなわち税・社会保険負担の変化
- 物価の変化

の3要因に整理する。

これは計算上の恒等分解であり、それぞれの変化の因果的な原因を推定するものではない。

### 2.9 制度変更と賃金変化の分離

実効負担率は制度変更だけでなく、同じ税制・社会保険制度の下でも賃金水準が変わることで変化する。例えば累進所得税では、賃金上昇によって制度を変更しなくても実効税率が変化し得る。

そこで、各時点の賃金と制度年を入れ替える反実仮想計算を行い、実効負担率の変化を、 $d = f(W,T,S)$ として、

- $W$：賃金水準
- $T$：所得税・住民税制度
- $S$：社会保険制度

の3要因にShapley分解する。

Shapley分解では、各要因を変更する順序によって生じる交互作用を、すべての変更順序について平均して配分する。

また、実質手取りについては、 $R = f(W,T,S,P)$ として、

- 賃金水準
- 税制度
- 社会保険制度
- 物価

の4要因に分解する。

この方法により、例えば「負担率が上昇した」という結果を、賃金水準の変化による機械的な効果と制度そのものの変更に分けて確認する。

ただし、Shapley値は要因の定義・グルーピングに依存する。本分析で「税制度」と「社会保険制度」を別々の要因とした結果と、両者をまとめて単一の「制度要因」とした結果は、それぞれの分解内部では整合するが、個別の寄与額が一致する必要はない。

### 2.10 賃金系列の断層と比較可能系列

毎月勤労統計の実額系列には、標本交替やベンチマーク更新等による水準断層が含まれる場合がある。

税・社会保険料を円額で計算するには各年の給与水準が必要であるため、主分析では月次実額から構築した年間給与を使用する。

一方、長期的な賃金変化率が実額系列の水準断層に左右されていないかを確認するため、厚生労働省が公表する現金給与総額の前年比を連鎖し、

$$W_t^{chain} = W_{t-1}^{chain} \left(1 + \frac{g_t}{100} \right)$$

として比較可能な名目賃金指数を作成する。

この連鎖系列は長期変化率と実質賃金変化の頑健性確認に使用し、税・社会保険料の円額計算には使用しない。

### 2.11 頑健性確認

主分析の仮定によって結論が左右されていないかを確認するため、以下の感応度分析を行う。

| 確認項目         | 主分析             | 感応度分析                   |
| ---------------- | ------------------ | ---------------------------- |
| 住民税の時間対応 | income-year        | cash-flow                    |
| 性別             | 男性               | 女性                         |
| 年齢             | 35歳               | 45歳・介護保険料込み         |
| 税制             | 実際の制度         | 一時的減税を除いた構造的制度 |
| 賃金系列         | 月次実額から年平均 | 公表前年比の連鎖系列         |

女性モデルは、対象期間初期に存在した厚生年金保険料率の男女差を確認するために用いる。45歳モデルは、40～64歳の介護保険第2号被保険者としての負担を追加する。

一時的減税を除く感応度分析では、恒久的または比較的長期に組み込まれた制度変更と、一時的な税額軽減措置を区別し、特定年の減税によって長期時系列の特徴が生じていないかを確認する。

これらは主分析を置き換えるものではなく、標準労働者モデルの属性、制度の時間対応、統計系列の選択に対して結果がどの程度安定しているかを確認するための補助分析として位置づける。

## 3. 分析結果

### 3.1 額面賃金・名目手取り・実質手取りの長期変化

まず、標準労働者モデルについて、年間額面給与、名目手取り、実質手取りの長期変化を確認する。

主要年の結果は次のとおりである。

|   年 | 年間額面給与 |  名目手取り | 実効負担率 |    CPI |  実質手取り |
| ---: | -----------: | ----------: | ---------: | -----: | ----------: |
| 1990 |  3,939,398円 | 3,270,313円 |     16.98% |  89.72 | 3,645,156円 |
| 2000 |  4,263,666円 | 3,547,572円 |     16.80% |  96.40 | 3,680,054円 |
| 2010 |  3,817,755円 | 3,072,301円 |     19.53% |  93.53 | 3,284,712円 |
| 2015 |  3,786,062円 | 3,001,425円 |     20.72% |  97.80 | 3,068,941円 |
| 2020 |  3,819,595円 | 3,024,651円 |     20.81% | 100.00 | 3,024,651円 |
| 2025 |  4,267,634円 | 3,381,644円 |     20.76% | 114.03 | 2,965,704円 |

1990→2025年では、年間額面給与は393.9万円から426.8万円へ増加し、変化率は+8.33%となった。一方、名目手取りは327.0万円から338.2万円への+3.40%にとどまった。

この差は、実効負担率が16.98%から20.76%へ3.78ポイント上昇したためである。額面賃金は約32.8万円増加したが、そのすべてが手取りの増加にはつながらず、名目手取りの増加は約11.1万円にとどまった。

さらに、同期間にCPIは約27.1%上昇した。その結果、実質額面賃金は14.76%、実質手取りは18.64%低下した。

1990年を100とすると、2025年の指数は、

- 額面名目賃金：約108.3
- 名目手取り：約103.4
- 実質額面賃金：約85.2
- 実質手取り：約81.4

となる。

したがって、1990年以降の長期変化は、

> **名目額面賃金はわずかに増加したが、税・社会保険負担の上昇によって名目手取りの伸びはさらに小さくなり、物価上昇を考慮すると実質手取りは約19%低下した**

と整理できる。

実質手取りは1996年に約381.1万円で期間中の最高水準となり、その後長期的に低下した。最低水準は2023年の約291.7万円であり、2024～2025年には名目賃金上昇によってやや回復したものの、1990年代の水準には戻っていない。

---

### 3.2 期間別にみた変化

長期変化を年代別に分けると、実質手取りを押し下げた要因は期間によって異なる。

| 期間      | 額面賃金 | 名目手取り |     CPI | 実質額面賃金 | 実質手取り | 負担率変化 |
| --------- | -------: | ---------: | ------: | -----------: | ---------: | ---------: |
| 1990→2000 |   +8.23% |     +8.48% |  +7.45% |       +0.73% |     +0.96% |    −0.19pt |
| 2000→2010 |  −10.46% |    −13.40% |  −2.97% |       −7.71% |    −10.74% |    +2.73pt |
| 2010→2020 |   +0.05% |     −1.55% |  +6.91% |       −6.42% |     −7.92% |    +1.29pt |
| 2020→2025 |  +11.73% |    +11.80% | +14.03% |       −2.01% |     −1.95% |    −0.05pt |
| 2015→2025 |  +12.72% |    +12.67% | +16.59% |       −3.32% |     −3.36% |    +0.04pt |
| 1990→2025 |   +8.33% |     +3.40% | +27.10% |      −14.76% |    −18.64% |    +3.78pt |

1990年代は、額面賃金の伸びが物価上昇をわずかに上回り、実質手取りも約1%上昇した。

2000年代は状況が大きく異なる。額面賃金自体が10.5%減少したうえ、実効負担率が2.73ポイント上昇したため、実質手取りは10.7%低下した。物価はむしろ低下しており、この期間の実質手取り悪化は主として賃金低下と負担率上昇によって生じた。

2010年代は額面賃金がほぼ横ばいであった一方、物価が6.9%上昇し、負担率も1.29ポイント上昇した。このため実質手取りは7.9%低下した。

2020→2025年では、額面賃金は11.7%上昇したが、CPIが14.0%上昇したため、実質手取りはなお1.9%低下した。この期間では負担率はわずかに低下しており、実質手取り低下の中心は税・社会保険負担ではなく、物価上昇が名目賃金の伸びを上回ったことである。

特に既存分析との接続に用いる2015→2025年では、額面賃金+12.72%、名目手取り+12.67%に対し、CPIは+16.59%であった。その結果、実質手取りは−3.36%となった。実効負担率の変化は+0.04ポイントにすぎず、この10年間については制度負担よりも物価上昇の影響が支配的である。

---

### 3.3 税・社会保険料の負担構造

実効負担率を控除項目別にみる。

|   年 | 所得税 | 住民税 | 厚生年金 | 健康保険 | 雇用保険 |   合計 |
| ---: | -----: | -----: | -------: | -------: | -------: | -----: |
| 1990 |  4.96% |  3.10% |    5.23% |    3.14% |    0.55% | 16.98% |
| 2000 |  3.81% |  2.24% |    6.94% |    3.41% |    0.40% | 16.80% |
| 2010 |  2.15% |  4.47% |    7.82% |    4.53% |    0.56% | 19.53% |
| 2015 |  2.11% |  4.34% |    8.78% |    4.99% |    0.50% | 20.72% |
| 2020 |  2.12% |  4.35% |    9.08% |    4.96% |    0.30% | 20.81% |
| 2025 |  1.77% |  4.58% |    8.96% |    4.90% |    0.56% | 20.76% |

1990→2025年の負担率変化を項目別にみると、

| 項目     | 負担率変化 |
| -------- | ---------: |
| 所得税   |    −3.19pt |
| 住民税   |    +1.48pt |
| 厚生年金 |    +3.73pt |
| 健康保険 |    +1.75pt |
| 雇用保険 |    +0.01pt |
| 合計     |    +3.78pt |

となる。

最大の上昇要因は厚生年金であり、健康保険と住民税も負担率を押し上げた。一方、所得税の実効負担率は3.19ポイント低下している。

したがって、1990→2025年の実効負担率上昇を「税負担の増加」とだけ表現することは適切ではない。

> **長期的な負担率上昇の中心は社会保険料であり、所得税はむしろ負担率を低下させる方向に変化した。**

1990年時点では所得税負担率4.96%に対し厚生年金5.23%であったが、2025年には所得税1.77%に対し厚生年金8.96%となっている。給与からの公的負担の構成そのものが、税中心から社会保険料中心へ移ったことが分かる。

なお、2003年の総報酬制導入では、厚生年金・健康保険について月例報酬と賞与の取扱いが変更されている。このため、表面的な保険料率の変化だけでは制度負担の増減を評価できず、月例報酬と賞与を含めた年間保険料で比較する必要がある。

---

### 3.4 2015→2025年の負担構造

2015→2025年については、合計の実効負担率は20.72%から20.76%への+0.04ポイントであり、ほぼ横ばいであった。

項目別変化は、

| 項目     | 2015→2025年 |
| -------- | ----------: |
| 所得税   |     −0.34pt |
| 住民税   |     +0.24pt |
| 厚生年金 |     +0.18pt |
| 健康保険 |     −0.09pt |
| 雇用保険 |     +0.06pt |
| 合計     |     +0.04pt |

である。

所得税負担率の低下が、住民税・厚生年金・雇用保険の上昇をほぼ相殺した。

このため、2015→2025年に名目手取りの伸びが額面賃金の伸びとほぼ同じであるのは、偶然ではなく、実効負担率がほぼ変化しなかったためである。

したがって、この期間の実質手取り低下を「税・社会保険料の増加」によって説明することは難しい。

> **2015→2025年の実質手取り低下は、主として物価上昇率が名目賃金上昇率を上回ったことによる。**

---

### 3.5 実質手取り変化の対数分解

実質手取りを、 $R = \frac{W(1-d)}{P}$ とし、 $\Delta \ln R = \Delta \ln W + \Delta \ln(1-d) - \Delta \ln P$ として分解した。

主な結果は次のとおりである。

| 期間      | 賃金要因 | 負担率要因 | 物価要因 | 実質手取りの対数変化 |
| --------- | -------: | ---------: | -------: | -------------------: |
| 1990→2000 |   +7.91% |     +0.23% |   −7.19% |               +0.95% |
| 2000→2010 |  −11.05% |     −3.34% |   +3.02% |              −11.36% |
| 2010→2020 |   +0.05% |     −1.61% |   −6.69% |               −8.25% |
| 2020→2025 |  +11.09% |     +0.07% |  −13.12% |               −1.97% |
| 2015→2025 |  +11.97% |     −0.05% |  −15.35% |               −3.42% |
| 1990→2025 |   +8.00% |     −4.66% |  −23.98% |              −20.63% |

1990→2025年では、額面賃金上昇が実質手取りを押し上げる方向に寄与した一方、負担率上昇と物価上昇がこれを上回った。

とりわけ物価要因の押下げが大きく、長期の実質手取り低下における最大の要因となっている。

一方、2000→2010年では物価低下が実質手取りを押し上げる方向に働いている。それにもかかわらず実質手取りが10%以上低下したのは、額面賃金低下と負担率上昇の影響が大きかったためである。

このように、実質手取り低下の背景は期間ごとに異なる。

- 2000年代：賃金低下と負担率上昇
- 2010年代：物価上昇と負担率上昇
- 2020年代前半：賃金上昇を上回る物価上昇

という違いが確認できる。

---

### 3.6 実効負担率変化のShapley分解

実効負担率を、 $d=f(W,T,S)$ として、賃金水準 $W$、税制度 $T$、社会保険制度 $S$ の3要因にShapley分解した。

結果は次のとおりである。

| 期間      | 賃金水準要因 | 税制度要因 | 社会保険制度要因 | 負担率変化 |
| --------- | -----------: | ---------: | ---------------: | ---------: |
| 1990→2000 |      +0.95pt |    −2.09pt |          +0.95pt |    −0.19pt |
| 2000→2010 |      −0.23pt |    +1.27pt |          +1.68pt |    +2.73pt |
| 2010→2020 |      +0.06pt |    +0.07pt |          +1.16pt |    +1.29pt |
| 2020→2025 |      +0.23pt |    −0.51pt |          +0.22pt |    −0.05pt |
| 2015→2025 |      +0.20pt |    −0.51pt |          +0.35pt |    +0.04pt |
| 1990→2025 |      +0.68pt |    −1.13pt |          +4.23pt |    +3.78pt |

1990→2025年では、社会保険制度の変更が実効負担率を+4.23ポイント押し上げる方向に寄与した。

一方、税制度の変更は−1.13ポイント、すなわち実効負担率を低下させる方向に寄与した。賃金水準の変化による機械的な効果は+0.68ポイントであった。

したがって、長期の負担率上昇は、

> **主として社会保険制度の変更によって生じ、税制度の変更はその一部を相殺した**

と整理できる。

特に2010→2020年では、負担率上昇+1.29ポイントのうち、社会保険制度要因が+1.16ポイントを占める。

これに対し2020→2025年では、社会保険制度要因+0.22ポイントと賃金水準要因+0.23ポイントを、税制度要因−0.51ポイントが相殺し、合計ではわずかに負担率が低下した。

---

### 3.7 実質手取りの4要因Shapley分解

最後に、実質手取りを、 $R = f(W,T,S,P)$ として、

- 額面賃金
- 税制度
- 社会保険制度
- 物価

の4要因に分解した。

#### 1990→2025年

1990年の実質手取りは3,645,156円、2025年は2,965,704円であり、679,452円減少した。

この変化をShapley分解すると、

| 要因         |     寄与額 | 1990年実質手取り比 |
| ------------ | ---------: | -----------------: |
| 額面賃金     | +236,602円 |             +6.49% |
| 税制度       |  +46,423円 |             +1.27% |
| 社会保険制度 | −172,288円 |             −4.73% |
| 物価         | −790,189円 |            −21.68% |
| 合計         | −679,452円 |            −18.64% |

となった。

最大の押下げ要因は物価であり、1990年実質手取りの21.68%に相当するマイナス寄与となった。

社会保険制度も4.73%相当の押下げ要因となった。一方、額面賃金は6.49%、税制度は1.27%相当の押上げ要因であった。

したがって、

> **1990→2025年の実質手取り低下は、物価上昇の影響が最も大きく、それに社会保険制度による負担増が加わった。名目賃金上昇と税制度変更による押上げではこれらを相殺できなかった。**

と整理できる。

#### 2015→2025年

2015→2025年の実質手取り変化については、

| 要因         |     寄与額 | 2015年実質手取り比 |
| ------------ | ---------: | -----------------: |
| 額面賃金     | +354,946円 |            +11.57% |
| 税制度       |  +19,375円 |             +0.63% |
| 社会保険制度 |  −13,173円 |             −0.43% |
| 物価         | −464,385円 |            −15.13% |
| 合計         | −103,238円 |             −3.36% |

となった。

額面賃金上昇は実質手取りを約35.5万円押し上げる方向に働いたが、物価上昇の押下げ効果は約46.4万円とさらに大きかった。

税制度と社会保険制度の寄与は両者を合わせても比較的小さい。

この結果からも、2015→2025年の実質手取り低下は、

> **制度負担の増加よりも、名目賃金上昇を上回る物価上昇によって説明される部分が大きい**

ことが確認できる。

---

### 3.8 長期変化のまとめ

1990～2025年の結果を整理すると、次の3点が重要である。

第一に、額面賃金は名目では増加したが、その増加率は35年間で8.3%にとどまり、同期間の物価上昇率27.1%を大きく下回った。

第二に、実効負担率は17.0%から20.8%へ上昇したが、その主因は所得税ではなく社会保険料であった。所得税負担率はむしろ低下しており、厚生年金・健康保険を中心とする社会保険負担の上昇が合計負担率を押し上げた。

第三に、実質手取り低下の最大の要因は物価上昇であった。特に2015年以降は実効負担率がほぼ横ばいであるにもかかわらず実質手取りが低下しており、近年の購買力低下を税・社会保険負担だけで説明することはできない。

したがって、本分析からは、

> **長期では「低い名目賃金成長」「社会保険負担の上昇」「物価上昇」が重なって実質手取りを押し下げたが、各要因の重要性は時期によって異なる**

という結果が得られた。

---

## 4. 結果の頑健性確認

主分析では、35歳男性、住民税は `income_year` 方式、実際の税制、毎月勤労統計の実額系列を使用した。

これらの仮定によって結論が大きく左右されていないかを確認するため、

1. 住民税の計上時期
2. 一時的な減税措置
3. 厚生年金保険料率の男女差
4. 年齢と介護保険料
5. 賃金系列の水準断層

について感応度分析を行った。

### 4.1 住民税の計上時期

主分析の `income_year` 方式では、所得年 $t$ の給与に対し、その所得から生じる賦課年度 $t+1$ の住民税を対応させている。

一方、実際のキャッシュフローに近づける感応度分析として、年 $t$ に前年所得 $t-1$ に基づく住民税年額を対応させる `cash_flow` 方式でも計算した。

1991→2025年の実質手取り変化率は、

| 方式        | 実質手取り変化率 |
| ----------- | ---------------: |
| income-year |          −19.36% |
| cash-flow   |          −19.48% |
| 差          |          −0.12pt |

となった。

長期変化率の差は約0.12ポイントであり、1990年代初期を除く長期的な結論にはほとんど影響しない。

ただし、単年の変化については両方式の差が大きくなる場合がある。

特に2007年の所得税から住民税への税源移譲前後では、`income_year` 方式では制度変更が同じ所得年に集中的に反映されるため、

- 2006年：負担率が大きく上昇
- 2007年：負担率が大きく低下

する形となる。

`cash_flow` 方式ではこの変化が時間的に分散され、2006年の実質手取りは `income_year` 方式より約10.4万円高くなる。

したがって、

> **住民税の時間対応は、2006～2007年などの単年変化の解釈には重要であるが、1990年代以降の長期的な実質手取り低下という結論にはほとんど影響しない。**

なお、`cash_flow` 方式も住民税の年税額を1年ずらす近似であり、6月から翌年5月にわたる実際の特別徴収を月別に再現したものではない。

---

### 4.2 一時的な税額軽減措置

対象期間には、恒久的な税制改正だけでなく、一時的な特別減税や定額減税が存在する。

主分析では実際に標準労働者へ適用された制度を再現するため、これらも含めた `actual_policy` を使用した。

一方、一時的措置によって長期時系列の特徴が生じていないかを確認するため、

- 1994～1996年の特別減税
- 1998年の定額的な特別減税
- 2024年の定額減税

などを除外した `structural_policy` 系列も計算した。

主な一時的措置による名目手取りへの影響は次のとおりである。

|   年 | 実際の制度による名目手取り押上げ |
| ---: | -------------------------------: |
| 1993 |                        約2.8万円 |
| 1994 |                        約6.2万円 |
| 1995 |                        約4.9万円 |
| 1996 |                        約3.2万円 |
| 1997 |                        約1.7万円 |
| 1998 |                        約3.8万円 |
| 2023 |                        約1.0万円 |
| 2024 |                        約3.1万円 |

一時的措置を除くと該当年の手取り水準は低下するが、実質手取りの長期的な形状は大きく変わらない。

特に、主分析では実質手取りの最高値が1996年となったが、一時的減税を除外した構造的制度系列でも最高値は1996年であった。

したがって、

> **1990年代半ばの実質手取りの高水準は、一時的減税だけによって生じたものではない。**

一時的減税は年次水準には無視できない影響を与えるものの、長期トレンドそのものを逆転させるほどではない。

---

### 4.3 厚生年金保険料率の男女差

対象期間初期には、厚生年金保険料率に男女差が存在した。

主分析では男性モデルを使用しているため、女性モデルでも再計算した。

主要な差は次のとおりである。

|   年 | 女性－男性の厚生年金保険料 | 女性－男性の実質手取り | 負担率差 |
| ---: | -------------------------: | ---------------------: | -------: |
| 1990 |                   −7,200円 |             +約6,465円 | −0.147pt |
| 1991 |                   −5,460円 |             +約4,813円 | −0.108pt |
| 1992 |                   −3,120円 |             +約2,676円 | −0.060pt |
| 1993 |                     −840円 |               +約777円 | −0.018pt |

1994年以降は本分析の標準労働者モデルにおいて男女差がなくなる。

1990→2025年の実質手取り変化率は、

| 性別 | 実質手取り変化率 |
| ---- | ---------------: |
| 男性 |          −18.64% |
| 女性 |          −18.78% |

となった。

女性の方が低下率がわずかに大きいのは、1990年時点の保険料が男性より低く、出発時点の実質手取りが高いためである。

差は約0.14ポイントにすぎない。

したがって、

> **対象期間初期の厚生年金保険料率の男女差を考慮しても、長期的な実質手取り低下という結論は変わらない。**

---

### 4.4 年齢と介護保険料

主分析の35歳モデルは介護保険第2号被保険者に該当しないため、介護保険料を負担しない。

そこで、毎年45歳の標準労働者が存在すると仮定し、40～64歳に適用される介護保険料を加えた感応度分析を行った。

主要年の35歳モデルとの差は次のとおりである。

|   年 | 介護保険料 | 名目手取り差 | 実質手取り差 | 負担率差 |
| ---: | ---------: | -----------: | -----------: | -------: |
| 1990 |        0円 |          0円 |          0円 |  0.000pt |
| 2000 |    7,560円 |     −6,460円 |     −6,701円 | +0.152pt |
| 2003 |   19,072円 |    −16,772円 |    −17,808円 | +0.409pt |
| 2010 |   27,469円 |    −23,269円 |    −24,878円 | +0.609pt |
| 2015 |   30,392円 |    −25,892円 |    −26,475円 | +0.684pt |
| 2020 |   33,765円 |    −28,765円 |    −28,765円 | +0.753pt |
| 2025 |   33,243円 |    −28,043円 |    −24,594円 | +0.657pt |

2000年以前は介護保険制度導入前であるため差はない。

2025年では、45歳モデルの介護保険料本人負担は約3.32万円となる。

ただし、介護保険料は社会保険料控除の対象となるため、所得税・住民税が減少する。

2025年では、

- 介護保険料：+33,243円
- 所得税：−1,800円
- 住民税：−3,400円

となり、介護保険料の一部が税負担低下によって相殺される。

その結果、名目手取りの純減少額は約2.80万円となった。

1990→2025年の実質手取り変化率は、

| 年齢 | 実質手取り変化率 |
| ---- | ---------------: |
| 35歳 |          −18.64% |
| 45歳 |          −19.32% |
| 差   |          −0.68pt |

である。

したがって、

> **介護保険料を負担する年齢層では実質手取りの低下幅はやや大きくなるが、1990→2025年の長期的な結論を大きく変えるほどではない。**

本分析では年齢による差を純粋に確認するため、45歳の同一人物を追跡するのではなく、各年に45歳の標準労働者が存在すると仮定している。

---

### 4.5 毎月勤労統計の賃金系列の断層

主分析では、毎月勤労統計の月次実額から年平均給与を作成している。

しかし、毎月勤労統計の実額系列には、標本交替やベンチマーク更新等による水準断層が含まれる可能性がある。

そこで、厚生労働省が公表する現金給与総額の前年比を1990年から順次連鎖した比較可能系列を作成し、実額系列による変化率と比較した。

結果は次のとおりである。

| 期間      | 指標         | 実額系列 | 公表前年比連鎖系列 |      差 |
| --------- | ------------ | -------: | -----------------: | ------: |
| 1990→2025 | 名目額面賃金 |   +8.33% |             +8.84% | +0.51pt |
| 1990→2025 | 実質額面賃金 |  −14.76% |            −14.36% | +0.40pt |
| 2015→2025 | 名目額面賃金 |  +12.72% |             +9.73% | −2.99pt |
| 2015→2025 | 実質額面賃金 |   −3.32% |             −5.88% | −2.56pt |

1990→2025年では、実額系列と連鎖系列の実質賃金変化率の差は約0.4ポイントにすぎない。

したがって、

> **1990年からの長期的な実質賃金低下は、実額系列の水準断層によって生じた結果ではない。**

一方、2015→2025年では、実質額面賃金の低下率が実額系列−3.32%に対し、連鎖系列では−5.88%となった。

約2.6ポイントの差があるため、

> **直近10年間の賃金変化幅については、毎月勤労統計の系列選択による不確実性を無視できない。**

このため、2015→2025年の賃金変化を評価する際には、実額端点比較だけを唯一の変化率として扱わず、公表前年比を連鎖した比較可能系列も併記する。

なお、税・社会保険料の推計には各年の円額の給与水準が必要であるため、連鎖指数を使って手取り額そのものを再計算することはしない。連鎖系列は賃金変化率の頑健性確認に限定して使用する。

---

### 4.6 頑健性確認のまとめ

各感応度分析の長期結果をまとめると、次のようになる。

| 確認項目         |                 主分析 |           感応度分析 | 評価                     |
| ---------------- | ---------------------: | -------------------: | ------------------------ |
| 住民税タイミング |                −19.36% |              −19.48% | 長期差は小さい           |
| 性別             |           男性 −18.64% |         女性 −18.78% | 差は小さい               |
| 年齢・介護保険   |           35歳 −18.64% |         45歳 −19.32% | やや悪化するが結論は同じ |
| 一時的減税       | 1996年が実質手取り最高 | 除外後も1996年が最高 | 時系列の形状は維持       |
| 賃金系列         |      1990→2025 −14.76% |     連鎖系列 −14.36% | 長期結論は頑健           |

以上から、

> **1990年代以降に実質手取りが大きく低下したという主分析の結果は、住民税の時間対応、性別、介護保険、一時的減税、賃金系列の選択を変更しても概ね維持される。**

と判断できる。

ただし、頑健性の程度はすべて同じではない。

特に注意が必要なのは、

- 2006～2007年のような住民税制度変更前後の単年変化
- 2015→2025年の賃金変化率
- 40～64歳の介護保険加入者の手取り水準

である。

したがって、長期的な方向性については比較的頑健な結果が得られた一方、特定年や直近10年間の変化幅については、単一の推計値だけでなく感応度分析を併せて解釈する必要がある。

---

## 5. 考察と限界

### 5.1 長期的な実質手取り低下をどう解釈するか

1990→2025年の標準労働者モデルでは、実質手取りは18.64%低下した。

この結果だけを見ると、「税・社会保険料の増加によって手取りが減った」と解釈しやすい。しかし、本分析の分解結果からは、その説明だけでは不十分である。

1990→2025年の4要因Shapley分解では、1990年の実質手取りに対して、

- 額面賃金要因：+6.49%
- 税制度要因：+1.27%
- 社会保険制度要因：−4.73%
- 物価要因：−21.68%

となった。

最大の押下げ要因は物価であり、社会保険制度の影響はそれに次ぐ。一方、税制度は長期ではむしろ実質手取りを押し上げる方向に寄与した。

したがって、1990年以降の実質手取り低下は、

> **名目賃金の伸びが弱い中で、社会保険負担が上昇し、さらに物価が賃金以上に上昇したことの組合せ**

として捉える必要がある。

特に、所得税の負担率は1990年の4.96%から2025年には1.77%へ低下している。そのため、「公的負担が増えた」という事実と「税負担が増えた」という主張は区別する必要がある。

---

### 5.2 税から社会保険料への負担構造の変化

1990→2025年の実効負担率は16.98%から20.76%へ3.78ポイント上昇した。

項目別には、

- 所得税：−3.19ポイント
- 住民税：+1.48ポイント
- 厚生年金：+3.73ポイント
- 健康保険：+1.75ポイント
- 雇用保険：+0.01ポイント

であった。

この結果から、給与から差し引かれる公的負担の構成は大きく変化したと考えられる。

1990年には所得税と厚生年金の負担率は近い水準だったが、2025年には厚生年金の負担率が所得税を大きく上回る。

また、賃金・税制度・社会保険制度を分離したShapley分解でも、1990→2025年の負担率変化+3.78ポイントのうち、社会保険制度要因は+4.23ポイント、税制度要因は−1.13ポイントとなった。

したがって、

> **長期的な給与控除負担の上昇は、税率の上昇よりも社会保険制度の変化による部分が大きい。**

ただし、ここから社会保険料の上昇そのものが望ましいか望ましくないかを判断することはできない。

社会保険料は年金・医療等の給付と対応する負担であり、本分析は給与から差し引かれる本人負担額のみを分析している。将来または現在受ける社会保障給付の価値は評価していない。

---

### 5.3 1990→2025年と2015→2025年では構造が異なる

分析期間の選択によって、実質手取り低下の背景は大きく異なる。

1990→2025年では実効負担率が3.78ポイント上昇しており、社会保険料負担の増加が長期的な手取りの伸びを抑制した。

一方、2015→2025年では実効負担率の変化は+0.04ポイントにすぎない。

この10年間では、

- 額面賃金：+12.72%
- 名目手取り：+12.67%
- CPI：+16.59%
- 実質手取り：−3.36%

であり、名目手取りは額面賃金とほぼ同じ割合で増加している。

4要因Shapley分解でも、2015→2025年の実質手取りに対する寄与は、

- 額面賃金：+11.57%
- 税制度：+0.63%
- 社会保険制度：−0.43%
- 物価：−15.13%

となった。

したがって、

> **近年の実質手取り低下を、1990年代以降の長期的な社会保険負担増と同じ構造で説明することはできない。**

2015→2025年では、制度負担の変化よりも、物価上昇に名目賃金が追いつかなかったことの方が重要である。

長期分析では、期間全体の結果だけでなく、どの時期に何が変化したかを分けて解釈する必要がある。

---

### 5.4 2000年代の特徴

2000→2010年には実質手取りが10.74%低下した。

この期間はCPIが2.97%低下しており、物価は実質手取りを押し上げる方向に働いた。それにもかかわらず実質手取りが大きく低下したのは、

- 額面賃金が10.46%低下したこと
- 実効負担率が2.73ポイント上昇したこと

による。

対数分解でも、賃金要因−11.05%、負担率要因−3.34%に対し、物価要因は+3.02%であった。

この結果は、

> **実質所得が悪化するためにインフレが必要なわけではなく、デフレ期でも名目賃金低下と負担増が組み合わされば購買力は低下し得る**

ことを示している。

---

### 5.5 2020年代前半の特徴

2020→2025年では、額面賃金は11.73%、名目手取りは11.80%増加した。

一方、CPIは14.03%上昇したため、実質手取りは1.95%低下した。

この期間の実効負担率は20.81%から20.76%へわずかに低下しているため、税・社会保険料が実質手取りを悪化させたとは言いにくい。

したがって、2020年代前半については、

> **名目賃金は明確に上昇したものの、その上昇率が物価上昇率に届かなかった**

という構図が中心となる。

これは、名目賃金の上昇だけを確認して生活水準の改善を判断することの難しさを示している。

---

### 5.6 本分析は「平均的な労働者の平均手取り」ではない

本分析で最も重要な制約は、結果が標準労働者モデルによるシミュレーションであることである。

各年について、

- 35歳
- 男性
- 単身
- 扶養なし
- 給与所得のみ

という属性を固定し、毎月勤労統計の平均賃金を与えている。

したがって、本分析の手取り額は、日本の労働者が実際に平均して受け取った手取り額を表すものではない。

税・社会保険料は非線形であるため、一般に、 $Tax(E[W]) \neq E[Tax(W)]$ である。

すなわち、「平均賃金に税制を適用した税額」と「各労働者の税額を計算して平均した値」は一致しない。

本分析は後者を推定するものではなく、

> **平均的な賃金水準を与えられた一定属性の標準労働者に、各年の制度を適用した場合の手取り**

を比較している。

そのため、結果は「平均手取り額」ではなく「標準労働者モデルによる手取り推計」と表現する必要がある。

---

### 5.7 毎月勤労統計の平均値を年間給与へ換算する限界

毎月勤労統計は事業所を対象とした集計統計であり、本分析で使用する給与額は個人を1年間追跡した年間給与ではない。

各年の月次平均値を単純平均し、 $12 \times \text{年平均月額}$ として年間給与相当額を作成している。

したがって、

- 同じ個人が12か月働いたとは限らない
- 労働者構成は月ごと・年ごとに変化する
- 入職・離職の影響が含まれる
- 労働時間や雇用形態の構成変化が平均給与に影響する

といった点に注意が必要である。

本分析は個人の生涯所得や同一人物の給与履歴を分析するものではない。

---

### 5.8 月例賃金・賞与のモデル化

社会保険料を計算するため、本分析では「きまって支給する給与」の年平均月額を各年を通じた月例報酬の代理値として用いている。

また、年間特別給与は6月と12月に半額ずつ支給されると仮定した。

実際には、

- 月例賃金は年内でも変化する
- 賞与の支給時期・回数は企業によって異なる
- 標準報酬月額は資格取得時決定、定時決定、随時改定等によって決まる

ため、本分析の社会保険料は個々の給与明細を厳密に再現したものではない。

特に標準報酬月額には等級があるため、平均月例賃金のわずかな差が必ずしも保険料に連続的に反映されるとは限らない。

本分析では制度の長期比較を優先し、年ごとに同一のルールで標準化して計算している。

---

### 5.9 健康保険料率の地域差

政府管掌健康保険時代については全国的な料率を使用し、協会けんぽ移行後については全国平均相当の保険料率を使用している。

実際の協会けんぽ保険料率は都道府県によって異なる。

したがって、2025年などの健康保険料は特定の都道府県に居住する労働者の実際の負担額とは一致しない。

本分析の目的は全国的な長期推移を比較することであるため、地域差を捨象している。

---

### 5.10 住民税の地域差と時間差

個人住民税については標準税率・標準的な均等割を使用している。

一部自治体の超過課税等は考慮していない。また、古い時期の均等割については標準的な自治体規模を仮定している部分がある。

さらに、主分析では所得年と税負担を対応させる `income_year` 方式を使用しているため、実際の給与からその年に控除される住民税とは時間対応が異なる。

特に2007年前後の税源移譲のように、所得税と住民税が同時期に大きく変更された場合、単年の変化率はこの計上方法に敏感となる。

ただし、`cash_flow` 感応度分析では長期変化率への影響が小さいことを確認している。

---

### 5.11 一時的減税と政策効果の解釈

主分析では、実際に適用された税制を再現するため、一時的な特別減税や定額減税も含めている。

そのため、特定年の手取り増加には恒久的な制度改正だけでなく、一時的措置の影響が含まれる。

一方、一時的減税を除いた感応度分析でも長期的な時系列の形状は大きく変わらなかった。

ただし、本分析から、

- 特定の減税政策が景気を改善した
- 社会保険料率引上げが賃金を低下させた
- 税制変更が雇用行動を変化させた

といった因果関係を示すことはできない。

制度を機械的に適用した場合の手取りへの直接効果を測定しているにすぎない。

---

### 5.12 固定制度反実仮想の解釈

制度変更の影響を確認するため、ある基準年の制度を別の年の賃金へ適用する固定制度反実仮想を使用している。

例えば2025年の賃金に1990年制度を適用すると、実際の2025年制度より手取りが約12.0万円高くなる。

ただし、この結果を、

> 「1990年制度を維持していれば、現実に2025年の手取りが12万円多かった」

という政策予測として解釈することはできない。

実際に制度を固定していれば、

- 賃金
- 雇用
- 社会保障給付
- 財政
- 企業行動
- 家計行動

なども変化していた可能性がある。

固定制度計算は、

> **同じ賃金に異なる制度を機械的に適用した場合の差**

を示す比較静学的な反実仮想である。

---

### 5.13 Shapley分解の解釈

Shapley分解は、非線形な税・社会保険制度のもとでも、最終的な変化を複数要因へ加法的に配分できる利点がある。

一方、その寄与は要因をどのように定義するかに依存する。

本分析では、 $R = f(W,T,S,P)$ として、

- 賃金
- 税制度
- 社会保険制度
- 物価

を独立した要因としている。

例えば税制度と社会保険制度をまとめて「制度」という1要因にすれば、個別のShapley値は変化する。

したがって、

> **Shapley値は唯一の「真の寄与率」ではなく、本分析で設定した要因分類のもとで、交互作用を公平に配分した結果**

として解釈する必要がある。

ただし、各分解の中ではShapley寄与の合計が実際の変化に一致しており、本分析では数値的な分解誤差がほぼゼロであることを確認している。

---

### 5.14 CPIによる実質化の限界

実質化には「持家の帰属家賃を除く総合」CPIを使用している。

これは既存の実質賃金分析との整合性を保つためである。

しかし、実際の生活費上昇率は家計によって異なる。

例えば、

- 住居形態
- 年齢
- 世帯人数
- 食料・エネルギー支出比率
- 自動車保有
- 医療・教育支出

によって、個々の家計が直面する物価上昇率は異なる。

したがって、実質手取りは標準的な消費者物価で調整した購買力指標であり、特定世帯の生活水準を直接示すものではない。

また、消費税等の間接税は給与から直接控除していない。その影響は原則として商品・サービス価格を通じてCPIに含まれるものとして扱っている。

---

### 5.15 「手取り賃金」と「可処分所得」の違い

本分析では、給与から所得税・住民税・本人負担社会保険料を控除した額を「名目手取り賃金」と呼ぶ。

これは家計統計や国民経済計算で用いられる「可処分所得」と同一ではない。

可処分所得には、

- 給与以外の所得
- 社会保障給付
- 財産所得
- 世帯内の他の所得者
- その他の経常移転

などが含まれ得る。

本分析ではこれらを扱っていない。

したがって、結果から日本の家計全体の可処分所得が18.6%低下したと解釈することはできない。

---

### 5.16 本分析で分からないこと

以上の制約から、本分析で直接答えられるのは、

> **一定属性の標準労働者に毎月勤労統計の平均賃金水準を与え、各年の税・社会保険制度を適用した場合、手取りとその購買力がどのように変化するか**

である。

一方、本分析だけでは、

- 実際の個人の手取り分布
- 世帯別の可処分所得
- 正規・非正規、年齢、所得階級別の違い
- 社会保険料に対応する給付の便益
- 税・社会保険制度変更の行動変化
- 政策変更の因果効果

までは判断できない。

したがって、本分析は日本の生活水準全体を一つの数値で評価するものではなく、

> **賃金、直接負担、物価という三つの経路を同じ標準労働者モデル上で統合し、長期的な手取り購買力の変化を可視化する分析**

として位置づけるのが適切である。

---

## 6. 結論と今後の課題

### 6.1 結論

本分析では、厚生労働省「毎月勤労統計調査」の平均賃金水準に、各年の所得税・個人住民税・厚生年金・健康保険・雇用保険制度を適用し、1990～2025年の標準労働者モデルにおける名目手取り賃金と実質手取り賃金を推計した。

主分析では、各年に35歳・男性・単身・扶養なし・給与所得のみの標準労働者が存在すると仮定した。

主要な結果は次のとおりである。

1. **年間額面給与は1990→2025年に8.33%増加したが、名目手取りの増加は3.40%にとどまった。**
   実効負担率が16.98%から20.76%へ3.78ポイント上昇したため、額面賃金の伸びの一部が税・社会保険料負担によって相殺された。

2. **実質手取りは1990→2025年に18.64%低下した。**
   CPIが27.10%上昇したため、名目手取りの小幅な増加では物価上昇を補えなかった。

3. **長期的な負担率上昇の中心は社会保険料であった。**
   1990→2025年の負担率変化は、所得税−3.19ポイント、住民税+1.48ポイント、厚生年金+3.73ポイント、健康保険+1.75ポイント、雇用保険+0.01ポイントであった。

4. **制度要因を分離すると、社会保険制度は負担率を押し上げ、税制度は押し下げる方向に寄与した。**
   3要因Shapley分解では、1990→2025年の負担率変化+3.78ポイントに対し、賃金水準+0.68ポイント、税制度−1.13ポイント、社会保険制度+4.23ポイントとなった。

5. **実質手取り低下の最大の押下げ要因は物価上昇であった。**
   4要因Shapley分解では、1990年実質手取り比で、額面賃金+6.49%、税制度+1.27%、社会保険制度−4.73%、物価−21.68%となった。

6. **実質手取り低下の構造は時期によって異なる。**
   2000年代は賃金低下と負担率上昇、2010年代は物価上昇と社会保険負担増、2020年代前半は名目賃金を上回る物価上昇の影響が大きかった。

7. **2015→2025年については、税・社会保険負担増より物価上昇の影響が大きい。**
   額面賃金+12.72%、名目手取り+12.67%、CPI+16.59%、実質手取り−3.36%であり、負担率の変化は+0.04ポイントにとどまった。

8. **長期的な結論は主要な仮定変更に対して概ね頑健であった。**
   女性モデルでは1990→2025年の実質手取り−18.78%、45歳モデルでは−19.32%、公表前年比を連鎖した実質額面賃金では−14.36%となり、主分析の方向性は維持された。

以上から、本分析の標準労働者モデルでは、

> **1990年以降、名目額面賃金はわずかに増加したものの、社会保険料を中心とする本人負担の上昇によって手取りの伸びが抑えられ、さらに物価上昇によって実質的な手取り購買力は大きく低下した。**

と結論づけられる。

ただし、これは日本の平均的な個人や世帯の実際の可処分所得を推計した結果ではない。一定の属性と平均賃金水準を与えた標準労働者モデルにおける制度比較である。

---

### 6.2 今後の課題

#### 所得階級別分析

税・社会保険制度は非線形であるため、平均賃金水準だけでは所得階級による影響の違いを捉えられない。

今後は、

- 低賃金
- 中央的な賃金
- 高賃金

など複数の給与水準を設定し、負担率・手取り率の変化を比較する余地がある。

これにより、

> 平均賃金水準で観察された負担増が、どの所得階級で強かったのか

を確認できる。

#### 年齢・世帯属性別分析

本分析では35歳・単身・扶養なしを主ケースとした。

今後、

- 40～64歳
- 配偶者あり
- 扶養親族あり
- 子どもあり

などのモデルを追加すれば、基礎控除以外の所得控除や介護保険料を含む制度差を確認できる。

ただし、ケースを増やしすぎると分析の主眼が不明確になるため、実際に意味のある代表ケースに限定する必要がある。

#### 健康保険の地域差

協会けんぽ移行後は都道府県別保険料率が存在する。

全国平均に加えて、

- 保険料率の低い地域
- 全国平均付近
- 保険料率の高い地域

を比較することで、地域差が標準労働者の手取りへ与える影響を確認できる。

#### 賃金分布との統合

本分析は平均賃金に制度を適用しているため、実際の労働者分布を考慮していない。

賃金構造基本統計調査等の賃金分布と統合できれば、 $E[TakeHome(W)]$ を直接近似し、 $TakeHome(E[W])$ との違いを検証できる。

これは本分析を「標準労働者モデル」から「労働者集団の平均手取り推計」へ拡張する際の重要な課題である。

#### 社会保障給付との統合

本分析では社会保険料を負担として扱う一方、対応する、

- 年金給付
- 医療給付
- 傷病手当等

の便益を評価していない。

したがって、本分析は公的制度の純便益分析ではない。

より広い厚生分析を行う場合には、負担側だけでなく給付側を含める必要がある。

#### 公式実質賃金系列との比較

主分析では円額の手取りを構築するため、毎月勤労統計の実額系列とCPIを使用した。

一方、賃金変化率については、公表前年比連鎖系列との差が2015→2025年で一定程度存在した。

今後は公式実質賃金指数との比較を補助的に整理することで、

- 本分析の機械的な実質額面賃金
- 毎月勤労統計の公式実質賃金指数

の関係をより明確にできる。

## 付録A. 指標・計算式の詳細

### A.1 年間額面給与

各年 $t$ の月次現金給与総額を $W_{t,m}$ とすると、年平均月額は、

$$\bar{W}_t = \frac{1}{12} \sum_{m=1}^{12} W_{t,m}$$

とする。

年間額面給与相当額は、

$$W_t = 12 \bar{W}_t$$

である。

同様に、

$$Regular_t = 12 \bar{M}_t$$

$$Bonus_t = 12 \bar{B}_t$$

として、月例賃金相当額と年間賞与相当額を構築する。

---

### A.2 社会保険料

年間社会保険料を、

$$SI_t = Pension_t + Health_t + Employment_t + LTC_t$$

とする。

主分析の35歳モデルでは、

$$LTC_t = 0$$

である。

厚生年金・健康保険の月例給与分は、各年の「きまって支給する給与」の年平均月額から標準報酬月額を決定し、該当月の保険料率を適用する。

概念的には、

$$Contribution_{t,m} = StandardMonthlyRemuneration_{t,m} \times Rate_{t,m} \times EmployeeShare_{t,m}$$

である。

賞与については、制度上の標準賞与額、端数処理、上限を適用して計算する。

---

### A.3 給与所得

給与収入を $W_t$、給与所得控除を $SD_t$ とすると、

$$SalaryIncome_t = W_t - SD_t$$

とする。

給与所得控除は各年の制度に基づく区分式を適用する。

---

### A.4 所得税

所得税の課税所得を概念的に、

$$TaxableIncome_t = SalaryIncome_t - SocialInsurance_t - BasicDeduction_t$$

とする。

実際の計算では各年の端数処理を反映する。

基礎税額は、

$$BaseIncomeTax_t = f_t(TaxableIncome_t)$$

とし、各年の累進税率・控除額を適用する。

さらに必要に応じて、

- 特別減税
- 定率減税
- 定額減税
- 復興特別所得税

等を反映し、最終所得税額を算出する。

---

### A.5 個人住民税

個人住民税の課税所得は、

$$ResidentTaxableIncome_t = SalaryIncome_t - SocialInsurance_t - ResidentBasicDeduction_t$$

を基本とする。

所得割は、

$$ResidentIncomeLevy_t = g_t(ResidentTaxableIncome_t)$$

として各年の税率を適用する。

これに、

- 調整控除
- 一時的減税
- 均等割
- 森林環境税等

を加減して最終的な住民税額を算出する。

---

### A.6 名目手取り

控除総額を、

$$D_t = IncomeTax_t + ResidentTax_t + Pension_t + Health_t + Employment_t + LTC_t$$

とする。

名目手取り賃金は、

$$N_t = W_t - D_t$$

である。

---

### A.7 実効負担率

実効負担率は、

$$d_t = \frac{D_t}{W_t}$$

とする。

手取り率は、

$$q_t = \frac{N_t}{W_t} = 1-d_t$$

である。

各控除項目 $k$ の負担率は、

$$d_{k,t} = \frac{D_{k,t}}{W_t}$$

として算出する。

---

### A.8 実質額面賃金・実質手取り

CPIを $P_t$ とすると、

$$RealGross_t = \frac{W_t}{P_t/100}$$

$$R_t = \frac{N_t}{P_t/100}$$

とする。

ここで $R_t$ が実質手取り賃金である。

---

### A.9 1990年=100指数

指標 $X_t$ について、

$$Index_{X,t} = \frac{X_t}{X_{1990}} \times 100$$

とする。

主として、

- 額面名目賃金
- 名目手取り
- 実質額面賃金
- 実質手取り

を同じ基準で比較するために用いる。

---

### A.10 期間変化率

指標 $X$ の $t_0$ から $t_1$ への変化率は、

$$g_X = \left( \frac{X_{t_1}}{X_{t_0}} - 1 \right) \times 100$$

とする。

---

### A.11 実質手取りの対数分解

実質手取りは、

$$R = \frac{W(1-d)}{P}$$

と書けるため、

$$\ln R = \ln W + \ln(1-d) - \ln P$$

である。

したがって、

$$\Delta\ln R = \Delta\ln W + \Delta\ln(1-d) - \Delta\ln P$$

となる。

各項は、

- $\Delta\ln W$：額面賃金要因
- $\Delta\ln(1-d)$：負担率要因
- $-\Delta\ln P$：物価要因

として解釈する。

---

### A.12 Shapley分解

#### 実効負担率

実効負担率を、

$$d=f(W,T,S)$$

とする。

ここで、

- $W$：賃金水準
- $T$：所得税・住民税制度
- $S$：社会保険制度

である。

開始年から終了年への各要因の変更順序をすべて列挙し、各要因を追加した際の限界効果を全順序で平均してShapley値を求める。

3要因の場合、順序は、

$$3! = 6$$

通りである。

#### 実質手取り

実質手取りについては、

$$R=f(W,T,S,P)$$

とする。

4要因の変更順序、

$$4! = 24$$

通りについて限界効果を平均する。

各Shapley寄与の合計は、

$$\sum_i \phi_i = R_1 - R_0$$

となる。

本分析では数値的な分解誤差がほぼゼロであることを確認した。

---

### A.13 公表前年比連鎖系列

公表前年比を $g_t$ とすると、1990年を100として、

$$W_{1990}^{chain} = 100$$

$$W_t^{chain} = W_{t-1}^{chain} \left( 1 + \frac{g_t}{100} \right)$$

として連鎖指数を作成する。

実質連鎖賃金指数は、1990年=100に再基準化したCPIを $P_t^{1990}$ として、

$$RW_t^{chain} = \frac{W_t^{chain}}{P_t^{1990}} \times 100$$

とする。

この系列は賃金変化率の頑健性確認にのみ使用する。

---

### B.14 再現時の注意点

再計算時には、少なくとも以下を確認する。

1. 毎月勤労統計の対象条件が「調査産業計・5人以上・就業形態計」であること。
2. 各年1～12月がすべて存在すること。
3. 現金給与総額、きまって支給する給与、特別給与に欠損がないこと。
4. 現金給与総額＝きまって支給する給与＋特別給与が成立すること。
5. CPIが各年12か月そろっていること。
6. 制度ルール表の適用期間に欠損・重複がないこと。
7. 35歳主分析で介護保険料が0であること。
8. 各年で額面給与－控除総額＝名目手取りが成立すること。
9. Shapley寄与の合計が実際の変化に一致すること。
10. 保存済み主要年の結果と再計算値が一致すること。

これらを満たす場合、本文の主要な数値結果を再現できる。
