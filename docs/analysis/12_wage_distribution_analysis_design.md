# 賃金分布分析 設計書

作成日：2026-09-06  
想定配置先：`docs/analysis/12_wage_distribution_analysis_design.md`

---

## 1. 分析の位置づけ

本プロジェクトではこれまで、雇用形態、給与構成、労働投入、産業、産業構成、労働需給、企業業績・生産性・労働分配、企業の賃金改定行動、実質賃金、事業所規模、最低賃金を分析してきた。

これらは主として平均値を対象としているため、

- 低賃金層が強く上昇したのか
- 中央値付近が中心に上昇したのか
- 高賃金層の上昇によって平均値が押し上げられたのか

を十分に判別できない。

本分析では、**賃金分布の分位点を用いて、2015年以降の賃金上昇が分布のどの層で生じたかを確認する。**

---

## 2. 中心となる問い

> **2015年以降の賃金上昇は、賃金分布のどの層で生じたのか。低賃金層・中間層・高賃金層で伸び方は異なるか。**

この問いを以下に分解する。

1. P10、P25、P50、P75、P90は2015年以降どの程度上昇したか
2. 下位分位の上昇率は中央値・上位分位を上回ったか
3. P90/P10、P90/P50、P50/P10などの分位間格差は縮小したか
4. 名目賃金と実質賃金では分布変化の評価がどう異なるか
5. 男女、雇用形態、年齢などによって分布変化は異なるか
6. 分布下側の変化は最低賃金引上げとどの程度整合的か

---

## 3. 分析期間

主分析期間は、

```text
2015年～2025年
```

とする。

---

## 4. 使用データ

### 4.1 賃金構造基本統計調査

厚生労働省「賃金構造基本統計調査」の所定内給与額の分布特性値を使用する。

主な分位は以下とする。

- 第1十分位数：P10
- 第1四分位数：P25
- 中位数：P50
- 第3四分位数：P75
- 第9十分位数：P90

利用可能であれば、

- 十分位分散係数
- 四分位分散係数

も使用する。

### 4.2 物価

実質分位賃金の算出には、既存分析と同じCPI系列「持家の帰属家賃を除く総合」を使用する。

### 4.3 最低賃金

最低賃金分析との接続には、地域別最低賃金全国加重平均の2015～2025年度値を使用する。

---

## 5. 主指標

主指標は、**月額の所定内給与額の分位点**とする。

当初検討した時間当たり賃金分布は、公表分位からは正確に構築できない。

例えば、

```text
給与のP10 ÷ 労働時間のP10
```

は時間当たり賃金のP10にはならない。

したがってv1では月額所定内給与額の分布を分析する。

---

## 6. 分位別賃金指数

各分位について2015年=100の指数を作成する。

$$Index_{p,t} = \frac{W_{p,t}}{W_{p,2015}} \times 100$$

対象は、

```text
P10
P25
P50
P75
P90
```

とする。

---

## 7. 2015年から2025年の分位別変化

主結果として以下を作成する。

| 分位 | 2015年 | 2025年 | 名目変化率 | 実質変化率 |
| ---- | -----: | -----: | ---------: | ---------: |
| P10  |        |        |            |            |
| P25  |        |        |            |            |
| P50  |        |        |            |            |
| P75  |        |        |            |            |
| P90  |        |        |            |            |

特に、

```text
P10・P25
vs
P50
vs
P75・P90
```

の伸び率差を確認する。

---

## 8. 賃金格差指標

以下を算出する。

### P90/P10

$$D_{90/10} = \frac{P90}{P10}$$

### P90/P50

$$D_{90/50} = \frac{P90}{P50}$$

### P50/P10

$$D_{50/10} = \frac{P50}{P10}$$

最低賃金分析との接続上、特にP50/P10を重視する。

また、公表されている十分位分散係数・四分位分散係数が利用可能であれば、独自分位比との方向一致を確認する。

---

## 9. 実質分位賃金

各分位をCPIで実質化する。

$$RealW_{p,t} = \frac{NominalW_{p,t}}{CPI_t/100}$$

さらに2015年=100として指数化する。

目的は、

> 名目では賃金が上昇していても、物価上昇後の購買力が各分位でどの程度改善したか

を確認することである。

---

## 10. 属性別分析

v1では範囲を広げすぎないよう優先順位を設定する。

### 優先度S

- 男女別
  - 男女計
  - 男性
  - 女性
- 雇用形態別
  - 正社員・正職員
  - 正社員・正職員以外
  - 実際の公表区分を優先する

### 優先度A

- 年齢階級別
- 企業規模別

### 優先度B

- 産業別
- 職種別
- 学歴別
- 勤続年数別

---

## 11. 最低賃金分析との接続

最低賃金は時間当たりの制度値であり、P10～P90は月額所定内給与額である。

したがって、

$$最低賃金 / P10$$

のような比率は使用しない。

接続は2015～2025年の伸び率比較で行う。

| 指標     | 2015→2025変化率 |
| -------- | --------------: |
| 最低賃金 |          +40.5% |
| P10      |                 |
| P25      |                 |
| P50      |                 |
| P75      |                 |
| P90      |                 |

ここから、

> 最低賃金が大きく上昇した期間に、賃金分布の下位側が中央値・上位側より強く上昇したか

を確認する。

これは時系列上の整合性を見るものであり、最低賃金の因果効果を推定するものではない。

---

## 12. 仮説

### 仮説1

> 2015～2025年では、P10・P25の所定内給与上昇率がP50・P75・P90を上回り、賃金分布の下側が相対的に強く上昇した。

### 仮説2

> P50/P10およびP90/P10は低下し、分布下側との賃金格差は縮小した。

### 仮説3

> 実質化すると名目ほど改善せず、特に2022年以降の物価上昇によって各分位の購買力改善が抑えられた。

### 仮説4

> 分布下側の上昇は男女・雇用形態・年齢によって異なり、平均的な分布変化の背後に属性差が存在する。

### 補助仮説

> 分布下位の相対的に強い上昇は、同期間の最低賃金引上げと整合的に動いている。

---

## 13. 相関分析

最低賃金前年比とP10前年比などの相関分析は補助的に扱う。

主結果は、

- 分位別長期上昇率
- 分位比
- 実質分位賃金
- 属性別分布

とする。

観測数が少なく、年度・年次のずれや共通トレンドの影響があるため、相関を因果的に解釈しない。

---

## 14. 属性構成変化への注意

分位点の変化は、同一人物・同一属性の賃金変化だけを意味しない。

年齢、性別、雇用形態、職種、企業規模などの構成変化によって分布自体が変化する可能性がある。

したがってv1では、

> 賃金分布そのものがどう変化したか

を記述する。

属性構成を固定した分解は将来の拡張とする。

## 19. 因果解釈の範囲

本分析で主に言えるのは、

- どの分位の賃金が上昇したか
- 分布下側と上側で伸び率が異なるか
- 分位間格差が縮小・拡大したか
- 実質購買力が各分位でどう変化したか
- 属性別に分布変化が異なるか
- 最低賃金上昇と分布下側の上昇が時系列的に整合するか

である。

一方、

- 最低賃金がP10を何%押し上げたか
- 属性構成変化を除いた純粋な賃金率上昇
- 個々の労働者の賃金変化
- 分布変化の因果的要因

は本分析だけでは識別しない。

## 20. 設計上の結論

本分析のv1は、

> **賃金構造基本統計調査の所定内給与額分布を用いて、2015～2025年のP10・P25・P50・P75・P90の変化を確認し、賃金上昇が分布のどの層で生じたか、分位間格差がどう変化したかを明らかにする**

ことを中心とする。

最低賃金分析との接続は、

> **最低賃金が大きく上昇した期間に、賃金分布下位の伸びが中央値・上位層を上回ったか**

という長期的な整合性の確認として行う。
