# 12. 賃金分布分析

## 12.1 分析目的

2015年以降、日本の名目賃金は上昇している。しかし、平均賃金の上昇だけでは、その改善が賃金分布のどの層で生じたのかは分からない。

本分析では、賃金構造基本統計調査の所定内給与額の分布特性値を用いて、2015～2025年について次の問いを検討する。

> 2015年以降の賃金上昇は、賃金分布のどの層で生じたのか。低賃金層・中間層・高賃金層で伸び方は異なるか。

特に以下を確認する。

- P10、P25、P50、P75、P90の名目賃金上昇率
- 賃金分布内部の格差の変化
- CPIで実質化した場合に購買力が改善した分位
- 男女別の違い
- 正社員・正職員と正社員・正職員以外の違い
- 最低賃金上昇との時系列的な整合性

---

## 12.2 データと分析対象

### 賃金分布

厚生労働省「賃金構造基本統計調査」の一般労働者について、所定内給与額の分布特性値を利用する。

主要指標は以下である。

| 指標           | 意味                         |
| -------------- | ---------------------------- |
| P10            | 第1十分位数                  |
| P25            | 第1四分位数                  |
| P50            | 中位数                       |
| P75            | 第3四分位数                  |
| P90            | 第9十分位数                  |
| 十分位分散係数 | P10・P90を用いた分布の広がり |
| 四分位分散係数 | P25・P75を用いた分布の広がり |

基本集計の対象は以下で統一した。

- 民営事業所
- 産業計
- 企業規模計（10人以上）
- 男女計
- 学歴計
- 年齢計
- 一般労働者

また、属性別分析として男女別および雇用形態別を行った。

### 雇用形態別データの取得

雇用形態別については、e-Statの提供形式が期間によって異なるため、以下の方法を組み合わせた。

- 2015～2019年：e-Stat API
- 2020～2023年：e-Stat API
- 2024～2025年：e-Stat提供Excel

分析対象は、

- 正社員・正職員計
- 正社員・正職員以外計

の2区分である。

### CPI

名目賃金を実質化するため、「持家の帰属家賃を除く総合」の消費者物価指数を使用した。

各年の実質賃金は、

`名目所定内給与額 / (CPI / 100)`

として算出し、その後2015年を100として指数化した。

---

## 12.3 賃金分布全体の変化

### 名目所定内給与額

2015年と2025年を比較すると次のようになった。

| 分位 | 2015年 | 2025年 | 変化率 |
| ---- | -----: | -----: | -----: |
| P10  |  166.0 |  199.9 | +20.4% |
| P25  |  204.1 |  238.2 | +16.7% |
| P50  |  263.4 |  296.6 | +12.6% |
| P75  |  359.3 |  389.8 |  +8.5% |
| P90  |  487.9 |  527.3 |  +8.1% |

伸び率には明確な順序がみられる。

> P10 > P25 > P50 > P75 > P90

したがって、2015～2025年の名目所定内給与額の上昇は、分布全体に均等に発生したのではなく、低賃金側ほど強かった。

特にP10は約20%上昇したのに対し、P90は約8%にとどまる。

---

## 12.4 賃金分布の圧縮

下位賃金の伸びが相対的に強かったため、分布内の格差指標も縮小した。

### 分位比

| 指標      | 2015年 | 2025年 |
| --------- | -----: | -----: |
| P90 / P10 |  2.939 |  2.638 |
| P90 / P50 |  1.852 |  1.778 |
| P50 / P10 |  1.587 |  1.484 |

P90/P10だけでなく、P50/P10も低下している。

これは単に高賃金層と低賃金層の差が縮小しただけではなく、中央値と下位層の差も縮小したことを意味する。

### 分散係数

| 指標           | 2015年 | 2025年 |
| -------------- | -----: | -----: |
| 十分位分散係数 |   0.61 |   0.55 |
| 四分位分散係数 |   0.29 |   0.26 |

分位比と分散係数の双方が低下していることから、

> 2015～2025年の所定内給与分布は、全体として圧縮方向に動いた

と評価できる。

なお、この圧縮は2024～2025年だけに生じたものではない。P90/P10や十分位分散係数は2010年代後半から継続的に低下しており、長期的な変化である。

2024年には一時的にP90/P10や十分位分散係数がやや上昇したが、2025年には再び低下している。

---

## 12.5 実質賃金分布

名目上昇率だけでは購買力の改善を評価できないため、CPIで実質化した。

2025年の2015年比実質指数は以下のとおりである。

| 分位 | 2025年実質指数 |
| ---- | -------------: |
| P10  |          103.3 |
| P25  |          100.1 |
| P50  |           96.6 |
| P75  |           93.1 |
| P90  |           92.7 |

この結果は名目賃金とは大きく異なる。

- P10：2015年比で約3.3%改善
- P25：ほぼ横ばい
- P50：約3.4%低下
- P75：約6.9%低下
- P90：約7.3%低下

つまり、2015～2025年ではすべての分位で名目賃金は上昇したものの、物価上昇まで考慮すると改善が残ったのは主として低賃金側である。

> 名目賃金の改善は分布全体に及んだが、実質購買力の改善は低賃金側に集中した。

特に2022年以降の物価上昇によって、中央値以上の名目賃金上昇の多くが相殺された。

---

## 12.6 男女別分析

### 12.6.1 名目賃金

2015～2025年の上昇率は以下のとおりである。

| 分位 |   女性 |   男性 |
| ---- | -----: | -----: |
| P10  | +24.2% | +17.3% |
| P25  | +21.9% | +14.3% |
| P50  | +19.3% | +10.9% |
| P75  | +15.9% |  +8.4% |
| P90  | +13.4% |  +9.0% |

男女とも、

> 下位分位ほど伸びが大きい

という基本パターンは共通している。

一方、すべての分位で女性の上昇率が男性を上回った。

---

### 12.6.2 男女それぞれの分布圧縮

女性では、

- P90/P10：2.394 → 2.185
- P50/P10：1.461 → 1.403
- 十分位分散係数：0.48 → 0.42
- 四分位分散係数：0.23 → 0.20

男性では、

- P90/P10：2.918 → 2.711
- P50/P10：1.604 → 1.516
- 十分位分散係数：0.60 → 0.56
- 四分位分散係数：0.30 → 0.27

となった。

したがって、男女双方で賃金分布は圧縮方向に動いている。

---

### 12.6.3 男女間の賃金水準差

女性の所定内給与額を男性で割った比率は、2015～2025年にすべての分位で長期的に上昇した。

| 分位 | 2015年 | 2025年 |
| ---- | -----: | -----: |
| P10  |  81.5% |  86.3% |
| P25  |  78.3% |  83.5% |
| P50  |  74.3% |  79.9% |
| P75  |  69.3% |  74.1% |
| P90  |  66.9% |  69.6% |

男女間の所定内給与額の水準差は縮小しているが、高賃金側ほど依然として差が大きい。

ただし、これは同一職務・同一条件で調整した「男女間賃金格差」を測定したものではない。

年齢、勤続年数、職種、産業、企業規模などの構成差が含まれるため、

> 男女別の所定内給与分布の水準差

として解釈する必要がある。

---

### 12.6.4 男女別実質賃金

2025年の2015年比実質指数は以下のとおりである。

| 分位 |  女性 |  男性 |
| ---- | ----: | ----: |
| P10  | 106.6 | 100.6 |
| P25  | 104.5 |  98.1 |
| P50  | 102.3 |  95.1 |
| P75  |  99.4 |  93.0 |
| P90  |  97.3 |  93.5 |

女性ではP10～P50まで2015年水準を上回っている。

一方、男性ではP10がほぼ横ばいであり、P25以上では2015年を下回った。

したがって、

> 女性では低～中位層まで実質賃金の改善が残ったのに対し、男性では実質改善がほぼ下位層に限定された

という違いが確認できる。

---

## 12.7 雇用形態別分析

### 12.7.1 名目賃金

2015～2025年の上昇率は以下のとおりである。

| 分位 | 正社員・正職員 | 正社員・正職員以外 |
| ---- | -------------: | -----------------: |
| P10  |         +18.9% |             +24.3% |
| P25  |         +16.0% |             +21.6% |
| P50  |         +11.9% |             +19.1% |
| P75  |          +8.3% |             +15.3% |
| P90  |          +8.3% |             +12.4% |

両雇用形態とも、

> P10 > P25 > P50 > P75・P90

という下位分位ほど伸びが大きい構造が確認できる。

また、すべての分位で正社員・正職員以外の上昇率が正社員・正職員を上回った。

---

### 12.7.2 雇用形態別の分布圧縮

正社員・正職員では、

- P90/P10：2.796 → 2.547
- P50/P10：1.542 → 1.450
- 十分位分散係数：0.58 → 0.53
- 四分位分散係数：0.28 → 0.25

正社員・正職員以外では、

- P90/P10：2.137 → 1.932
- P50/P10：1.350 → 1.294
- 十分位分散係数：0.42 → 0.36
- 四分位分散係数：0.20 → 0.17

となった。

したがって、正社員・正職員、正社員・正職員以外の双方で内部の賃金分布は圧縮している。

---

### 12.7.3 雇用形態別実質賃金

2025年の2015年比実質指数は次のとおりである。

| 分位 | 正社員・正職員 | 正社員・正職員以外 |
| ---- | -------------: | -----------------: |
| P10  |          102.0 |              106.6 |
| P25  |           99.5 |              104.3 |
| P50  |           95.9 |              102.2 |
| P75  |           92.9 |               98.9 |
| P90  |           92.9 |               96.4 |

正社員・正職員ではP10のみが2015年水準をわずかに上回り、P25以上は実質低下した。

一方、正社員・正職員以外ではP10～P50が2015年水準を上回った。

したがって、

> 実質賃金の改善は正社員・正職員以外の低～中位層でより広く確認される。

この結果は、賃金改善が高賃金側より低賃金側で強かったという全体分析とも整合的である。

---

## 12.8 企業規模別分析

### 12.8.1 名目賃金

企業規模別に2015年から2025年の所定内給与分布を比較すると、すべての企業規模で名目賃金は上昇したが、上昇率には明確な差がみられた。

| 分位 | 大企業 | 中企業 | 小企業 |
| ---- | -----: | -----: | -----: |
| P10  | +17.0% | +20.5% | +22.1% |
| P25  | +12.8% | +17.1% | +19.4% |
| P50  |  +7.6% | +13.2% | +16.0% |
| P75  |  +4.4% | +10.2% | +12.8% |
| P90  |  +7.5% |  +9.3% | +11.6% |

全体として、企業規模が小さいほど名目賃金上昇率が高く、特にP10～P50の低～中位分位で差が大きい。

また、各企業規模の内部では、おおむね下位分位ほど伸び率が高い。

したがって、

> 2015～2025年の名目賃金上昇は、企業規模が小さいほど強く、かつ各規模の内部でも低賃金側ほど強かった

と整理できる。

---

### 12.8.2 企業規模別の分布圧縮

P90/P10は、2015年から2025年にかけて以下のように低下した。

| 企業規模 | 2015年 | 2025年 |
| -------- | -----: | -----: |
| 大企業   |  3.257 |  2.994 |
| 中企業   |  2.750 |  2.495 |
| 小企業   |  2.531 |  2.314 |

十分位分散係数も、

- 大企業：0.67 → 0.64
- 中企業：0.57 → 0.51
- 小企業：0.50 → 0.45

へ低下した。

四分位分散係数も、

- 大企業：0.34 → 0.30
- 中企業：0.27 → 0.24
- 小企業：0.25 → 0.22

とすべての規模で低下している。

したがって、企業規模にかかわらず賃金分布は圧縮方向に動いている。

一方、分布の広がりそのものは大企業ほど大きく、2025年時点でもP90/P10は大企業が約2.99、小企業が約2.31となっている。

---

### 12.8.3 企業規模別実質賃金

CPIで実質化した2025年の2015年比指数は以下のとおりである。

| 分位 | 大企業 | 中企業 | 小企業 |
| ---- | -----: | -----: | -----: |
| P10  |  100.3 |  103.3 |  104.7 |
| P25  |   96.8 |  100.4 |  102.4 |
| P50  |   92.3 |   97.1 |   99.5 |
| P75  |   89.5 |   94.5 |   96.8 |
| P90  |   92.2 |   93.8 |   95.7 |

大企業では、P10のみが2015年水準をわずかに上回り、P25以上では実質賃金が低下した。

中企業ではP10とP25が2015年水準を上回る一方、P50以上では下回った。

小企業ではP10とP25が明確に2015年水準を上回り、P50もほぼ2015年水準を維持した。

特に中央値P50では、

- 大企業：92.3
- 中企業：97.1
- 小企業：99.5

となっており、企業規模が小さいほど実質賃金の低下幅が小さい。

したがって、

> 実質賃金の改善は相対的に小規模企業の低～中位層で強く残った

と整理できる。

ただし、これは「小企業の賃金水準が大企業より高い」ことを意味しない。

2015年・2025年とも、所定内給与額の絶対水準は大企業ほど高い。ここで比較しているのはあくまで2015年からの変化率である。

---

### 12.8.4 解釈上の注意

企業規模別の違いには、企業規模そのものの効果だけでなく、

- 産業構成
- 職種構成
- 年齢構成
- 性別構成
- 勤続年数
- 雇用形態構成
- 地域構成

などの違いが含まれる。

したがって、

> 小企業で賃金上昇率が高かった原因が企業規模そのものにある

と因果的に解釈することはできない。

本分析から言えるのは、

> 2015～2025年の所定内給与分布では、小規模企業ほど低～中位分位の名目賃金上昇率が高く、実質化後も2015年水準を維持・上回る分位が相対的に広かった

という記述的事実である。

---

## 12.9 最低賃金との関係

2015～2025年の最低賃金は大きく上昇している。

同期間には、

- P10が最も強く上昇
- P25がそれに続く
- P50以上では上昇率が相対的に低い
- 正社員・正職員以外で強い賃金上昇
- 賃金分布の圧縮

という現象が確認された。

これは、

> 最低賃金が大幅に引き上げられた期間に、賃金分布の下位側ほど強い賃金上昇が生じた

という点で整合的である。

特に2015～2025年の最低賃金上昇率は約40.5%であり、低賃金層の賃金上昇と同時期に進行している。

ただし、本分析から最低賃金引上げの因果効果を推定することはできない。

最低賃金以外にも、

- 労働需給
- 人手不足
- 企業の賃上げ
- 雇用構成の変化
- 年齢構成の変化
- 産業構成の変化
- 労働市場制度の変化

などが賃金分布に影響しうる。

したがって、

> 低賃金側の強い賃金上昇は、最低賃金が大幅に引き上げられた時期と整合的である

という記述にとどめる。

最低賃金引上げがP10などを何%押し上げたかという因果的寄与率は、本分析からは算出できない。

---

## 12.10 分析上の注意点

### 所定内給与額の分布である

本分析で使用しているのは、一般労働者の月額所定内給与額である。

したがって、

- 時間当たり賃金
- 年収
- 賞与込み賃金
- 総現金給与額

の分布とは異なる。

特に最低賃金は時間額であるため、

`最低賃金 / P10`

のような比率を直接計算することは単位が異なり適切ではない。

---

### 構成効果を含む

各分位の変化には、同じ労働者の賃金上昇だけでなく、労働者構成の変化も含まれる。

例えば、

- 年齢
- 性別
- 勤続年数
- 雇用形態
- 職種
- 産業
- 企業規模

の構成変化によって分位点は変化しうる。

したがって、P10が20%上昇したことを、

> 2015年にP10にいた同一労働者の賃金が20%上昇した

とは解釈できない。

---

### 個人パネルではない

賃金構造基本統計調査は本分析において個人を追跡するパネルデータとして使用していない。

そのため、個人の賃金移動や階層移動を直接分析しているものではない。

---

### 男女差・雇用形態差の因果解釈

男女別・雇用形態別の違いについても、属性構成の違いが存在する。

特に男女差については、同一職種・同一勤続年数等に調整した賃金格差ではない。

雇用形態別についても、職種・産業・年齢などの分布が異なるため、

> 非正社員で賃金上昇率が高かった原因が雇用形態そのものにある

とは解釈できない。

---

## 12.11 結論

2015～2025年の一般労働者の所定内給与分布を分析すると、以下の特徴が確認された。

第一に、**名目賃金はすべての分位で上昇したが、上昇率は下位分位ほど高かった。**

全体では、

- P10：+20.4%
- P25：+16.7%
- P50：+12.6%
- P75：+8.5%
- P90：+8.1%

であり、明確に低賃金側ほど賃金上昇が強い。

第二に、**賃金分布は圧縮方向に動いた。**

P90/P10は2.94から2.64へ低下し、十分位分散係数・四分位分散係数も低下した。

第三に、**実質化すると賃金改善はさらに低賃金側へ集中する。**

2025年の実質指数は、

- P10：103.3
- P25：100.1
- P50：96.6
- P75：93.1
- P90：92.7

となり、P10は2015年水準を上回る一方、中央値以上では購買力が2015年を下回った。

第四に、**女性および正社員・正職員以外で名目賃金上昇が相対的に強かった。**

女性ではP10～P50、正社員・正職員以外でもP10～P50が2025年時点で2015年の実質水準を上回っている。

一方、男性ではP10以外、正社員ではP25以上で2015年水準を下回った。

以上から、

> **2015～2025年の日本の賃金上昇は分布全体に均等に生じたのではなく、低賃金側ほど強かった。その結果、名目賃金分布は圧縮方向に動き、実質購買力の改善も主として低賃金側に残った。**

と整理できる。

これは、平均賃金だけを見た場合には捉えにくい変化である。

一方で、最低賃金上昇との時系列的整合性は確認できるものの、本分析は記述的分析であり、その因果的寄与を特定するものではない。
