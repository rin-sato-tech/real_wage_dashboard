# 労働需給と賃金分析

作成日：2026-08-24

## 1. 分析目的

本分析では、

> 労働需給が逼迫した後、賃金上昇率は高まるのか。また、その関係にはどの程度の時間差があるのか。

を検証する。

これまでの分析では、給与構成、労働投入、産業別賃金、産業構成効果を通じて、平均賃金の変化を構成する内部要因を確認してきた。

本分析では、それらとは異なり、賃金決定を取り巻く外部環境として**労働市場の需給状況**に着目する。

想定する経済的な関係は以下である。

```text
労働需給の逼迫
→ 採用・定着競争の強まり
→ 企業の賃上げ圧力
→ 所定内給与などの上昇
```

ただし、本分析は観察データによる時系列比較・相関分析を中心とするため、労働需給の逼迫が賃金上昇を直接引き起こしたという因果関係までは断定しない。

---

## 2. 分析上の問い

### 主問い

**労働需給が逼迫すると、その後の所定内給与上昇率は高まるのか。**

### 補助的な問い

1. 有効求人倍率と所定内給与前年比にはどの程度の関連があるか
2. 完全失業率と所定内給与前年比にはどの程度の関連があるか
3. 労働需給指標は賃金上昇率に先行するか
4. 最も関連が強くなる時間差は何か月程度か
5. 労働需給と賃金の関係は時期によって異なるか
6. 所定内給与以外の賃金指標でも同様の関係が確認できるか
7. 新規求人倍率や短観の雇用人員判断DIを用いても同様の傾向が確認できるか

---

## 3. 使用データ

### 3.1 賃金

毎月勤労統計調査を使用する。

主指標：

- 所定内給与
- 所定内給与前年比

補助指標：

- きまって支給する給与
- きまって支給する給与前年比
- 時間当たり賃金（きまって支給する給与÷総実労働時間）
- 上記の時間当たり賃金の前年比

基本条件：

- 事業所規模：5人以上
- 就業形態：就業形態計
- 産業：調査産業計

### 3.2 労働需給

#### 一般職業紹介状況

主に以下を使用する。

- 有効求人倍率
- 新規求人倍率

原則として季節調整値を使用する。

#### 労働力調査

- 完全失業率

原則として季節調整値を使用する。

#### 日本銀行「全国企業短期経済観測調査（短観）」

追加分析として以下を使用する。

- 雇用人員判断DI

短観は四半期統計であるため、月次統計とは別に四半期単位で分析する。

## 4. 分析期間

主分析期間：

```text
2000-01 ～ 2025-12
```

選定理由：

- 労働需給指標と賃金指標の双方について連続した月次データを確保できること
- 異なる景気・雇用局面を十分に含むこと
- 長期的な関係と近年の変化を双方確認できること

必要に応じて、データ取得後に共通期間を確定する。

局面別分析では、暫定的に以下の区分を用いる。

| 区分                 | 期間         | 主な特徴                       |
| -------------------- | ------------ | ------------------------------ |
| 長期停滞・デフレ期   | 2000～2012年 | 低インフレ・雇用環境の弱さ     |
| アベノミクス期       | 2013～2019年 | 雇用改善・人手不足の進行       |
| コロナ期             | 2020～2021年 | 雇用・労働時間の急変           |
| 物価上昇・賃上げ局面 | 2022～2025年 | 物価上昇、人手不足、賃上げ拡大 |

最終的な期間区分は分析結果とデータ整合性を確認したうえで決定する。

## 5. 指標定義

### 5.1 所定内給与前年比

```text
所定内給与前年比 = (当月所定内給与 / 前年同月所定内給与 - 1) × 100
```

賞与や残業の影響を抑え、基本給に近い継続的な賃金変化を見る主指標として使用する。

### 5.2 きまって支給する給与と総実労働時間から算出した時間当たり賃金

```text
時間当たり賃金 = きまって支給する給与 / 総実労働時間
```

前年比は、

```text
時間当たり賃金前年比 = (当月値 / 前年同月値 - 1) × 100
```

として計算する。

### 5.3 有効求人倍率

```text
有効求人倍率 = 有効求人数 / 有効求職者数
```

値が高いほど、求職者に対して求人が多く、労働需給が逼迫していると解釈する。

### 5.4 新規求人倍率

```text
新規求人倍率 = 新規求人数 / 新規求職申込件数
```

有効求人倍率よりも短期的な求人動向を反映する指標として扱う。

### 5.5 完全失業率

完全失業者が労働力人口に占める割合。

値が低いほど労働需給が逼迫していると解釈する。

### 5.6 雇用人員判断DI

短観における、

```text
「過剰」と回答した企業割合 - 「不足」と回答した企業割合
```

で表される。

値が低いほど雇用人員不足が強い。

## 6. 労働需給指標の方向統一

労働需給指標は、そのままでは逼迫を示す方向が異なる。

| 指標           | 逼迫時の動き |
| -------------- | ------------ |
| 有効求人倍率   | 上昇         |
| 新規求人倍率   | 上昇         |
| 完全失業率     | 低下         |
| 雇用人員判断DI | 低下         |

相関係数やラグ相関を比較しやすくするため、必要に応じて分析用に方向を統一する。

```text
有効求人倍率       → そのまま
新規求人倍率       → そのまま
完全失業率         → -1 × 完全失業率
雇用人員判断DI     → -1 × 雇用人員判断DI
```

これらを便宜上「労働需給逼迫指標」とし、

> 値が高いほど労働需給が逼迫している

ように統一する。

ただし、グラフやCSVでは原系列も保持する。

## 8. 基礎時系列分析

### 8.1 有効求人倍率と所定内給与前年比

2000年1月～2025年12月について、有効求人倍率と所定内給与前年比の推移を比較した。

結果：

- 有効求人倍率が高い局面ほど所定内給与前年比も高い傾向がみられた
- 一方で、この関係は全期間を通じて一定ではなかった
- 2013～2019年では比較的明確な正の関係が確認された
- 2022年以降では同時点の関係が弱まり、有効求人倍率と賃金上昇率の動きにずれがみられた

考察：

有効求人倍率と所定内給与前年比には長期的な関連が確認されるものの、求人倍率の上昇がそのまま賃金上昇へ直結するとはいえない。
特に近年は、物価上昇や賃金改定行動など他の要因が同時に作用している可能性がある。

### 8.2 完全失業率と所定内給与前年比

完全失業率は、分析上は符号を反転し、値が大きいほど労働需給が逼迫する方向に統一して比較した。

結果：

- 全期間では比較的明確な正の関係が確認された
- 同時点相関は約0.60で、3つの月次労働需給指標の中では最も高かった
- 一方で、局面別にみると相関の強さは大きく異なった

考察：

完全失業率は労働市場全体の需給状況を表す指標として、所定内給与前年比と比較的安定した関連を示した。
ただし、局面によって関係が変化するため、単一の相関係数だけで賃金変動を説明することはできない。

### 8.3 新規求人倍率

新規求人倍率についても、所定内給与前年比との関係を確認した。

結果：

- 全期間の同時点相関は約0.57だった
- 有効求人倍率と同様に、労働需給が逼迫している局面ほど賃金上昇率が高い傾向がみられた
- ラグ相関では半年～1年程度先行させた場合に相関がやや高くなった
- ただし局面別では関係が安定せず、2022年以降では同時点相関が負となった

考察：

新規求人倍率は比較的短期的な求人動向を反映するため、賃金との時間差をみる補助指標として有用である。
一方、ラグ相関のピークは景気循環や系列の持続性の影響を受ける可能性があり、
最大相関ラグだけを賃金反応期間と解釈するのは適切ではない。

## 9. 同時点相関

各労働需給指標と賃金上昇率のPearson相関係数を計算する。

想定する比較表：

| 労働需給指標 | 賃金指標                   | 相関係数 | 観測数 |
| ------------ | -------------------------- | -------: | -----: |
| 有効求人倍率 | 所定内給与前年比           |        - |      - |
| 完全失業率   | 所定内給与前年比           |        - |      - |
| 新規求人倍率 | 所定内給与前年比           |        - |      - |
| 有効求人倍率 | きまって支給する給与前年比 |        - |      - |
| 有効求人倍率 | 時間当たり賃金前年比       |        - |      - |

時間当たり賃金は、きまって支給する給与を総実労働時間で除して算出する。

### 解釈上の注意

相関係数は変数間の線形な関連を示すものであり、因果関係を示すものではない。

また、時系列データでは共通トレンドや自己相関により相関が高く見える可能性があるため、相関係数のみで結論を出さない。

### 結果

2000年1月～2025年12月の312か月を対象に、労働需給指標と所定内給与前年比の同時点相関を確認した。
労働需給が逼迫する方向に符号を統一した場合、有効求人倍率は0.45、完全失業率は0.60、新規求人倍率は0.57の正の相関を示した。
3指標で共通して、**労働需給が逼迫している局面ほど所定内給与の伸び率が高い傾向**が確認された。一方、同時点相関のみでは労働需給と賃金改定の時間差を考慮できないため、次にラグ相関を検証する。

## 10. ラグ相関分析

### 10.1 目的

労働需給の変化が賃金上昇より先に現れる可能性を検証する。

基本的には、

```text
過去の労働需給指標 → 現在の賃金前年比
```

の関係を見る。

### 10.2 月次ラグ

以下を候補とする。

```text
0か月
1か月
2か月
3か月
4か月
5か月
6か月
9か月
12か月
```

必要に応じて0～12か月を1か月単位ですべて計算する。

定義例：

```text
lag = 6
```

の場合、

> 6か月前の有効求人倍率と、当月の所定内給与前年比

の相関を計算する。

### 10.3 結果表

| 指標         | 0か月 | 3か月 | 6か月 | 9か月 | 12か月 | 最大相関ラグ |
| ------------ | ----: | ----: | ----: | ----: | -----: | -----------: |
| 有効求人倍率 |     - |     - |     - |     - |      - |            - |
| 完全失業率   |     - |     - |     - |     - |      - |            - |
| 新規求人倍率 |     - |     - |     - |     - |      - |            - |

結果：

2000年1月～2025年12月を対象として、労働需給指標を0～12か月先行させた場合の所定内給与前年比との相関を確認した。最大相関は、有効求人倍率が12か月前で約0.478、完全失業率（逼迫方向に符号反転）が3か月前で約0.605、新規求人倍率が10か月前で約0.603となった。

有効求人倍率については最大値が当初の分析範囲の上限に位置したため、補助的に24か月まで拡張した。その結果、13か月前の約0.478を頂点として、その後は緩やかに低下した。このため、分析範囲の打ち切りによって最大値が12か月となっていた影響は小さいと考えられる。

3指標とも同時点でも正の相関があり、ラグを設けた場合の相関上昇は限定的だった。一方、新規求人倍率では半年～1年程度、有効求人倍率では1年前後、完全失業率では数か月前の値との関連がやや強かった。労働需給の逼迫が賃金上昇に先行する可能性とは整合的だが、相関分析のみから因果関係や厳密な先行期間を特定することはできない。

### 10.4 解釈

確認するポイント：

- 同時点より先行値との相関が高いか
- どの指標が最も先行性を示すか
- 相関が最大になるラグは経済的に妥当か
- 近接するラグで同程度の相関が続くか
- 一つのラグだけ突出していないか

最大相関となるラグだけを過度に重視せず、周辺ラグの安定性も確認する。

## 11. 局面別分析

全期間をまとめた相関だけでは、時期ごとの経済構造の違いが隠れる可能性がある。

そのため局面別に、

- 相関係数
- ラグ相関
- 労働需給の平均水準
- 賃金上昇率の平均

を比較する。

想定表：

| 期間       | 有効求人倍率平均 | 所定内給与前年比平均 | 同時点相関 | 最大ラグ相関 | 最大ラグ |
| ---------- | ---------------: | -------------------: | ---------: | -----------: | -------: |
| 2000～2012 |                - |                    - |          - |            - |        - |
| 2013～2019 |                - |                    - |          - |            - |        - |
| 2020～2021 |                - |                    - |          - |            - |        - |
| 2022～2025 |                - |                    - |          - |            - |        - |

### 確認したい点

- 人手不足が進んだ2013～2019年に賃金との関係が強まったか
- コロナ期に通常の関係が崩れたか
- 2022年以降は以前より賃金反応が大きくなったか
- 同程度の求人倍率でも時期によって賃金上昇率が異なるか

結果：

局面別に同時点相関を確認すると、労働需給と所定内給与前年比の関係は時期によって大きく異なった。
2000～2012年では相関は0.11～0.23程度と弱かった一方、2013～2019年の雇用改善期では3指標すべてで0.52～0.55程度の正の相関が確認された。コロナ期も正の相関を示したが、観測数が24か月と少ないため解釈には注意が必要である。2022～2025年では有効求人倍率と新規求人倍率が負の相関となり、全期間で確認された正の関係が維持されなかった。

この結果から、労働需給と賃金上昇率の関係は一定ではなく、経済局面によって変化する可能性が示唆される。特に2022年以降の賃金上昇については、労働需給だけでなく、物価上昇や賃金改定をめぐる制度・企業行動など他の要因も併せて検討する必要がある。

2022～2025年では同時点相関は弱い、または負であった一方、労働需給指標を約18～19か月先行させると相関が大きく上昇した。有効求人倍率では19か月ラグで0.759、新規求人倍率では18か月ラグで0.699、完全失業率では19か月ラグで0.589となった。ただし、この期間の先行値にはコロナ期の労働市場が含まれており、コロナショックとその後の回復という大きな時系列変動が相関を押し上げている可能性がある。このため、約18～19か月というラグを構造的な賃金反応期間とは解釈せず、追加の頑健性確認が必要である。

2022年以降について、水準系列では有効求人倍率・新規求人倍率を約18～19か月先行させた場合に高い正の相関が確認された。2022年を除いた2023～2025年でもこの関係は維持された。

一方、労働需給指標を前年差に変換して確認すると、短期ラグでは負の相関がみられ、20か月以降に正の相関へ転じた。最大相関は有効求人倍率前年差で23か月、新規求人倍率前年差・完全失業率前年差では分析上限の24か月付近となった。

この結果から、水準系列で確認された18～19か月の最大相関を、労働需給逼迫から賃金上昇までの構造的な反応期間と解釈することは難しい。労働需給指標には強い持続性や景気循環があり、系列間の位相差によってラグ相関が高くなっている可能性がある。そのため、本分析では最大ラグの値そのものよりも、労働需給と賃金の関係が局面によって大きく変化していることを重視する。

考察：

### 考察

局面別にみると、労働需給と所定内給与前年比の関係は一定ではなかった。

2000～2012年では、同時点相関は0.11～0.23程度と弱く、
ラグを長くしても相関は強まらなかった。
分析期間以前のデータもラグ計算に利用するよう修正した後も、
この局面では明確な先行関係は確認されなかった。

2013～2019年の雇用改善期では、
有効求人倍率0.552、完全失業率0.520、新規求人倍率0.538と、
3指標すべてで比較的明確な正の同時点相関が確認された。
また、ラグを長くすると相関はおおむね緩やかに低下した。
このため、この局面では「労働需給が数か月先行した」というより、
労働需給の改善と所定内給与上昇が比較的同時期に進行していたと解釈する方が適切である。

2020～2021年のコロナ期では、
相関係数がラグによって大きく変動した。
観測数が24か月と少なく、
急激な景気・雇用ショックを含むため、参考結果として扱う。

2022～2025年では、
有効求人倍率と新規求人倍率の同時点相関が負となった一方、
ラグを長くすると正の相関へ転じた。
ただし、水準系列と前年差系列で最大相関ラグが安定せず、
コロナ後の回復局面や時系列の持続性による影響が強い可能性がある。
したがって、この時期について特定のラグを
「労働需給逼迫から賃上げまでの反応期間」とみなすことはできない。

以上から、全期間で一つの固定的な関係を仮定するよりも、
労働需給と賃金の関係が経済局面によって変化することを重視する。

## 12. 短観・雇用人員判断DI

### 12.1 分析単位

短観は四半期統計であるため、毎月勤労統計も四半期平均に変換する。

採用方法：

```text
四半期所定内給与前年比 = 各四半期に含まれる月次の所定内給与前年比の平均
```

短観の公表時点に合わせて、3月、6月、9月、12月を各四半期の代表日として結合する。

短観の雇用人員判断DIは、`「過剰」回答割合 - 「不足」回答割合`であるため、分析時には符号を反転し、`値が大きいほど人手不足感が強い`方向に統一する。

原系列は保持したまま、分析用の人手不足方向系列を別列として作成する。

### 12.2 四半期ラグ

```text
0四半期
1四半期
2四半期
3四半期
4四半期
```

で比較する。

結果：

日銀短観の雇用人員判断DIについて、「過剰－不足」で公表される原系列の符号を反転し、値が大きいほど人手不足感が強くなるよう統一した。2000年第1四半期～2025年第4四半期の104四半期について、四半期平均した所定内給与前年比との関係を確認した。

同時点相関は大企業0.579、中堅企業0.639、中小企業0.627であり、すべて比較的明確な正の相関を示した。0～4四半期のラグ相関では、3系列とも1四半期（3か月）先行時に最大となり、大企業0.603、中堅企業0.659、中小企業0.644だった。一方、同時点から2四半期先行までの相関差は小さく、特定の3か月ラグが突出しているわけではない。

この結果は、企業側の人手不足感が強い局面ほど所定内給与の伸び率も高い傾向にあり、その関係が同時点～半年程度の比較的近い時期に現れることを示している。ただし、相関分析であり、人手不足が賃金上昇を引き起こしたという因果関係を示すものではない。

## 14. 主な分析結果

### 14.1 時系列

2000年以降の長期推移を確認すると、労働需給が逼迫している局面ほど所定内給与前年比も高い傾向がみられた。

一方で、この関係は時期によって大きく異なり、特に2022年以降では求人倍率と賃金上昇率の同時点の動きが一致しない局面も確認された。

### 14.2 同時点相関

2000年1月～2025年12月の312か月について、労働需給指標と所定内給与前年比のPearson相関係数を確認した。

| 指標                   | 同時点相関 |
| ---------------------- | ---------: |
| 有効求人倍率           |      0.451 |
| 完全失業率（逼迫方向） |      0.596 |
| 新規求人倍率           |      0.570 |

3指標すべてで正の相関が確認された。

### 14.3 ラグ相関

0～12か月のラグ相関を確認した結果、最大相関は以下となった。

| 指標                   | 最大相関 |   ラグ |
| ---------------------- | -------: | -----: |
| 有効求人倍率           |    0.478 | 12か月 |
| 完全失業率（逼迫方向） |    0.605 |  3か月 |
| 新規求人倍率           |    0.603 | 10か月 |

ただし、同時点から最大ラグまでの相関差は大きくない。
また、局面別分析や前年差系列で確認すると、最大相関ラグは安定していない。

このため、特定の月数を賃金反応期間として解釈することは避ける。

### 14.4 局面別分析

局面別では、労働需給と賃金の関係が大きく異なった。

- 2000～2012年：相関は弱く、ラグを設けても強まらない
- 2013～2019年：同時点で比較的強い正の相関
- 2020～2021年：結果は不安定で、観測数も少ない
- 2022～2025年：同時点では弱い・負の関係もみられるが、長いラグでは正の相関が高まる

このことから、労働需給と賃金の関係は一定ではなく、経済局面によって変化する可能性が高い。

### 14.5 短観

2000年第1四半期～2025年第4四半期の104四半期について、
短観の雇用人員判断DIと四半期平均した所定内給与前年比の関係を確認した。

同時点相関は、

| 企業規模 | 同時点相関 |
| -------- | ---------: |
| 大企業   |      0.579 |
| 中堅企業 |      0.639 |
| 中小企業 |      0.627 |

となり、3系列すべてで比較的明確な正の相関が確認された。

0～4四半期のラグ相関では、3系列とも1四半期先行時に最大となった。

| 企業規模 | 最大相関 | 最大ラグ |
| -------- | -------: | -------: |
| 大企業   |    0.603 |  1四半期 |
| 中堅企業 |    0.659 |  1四半期 |
| 中小企業 |    0.644 |  1四半期 |

ただし、同時点～2四半期先行の相関差は小さく、3か月ラグだけが突出しているわけではない。

企業側の人手不足感と所定内給与上昇率は、比較的近い時期に連動していると解釈できる。

## 15. 考察

### 15.1 労働需給と賃金の関連

全期間では、有効求人倍率、完全失業率、新規求人倍率、短観の雇用人員判断DIのいずれについても、
労働需給が逼迫している局面ほど所定内給与前年比が高い傾向が確認された。

特に短観では、大企業・中堅企業・中小企業のすべてで比較的高い正の相関が確認された。
求人・失業といった客観的な労働市場統計だけでなく、企業側の人手不足感でも同様の関係が確認された点は重要である。

### 15.2 時間差

月次指標では、労働需給指標を数か月～1年前後先行させた場合に相関が高くなる系列があった。
一方で、最大相関ラグは指標や局面によって大きく異なり、前年差系列を用いた頑健性確認でも安定しなかった。
短観では3系列とも1四半期先行時に最大相関となったが、同時点～2四半期の相関差は小さかった。

したがって、本分析から「労働需給逼迫から何か月後に賃金が上昇する」という固定的な反応期間を特定することはできない。

### 15.3 時期による違い

労働需給と賃金の関係は、経済局面によって大きく異なった。

2013～2019年では比較的明確な正の関係が確認された一方、2000～2012年では関係は弱かった。
2022年以降は、求人倍率と賃金上昇率の同時点相関が弱い、または負となり、過去の局面とは異なる動きがみられた。

近年の賃金上昇については、人手不足だけでなく、物価上昇、春闘、最低賃金、企業収益、賃金改定行動など複数の要因が同時に作用している可能性がある。

### 15.4 これまでの分析との接続

これまでの分析では、賃金上昇の内部構造として、所定内給与の上昇や産業内部での賃金上昇が重要であることを確認してきた。
今回の分析では、その外部環境として労働需給に着目した。

結果として、

```text
労働需給が逼迫している局面
↓
企業の人手不足感が強い
↓
所定内給与前年比が高い傾向
```

という関係はデータ上確認できた。

一方で、この関係は時期によって異なり、労働需給だけで賃金変動全体を説明することはできない。

---

## 16. 本分析から言えること

本分析から、以下の点が確認された。

- 2000年以降の長期データでは、労働需給の逼迫と所定内給与前年比の間に正の関連が確認された
- 有効求人倍率、完全失業率、新規求人倍率という異なる労働市場指標でも共通して正の関係がみられた
- 短観の雇用人員判断DIでも、大企業・中堅企業・中小企業のすべてで比較的明確な正の関係が確認された
- 労働需給指標が賃金上昇率に先行して見える局面は存在する
- ただし、最大相関ラグは指標・期間・変換方法によって安定せず、固定的な賃金反応期間は特定できない
- 労働需給と賃金の関係は経済局面によって大きく異なる
- 特に2013～2019年では比較的明確な正の関係が確認された
- 2022年以降の賃金上昇は、労働需給だけでは十分に説明できない

---

## 17. 本分析からは言えないこと

本分析だけでは以下は断定できない。

- 求人倍率の上昇が賃上げを直接引き起こしたこと
- 最大相関となったラグが企業の賃金決定期間そのものを表すこと
- 労働需給だけで日本の賃金変動を十分に説明できること
- 個々の企業や労働者の賃金決定メカニズム
- 春闘、最低賃金、物価、生産性、企業収益など他要因の影響が存在しないこと
- ラグ相関が最大となった月数・四半期数を、企業の賃金決定に必要な時間そのものと解釈すること

賃金決定には複数の要因が同時に作用するため、本分析はそのうち「労働需給」という一つの要因との関連を検証するものとして位置づける。

---

## 18. データ・分析上の制約

- 公共職業安定所を経由しない求人は求人倍率に直接反映されない
- 有効求人倍率は労働市場全体を完全に表す指標ではない
- 完全失業率と求人倍率は異なる側面の労働需給を測定している
- 毎月勤労統計の平均賃金には労働者構成変化の影響が含まれる
- 時系列データには自己相関や共通トレンドが存在し得る
- 単純相関・ラグ相関では第三の要因を統制していない
- ラグ候補を多数比較すると偶然高い相関が得られる可能性がある
- 短観と月次統計では調査対象・頻度が異なる
- コロナ期など特殊なショックが全期間の結果へ強く影響する可能性がある
