# 企業収益・生産性・労働分配率と賃金分析

作成日：2026-08-26

## 1. 分析目的

本分析では、

> 企業が生み出す付加価値と、その労働者への配分は、日本の賃金上昇とどのように関係しているか。

を検証する。

これまでの分析では、給与構成、労働投入、雇用形態、産業、産業構成、労働需給の各側面から賃金変動を分析してきた。

特に労働需給分析では、人手不足が強いほど所定内給与上昇率も高い傾向が確認された一方、労働需給だけでは近年の賃金上昇を十分に説明できなかった。

そこで本分析では、企業側の

- 収益力
- 付加価値創出
- 労働生産性
- 人件費負担
- 労働者への付加価値配分

に着目する。

想定する経済的な関係は以下である。

```text
企業活動
    ↓
付加価値の創出
    ↓
┌────────────────┐
│                │
労働側への配分    その他への配分
│                │
人件費            営業純益など
│
1人当たり人件費
│
賃金
```

また、これまで確認してきた労働需給との関係を、

```text
人手不足 → 賃上げ圧力

企業収益・生産性 → 賃上げ余力
```

という二つの側面から統合して考察する。

ただし、本分析は企業単位のパネルデータではなく、法人企業統計や毎月勤労統計の集計値を用いた記述分析・時系列分析を中心とする。

したがって、企業収益や生産性の上昇が賃金上昇を直接引き起こしたという因果関係までは断定しない。

---

## 2. 分析上の問い

### 主問い

**企業が生み出す付加価値と、その労働者への配分は、賃金上昇とどのように関係しているか。**

### 補助的な問い

1. 企業が生み出す付加価値は2015年度から直近年度にかけて増加したか
2. 1人当たり付加価値額、すなわち労働生産性は上昇したか
3. 1人当たり人件費は労働生産性と同程度に上昇したか
4. 労働分配率はどのように変化したか
5. 企業収益の改善と人件費・賃金上昇にはどのような関係があるか
6. 生産性・人件費・労働分配率の関係は企業規模によって異なるか
7. 生産性・人件費・賃金の関係は産業によって異なるか
8. 生産性や企業収益の変化は、その後の賃金上昇と関連しているか
9. 労働需給が逼迫し、かつ企業側の支払い余力が大きい場合に、賃金上昇がより強くなる傾向は確認できるか

---

## 3. 分析の考え方

本分析では、企業側の状態を大きく三つに分ける。

### 3.1 付加価値をどれだけ生み出しているか

主な指標：

- 付加価値額
- 1人当たり付加価値額
- 付加価値率

ここでは、企業活動から新たに生み出された価値と、その生産効率を確認する。

### 3.2 その付加価値が労働側へどれだけ配分されているか

主な指標：

- 人件費
- 1人当たり人件費
- 労働分配率

ここでは、企業が生み出した付加価値のうち、どの程度が労働側へ配分されたかを確認する。

### 3.3 企業に賃金を支払う余力があるか

主な指標候補：

- 営業利益
- 経常利益
- 営業利益率
- 経常利益率

企業の収益状況と人件費・賃金の変化を比較する。

ただし、「利益が増えれば賃金が増える」という関係を前提とはせず、実際のデータから関係を確認する。

## 4. 使用データ

### 4.1 法人企業統計調査

財務省「法人企業統計調査」を使用する。

主に年次調査を使用し、必要に応じて四半期調査を補助的に使用する。

取得候補項目：

- 売上高
- 営業利益
- 経常利益
- 人件費
- 従業員数
- 役員数
- 付加価値関連項目
- 業種
- 資本金階層

分析に必要な項目について、実際の公開データ構造を確認したうえで確定する。

### 4.2 毎月勤労統計調査

賃金側の指標として使用する。

主指標候補：

- 所定内給与
- きまって支給する給与

補助指標候補：

- 現金給与総額
- 概算時間当たり賃金

基本条件：

- 事業所規模：法人企業統計との比較可能性を確認したうえで設定
- 就業形態：就業形態計
- 産業：調査産業計、または対応可能な産業分類

### 4.3 労働需給指標

既存の労働需給分析結果を統合分析で使用する。

候補：

- 有効求人倍率
- 新規求人倍率
- 完全失業率
- 短観・雇用人員判断DI

新規に同一処理を実装するのではなく、既存分析の結果や中間データを可能な範囲で再利用する。

## 5. 分析期間

### 主比較期間

```text
2015年度 ～ 2024年度
```

を暫定的な主比較期間とする。

比較の中心は、

```text
2015年度 → 2024年度
```

とする。

### 選定理由

- 法人企業統計年次調査の最新公表年度に合わせる
- 既存分析の2015年を起点とする長期比較と可能な限り整合させる
- 約10年間の構造変化を確認できる
- コロナ前、コロナ期、回復期、近年の賃上げ局面を含む

法人企業統計と毎月勤労統計では「年度」と「暦年」が異なるため、両統計を直接比較する場合の期間対応方法を別途定義する。

必要に応じて、

- 暦年平均
- 年度平均
- 四半期平均

のいずれを用いるか検討し、比較可能性を優先する。

## 6. 指標定義

### 6.1 付加価値額

法人企業統計の定義に基づき算出する。

```text
付加価値額
= 人件費
+ 支払利息等
+ 動産・不動産賃借料
+ 租税公課
+ 営業純益
```

実際には法人企業統計の公開項目・公式定義に基づいて計算方法を確定する。

---

### 6.2 労働生産性

```text
労働生産性 = 付加価値額 / 従業員数
```

本分析では原則として「1人当たり付加価値額」を労働生産性として扱う。

単位はデータ取得後に統一する。

---

### 6.3 1人当たり人件費

```text
1人当たり人件費 = 人件費 / 従業員数
```

ただし、法人企業統計の人件費には給与以外の項目も含まれるため、毎月勤労統計の賃金と同一の概念ではない。

そのため、

> 企業側から見た1人当たり労働コスト

に近い指標として解釈する。

---

### 6.4 労働分配率

```text
労働分配率 = 人件費 / 付加価値額 × 100
```

付加価値のうち、労働側へ配分された割合を見る。

労働分配率が高いこと自体を、高賃金または労働者に有利な状態とは解釈しない。

付加価値額そのものが小さい場合、

```text
高い労働分配率 かつ 低い1人当たり人件費
```

となる可能性があるためである。

---

### 6.5 付加価値率

```text
付加価値率 = 付加価値額 / 売上高 × 100
```

売上高からどの程度の付加価値を生み出しているかを見る。

---

### 6.6 経常利益率

```text
経常利益率 = 経常利益 / 売上高 × 100
```

企業の収益力を確認する補助指標として使用する。

営業利益率についても必要性を確認する。

---

### 6.7 変化率

長期比較では、

```text
変化率 = (比較年の値 / 基準年の値 - 1) × 100
```

を使用する。

例：

```text
2015年度 → 2024年度
```

---

### 6.8 前年比・前年差

時系列分析では、トレンドを持つ水準値同士の単純相関を避けるため、

```text
前年比
前年差
対数差分
```

などの使用を検討する。

最終的な変換方法は、各指標の性質を確認して決定する。

## 7. 分析対象区分

### 7.1 全規模・全産業

最初に全体構造を確認する。

主に、

- 付加価値
- 労働生産性
- 人件費
- 1人当たり人件費
- 労働分配率
- 利益率

の長期変化を見る。

---

### 7.2 企業規模別

法人企業統計の資本金階層を利用して企業規模別に比較する。

暫定的には、

- 大企業
- 中堅企業
- 中小企業

の3区分を想定する。

ただし、法人企業統計・毎月勤労統計・短観では企業規模の定義が異なるため、完全に同一の区分として扱わない。

各統計の定義を明示したうえで比較する。

主な問い：

> 生産性・収益性・人件費の関係は企業規模によってどの程度異なるか。

---

### 7.3 産業別

法人企業統計と毎月勤労統計で対応可能な産業を選定する。

主な問い：

> 賃金が大きく伸びた産業では、労働生産性や1人当たり人件費も大きく伸びていたか。

既存の産業別賃金分析との接続を重視する。

産業分類が完全には一致しない可能性があるため、対応表を作成し、無理な統合は行わない。

2015年度と2024年度について比較する。

主要指標：

- 売上高
- 付加価値額
- 労働生産性
- 人件費
- 1人当たり人件費
- 労働分配率

| 指標            | 2015年度 | 2024年度 | 差分 | 変化率 |
| --------------- | -------: | -------: | ---: | -----: |
| 付加価値額      |          |          |      |        |

| 労働分配率      |          |          |      |        |
| 経常利益率      |          |          |      |        |

---

### 8.3 労働生産性と人件費の比較

中心となる比較として、

```text
労働生産性の変化率
vs
1人当たり人件費の変化率
```

を見る。

確認する点：

- 労働生産性と人件費が同方向に動いているか
- 生産性上昇より人件費上昇が弱いか
- 生産性上昇より人件費上昇が強い時期があるか
- 労働分配率の変化と整合するか

---

### 8.4 企業規模別分析

各企業規模について、

```text
労働生産性
1人当たり人件費
労働分配率
利益率
```

を比較する。

特に、

```text
高生産性・低労働分配率
低生産性・高労働分配率
```

のような組み合わせに注意する。

労働分配率単独で評価せず、

```text
付加価値水準
×
労働分配率
×
1人当たり人件費
```

として解釈する。

---

### 8.5 産業別分析

産業ごとに、

- 労働生産性変化率
- 1人当たり人件費変化率
- 毎月勤労統計の賃金変化率

を比較する。

散布図候補：

```text
x = 労働生産性変化率
y = 賃金変化率
```

```text
x = 1人当たり人件費変化率
y = 賃金変化率
```

必要に応じて相関係数を算出する。

ただし、産業数が少ない場合は相関係数を過度に重視せず、記述的比較を中心とする。

---

### 8.6 時系列分析

全体および企業規模別について、

- 労働生産性
- 1人当たり人件費
- 労働分配率
- 利益率
- 所定内給与

の時系列を確認する。

水準値の長期トレンドそのものではなく、主として変化率を利用する。

候補：

```text
労働生産性前年比
vs
所定内給与前年比
```

```text
経常利益率前年差
vs
所定内給与前年比
```

```text
1人当たり人件費前年比
vs
所定内給与前年比
```

---

### 8.7 ラグ分析

企業側の変化が賃金に反映されるまで時間差がある可能性を確認する。

例：

```text
企業指標(t)
vs
賃金上昇率(t + k)
```

候補ラグ：

```text
0年
1年
2年
```

年次データでは観測数が限られるため、ラグを過剰に増やさない。

必要性がある場合のみ四半期統計を用いて補助分析を行う。

---

### 8.8 労働需給との統合

既存分析で確認した労働需給指標と企業側指標を組み合わせる。

概念的には、

```text
賃上げ圧力 = 労働需給の逼迫

賃上げ余力 = 収益力・生産性・付加価値
```

として整理する。

例えば企業規模別に、

|             | 賃上げ余力 小                    | 賃上げ余力 大            |
| ----------- | -------------------------------- | ------------------------ |
| 人手不足 弱 | 賃上げ圧力が弱い                 | 余力はあるが圧力が弱い   |
| 人手不足 強 | 賃上げしたくても制約が強い可能性 | 賃上げが起きやすい可能性 |

という整理を検討する。

これは厳密な因果モデルではなく、既存分析結果を統合するための解釈フレームとして使用する。

### 12.2 生産性と賃金の関係

分析結果を踏まえて記載する。

```text
生産性上昇 → 賃金上昇

+
その他の制度・経済要因
```

という観点から整理する。

ただし、これは厳密な加法モデルではなく、説明上の整理である。

## 14. この分析からは言えないこと

以下については本分析だけでは断定しない。

- 企業収益の増加が賃金上昇を直接引き起こした
- 労働生産性上昇が賃金上昇を直接引き起こした
- 労働分配率の変化が企業の意図的な賃金政策による
- 個々の企業で収益改善が賃金へ還元された
- 企業規模間の賃金差が生産性だけで説明できる

主な理由：

1. 使用する統計は企業単位のパネルデータではない
2. 法人企業統計と毎月勤労統計では調査対象・定義が異なる
3. 企業収益・生産性・賃金には共通する第三の要因が影響する
4. 物価、最低賃金、春闘、労働需給、制度変更なども同時に影響する
5. 集計データ間の相関から個別企業レベルの因果関係は導けない

---

## 15. 分析上の注意点

### 15.1 法人企業統計の人件費と賃金は異なる

法人企業統計の人件費には給与以外の費用も含まれる。

そのため、

```text
1人当たり人件費
≠
毎月勤労統計の1人当たり賃金
```

である。

直接一致を検証するのではなく、企業側の労働コストと労働者側の賃金指標の動きを比較する。

---

### 15.2 労働生産性と人件費は完全に独立した指標ではない

付加価値額には人件費が含まれるため、

```text
労働生産性
=
付加価値額 / 従業員数
```

と、

```text
1人当たり人件費
=
人件費 / 従業員数
```

には構造的な関係がある。

両者の高い相関をそのまま経済的な因果関係とは解釈しない。

---

### 15.3 水準値同士の時系列相関に注意する

長期的に上昇する二つの指標は、実質的な関係が弱くても高い相関を示す可能性がある。

したがって相関分析では、

- 前年比
- 前年差
- 対数差分

などを主に使用する。

---

### 15.4 企業規模区分の違い

法人企業統計、毎月勤労統計、短観では企業規模の定義が異なる。

企業規模別分析では、

> 完全に同一の企業群を比較しているわけではない

ことを明示する。

---

### 15.5 産業分類の違い

統計間で産業分類が一致しない場合は、比較可能な上位分類へ統合する。

無理な1対1対応は行わない。

---

## 16. 既存分析との位置づけ

本分析は、既存分析のうち特に以下と接続する。

```text
給与構成
    ↓
何の給与が増えたか

労働投入
    ↓
賃金単価と労働時間のどちらが変わったか

産業分析
    ↓
どの産業で賃金が変化したか

労働需給
    ↓
企業に賃上げ圧力があったか

企業収益・生産性・労働分配率 ← 本分析
    ↓
企業に賃上げ余力があったか
付加価値が労働へどの程度配分されたか
```

本分析完了後は、

> 「人手不足による賃上げ圧力」と「企業側の賃上げ余力・配分」

を統合して賃金変動を考察する。

---

## 17. 次の分析候補

本分析で企業側の賃上げ余力を確認した後、以下を検討する。

1. 賃金引上げ等の実態に関する調査を用いた賃金改定行動分析
2. 最低賃金とパートタイム労働者賃金の分析
3. 春闘賃上げ率と所定内給与の分析
4. 物価上昇から名目賃金への波及分析

これらを追加することで、

```text
労働需給
企業収益・生産性
賃金改定行動
制度要因
物価
    ↓
名目賃金
    ↓
実質賃金
```

という全体的な説明体系へ発展させる。
