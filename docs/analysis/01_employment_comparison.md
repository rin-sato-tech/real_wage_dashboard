# 一般労働者・パートタイム労働者比較分析

## 要約

本分析では、一般労働者（以下、一般）とパートタイム労働者（以下、パート）の賃金変化を、月額賃金・労働時間・時間当たり賃金・実質賃金から比較した。厚生労働省「毎月勤労統計調査」の事業所規模5人以上・調査産業計を対象とし、2015年平均と2025年平均を比較した。

月額賃金には「きまって支給する給与」、労働時間には「総実労働時間」を使用した。時間当たり賃金は両者の比率として算出した概算値であり、個人の契約上の時給とは異なる。実質化には同月の消費者物価指数（CPI、総合）を用い、各指標の月次値を年ごとに単純平均して変化率を求めた。

名目月額賃金は一般で10.6%、パートで15.5%上昇した一方、労働時間はそれぞれ4.8%、11.2%減少した。時間当たり賃金は一般で16.2%、パートで30.1%上昇した。実質月額賃金は一般で2.9%低下し、パートで1.4%上昇した。実質時間当たり賃金はそれぞれ2.0%、14.2%上昇した。

年平均の賃金・労働時間・CPIから各指標を算出する方法でも確認したところ、主分析との変化率の差は、対象とした指標すべてで絶対値0.01パーセントポイント未満だった。今回の対象・比較期間では、集計順序によって主な結論は変わらなかった。ただし、公式の労働者数加重平均との比較は行っていない。

一般・パートは正規・非正規とは異なる区分であり、結果には各集団の構成変化が含まれる。本分析は集団平均の動向を示すもので、個人の賃上げや労働時間減少の原因を特定するものではない。

以上から、時間当たり賃金は両者で上昇し、特にパートで上昇率が大きかった一方、実質月額賃金の改善はパートで小幅にとどまり、一般では低下した。賃金の変化の評価は、就業形態だけでなく、月額と時間当たり、名目と実質のどれに着目するかによって異なる。

## 1. 分析目的と問い

月額賃金の変化だけでは、労働時間を考慮した賃金の動向や、物価変動を考慮した購買力の変化を十分に把握できない。また、就業形態をまとめた平均では、一般労働者とパートタイム労働者の変化の違いが見えにくい。

そこで本分析では、一般・パートについて、月額賃金、総実労働時間、時間当たり賃金を比較し、さらに賃金を実質化することで、2015年から2025年にかけての変化を整理する。主な問いは次の3点である。

1. 名目月額賃金・総実労働時間・時間当たり賃金の変化は、一般・パートでどのように異なるか。
2. 物価変動を考慮すると、月額賃金と時間当たり賃金の評価はどのように変わるか。
3. 集計順序を変えても、各指標の増減方向や一般・パートの比較結果は維持されるか。

補足として、月次の月額賃金の前年同月対数変化を、時間当たり賃金と労働時間の対数変化に分解する。この分解は指標間の計算上の関係を確認するために用い、賃金や労働時間が変化した原因の推定とは区別する。

## 2. データと分析方法

### 2.1 使用データと対象範囲

主分析の対象条件を以下に示す。

| 項目                     | 内容                           |
| ------------------------ | ------------------------------ |
| 賃金・労働時間の出典     | 厚生労働省「毎月勤労統計調査」 |
| 物価の出典               | 総務省「消費者物価指数」       |
| 産業                     | 調査産業計                     |
| 事業所規模               | 常用労働者5人以上              |
| 就業形態                 | 一般労働者・パートタイム労働者 |
| 賃金項目                 | きまって支給する給与           |
| 労働時間                 | 総実労働時間                   |
| 実質化に使用する物価指数 | CPI総合（2020年基準）          |
| 主比較                   | 2015年平均と2025年平均         |
| 年次集計                 | 各年12か月の月次値の単純平均   |

就業形態計は比較対象に含めない。本書に掲載する検証済みの結果は、2015年平均と2025年平均の比較、および集計順序を変更した感度分析である。

アプリでは、利用可能な月次データによる時系列表示と、前年同月からの月額賃金変化の分解も実装している。
ただし、長期時系列からの詳細な読み取りと月次分解の期間要約は、本書では未掲載である。画面に表示できる範囲と、本書で結果を報告する範囲は区別する。

30人以上の事業所や現金給与総額による補助分析についても、本書では結果を報告していない。

### 2.2 一般労働者・パートタイム労働者の定義

毎月勤労統計調査では、常用労働者のうち、次のいずれかに該当する者をパートタイム労働者とし、それ以外を一般労働者としている。

- 1日の所定労働時間が一般の労働者より短い者。
- 1日の所定労働時間が一般の労働者と同じで、1週の所定労働日数が一般の労働者より少ない者。

常用労働者とは、期間を定めずに雇われている者、または1か月以上の期間を定めて雇われている者を指す。
この区分は所定労働時間・日数に基づくものであり、正規・非正規という雇用区分とは一致しない。

出典：[厚生労働省「毎月勤労統計調査で使用されている主な用語の説明」](https://www.mhlw.go.jp/toukei/itiran/roudou/monthly/yougo-01.html)

### 2.3 指標の定義

各月のきまって支給する給与を $W$、総実労働時間を $H$、CPI総合を $P$ とし、次の指標を使用する。

| 指標               | 月次値の定義      | 単位                       |
| ------------------ | ----------------- | -------------------------- |
| 名目月額賃金       | $W$               | 円／月                     |
| 総実労働時間       | $H$               | 時間／月                   |
| 時間当たり賃金     | $W ÷ H$           | 円／時間                   |
| 実質月額賃金       | $W ÷ P × 100$     | 円／月（2020年価格換算）   |
| 実質時間当たり賃金 | $W ÷ H ÷ P × 100$ | 円／時間（2020年価格換算） |

賃金・労働時間は各就業形態の1人平均の集計値を使用し、実質化には同じ年月のCPIを結合する。

時間当たり賃金は、集団平均の月額賃金を集団平均の労働時間で割った分析用の概算値であり、個々の労働者の契約上の時給や、個人別時給の単純平均を示すものではない。

実質賃金は本分析でCPI総合を用いて算出した値であり、公式の実質賃金指数とは区別する。なお、実質化に用いるCPIの基準と、時系列比較のために各賃金指標を指数化する基準は、別の役割を持つ。

### 2.4 年平均と期間変化率の算出

主比較では、2015年・2025年それぞれについて、各指標の12か月の月次値を単純平均する。時間当たり賃金と実質賃金も、月次段階で計算してから年平均を求める。

指標 $X$ の年平均と期間変化率は、次のように定義する。

年平均：

$$\bar{X}_y = \frac{1}{12} \sum_{m=1}^{12} X_{y,m}$$

2015年平均から2025年平均への変化率：

$$g_X = \left( \frac{\bar{X}_{2025}}{\bar{X}_{2015}} - 1 \right) \times 100$$

年次比較では、対象年に重複のない12か月がそろい、対象指標に欠損値・無限大がないことを確認する。不足月を補完したり、利用可能な月だけで年平均を算出したりはしない。

各月を同じ重みで扱うため、この年平均は、各月の常用労働者数で加重平均する毎月勤労統計の公式な実数の年平均とは異なる。

また、月次比率の平均と年平均値の比率は一般に一致しない。そのため、月次で成立する「月額賃金＝時間当たり賃金×労働時間」という関係が、本分析の年平均指標の間でも成立するとは限らない。

集計順序の影響を確認するため、年平均の賃金・労働時間・CPIから時間当たり賃金・実質賃金を計算する方法とも比較する。その結果は「4. 結果の頑健性確認」に示す。

参考：[厚生労働省「毎月勤労統計調査 用語の解説」](https://www.mhlw.go.jp/toukei/list/30-1j.html)

### 2.5 時系列の比較と月次変化の分解

本節は、アプリに実装している時系列指標と月次分解の計算方法を示す。これらの期間要約や詳細な分析結果は、本書では未掲載である。

#### 指数による比較

各指標の時系列変化を比較するため、一般・パートそれぞれについて、自身の2020年平均を100とする指数を算出する。

$$I_{X,t} = \frac{X_t}{\bar{X}_{2020}} \times 100$$

この指数は、各就業形態における基準年からの変化を示す。一般・パートで基準となる実額が異なるため、指数の高さから両者の賃金水準や金額差を比較することはできない。

#### 前年同月比

月次原系列を使い、各指標について前年の同じ月からの変化率を求める。

$$g_{X,t}= \left( \frac{X_t}{X_{t-12}} - 1 \right) \times 100$$

前年同月の値は年月で対応づける。対応する値がない月は算出せず、前年同月比に移動平均は適用しない。

#### 月額賃金変化の分解

月次の時間当たり賃金を $q$ とすると、定義上、次の関係が成立する。

$$q_t=\frac{W_t}{H_t}, \qquad W_t=q_tH_t$$

したがって、前年同月からの月額賃金の自然対数変化を、時間当たり賃金と労働時間の自然対数変化に分解できる。

$$100\ln\frac{W_t}{W_{t-12}} = 100\ln\frac{q_t}{q_{t-12}} + 100\ln\frac{H_t}{H_{t-12}}$$

右辺の第1項を時間当たり賃金要因、第2項を労働時間要因とする。分解には当月・前年同月の正の値が必要であり、必要な値が欠ける月は算出しない。

表示値は自然対数差を100倍したもので、通常の前年同月比とは異なる。また、この分解は指標の定義に基づく恒等的な関係を示すものであり、賃金や労働時間が変化した原因を推定するものではない。

月次の前年同月変化の分解と、2015年平均から2025年平均への変化率の比較は区別する。前年同月変化は比較期間が重なるため、月次の寄与を単純に合計して長期の累積変化とはしない。

## 3. 分析結果

### 3.1 2015年から2025年の主要指標の変化

事業所規模5人以上・調査産業計について、2015年平均から2025年平均への変化率を比較した。

| 指標               | 一般労働者 | パートタイム労働者 | パート－一般 |
| ------------------ | ---------: | -----------------: | -----------: |
| 名目月額賃金       |     +10.6% |             +15.5% |         +4.9 |
| 総実労働時間       |      −4.8% |             −11.2% |         −6.4 |
| 時間当たり賃金     |     +16.2% |             +30.1% |        +13.9 |
| 実質月額賃金       |      −2.9% |              +1.4% |         +4.3 |
| 実質時間当たり賃金 |      +2.0% |             +14.2% |        +12.2 |

「パート－一般」は変化率の差であり、単位はパーセントポイントである。賃金額や労働時間そのものの差を示すものではない。実質値はCPI総合を用いて算出した。

### 3.2 名目月額賃金・労働時間・時間当たり賃金

名目月額賃金は一般・パートともに上昇し、上昇率はパートの方が大きかった。一方、総実労働時間は両者とも減少し、減少率もパートの方が大きかった。

時間当たり賃金は、一般で16.2%、パートで30.1%上昇した。いずれの就業形態でも、時間当たり賃金の上昇率は名目月額賃金の上昇率を上回っていた。

したがって、両者に共通して、月額賃金の上昇、労働時間の減少、時間当たり賃金の上昇が観測された。ただし、この年次比較から、労働時間の減少が月額賃金の変化に何パーセントポイント寄与したかを直接求めることはできない。

### 3.3 物価を考慮した実質賃金

CPI総合で実質化すると、月額賃金は一般で2.9%低下した一方、パートでは1.4%上昇した。名目月額賃金は両者とも上昇していたが、実質月額賃金の増減方向は就業形態によって異なった。

実質時間当たり賃金は一般で2.0%、パートで14.2%上昇した。一般では、実質月額賃金が低下する一方、実質時間当たり賃金は上昇していた。パートでは両指標とも上昇したが、実質月額賃金の上昇率は実質時間当たり賃金の上昇率より小さかった。

物価を考慮した場合も、月額と時間当たりでは賃金の変化の評価が異なり、特にパートでは両者の上昇率に大きな違いがみられた。

## 4. 結果の頑健性確認

### 4.1 集計順序を変えた比較

主分析では、時間当たり賃金と実質賃金を月次で算出してから、各年の12か月を単純平均した。

この集計順序が結果に与える影響を確認するため、賃金・労働時間・CPIをそれぞれ年平均にしてから各指標を算出する方法と比較した。対象条件と比較年は主分析と同じとした。

| 指標               | 主分析：月次で計算して平均        | 比較方法：年平均から計算            |
| ------------------ | --------------------------------- | ----------------------------------- |
| 時間当たり賃金     | 月次の「給与÷時間」の平均         | 年平均給与÷年平均時間               |
| 実質月額賃金       | 月次の「給与÷CPI×100」の平均      | 年平均給与÷年平均CPI×100            |
| 実質時間当たり賃金 | 月次の「給与÷時間÷CPI×100」の平均 | 年平均給与÷年平均時間÷年平均CPI×100 |

給与は「きまって支給する給与」、時間は「総実労働時間」を指す。比較方法でも、各系列の年平均には月次値の単純平均を使用した。

両方法による2015年平均から2025年平均への変化率を以下に示す。

| 就業形態 | 指標               |   主分析 | 年平均から計算 | 差（パーセントポイント） |
| -------- | ------------------ | -------: | -------------: | -----------------------: |
| 一般     | 時間当たり賃金     | +16.224% |       +16.232% |                   +0.008 |
| 一般     | 実質月額賃金       |  −2.897% |        −2.894% |                   +0.003 |
| 一般     | 実質時間当たり賃金 |  +2.000% |        +2.005% |                   +0.005 |
| パート   | 時間当たり賃金     | +30.091% |       +30.084% |                   −0.007 |
| パート   | 実質月額賃金       |  +1.387% |        +1.390% |                   +0.003 |
| パート   | 実質時間当たり賃金 | +14.164% |       +14.162% |                   −0.002 |

差は「年平均から計算した変化率－主分析の変化率」である。変化率と差は、丸める前の計算値からそれぞれ小数第3位に丸めて表示した。

### 4.2 確認結果と適用範囲

集計順序による変化率の差は、対象とした6項目すべてで絶対値0.01パーセントポイント未満だった。小数第1位の掲載値に変化はなく、次の結果も維持された。

- 実質月額賃金は、一般で低下し、パートで小幅に上昇した。
- 実質時間当たり賃金は、一般・パートともに上昇した。
- 名目・実質の時間当たり賃金の上昇率は、パートの方が大きかった。

この確認は、事業所規模5人以上・調査産業計・CPI総合による、2015年平均と2025年平均の比較に限られる。他の期間・対象・CPI系列でも同じ結果になることを保証するものではない。

また、公式の労働者数加重平均との比較や、集団の構成変化を調整した比較は含まれない。主分析の年平均指標の間に、月次と同じ恒等関係が成立することを示すものでもない。

以上から、今回検証した集計順序の違いに対しては、主な結論が維持されることを確認した。

## 5. 考察と限界

### 5.1 月額と時間当たりで異なる改善の程度

一般・パートともに、時間当たり賃金の上昇率は月額賃金の上昇率を上回った。実質化すると、一般では時間当たり賃金が上昇した一方、月額賃金は2015年の水準を下回った。パートでは両者とも上昇したが、実質月額賃金の改善は小幅だった。

この結果は、賃金の変化を月額だけで評価する場合と、労働時間を考慮して評価する場合とでは、見え方が異なることを示している。月額賃金は月単位で受け取る給与の動向を、時間当たり賃金は実労働時間に対する給与の比率の動向を示すため、両者を併せて確認する必要がある。

ただし、時間当たり賃金は月額賃金と労働時間から算出した比率であり、独立に観測した賃金率ではない。その上昇を、契約上の時給の引上げだけによるものとは解釈できない。

### 5.2 集団平均・指標定義による解釈の限界

#### 集団平均と構成変化

本分析は、各時点の一般・パートそれぞれの集団平均を比較している。産業・職種・年齢・勤続年数等の構成変化が結果に含まれるため、同じ労働者の賃金や労働時間がどれだけ変化したかは分からない。

例えば、平均労働時間の減少は、個々の労働者の勤務時間の短縮だけでなく、短時間で働く労働者の構成比の上昇によっても生じ得る。本分析だけでは、これらを区別できない。

#### 賃金指標と購買力

使用した賃金は、税・社会保険料控除前の「きまって支給する給与」である。賞与・特別給与を含む年間収入や手取り額を示すものではない。

また、実質化には一般・パートに共通のCPI総合を使用している。就業形態別・世帯別の消費構成、世帯内の他の所得などは反映していないため、実質賃金の変化を生活水準全体の変化と同一視することはできない。

時間当たり賃金も、給与と実労働時間の集計値から算出した概算値であり、個人別時給の平均や、同一条件の労働に対する報酬を直接示すものではない。

#### 上昇率と賃金格差

パートの賃金上昇率が一般を上回ったことだけから、両者の賃金の金額差が縮小したとは結論づけられない。金額差の変化は、比較開始時点の賃金水準にも左右される。

また、一般・パートは正規・非正規とは異なる区分であり、職務や労働者属性もそろえていない。したがって、今回の結果を、正規・非正規間の待遇差や、同一の職務・属性を持つ労働者間の待遇差の変化としては解釈しない。

### 5.3 要因分解と因果関係の区別

月額賃金を時間当たり賃金と労働時間に分ける方法は、指標の定義に基づく恒等的な分解である。各項が観測された月額賃金の変化をどのように構成するかを示すが、賃金や労働時間が変化した原因を特定するものではない。

例えば、最低賃金改定、労働需給、制度変更などが賃金変化にどの程度影響したかは、この分解だけでは判断できない。労働時間の減少が本人の希望によるものか、企業側の事情によるものかも分からない。

また、労働時間が変化しなかった場合に賃金がどうなったかという反実仮想を推定したものでもない。

月次の恒等分解と年平均指標の比較は区別する必要がある。集計順序を変えたときの差が小さかったとしても、主分析の年次変化率をそのまま足し合わせて、長期変化への厳密な寄与として扱うことはできない。

---

## 6. 結論と今後の課題

### 6.1 結論

2015年平均から2025年平均にかけて、一般・パートともに名目月額賃金と時間当たり賃金が上昇し、総実労働時間は減少した。賃金の上昇率と労働時間の減少率は、いずれもパートの方が大きかった。

物価を考慮すると、実質月額賃金は一般で低下し、パートでは小幅な上昇にとどまった。一方、実質時間当たり賃金は両者で上昇した。このため、名目賃金の上昇を、そのまま月単位の購買力の改善と評価することはできない。

月次で比率を計算してから平均する方法と、年平均値から比率を計算する方法では、主な結論は変わらなかった。今回の対象・比較期間では、集計順序による結果への影響は小さかった。

本分析から得られる結論は、集団平均の賃金変化の評価が、就業形態に加え、月額と時間当たり、名目と実質の区別によって異なることである。個人の賃上げや待遇差の改善、賃金・労働時間の変化の原因については、追加の検証が必要である。

### 6.2 残る検証・追加分析

以下は、本分析として未検証、または本書に結果を未掲載の課題である。

## 付録

### A. 分析用の列名と計算式

#### 基本指標・実質指標

| 列名                      | 内容・計算式                              |
| ------------------------- | ----------------------------------------- |
| `date`                    | 対象年月                                  |
| `nominal_wage_amount`     | きまって支給する給与                      |
| `working_hours`           | 総実労働時間                              |
| `index_value`             | 実質化に使用する同月のCPI                 |
| `approx_hourly_wage`      | `nominal_wage_amount / working_hours`     |
| `real_regular_wage`       | `nominal_wage_amount / index_value * 100` |
| `real_approx_hourly_wage` | `approx_hourly_wage / index_value * 100`  |

本文では、`approx_hourly_wage`を「時間当たり賃金」、`real_approx_hourly_wage`を「実質時間当たり賃金」と表記する。いずれも集計値から算出した概算値である。

#### 指数・前年同月比

| 対象指標           | 2020年平均＝100の指数列         | 前年同月比の列                    |
| ------------------ | ------------------------------- | --------------------------------- |
| 名目月額賃金       | `regular_wage_index`            | `regular_wage_yoy_pct`            |
| 総実労働時間       | `working_hours_index`           | `working_hours_yoy_pct`           |
| 時間当たり賃金     | `approx_hourly_wage_index`      | `approx_hourly_wage_yoy_pct`      |
| 実質月額賃金       | `real_regular_wage_index`       | `real_regular_wage_yoy_pct`       |
| 実質時間当たり賃金 | `real_approx_hourly_wage_index` | `real_approx_hourly_wage_yoy_pct` |

指数は、一般・パートそれぞれの基準年平均に対する比率を100倍した値である。前年同月比は、年月で対応づけた前年同月の値に対する変化率である。

#### 月次の対数変化と分解

| 列名                             | 内容                                         |
| -------------------------------- | -------------------------------------------- |
| `wage_log_change`                | 月額賃金の前年同月からの自然対数差×100       |
| `hourly_wage_log_contribution`   | 時間当たり賃金の前年同月からの自然対数差×100 |
| `working_hours_log_contribution` | 総実労働時間の前年同月からの自然対数差×100   |

必要な値がそろう月について、次の関係が成立する。

```text
wage_log_change = hourly_wage_log_contribution + working_hours_log_contribution
```

これらは通常の前年同月比ではなく、自然対数差を100倍した値である。
