# 一般労働者・パートタイム労働者比較分析

## 1. 分析テーマ

一般労働者とパートタイム労働者では、賃金・労働時間・時間当たり賃金・実質購買力がどのように異なる推移をしてきたかを分析する。

---

## 2. 分析目的

月額賃金の変化だけでは、**賃金率そのものの変化と労働時間の変化を区別できない**。

そこで本分析では、

- 月額賃金
- 労働時間
- 概算時間当たり賃金
- 実質月額賃金
- 実質概算時間当たり賃金

を一般労働者とパートタイム労働者で比較し、賃金変化の背景を整理する。

---

## 3. 主な分析問い

1. 一般労働者とパートタイム労働者では、月額賃金の推移にどのような違いがあるか。

2. 総実労働時間はそれぞれどのように変化しているか。

3. 月額賃金の変化は、労働時間の変化によってどの程度説明できるか。

4. 労働時間を考慮した概算時間当たり賃金は、それぞれどのように推移しているか。

5. 物価変動を考慮した実質月額賃金、実質概算時間当たり賃金はどのように変化しているか。

6. 一般労働者とパートタイム労働者では、賃金変化の構造にどのような違いがあるか。

---

### 8.5 実質概算時間当たり賃金


## 11. 月額賃金変化の分解

定義上、

```text
月額賃金 = 概算時間当たり賃金 × 総実労働時間
```

である。

対数を用いると、

```text
log(月額賃金) = log(概算時間当たり賃金) + log(総実労働時間)
```

となる。

前年同月との対数変化を用いて、

```text
月額賃金変化 = 時間当たり賃金要因 + 労働時間要因
```

として分解する。

### 月額賃金変化の要因分解

月額賃金を、

```text
月額賃金 = 概算時間当たり賃金 × 総実労働時間
```

とみなす。

対数を取ると、

```text
log(月額賃金) = log(概算時間当たり賃金) + log(総実労働時間)
```

となるため、前年同月からの対数変化を、

- 時間当たり賃金要因
- 労働時間要因

に分解する。

```text
月額賃金の対数変化 = 時間当たり賃金要因 + 労働時間要因
```

## v2.1.1 分析結果

### 分析条件

主分析では、以下の条件で2015年平均と2025年平均を比較する。

- 産業：調査産業計
- 事業所規模：5人以上
- 賃金項目：きまって支給する給与
- 労働時間：総実労働時間
- CPI：総合
- 比較期間：2015年平均 → 2025年平均

各年について12か月の月次値を平均し、年平均同士の変化率を算出する。

### 主要指標の変化

| 指標                   | 一般労働者 | パートタイム労働者 | パート－一般 |
| ---------------------- | ---------: | -----------------: | -----------: |
| 月額賃金               |     +10.6% |             +15.5% |       +4.9pt |
| 総実労働時間           |      -4.8% |             -11.2% |       -6.4pt |
| 概算時間当たり賃金     |     +16.2% |             +30.1% |      +13.9pt |
| 実質月額賃金           |      -2.9% |              +1.4% |       +4.3pt |
| 実質概算時間当たり賃金 |      +2.0% |             +14.2% |      +12.2pt |

### 結果

2015年から2025年にかけて、一般労働者・パートタイム労働者ともに名目月額賃金および概算時間当たり賃金は上昇した。

一方、総実労働時間は両就業形態で減少した。

概算時間当たり賃金の変化率は、一般労働者とパートタイム労働者で差がみられた。
また、名目月額賃金と実質月額賃金を比較すると、物価変動を考慮した場合の伸びは名目値とは異なる。

### 考察

両就業形態とも、時間当たり賃金が上昇する一方で総実労働時間は減少している。

月額賃金は概算時間当たり賃金と総実労働時間の積として捉えられるため、
時間当たり賃金の上昇は月額賃金を押し上げる方向に、
労働時間の減少はその伸びを抑える方向に作用したと考えられる。

また、名目月額賃金の伸びに比べて実質月額賃金の改善が小さい場合、
名目賃金上昇の一部が物価上昇によって相殺されたと解釈できる。

したがって、一般労働者とパートタイム労働者の賃金変化を評価する際には、
月額賃金だけでなく、時間当たり賃金・労働時間・物価を分けて確認する必要がある。

### 月額賃金変化の要因分解

前年同月からの月額賃金変化を、

- 時間当たり賃金要因
- 労働時間要因

に分解した。

2015年から2025年について、各要因の平均値、
時間当たり賃金要因がプラスだった月の割合、
労働時間要因がマイナスだった月の割合、
両要因のうち変動幅が大きかった月の割合を確認する。

この分析は月額賃金変化の構造を整理するものであり、
時間当たり賃金や労働時間が変化した原因そのものを特定するものではない。
