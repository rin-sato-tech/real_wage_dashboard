# 労働投入の要因分解

## TL;DR

- 日本の労働時間は長期的に減少しているが、その内訳は時期によって異なる。長期ではパート比率上昇などの構成変化も大きかったが、近年は各集団内部での時間短縮が中心である。
- 年齢構成だけでは平均労働時間の低下を説明できず、2000～2025年の低下の約9割は各年齢階級内部の時間短縮に対応した。
- 働く人数の増加は時間短縮を一部相殺しており、総労働投入の減少は平均週間就業時間の低下に比べて小さい。

## 要約

本分析では、日本の労働投入の長期変化を、毎月勤労統計と労働力調査を用いて、1人当たり労働時間、就業形態構成、年齢別就業構造、平均週間就業時間、就業時間分布、総労働投入に分けて整理した。

毎月勤労統計では、就業形態計の総実労働時間は1990～2025年に約21%減少した。2000～2025年には一般・パートそれぞれの内部での時間短縮に加え、パート比率上昇による構成効果も大きかった。一方、2015～2025年では構成効果は小さく、一般・パート双方の内部での時間短縮、特に出勤日数の減少が中心だった。月額賃金でも、長期ではパート比率上昇が各就業形態内部の賃金上昇を集計値上で大きく相殺した。

労働力調査では、2000～2025年に就業率が全ての年齢階級で上昇する一方、就業者数は15～34歳で減少し、55歳以上で増加した。再構成した平均週間就業時間は42.73時間から35.87時間へ低下し、その約91%が年齢層内効果に対応した。就業時間分布でも49時間以上の割合が全階級で低下し、1～34時間の割合が上昇した。

総労働投入は2000～2025年に12.58%、2015～2025年に2.07%減少した。各年齢階級内部の時間短縮が主な押下げ要因だった一方、高年齢層を中心とする従業者数増加がその一部を相殺した。

以上から、日本の労働時間低下は単一の人口・雇用構成変化では説明できず、長期では構成効果も重要だった一方、近年は各集団内部の時間短縮の寄与がより大きい。

## 1. 分析目的と問い

平均労働時間の低下は個々の労働者が短く働くようになった場合だけでなく、短時間で働く人の構成比が高まった場合にも生じる。また、1人当たりの時間が減少しても働く人数が増加すれば、経済全体の労働投入は維持される可能性がある。したがって、平均労働時間の推移だけでは労働投入の変化の内訳を十分に把握できない。

本分析では、毎月勤労統計を用いて、1人当たり月間労働時間を所定内・所定外労働時間、出勤日数、1出勤日当たり時間へ分解する。さらに、労働力調査を用いて、就業者数と就業率、年齢別の平均週間就業時間、就業時間分布、総労働投入を分析する。両統計の対象範囲の違いを保ちながら、人数・時間・年齢構成が全体の変化にどのように対応するかを整理する。

主要な問いは次の6点である。

1. **1人当たり労働時間は長期的にどの程度変化したか。**
   所定内・所定外労働時間のどちらが変化し、所定内労働時間の変化は出勤日数と1出勤日当たり時間のどちらに対応するか。

2. **月額賃金の変化は、時間当たり賃金と労働時間にどのように分解されるか。**
   月額と時間当たりで賃金の変化の見え方が異なる理由を、指標間の恒等関係から確認する。

3. **年齢別の就業者数と就業率はどのように変化したか。**
   特に高年齢層の就業者数増加が、当該年齢層の人口増加と就業率上昇のどちらに対応するか。

4. **平均週間就業時間の低下は、年齢層内部の変化と年齢構成変化にどのように分解されるか。**
   25～34歳、35～44歳、45～54歳を含む各年齢階級でも平均就業時間が低下しているか。

5. **就業時間分布はどのように変化したか。**
   短時間帯と長時間帯の構成比がどの程度変化し、その変化が年齢階級によってどう異なるか。

6. **人数と時間を合わせた総労働投入はどのように変化したか。**
   従業者総数、年齢層内の平均就業時間、年齢構成の寄与と、期間・年齢階級による違いを確認する。

本分析は、記述統計と恒等式に基づく要因分解によって、観測された変化の内訳を示す。働き方改革・高齢者雇用政策・景気変動などの因果効果や労働時間短縮が、本人の希望・生活水準・厚生に与えた影響は推定しない。未活用労働や質調整済み労働投入については、今後の補助分析として扱う。

### 2.2 指標と対象者の定義

#### 毎月勤労統計の指標

各月の「きまって支給する給与」を $W$、総実労働時間を $T$、所定内労働時間を $S$、所定外労働時間を $O$、出勤日数を $D$ とする。

| 指標                        | 定義                     | 単位     |
| --------------------------- | ------------------------ | -------- |
| 月額賃金                    | きまって支給する給与 $W$ | 円／月   |
| 総実労働時間                | $T$                      | 時間／月 |
| 所定内労働時間              | $S$                      | 時間／月 |
| 所定外労働時間              | $O$                      | 時間／月 |
| 出勤日数                    | $D$                      | 日／月   |
| 時間当たり賃金              | $q=W/T$                  | 円／時間 |
| 1出勤日当たり所定内労働時間 | $h=S/D$                  | 時間／日 |

時間当たり賃金は、集団平均の月額賃金を集団平均の総実労働時間で割った分析用の概算値である。個人の契約上の時給や個人別時給の平均を示すものではない。本文では「時間当たり賃金」と表記するが、その上昇を契約上の賃金単価の引上げだけによるものとは解釈しない。

1出勤日当たり所定内労働時間も、集計値の比率として算出する。これは1出勤日当たりの平均的な所定内実労働時間であり、就業規則などで定められた1日の所定労働時間とは区別する。

#### 労働力調査の指標

| 指標                 | 本分析での扱い                                                                   |
| -------------------- | -------------------------------------------------------------------------------- |
| 就業者数 $E$         | 従業者と休業者を含む人数。就業率・人口との関係を分析する。                       |
| 就業率 $r$           | 当該年齢階級人口に占める就業者の割合。                                           |
| 従業者数 $N$         | 調査週間中に実際に仕事をした者の人数。平均週間就業時間と整合する人数として扱う。 |
| 平均週間就業時間 $H$ | 従業者1人当たりの週間就業時間。                                                  |
| 延週間就業時間 $L$   | 総労働投入の水準を示す公表値。単位は万時間／週。                                 |

就業者数には休業者が含まれるため、就業者数と平均週間就業時間の対象者は一致しない。このため、総労働投入の算出に「就業者数×平均週間就業時間」は使用しない。

平均週間就業時間の年齢構成分解では、年齢階級別の延週間就業時間と平均週間就業時間から従業者数を逆算する。一方、就業時間分布の構成比には、分布表に収録された従業者総数を使用する。両者は用途と作成方法を区別する。

本分析の総労働投入は、年平均の延週間就業時間である。年間の累積労働時間や、労働の質を調整した投入量を示すものではない。

### 2.3 年平均・期間比較・欠測の扱い

#### 毎月勤労統計の年平均

毎月勤労統計の実数系列は、各月の平均労働者数をウェイトとして年平均を算出する。

月 $m$ の前月末常用労働者数を $B_m$、本月末常用労働者数を $C_m$ とすると、ウェイトは次のとおりである。

$$w_m=\frac{1}{2} (B_m+C_m)$$

系列 $X$ の年 $y$ の加重平均を、

$$\bar X_y= \frac{\sum_{m=1}^{12}w_{y,m}X_{y,m}}{\sum_{m=1}^{12}w_{y,m}}$$

とする。対象は、きまって支給する給与、総実労働時間、所定内労働時間、所定外労働時間、出勤日数である。同じ対象集団について、各系列に共通のウェイトを使用する。

年次の派生指標は、基礎系列を年平均にした後で算出する。

$$q_y=\frac{\bar W_y}{\bar T_y}, \qquad h_y=\frac{\bar S_y}{\bar D_y}$$

これにより、年次指標についても、 $\bar W_y = q_y \bar T_y, \ \bar S_y = h_y \bar D_y$ という関係を維持する。月次の比率を計算してから平均する方法とは区別する。

ここで算出するのは、公表月次値と労働者数を用いて再計算した年平均である。公表値の丸めなどにより公式年平均と差が生じる可能性があるため、計算方法の整合と公表値との数値的一致は区別し、照合状況は付録に記録する。

年平均比較には1～12月がそろう完全な暦年を使用する。2026年のデータは月次推移に使用し、2025年までの年平均との比較には含めない。

#### 期間変化と時系列表示

開始年を $a$、終了年を $b$ とすると、指標 $X$ の期間変化率は、

$$g_{a,b} = \left( \frac{X_b}{X_a} - 1 \right) \times 100$$

とする。人数・時間の水準差は $X_b-X_a$、就業率や構成比の差はパーセントポイントで示す。

1990年以降または2000年以降の長期推移と、2015～2025年の詳細比較を併用する。期間による違いを確認する際には、2000～2010年、2012～2019年、2019～2020年、2020～2025年などに分ける。毎月勤労統計では、比較開始年への依存を確認するため、各年について10年前からの変化を求めるローリング10年比較も用いる。

期間全体の変化率は、期間の長さが異なる場合、そのまま変化の速さの比較には使用しない。また、2020～2021年を長期系列から除外せず、2020年の急変とその後の変化を区別して読む。

月次の前年同月比は、前年の同じ年月と対応づけて算出する。12か月移動平均を使用する場合は、連続した12暦月がそろう区間に限る。年平均、前年同月比、移動平均は、それぞれ別の集計として扱う。

#### 欠測と整合性の確認

労働力調査の年次分析には公表年平均を使用する。本分析で使用する平均週間就業時間、延週間就業時間、就業時間分布の2011年全国値は、補間せず欠測として扱う。

両端年の値が利用できる場合には、2011年をまたぐ期間の始点・終点比較は可能である。ただし、欠測年を含む連続した年次変化を観測できたとはみなさない。

毎月勤労統計の対象437か月について、主要5系列の欠損、年月重複、不正年月、欠損月がないことを確認した。また、 $T_m=S_m+O_m$ は、全437か月で絶対誤差 $10^{-10}$ 時間以内で成立した。検証の詳細は付録に示す。

### 2.4 毎月勤労統計による分解

#### 月額賃金の分解

時間当たり賃金を $q = W/T$ と定義するため、$W = qT$が成立する。開始時点0と終了時点1の自然対数差（ $\Delta \ln W = \Delta \ln q + \Delta \ln T$ ）を100倍すると、

$$100\ln\frac{W_1}{W_0} = \underbrace{100\ln\frac{q_1}{q_0}}_{時間当たり賃金要因} + \underbrace{100\ln\frac{T_1}{T_0}}_{総実労働時間要因}$$

となる。

この分解は月額賃金の変化を、時間当たり賃金と総実労働時間の変化へ恒等的に分けるものであり、因果効果や反実仮想を示すものではない。

#### 総実労働時間の分解

$T=S+O$より、水準差は、 $\Delta T=\Delta S+\Delta O$ と分解する。開始時点の総実労働時間を分母にすると、

$$100\frac{\Delta T}{T_0} = 100\frac{\Delta S}{T_0} + 100\frac{\Delta O}{T_0}$$

と分解する。各前年差を開始時点の総実労働時間で割ることで、総実労働時間変化率に対する所定内・所定外労働時間の寄与度を求める。

#### 所定内労働時間の分解

1出勤日当たり所定内労働時間を $h = S/D$ と定義するため、 $S = Dh$ が成立する。したがって、

$$100\ln\frac{S_1}{S_0} = \underbrace{100\ln\frac{D_1}{D_0}}_{出勤日数要因} + \underbrace{100\ln\frac{h_1}{h_0}}_{1出勤日当たり時間要因}$$

として分解する。

公式労働時間指数は、実数系列による長期方向の確認に用いる。指数そのものに実数と同じ加法関係を適用せず、所定内・所定外の恒等分解には実数系列を使用する。

#### 一般・パートの就業形態構成分解

就業形態計の平均的な水準変化が、一般労働者・パートタイム労働者それぞれの内部変化と、両者の構成比変化のどちらに対応するかを確認する。

就業形態 $e$、年 $t$ について、指標の年平均値を $X_{e,t}$、就業形態構成比を $s_{e,t}$ とする。

各月の労働者ウェイトを、

$$\frac{B_{e,y,m}+C_{e,y,m}}{2}$$

とし、$B$ は前月末労働者数、$C$ は本月末労働者数とする。年間の就業形態構成比は、

$$\frac{\sum_m w_{e,y,m}}{\sum_e\sum_m w_{e,y,m}}$$

として求める。

一般労働者とパートタイム労働者から再構成した指標水準は、

$$\sum_e s_{e,t}X_{e,t}$$

とする。

開始時点0と終了時点1の再構成値の変化は、対称分解により、

$$\underbrace{\sum_e \frac{s_{e,0}+s_{e,1}}{2} (X_{e,1}-X_{e,0})}_{就業形態内効果} + \underbrace{\sum_e \frac{X_{e,0}+X_{e,1}}{2} (s_{e,1}-s_{e,0})}_{就業形態構成効果}$$

に分ける。

就業形態内効果は、一般労働者・パートタイム労働者それぞれの内部で指標水準が変化したことに対応する。就業形態構成効果は、一般・パートの構成比が変化したことに対応する。

就業形態計として公表された値の変化を $\Delta X$ とし、一般・パートから再構成した変化との差を、 $\Delta X-\Delta X^{R}$ として再構成残差に残す。このため、

$$就業形態内効果 + 就業形態構成効果 + R$$

が成立する。

変化率への寄与として示す場合は、各効果を就業形態計の開始時点水準 $X_0$ で割り100倍する。

この分解は、きまって支給する給与、総実労働時間、所定内労働時間、所定外労働時間、出勤日数を対象とする。時間当たり賃金 $W/T$ と1出勤日当たり所定内労働時間 $S/D$ は比率指標であり、一般・パートの人数構成比による単純な加重平均として再構成できないため、この水準分解の対象とはしない。

### 2.5 就業者数と平均週間就業時間の分解

#### 就業者数の人口・就業率分解

年齢階級 $g$、年 $t$ の就業者数を $E_{g,t}$、人口を $P_{g,t}$、就業率を $r_{g,t}$ とする。就業率は、計算では百分率を100で割った比率として使用する。

$$
E_{g,t}=P_{g,t}r_{g,t}
$$

本分析では、人口を公表就業者数と就業率から逆算する。

$$
P_{g,t}=\frac{E_{g,t}}{r_{g,t}}
$$

年齢階級ごとの就業者数変化を、対称分解により、

$$\Delta E_g = \underbrace{\frac{r_{g,0}+r_{g,1}}{2}\Delta P_g}_{人口要因} + \underbrace{\frac{P_{g,0}+P_{g,1}}{2}\Delta r_g}_{就業率要因}$$

に分ける。

> 式展開 (添字 $g$ を省略)
> $P_1 = P_0 + \Delta P, \ r_1 = r_0 + \Delta r \text{より、}$
> $\Delta E = P_1 r_1 - P_0 r_0 = \underbrace{r_0 \Delta P}_{人口要因} + \underbrace{P_0 \Delta r}_{就業率要因} + \underbrace{\Delta P \Delta r}_{交差項}$
>
> 交差項を就業率要因と人口要因に半分ずつ配分すると、
> $\Delta E = \left(r_0 + \frac{\Delta r}{2} \right) \Delta P + \left(P_0 + \frac{\Delta P}{2} \right) \Delta r \text{なので、}$
> $$\Delta E = \frac{r_{0}+r_{1}}{2}\Delta P + \frac{P_{0}+P_{1}}{2}\Delta r$$

使用する就業率は丸められた公表値であるため、逆算人口と各要因は近似値として扱う。また、就業率要因は観測された就業率変化に対応する項であり、雇用政策などの因果効果ではない。

#### 従業者構成比と全体平均の再構成

年齢階級 $g$、年 $t$ とする。**年齢階級別の**延週間就業時間を $L_{g,t}$、平均週間就業時間を $H_{g,t}$ とし、従業者数を、 $N_{g,t}=\frac{L_{g,t}}{H_{g,t}}$ として逆算する。延週間就業時間が万時間／週、平均週間就業時間が時間／週の場合、人数の単位は万人となる。

年齢階級別の従業者構成比は、

$$s_{g,t} = \frac{N_{g,t}}{\sum_g N_{g,t}}$$

とする。**全体の**平均週間就業時間は、

$$H_t^{*} = \sum_g s_{g,t}H_{g,t} = \frac{\sum_g L_{g,t}}{\sum_g N_{g,t}}$$

として再構成する。

集計には重複しない6年齢階級を使用し、「15歳以上全体」を追加して二重計上しない。 $H_t^{*}$ は年齢階級別公表値からの再構成値であり、公表された全体平均と完全に一致することを前提としない。

#### 年齢層内効果と年齢構成効果

全体平均の変化は、対称分解により、

$$\Delta H^{*} = \underbrace{\sum_g \frac{s_{g,0}+s_{g,1}}{2} (H_{g,1}-H_{g,0})}_{年齢層内効果} + \underbrace{\sum_g \frac{H_{g,0}+H_{g,1}}{2} (s_{g,1}-s_{g,0})}_{年齢構成効果}$$

に分ける。両効果の単位は時間／週である。

年齢層内効果は、各年齢階級の平均時間が変化した項を示す。各年齢階級内の性別、雇用形態、産業などの構成は固定していないため、同一人物の時間変化を表すものではない。

年齢構成効果は、年齢階級間の従業者構成比が変化した項を示す。分解上の寄与であり、人口高齢化や特定の政策の因果効果とは区別する。

#### 年齢層内効果の性別追加分解

年齢階級 $g$、性別 $j$、年 $t$ について、男女別平均週間就業時間を $H_{g,j,t}$、年齢階級内の性別構成比を $q_{g,j,t}$ とする。

性別構成比は、男女別の延週間就業時間と平均週間就業時間から逆算した従業者数を用いて求める。

$$N_{g,j,t} = \frac{L_{g,j,t}}{H_{g,j,t}}, \qquad q_{g,j,t} = \frac{N_{g,j,t}}{\sum_j N_{g,j,t}}$$

各年齢階級の平均週間就業時間変化を、

$$\Delta H_g = \underbrace{\sum_j q_{g,j}^{mid}\Delta H_{g,j}}_{性別内時間効果} + \underbrace{\sum_j H_{g,j}^{mid}\Delta q_{g,j}}_{性別構成効果} + R_g$$

に分解する。

$R_g$ は、男女別公表値から再構成した年齢階級平均と、男女計として公表された平均週間就業時間との差に対応する再構成残差である。公表値の丸めなどによる小さな差を、性別内時間効果または性別構成効果へ配分しないために明示的に残す。

さらに、第2.5節の年齢層内効果と対応させるため、各項に開始・終了時点の平均年齢構成比 $s_g^{mid}$ を乗じる。

$$A = \underbrace{\sum_g s_g^{mid} \sum_j q_{g,j}^{mid}\Delta H_{g,j}}_{性別内時間効果} + \underbrace{\sum_g s_g^{mid} \sum_j H_{g,j}^{mid}\Delta q_{g,j}}_{性別構成効果} + \underbrace{\sum_g s_g^{mid}R_g}_{再構成残差}$$

ここで $A$ は既存の年齢層内効果である。この追加分解によって、年齢階級内部の平均時間低下が、男女それぞれの平均時間変化と男女構成比変化のどちらに対応するかを確認する。

### 2.6 就業時間分布の集計

長期比較では、週間就業時間を次の3区分に統一する。

| 長期比較区分 | 詳細区分からの再構成              |
| ------------ | --------------------------------- |
| 1～34時間    | 1～14時間＋15～29時間＋30～34時間 |
| 35～48時間   | 35～39時間＋40～48時間            |
| 49時間以上   | 49～59時間＋60時間以上            |

公表上位区分が利用できる年は、その値を優先する。上位区分が存在しない年のみ、対応する詳細区分を合計する。詳細区分を合計すると、各区分の公表値の丸めによって上位区分と差が生じる場合があるためである。

49時間以上は、2017年までは公表上位区分、2018年以降は49～59時間と60時間以上の合計を使用する。両者を同一年で直接照合できる重複期間がないため、2017～2018年だけの変化を強く解釈しない。

年齢階級 $g$、時間区分 $k$、年 $t$ の人数を $F_{g,k,t}$、同じ分布表の従業者総数を $F_{g,t}^{all}$ とすると、構成比は、

$$p_{g,k,t} = \frac{F_{g,k,t}}{F_{g,t}^{all}} \times 100$$

とする。

分母を3区分の人数合計に置き換えて100%に再調整することはしない。このため、区分の合計と従業者総数の差や公表値の丸めにより、構成比の合計は100%と一致しない場合がある。対象データでは、3区分が従業者総数をカバーする割合は平均約99.3%である。

2018～2025年は詳細7区分も使用し、長時間帯の減少が49～59時間と60時間以上のどちらで生じたかなどを確認する。

分布分析は、各時点の構成比の比較である。ある時間帯の構成比低下と別の時間帯の上昇が同時に観測されても、同じ個人が時間帯を移動したとは判断しない。

#### 正規・非正規別の時間分布分解

正規・非正規別の分析では、平均週間就業時間そのものではなく、週1～34時間および週49時間以上の就業者割合を対象とする。

年齢階級 $g$、雇用形態 $e$、年 $t$ について、対象時間区分の構成比を $p_{g,e,t}$、年齢階級内の正規・非正規構成比を $w_{g,e,t}$ とする。

年齢階級全体の時間区分構成比変化を、

$$\Delta p_g = \underbrace{\sum_e w_{g,e}^{mid}\Delta p_{g,e}}_{雇用形態内効果} + \underbrace{\sum_e p_{g,e}^{mid}\Delta w_{g,e}}_{雇用形態構成効果} + R_g$$

に分解する。

雇用形態内効果は、正規・非正規それぞれの内部で対象時間区分の割合が変化したことに対応する。雇用形態構成効果は、正規・非正規の人数構成比が変化したことに対応する。再構成残差 $R_g$ は、正規・非正規から再構成した値と、役員を除く雇用者全体の公表値との差である。

この分析は時間分布を対象とする補助分析であり、年齢層内効果を時間単位で正規・非正規に直接分解するものではない。

### 2.7 総労働投入の分解

#### 総労働投入の水準

総労働投入には、年齢階級別の公表延週間就業時間を使用する。

$$L_t = \sum_g L_{g,t}$$

従業者総数を、 $N_t = \sum_g N_{g,t}$ とすると、第2.5節の定義から、 $L_t=N_tH_t^{*}$ が成立する。総労働投入の水準は公表延週間就業時間から求め、逆算従業者数はその変化を分解するために使用する。

#### 従業者総数・年齢層内時間・年齢構成への分解

開始時点0と終了時点1について、

$$N^{mid} = \frac{N_0+N_1}{2}, \qquad H^{mid} = \frac{H_0^{*}+H_1^{*}}{2}$$

とすると、

$$\Delta L = H^{mid}\Delta N + N^{mid}\Delta H^{*}$$

と対称分解できる。

さらに、第2.5節の年齢層内効果を $A$、年齢構成効果を $B$ とすると、 $\Delta H^{*} = A + B$ であるため、

$$\Delta L = \underbrace{H^{mid}\Delta N}_{従業者総数効果} + \underbrace{N^{mid}A}_{年齢層内時間効果} + \underbrace{N^{mid}B}_{年齢構成効果}$$

となる。

各寄与の単位は万時間／週である。総労働投入の変化率への寄与として示す場合は、各項を開始時点の総労働投入 $L_0$ で割り、100倍する。

これは、まず総労働投入を人数と平均時間に分け、次に平均時間の変化を年齢層内と年齢構成に分ける、階層的な対称分解である。各寄与はこの分解方法に基づく値として解釈する。

#### 年齢階級別の人数・時間分解

年齢階級ごとの総労働投入変化も、

$$\Delta L_g = \underbrace{\frac{H_{g,0}+H_{g,1}}{2}\Delta N_g}_{従業者数効果} + \underbrace{\frac{N_{g,0}+N_{g,1}}{2}\Delta H_g}_{平均週間就業時間効果}$$

と分解する。

この分解によって、人数減少と時間短縮が重なった年齢階級や、人数増加が時間短縮を上回った年齢階級を確認する。年齢階級別の2要因分解と全体の3要因分解は、総変化については整合するが、分解の階層が異なるため、個々の要因をそのまま同一視しない。

分解の一致は丸め前の値で確認する。掲載表では表示桁への丸めにより、各寄与の合計と総変化に差が生じる場合がある。また、計算上の恒等関係が成立しても、公表値から逆算した人数の推計精度や、各要因の因果的な解釈が保証されるわけではない。

15～54歳では**人口要因が就業者数を押し下げる方向に働いたが、就業率上昇がその一部または全部を相殺**した。55～64歳では増加のほぼ全てが就業率要因に対応した。一方、65歳以上では人口要因の寄与が大きく、**高齢人口の増加と就業率上昇の双方が就業者数を押し上げた**。

#### 3.4.2 2015～2025年の直近10年間

直近10年間では、年齢階級ごとの就業者数変化の方向がさらに異なる。

以上から、年齢別就業者数の変化は、人口構成と就業率の双方によって決まり、その相対的重要性は年齢階級と比較期間によって異なる。就業者数の増減だけから就業参加の拡大・縮小を判断することはできない。

### 3.5 平均週間就業時間と年齢構成

> 平均週間就業時間は、2000～2025年、2015～2025年のいずれでも低下した。その大部分は年齢構成の変化ではなく、各年齢階級内部での平均週間就業時間の低下に対応した。2000～2025年では低下幅の約91%、2015～2025年では約89%が年齢層内効果だった。

#### 3.5.1 2000～2025年の長期変化

年齢階級別の平均週間就業時間を比較すると、すべての年齢階級で低下した。

| 年齢階級 |   2000年 |   2025年 |    変化量 |  変化率 |
| -------- | -------: | -------: | --------: | ------: |
| 15～24歳 | 39.6時間 | 29.0時間 | −10.6時間 | −26.77% |
| 25～34歳 | 45.7時間 | 39.2時間 |  −6.5時間 | −14.22% |
| 35～44歳 | 44.1時間 | 38.1時間 |  −6.0時間 | −13.61% |
| 45～54歳 | 43.3時間 | 38.2時間 |  −5.1時間 | −11.78% |
| 55～64歳 | 41.8時間 | 36.5時間 |  −5.3時間 | −12.68% |
| 65歳以上 | 34.9時間 | 28.2時間 |  −6.7時間 | −19.20% |

15～24歳で低下幅が最も大きかったが、25～64歳の各階級でも5～7時間程度低下した。65歳以上でも6.7時間低下しており、**長期的な時間短縮は特定の年齢階級だけに限られない**。  
年齢階級別の延週間就業時間と平均週間就業時間から従業者数を逆算し、その構成比を用いて全体平均を再構成すると、平均週間就業時間は42.73時間から35.87時間へ6.86時間低下した。

| 要因         |      寄与 | 低下幅に占める割合 |
| ------------ | --------: | -----------------: |
| 年齢層内効果 | −6.27時間 |            約91.4% |
| 年齢構成効果 | −0.59時間 |             約8.6% |
| 合計         | −6.86時間 |               100% |

両効果とも全体平均を低下させる方向だったが、**低下の大部分は年齢層内効果に対応**した。  
年齢構成効果の内部では、25～34歳など比較的平均時間の長い年齢階級の構成比低下が全体平均を押し下げる一方、55～64歳や65歳以上の構成比上昇は逆方向に作用した。したがって、「高齢者の増加」がそのまま年齢構成効果全体を意味するわけではなく、各年齢階級の時間水準と構成比変化の組合せによって決まる。

#### 3.5.2 2015～2025年の直近10年間

直近10年間でも、すべての年齢階級で平均週間就業時間が低下した。

| 年齢階級 |   2015年 |   2025年 |   変化量 |  変化率 |
| -------- | -------: | -------: | -------: | ------: |
| 15～24歳 | 34.6時間 | 29.0時間 | −5.6時間 | −16.18% |
| 25～34歳 | 42.2時間 | 39.2時間 | −3.0時間 |  −7.11% |
| 35～44歳 | 41.2時間 | 38.1時間 | −3.1時間 |  −7.52% |
| 45～54歳 | 40.6時間 | 38.2時間 | −2.4時間 |  −5.91% |
| 55～64歳 | 37.8時間 | 36.5時間 | −1.3時間 |  −3.44% |
| 65歳以上 | 31.6時間 | 28.2時間 | −3.4時間 | −10.76% |

再構成した全体平均は39.04時間から35.87時間へ3.17時間低下した。

| 要因         |      寄与 | 低下幅に占める割合 |
| ------------ | --------: | -----------------: |
| 年齢層内効果 | −2.83時間 |            約89.3% |
| 年齢構成効果 | −0.34時間 |            約10.7% |
| 合計         | −3.17時間 |               100% |

2000～2025年と同様に、年齢構成効果より**年齢層内効果の方が大きかった**。35～44歳の構成比低下は全体平均を押し下げる方向に働いた一方、45歳以上の構成比上昇は一部を相殺した。それでも年齢構成効果全体はマイナスとなった。  
したがって、2015～2025年の平均週間就業時間低下も、高年齢層の構成比上昇だけでは説明できない。**25～54歳を含むすべての年齢階級で平均週間就業時間そのものが低下しており、全体平均低下の約9割は各年齢階級内部の変化に対応**した。  
ただし、年齢層内効果には、それぞれの年齢階級内部における性別、就業形態、産業、職業、従業上の地位などの構成変化が含まれる。年齢層内効果を、同じ個人の労働時間短縮と解釈することはできない。

#### 3.5.3 年齢層内効果の性別分解

2015～2025年の年齢層内効果 −2.83時間を、男女それぞれの平均週間就業時間変化と、年齢階級内の男女構成比変化へさらに分解した。

| 要因           |       寄与 | 年齢層内効果に対する比率 |
| -------------- | ---------: | -----------------------: |
| 性別内時間効果 |  −2.59時間 |                  約91.6% |
| 性別構成効果   |  −0.24時間 |                   約8.6% |
| 再構成残差     | ＋0.01時間 |                  約−0.2% |
| 年齢層内効果   |  −2.83時間 |                     100% |

年齢層内効果の約92%は、年齢階級内の男女構成比変化ではなく、**男女それぞれの平均週間就業時間低下に対応**した。  
年齢階級別にみても、性別内時間効果はすべての階級でマイナスだった。一方、性別構成効果も全階級でマイナスだったが、その絶対値は性別内時間効果より小さかった。  
したがって、2015～2025年の平均週間就業時間低下は、高年齢層の構成比上昇だけでなく、年齢階級内の女性比率上昇だけでも説明できない。年齢と性別をある程度固定しても、平均週間就業時間の低下が確認された。  
ただし、性別内時間効果の内部には、就業形態、産業、職業、従業上の地位などの構成変化がなお含まれる。

### 3.6 就業時間分布の変化

> 就業時間分布は、2000～2025年、2015～2025年のいずれでも、49時間以上の長時間帯がすべての年齢階級で縮小し、1～34時間の短時間帯がすべての年齢階級で拡大した。一方、35～48時間帯の変化方向は年齢階級によって異なり、25～64歳では構成比が上昇したのに対し、15～24歳と65歳以上では低下した。

#### 3.6.1 2000～2025年の長期3区分

15歳以上全体について、従業者総数を分母とした週間就業時間の構成比を比較した。

| 週間就業時間 | 2000年 | 2025年 | 構成比の変化 |

**49時間以上の構成比は約29%から約14%へ低下し、ほぼ半減**した。一方、**1～34時間の構成比は約22%から約36%へ上昇**した。35～48時間の変化は全体では小さかった。

したがって、2000～2025年の就業時間短縮は、単に全体で短時間就業者が増えたという一様な変化ではない。**中核年齢層では49時間以上の縮小と35～48時間の拡大が同時に生じる一方、若年層と65歳以上では1～34時間への分布の偏りがより大きかった**。

#### 3.6.2 2015～2025年の直近10年間

2015～2025年の15歳以上全体では、次の変化が確認された。

| 35～48時間   |     ＋2.63pt |
| 49時間以上   |      −7.61pt |

| 年齢階級 | 1～34時間 | 35～48時間 | 49時間以上 |

したがって、2015～2025年にみられた「中核年齢層では長時間帯の縮小と35～48時間帯の拡大、若年層と高年齢層では1～34時間帯の拡大」という特徴は、長期的な分布変化とも方向が整合する。  
ただし、これらは各時点における集団の構成比を比較したものであり、同一人物が49時間以上から35～48時間、あるいは1～34時間へ移動したことを直接示すものではない。

ただし、時間区分内の平均時間も変化し得るため、時間帯別構成比の変化だけから平均週間就業時間低下への厳密な寄与を求めることはできない。

### 3.7 総労働投入の変化と要因分解

> 総労働投入は2000～2025年に12.58%減少した一方、2015～2025年の減少は2.07%にとどまった。いずれの期間でも、各年齢階級内部の平均週間就業時間低下が総労働投入を押し下げたが、従業者数の増加がこれを一部相殺した。年齢階級別には、人数変化の方向が異なるため、総労働投入の増減も一様ではなかった。

#### 3.7.1 総労働投入の長期変化

年齢階級別の公表延週間就業時間を合計し、総労働投入を比較した。

| 年     |        総労働投入 |
| ------ | ----------------: |
| 2000年 | 270,293万時間／週 |
| 2015年 | 241,272万時間／週 |
| 2025年 | 236,287万時間／週 |

| 比較期間     |            変化量 |  変化率 |
| ------------ | ----------------: | ------: |
| 2000～2025年 | −34,006万時間／週 | −12.58% |
| 2015～2025年 |  −4,985万時間／週 |  −2.07% |

**総労働投入は両期間で減少**したが、2000～2025年の減少幅の方が大きかった。**2015～2025年には従業者数増加による押上げが大きく**、1人当たり平均週間就業時間の低下に比べて、総労働投入の減少は小さかった。

#### 3.7.2 2000～2025年の3要因分解

総労働投入 $L$ を、従業者総数 $N$ と全体平均週間就業時間 $H^*$ の積、$L=NH^*$として考える。さらに、第3.5節で全体平均時間の変化を年齢層内効果と年齢構成効果に分解した結果を用いると、総労働投入の変化を、

$$\Delta L = \underbrace{H^{mid}\Delta N}_{従業者総数効果} + \underbrace{N^{mid}A}_{年齢層内時間効果} + \underbrace{N^{mid}B}_{年齢構成効果}$$

に分解できる。

ここでいう**年齢構成効果**とは、従業者総数そのものの増減や各年齢階級内部の平均週間就業時間変化とは別に、従業者が各年齢階級にどのように配分されるかが変化したことによる寄与である。例えば、平均週間就業時間の異なる年齢階級の構成比が変化すると、それだけで全体平均時間が変化し、総労働投入にも影響する。  
したがって、年齢構成効果は単純な「高齢者数の増加効果」ではない。25～34歳や35～44歳の構成比低下、55～64歳や65歳以上の構成比上昇など、すべての年齢階級の構成比変化を合わせた効果である。

2000～2025年の結果は次のとおりである。

| 要因             |               寄与 |
| ---------------- | -----------------: |
| 従業者総数効果   | ＋10,289万時間／週 |
| 年齢層内時間効果 |  −40,502万時間／週 |
| 年齢構成効果     |   −3,793万時間／週 |
| 総労働投入の変化 |  −34,006万時間／週 |

従業者総数の増加は総労働投入を押し上げたが、各年齢階級内部の平均週間就業時間低下による押下げの方が大きかった。年齢構成変化も総労働投入を押し下げる方向に寄与した。  
時間側の押下げの中心は年齢層内時間効果であり、2000～2025年の総労働投入減少の最大の構成項だった。

#### 3.7.3 2015～2025年の3要因分解

同じ方法で2015～2025年を分解すると、次のようになる。

| 要因             |               寄与 |
| ---------------- | -----------------: |
| 従業者総数効果   | ＋15,255万時間／週 |
| 年齢層内時間効果 |  −18,065万時間／週 |
| 年齢構成効果     |   −2,176万時間／週 |
| 総労働投入の変化 |   −4,985万時間／週 |

従業者総数効果は大きくプラスだった一方、年齢層内時間効果と年齢構成効果はいずれもマイナスだった。  
時間短縮と年齢構成変化による押下げの合計に対して、従業者数増加による押上げは約75%に相当した。そのため、**平均週間就業時間は大きく低下したものの、総労働投入の減少率は2.07%にとどまった**。  
また、時間側の押下げのうち約89%は年齢層内時間効果だった。これは第3.5節の平均週間就業時間分解を総労働投入の単位へ換算したものであり、独立した別の分析結果ではない。

#### 3.7.4 年齢階級別の総労働投入変化

全体の3要因分解とは別に、各年齢階級について、

$$\Delta L_g = \underbrace{\frac{H_{g,0} + H_{g,1}}{2} \Delta N_g}_{従業者数効果} + \underbrace{\frac{N_{g,0} + N_{g,1}}{2} \Delta H_g}_{平均週間就業時間効果}$$

と2要因に分解した。

この分解は、各年齢階級の総労働投入変化を「その階級の従業者数変化」と「その階級内部の平均週間就業時間変化」に分けるものである。

注：各値の単位は万時間／週。各効果は表示桁に丸めている。ここでいう従業者数は、延週間就業時間を平均週間就業時間で除して逆算した値であり、第3.4節の公表就業者数とは異なる。

2000～2025年では、すべての年齢階級で平均時間効果がマイナスだった。一方、従業者数効果は年齢によって方向が異なった。  
**15～34歳では人数減少と時間短縮が重なり、総労働投入が大きく減少**した。35～44歳でも両要因がマイナスだった。45～54歳では人数増加による押上げがみられたが、時間短縮の方が大きく、総労働投入は減少した。  
これに対し、**55～64歳と65歳以上では人数増加による押上げが時間短縮による押下げを上回り、総労働投入は増加**した。特に65歳以上では56.28%増加した。

**35～44歳では人数減少と時間短縮が重なり、総労働投入は約23%減少**した。25～34歳では人数はほぼ変わらず、減少のほぼ全てが平均時間低下に対応した。15～24歳では人数増加による押上げと時間短縮による押下げがほぼ相殺された。

なお、ここで示した年齢階級別の「従業者数効果」と、全体3要因分解の「従業者総数効果」「年齢構成効果」は分解の階層が異なる。年齢階級別の従業者数効果を単純に全体の年齢構成効果の内訳と解釈することはできない。

## 4. 結果の頑健性確認

本章では、公式労働時間指数との比較、比較期間の変更、一般労働者・パートタイム労働者別の補助分析を通じて、第3章の結果がどの範囲で維持されるかを確認する。

それぞれの確認対象は異なる。公式指数との比較は実数系列による長期方向、期間別比較は始点・終点への依存、就業形態別比較は集団を分けた場合の変化を確認するものである。これらによって、すべての統計上の問題や構成変化の影響が解消されるわけではない。

### 4.1 公式労働時間指数との比較

毎月勤労統計の実数系列には、標本入替えやベンチマーク更新などに伴う時系列上の影響が含まれる可能性がある。そこで、実数系列による1990～2025年の変化率を、時系列比較用の公式労働時間指数による変化率と比較した。

| 指標           | 実数系列による変化率 | 公式指数による変化率 |
| -------------- | -------------------: | -------------------: |
| 総実労働時間   |              −21.48% |              −21.32% |
| 所定内労働時間 |              −21.20% |              −20.65% |
| 所定外労働時間 |              −24.89% |              −27.73% |

総実労働時間と所定内労働時間では、実数系列と公式指数の変化率が近かった。総実労働時間が約21%減少したこと、所定内労働時間も長期的に減少したことは、公式指数を用いても確認された。

所定外労働時間は、公式指数の方が減少率が大きかった。減少方向は一致したが、変化の大きさには総実・所定内労働時間よりも差があった。

したがって、**1人当たり総実労働時間と所定内労働時間が長期的に減少したという結果は、公式指数との比較でも維持された**。一方、実数系列による変化率や寄与の数値が、公式指数でもそのまま再現されるわけではない。

公式指数は各系列について作成されるため、指数値に実数と同じ加法関係を適用しない。本分析では、実数系列を恒等分解に、公式指数を長期方向の確認に使用する。また、この比較だけでは、出勤日数と1出勤日当たり時間への分解結果や、月額賃金の分解結果まで検証したことにはならない。

公式労働時間指数については、保存した公式指数ファイルから1990年・2025年の年平均指数を再取得し、総実労働時間−21.32%、所定内労働時間−20.65%、所定外労働時間−27.73%を再計算した。上表はこの最終確認結果と一致している。再計算方法とCY公表年平均との照合結果は付録Bに記録する。

### 4.2 比較期間による違い

#### 総労働投入の期間別比較

2015～2025年という比較期間への依存を確認するため、労働力調査による総労働投入の変化を複数期間で比較した。

| 比較期間     | 総労働投入の変化率 | 従業者総数効果 | 年齢層内時間効果 | 年齢構成効果 |
| ------------ | -----------------: | -------------: | ---------------: | -----------: |
| 2000～2010年 |             −9.09% |         −9,436 |          −14,487 |         −646 |
| 2012～2019年 |            ＋0.28% |       ＋15,361 |          −11,996 |       −2,686 |
| 2012～2025年 |             −3.47% |       ＋18,371 |          −23,512 |       −3,359 |
| 2015～2025年 |             −2.07% |       ＋15,255 |          −18,065 |       −2,176 |
| 2020～2025年 |            ＋1.15% |        ＋7,810 |           −4,590 |         −530 |
| 2000～2025年 |            −12.58% |       ＋10,289 |          −40,502 |       −3,793 |

各効果の単位は万時間／週である。期間の長さが異なるため、変化率や寄与の絶対値を変化の速さとして直接比較しない。また、重複する期間を含むため、各行は独立した観測ではない。

年齢層内時間効果と年齢構成効果は、掲載したすべての期間でマイナスだった。一方、従業者総数効果の符号と大きさは期間によって異なった。

2000～2010年には、人数と時間の双方が総労働投入を押し下げた。2012～2019年には、従業者数増加が時間短縮と年齢構成変化による押下げをほぼ相殺し、総労働投入はほぼ横ばいだった。2020～2025年には人数増加の寄与が押下げを上回り、総労働投入は増加した。

このため、**時間側の寄与がマイナスであることは複数期間に共通するが、総労働投入が減少するかどうかは比較期間に依存する**。2015～2025年に確認された約75%という相殺割合も、その期間に固有の値であり、他の期間へ一般化しない。

また、各期間の始点・終点比較から、期間内のすべての年で同じ方向に変化したとは判断しない。

#### 長時間就業者の構成比と2020年の変化

49時間以上の就業者構成比について、2020年以前の変化と2019～2020年の変化を比較した。

| 比較期間     | 49時間以上の構成比変化 |
| ------------ | ---------------------: |
| 2000～2010年 |          −5.15ポイント |
| 2012～2019年 |          −4.39ポイント |
| 2019～2020年 |        約−3.16ポイント |

49時間以上の構成比は、2020年以前の両期間でも低下していた。したがって、2000～2025年の長時間帯の縮小を、2020年の変化だけで説明することはできない。

一方、2019～2020年には1年間で大きな低下が観測された。長期的な変化を読む際には、2020年の急変を区別する必要がある。同様に、2020年を起点とした総労働投入の増加には、起点の水準が影響するため、それだけで長期的な増加への転換とは判断しない。

これらの比較は変化の時期を整理したものであり、感染症流行の因果効果を推定したものではない。

#### 確認範囲

以上から、長時間帯の構成比低下が2020年以前から生じていたこと、総労働投入に対する時間側の押下げが複数期間で確認されることは維持された。一方、総労働投入の増減方向と人数による相殺の程度は、比較期間によって異なった。

毎月勤労統計のローリング10年比較については、本章では個別の再計算結果を掲載していない。そのため、すべての10年区間で出勤日数が主要な寄与項だったなど、未掲載の結果に基づく一般化は行わない。

## 5. 考察と限界

### 5.1 時間短縮・就業形態構成・人数増加の関係

本分析では、1人当たり労働時間の変化を、その内部構造、就業形態構成、働く人数の変化に分けることで、集計平均だけでは分からない相殺関係を確認した。

毎月勤労統計では、長期的な平均労働時間低下の一部に、一般労働者・パートタイム労働者の構成変化が対応していた。2000～2025年の総実労働時間は12.50%減少したが、このうち就業形態内効果は−7.00ポイント、就業形態構成効果は−5.52ポイントだった。パートタイム労働者の構成比は20.16%から31.30%へ上昇しており、相対的に労働時間の短いパートタイム労働者の比率上昇が、全体平均を押し下げる方向に寄与した。

就業形態別系列が利用できる1993～2025年まで遡ると、総実労働時間の変化は−15.60%、就業形態内効果は−7.51ポイント、構成効果は−8.10ポイントとなった。この最長比較では、両者の寄与はほぼ同程度だった。

一方、2015～2025年では構造が異なる。パートタイム労働者の構成比は30.39%から31.30%への上昇にとどまり、総実労働時間の変化−6.49%に対して、就業形態内効果が−6.00ポイント、構成効果が−0.51ポイントだった。したがって、近年の平均労働時間低下をパート比率上昇によって説明することは難しく、一般労働者・パートタイム労働者それぞれの内部での時間短縮が中心だった。

この期間差は、「平均労働時間低下の原因」を単一の構成変化で説明することの危険性を示す。1990年代から2000年代を含む長期では就業形態構成の変化が重要だったが、近年ではその寄与は小さい。どの要因が大きいかは、比較期間を明示した上で判断する必要がある。

月額賃金についても同様である。2000～2025年には一般労働者の月額賃金が10.72%、パートタイム労働者では20.84%上昇したにもかかわらず、就業形態計では1.26%の上昇にとどまった。分解では就業形態内効果＋11.05ポイントに対して構成効果が−9.79ポイントとなり、内部の賃金上昇の約89%に相当する部分が構成変化によって集計値上相殺されていた。

したがって、長期の就業形態計だけから「月額賃金がほとんど上昇しなかった」と評価すると、一般・パートそれぞれの内部で生じた変化を見落とす。他方、2015～2025年では月額賃金の構成効果は−0.86ポイントと小さく、近年については各就業形態内部の変化が集計値にも比較的そのまま表れている。

労働力調査では、1人当たり時間と総労働投入を区別することで、時間短縮と人数増加の相殺関係を確認した。2015～2025年には各年齢層の平均週間就業時間が低下する一方、従業者総数が増加した。人数増加は時間短縮と年齢構成変化による総労働投入の押下げの約75%を相殺し、総労働投入の減少は2.07%にとどまった。

一方、2000～2010年には人数と時間の双方が減少し、2012～2019年には人数増加と時間側の押下げがほぼ相殺した。2020～2025年には人数増加が時間側の押下げを上回った。したがって、日本の労働投入の変化を、全期間を通じた単一の人数・時間関係で説明することもできない。

毎月勤労統計と労働力調査は異なる対象と時間単位を測定しているため、両者の分解結果を直接足し合わせることはできない。毎月勤労統計で確認された出勤日数減少が、労働力調査の年齢層内時間効果の何割を説明するかといった接続分解は行っていない。

賃金についても、月額と時間当たりを区別する必要がある。時間当たり賃金が上昇しても労働時間が減少すれば、恒等関係上、月額賃金の伸びは小さくなる。ただし、本分析の時間当たり賃金は集計値の比率であり、その変化だけから契約上の時給や個人の待遇改善を評価することはできない。

### 5.2 集団平均・分布から読み取れる範囲

#### 複数段階の構成分解から分かること

本分析では、異なる統計と分類を用いて複数の構成効果を確認した。

毎月勤労統計では、一般労働者・パートタイム労働者の構成変化を分離した。その結果、長期では構成効果が平均労働時間低下に大きく対応した一方、2015～2025年では構成効果は小さく、一般・パート双方の内部での時間短縮が中心だった。

労働力調査では、2015～2025年の平均週間就業時間低下の約89%が年齢層内効果に対応した。さらに性別で追加分解すると、年齢層内効果の約92%は男女それぞれの平均週間就業時間低下に対応し、男女構成比変化の寄与は約9%だった。

また、役員を除く雇用者について正規・非正規別の週間就業時間分布を分析すると、週1～34時間割合の雇用形態内効果は確認したすべての年齢・期間でプラス、週49時間以上割合ではすべてマイナスだった。

以上から、労働時間低下について「高齢者が増えたから」「女性が増えたから」「パート・非正規が増えたから」という単一の構成要因だけで説明することはできない。構成変化の寄与は確かに存在するが、その大きさは分類と期間によって異なり、各集団内部の時間変化も大きい。

ただし、毎月勤労統計の一般労働者・パートタイム労働者と、労働力調査の正規・非正規は異なる分類である。両者の結果を同一の「雇用形態効果」として読み替えない。

さらに、性別や就業形態を分けても、その内部には産業、職業、企業規模、勤続年数などの構成変化が残る。したがって、本分析は同じ個人の勤務時間が短縮したことまで示すものではない。

#### 同じ年齢階級と同じ人々の違い

年を隔てた同じ年齢階級の比較は、同じ人々を追跡した比較ではない。例えば、2015年の35～44歳と2025年の35～44歳は、基本的に異なる出生年の集団である。

したがって、35～44歳の総労働投入減少を、その年齢にある個人の行動変化だけに帰属させることはできない。人口規模の異なる世代が年齢階級を移ることも、人数や構成比の変化に含まれる。

同様に、45歳以上の総労働投入増加が若い年齢層の減少を部分的に補ったという結果は、集計上の相殺関係である。企業や職場で、両者が同じ仕事を代替したことを示すものではない。

#### 分布変化と個人の移動

就業時間分布では、49時間以上の構成比が低下し、短時間帯や35～48時間帯の構成比が上昇した。しかし、この比較から、長時間働いていた人が別の時間帯へ移動したとは判断できない。

分布変化には、既存就業者の時間変更に加え、就業への参入・退出や、異なる属性を持つ人々の構成変化が含まれる。また、同じ時間区分の内部でも平均時間は変化し得るため、区分別構成比だけから平均週間就業時間の変化を完全には復元できない。

1～34時間の構成比上昇も、それ自体では本人が望んだ短時間就業の拡大を意味しない。追加就労を希望しているかどうかを本分析では確認しておらず、自発的な選択と希望に満たない就業時間を区別できない。

### 5.3 統計・推計上の限界

#### 調査対象と時間の測定方法

毎月勤労統計は対象事業所の常用労働者に関する月間指標、労働力調査は世帯側から把握した就業状態・週間就業時間に関する指標である。対象範囲と測定方法が異なるため、両統計の水準差をそのまま測定誤差とみなすことはできない。

総労働投入として使用した年平均の延週間就業時間も、年間の累積労働時間ではない。月間時間や年間時間へ単純に換算して、他の指標と同一視しない。

#### 公表値からの逆算

年齢構成分解に用いる従業者数は、年齢別の延週間就業時間を平均週間就業時間で割って求めた値である。また、人口・就業率分解の人口も、公表就業者数と就業率から逆算している。

これらの公表値には丸めがあるため、逆算値にもその影響が含まれる。特に、人口・就業率分解は近似的な寄与として解釈する必要がある。再構成した全体平均についても、公表された全体平均との完全一致を前提としない。

逆算した人数を使えば計算上の恒等関係を維持できるが、その一致は人数推計の精度を独立に検証したことにはならない。分解残差が小さいことと、元の統計値に誤差がないことは別である。

#### 年平均の再計算と公式年平均

毎月勤労統計の本文掲載値は、公表月次値について前月末・本月末労働者数の平均を月次ウェイトとし、12か月を加重平均して再計算した年平均に統一した。時間当たり賃金および1出勤日当たり所定内労働時間は、この年平均基礎系列から算出している。

2015年・2025年の就業形態計、一般労働者、パートタイム労働者について、月額賃金、総実・所定内・所定外労働時間、出勤日数、派生指標の水準・変化率を再計算した。また、1993年、2000年についても同じ方法で算出し、長期比較に使用した。

したがって、本文に掲載する毎月勤労統計の精密値について、旧集計からの最終再計算そのものは完了している。

一方、公表月次値には丸めが含まれるため、月次値から再計算した年平均と、原表に収録された公表年平均（CY）が完全に一致するとは限らない。分析・分解では恒等関係を維持できる再計算年平均を使用し、公表年平均は外部照合値として扱う。

公式年平均との差については、主要年・主要系列を対象とした最終照合結果を付録に記録する必要がある。小さな差が確認された場合には、月次公表値の丸めによる差と、集計条件・計算方法の不一致を区別する。

#### 就業形態構成分解の再構成残差

毎月勤労統計の就業形態構成分解では、一般労働者・パートタイム労働者から再構成した変化と、就業形態計として直接算出した変化との差を再構成残差として残している。

総実労働時間や所定内労働時間、月額賃金では残差は極めて小さく、主要結論を左右しない。一方、出勤日数などでは2015～2025年の構成効果自体が小さいため、構成効果と残差の細かな大小を過度に解釈しない。

再構成残差が小さいことは分解の数値的一貫性を示すが、元統計の測定誤差がないことや、構成効果に因果的意味があることを保証しない。

#### 時系列断層・欠測・区分接続

毎月勤労統計の公式指数との比較では主要な長期方向が維持されたが、標本入替えやベンチマーク更新の影響が、実数系列のすべての年や分解項について除去されたわけではない。

労働力調査では、使用する一部系列の2011年全国値が欠測している。始点・終点が利用できる長期比較は行えるが、欠測年を含む連続した年次変化は確認できない。

就業時間分布の49時間以上は、2017年までの公表上位区分と、2018年以降の詳細区分合計を接続している。定義上は対応するが、重複年で直接照合できないため、接続点だけの変化には慎重な解釈が必要である。

さらに、分布の構成比は未分類分などを除いて100%へ再調整していない。構成比合計が100%にならないことを踏まえ、3区分間の変化が完全な一対一の置換であるとは扱わない。

#### 推計誤差と分解方法

本分析は公表集計値を用いた点推定の比較であり、各変化や寄与について標本誤差を反映した信頼区間を算出していない。そのため、小幅な変化について統計的に有意な差があるとは判断しない。

総労働投入の3要因分解は、まず人数と平均時間を分け、次に平均時間を年齢層内と年齢構成に分ける方法である。総変化は恒等的に一致するが、各項への配分は採用した分解方法に基づく。別の分解順序や交差項の配分方法でも、各要因の寄与が同じになることまでは保証しない。

### 5.4 恒等分解と因果関係の区別

特に、2000～2025年のパートタイム労働者構成比上昇と月額賃金・労働時間の構成効果は、パートタイム労働者の増加がそれらの変化を因果的に発生させたことを意味しない。観測された一般・パートの水準差と構成比変化を、対称分解によって整理した結果である。

本分析の「効果」「要因」「寄与」は、観測された変化を恒等式に基づいて分けた項を指す。特定の政策や行動が、結果をどれだけ変化させたかという因果効果ではない。

例えば、所定内労働時間の低下が出勤日数減少に対応したとしても、その背景が有給休暇の取得、会社休日の増加、暦配置、シフト変更、就業形態の変化のどれであるかは分からない。

年齢構成効果についても、高齢者雇用政策の効果や人口高齢化だけの影響を取り出したものではない。従業者構成比には、年齢別人口、就業率、休業状態などの変化が関係し得る。

同様に、従業者数増加が時間短縮による総労働投入減少を相殺したという結果は、人数が増えなかった場合の労働時間や総労働投入を予測したものではない。人数と時間は互いに関連して変化し得るため、一方だけを固定した反実仮想として解釈しない。

また、労働時間の減少を、そのまま生産性の上昇や労働者の厚生改善と評価することはできない。生産性を論じるには産出量との関係が、厚生を論じるには所得、本人の希望、健康、余暇などの情報が必要である。本分析では、労働の質や職務内容を調整していないため、総労働投入の減少を経済全体の生産能力の同率の低下ともみなさない。

したがって、本分析から示せるのは、**どの集団で人数・時間・分布が変化し、それらが平均時間と総労働投入の変化をどのように構成したか**である。その変化がなぜ生じ、望ましいものだったかを判断するには、各仮説に対応した追加データと分析設計が必要となる。

## 6. 結論と今後の課題

### 6.1 結論

本分析では、日本の労働投入の長期変化を、毎月勤労統計による月間労働時間・賃金・就業形態構成と、労働力調査による年齢別の人数・時間・性別構成・就業時間分布・総労働投入から整理した。

毎月勤労統計では、1990～2025年に就業形態計の1人当たり総実労働時間が約21%減少した。一般労働者・パートタイム労働者別に2000～2025年をみると、総実労働時間はそれぞれ4.87%、18.75%減少した。就業形態計の12.50%減少を分解すると、就業形態内効果が−7.00ポイント、就業形態構成効果が−5.52ポイントであり、長期的な平均労働時間低下には各就業形態内部の時間短縮とパート比率上昇の双方が対応した。利用可能な最長期間である1993～2025年でも、両効果はほぼ同程度だった。

これに対し2015～2025年では、総実労働時間の6.49%減少のうち就業形態内効果が−6.00ポイント、構成効果が−0.51ポイントだった。一般労働者・パートタイム労働者の双方で出勤日数が減少し、1出勤日当たり所定内労働時間は小幅に増加していた。したがって、直近10年間の労働時間低下はパート比率上昇ではなく、主として各就業形態内部の出勤日数減少に対応した。

月額賃金でも期間による違いが確認された。2000～2025年には一般労働者で10.72%、パートタイム労働者で20.84%上昇した一方、就業形態計では1.26%の上昇にとどまった。分解では就業形態内効果＋11.05ポイントに対して構成効果が−9.79ポイントであり、長期の集計値には一般・パート構成変化が大きく影響していた。2015～2025年では構成効果は−0.86ポイントまで縮小し、近年の賃金変化は各就業形態内部の変化をより強く反映していた。

労働力調査では、2000～2025年に就業率がすべての年齢階級で上昇した一方、就業者数は15～34歳で減少し、55歳以上で大きく増加した。65歳以上では461万人増加し、長期では人口増加の寄与が大きかった。一方、2015～2025年では35～44歳の就業者数が減少したにもかかわらず就業率は上昇しており、人数の増減と就業参加の変化は区別して見る必要がある。65歳以上の211万人増加については、約7割が就業率要因に対応した。

平均週間就業時間は、2000～2025年に再構成平均で42.73時間から35.87時間へ6.86時間低下し、その約91%が年齢層内効果に対応した。2015～2025年でも39.04時間から35.87時間へ3.17時間低下し、その約89%が年齢層内効果だった。さらに直近10年間の年齢層内効果を性別で分解すると、その約92%は男女それぞれの平均週間就業時間低下に対応した。したがって、平均週間就業時間の低下を高年齢層や女性の構成比上昇だけで説明することはできない。

就業時間分布でも、2000～2025年には49時間以上の構成比が大幅に低下し、1～34時間の構成比が上昇した。49時間以上の割合はすべての年齢階級で低下したが、25～64歳では35～48時間帯も拡大した一方、15～24歳と65歳以上では1～34時間帯の拡大がより大きかった。正規・非正規別の時間分布でも、短時間・長時間就業割合の変化は雇用形態構成だけでは説明できず、それぞれの雇用形態内部の変化が大きかった。

総労働投入は2000～2025年に12.58%、2015～2025年に2.07%減少した。両期間で最大の押下げ項は年齢層内時間効果だった一方、従業者数増加は減少を相殺する方向だった。2015～2025年には人数増加が時間短縮と年齢構成変化による押下げの約75%を相殺した。年齢階級別には、平均週間就業時間の低下による効果はすべての階級でマイナスだった一方、55歳以上では長期的な人数増加が時間短縮を上回り、総労働投入が増加した。

以上から、日本の労働投入の変化を理解するには、①1人当たり時間と人数、②各属性集団内部の変化と構成比変化、③月額賃金と時間当たり賃金、④長期変化と近年の変化を分ける必要がある。構成変化は長期的には重要だったが、近年の時間短縮の大部分は各集団内部の変化として残る。また、各年齢階級で平均時間が低下する一方、高年齢層の人数増加が経済全体の労働投入減少を部分的に相殺していた。

これらは記述統計と恒等分解に基づく結論であり、同じ個人の行動変化、政策の因果効果、生産性、本人の希望や厚生を直接示すものではない。

$g$ は年齢階級、 $k$ は就業時間区分、 $t$ は年、 $m$ は月を表す。開始時点と終了時点を0、1とし、 $\Delta X=X_1-X_0$ とする。

年齢別の合計・構成分解には、重複しない6年齢階級を使用する。「15歳以上全体」の行を同時に合計しない。

### A.2 年平均と派生指標

就業形態 $e$、年 $y$、月 $m$ の毎月勤労統計の各月のウェイトを、 $w_{e,y,m}=\frac{B_{e,y,m}+C_{e,y,m}}{2}$ とする。 $B$ は前月末、 $C$ は本月末の常用労働者数である。

基礎系列 $X$ の年平均は、

$$\bar X_y= \frac{\sum_{m=1}^{12}w_{y,m}X_{y,m}}{\sum_{m=1}^{12}w_{y,m}}$$

とする。年次の派生指標は、

$$q_y=\frac{\bar W_y}{\bar T_y},\qquad h_y=\frac{\bar S_y}{\bar D_y}$$

として、年平均値から計算する。

したがって、月次比率の加重平均、

$$\frac{\sum_m w_m(W_m/T_m)}{\sum_m w_m}$$

は、本分析の年次時間当たり賃金とは異なる。分解に使用する年次指標は、集計順序を統一する。

年間の一般・パート構成比は、

$$\pi_{e,y} = \frac{\sum_m w_{e,y,m}}{\sum_e\sum_m w_{e,y,m}}$$

として求める。

この構成比は、各月の構成比を単純平均したものではなく、年間の労働者ウェイト合計から算出する。

### A.3 変化率・指数・移動平均

| 指標                    | 計算式                                                |
| ----------------------- | ----------------------------------------------------- |
| 水準差                  | $\Delta X=X_1-X_0$                                    |
| 期間変化率              | $100(\frac{X_1}{X_0}-1)$                              |
| 対数変化                | $100\ln\frac{X_1}{X_0}$                               |
| 基準時点を100とする指数 | $I_t=100\frac{X_t}{X_b}$                              |
| 前年同月比              | $100(\frac{X_{y,m}}{X_{y-1,m}}-1)$                    |
| 12か月移動平均          | $\text{MA}_{12,t}=\frac{1}{12}\sum_{j=0}^{11}X_{t-j}$ |

$X_b$ は明示した基準時点の値である。変化率の分母は正、対数変化では両時点の値が正であることを前提とする。前年同月比は年月で対応づけ、移動平均は連続した12暦月がそろう場合に限る。

対数変化を $d$ とすると、通常の変化率との関係は、

$$g = 100 \left( e^{\frac{d}{100}} - 1 \right)$$

である。対数寄与を通常の変化率の寄与として、そのまま読み替えない。

構成比を百分率で表した場合、その差 $p_1 - p_0$ の単位はパーセントポイントとする。

### A.4 分解式の一覧

年次の毎月勤労統計の分解には、A.2で定義した年平均と派生指標を使用する。

| 対象                   | 分解式                                                                                          |
| ---------------------- | ----------------------------------------------------------------------------------------------- |
| 月額賃金               | $100\ln(\frac{W_1}{W_0})=100\ln(\frac{q_1}{q_0})+100\ln(\frac{T_1}{T_0})$                       |
| 総実労働時間           | $\Delta T=\Delta S+\Delta O$                                                                    |
| 所定内労働時間         | $100\ln(\frac{S_1}{S_0})=100\ln(\frac{D_1}{D_0})+100\ln(\frac{h_1}{h_0})$                       |
| 就業者数               | $\Delta E_g=r_g^{mid}\Delta P_g+P_g^{mid}\Delta r_g$                                            |
| 平均週間就業時間       | $\Delta H^{*}=\sum_g s_g^{mid}\Delta H_g+\sum_g H_g^{mid}\Delta s_g$                            |
| 総労働投入             | $\Delta L=H^{mid}\Delta N+N^{mid}A+N^{mid}B$                                                    |
| 年齢別総労働投入       | $\Delta L_g=H_g^{mid}\Delta N_g+N_g^{mid}\Delta H_g$                                            |
| 年齢層内効果の性別分解 | $A=\sum_g s_g^{mid}(\sum_j q_{g,j}^{mid}\Delta H_{g,j}+\sum_j H_{g,j}^{mid}\Delta q_{g,j}+R_g)$ |
| 雇用形態別時間分布     | $\Delta p_g=\sum_e w_{g,e}^{mid}\Delta p_{g,e}+\sum_e p_{g,e}^{mid}\Delta w_{g,e}+R_g$          |
| 一般・パート構成分解   | $\Delta X^R=\sum_e \pi_e^{mid}\Delta X_e+\sum_e X_e^{mid}\Delta \pi_e$                          |
| 就業形態計との差       | $\Delta X=\Delta X^R+R_X$                                                                       |

上付きの $mid$ は開始・終了時点の単純平均を示す。例えば、 $X^{mid} = \frac{X_0 + X_1}{2}$ である。総労働投入の式では、 $H^{mid} = \frac{H_0^{*} + H_1^{*}}{2}$ とし、 $A$ は年齢層内効果、 $B$ は年齢構成効果を表す。

$$A=\sum_g s_g^{mid}\Delta H_g, \qquad B=\sum_g H_g^{mid}\Delta s_g$$

対称分解は、積 $Z=XY$ に対する次の恒等関係に基づく。

$$\Delta Z = Y_0\Delta X+X_0\Delta Y+\Delta X\Delta Y = Y^{mid}\Delta X+X^{mid}\Delta Y$$

開始時点を基準にした展開の交差項 $\Delta X\Delta Y$ を、両要因へ半分ずつ配分した形である。

したがって、

$$\Delta X = \underbrace{\sum_e \pi_e^{mid}\Delta X_e}_{就業形態内効果} + \underbrace{\sum_e X_e^{mid}\Delta\pi_e}_{就業形態構成効果} + R_X$$

となる。

変化率への寄与として示す場合は、

$$100\frac{就業形態内効果}{X_0}, \qquad 100\frac{就業形態構成効果}{X_0}, \qquad 100\frac{R_X}{X_0}$$

を用いる。

対象は、きまって支給する給与、総実労働時間、所定内労働時間、所定外労働時間、出勤日数とする。

時間当たり賃金 $q=W/T$ と1出勤日当たり所定内労働時間 $h=S/D$ は比率指標であり、 $\pi_{e,t}$ による単純加重平均として再構成できないため、この分解の対象としない。

### A.5 逆算値・時間分布・寄与割合

就業者数の人口・就業率分解では、 $P_{g,t} = \frac{E_{g,t}}{r_{g,t}}$ を使用する。平均時間と総労働投入の分解では、

$$N_{g,t} = \frac{L_{g,t}}{H_{g,t}}, \qquad s_{g,t} = \frac{N_{g,t}}{\sum_g N_{g,t}}, \qquad H_t^{*} = \frac{\sum_g L_{g,t}}{\sum_g N_{g,t}}$$

を使用する。逆算元となる就業率・平均時間は正であることを前提とする。

時間分布の構成比とカバー率は、

$$p_{g,k,t} = 100 \frac{F_{g,k,t}}{F_{g,t}^{all}}$$

$$c_{g,t} = 100 \frac{\sum_k F_{g,k,t}}{F_{g,t}^{all}}$$

とする。構成比の分母は分布表の従業者総数であり、分類できた人数だけを分母にして100%へ再調整しない。

長期3区分は公表上位区分を優先し、存在しない年のみ対応する詳細区分を合計する。

平均時間の低下に占める年齢層内効果の割合は、両効果がともに負の場合、

$$100\frac{-A}{-(A + B)}$$

とする。効果の符号が異なる場合は、単純な「低下幅の内訳」として解釈しない。

総労働投入について、従業者総数効果を $C_N$、年齢層内時間効果を $C_H$、年齢構成効果を $C_S$ とする。 $C_N>0$ 、 $C_H<0$ 、 $C_S<0$ の場合、人数増加による相殺割合は、

$$100\frac{C_N}{-(C_H + C_S)}$$

とする。2015～2025年の約75%はこの定義による。一般に100%を超える場合もあり、その場合は人数の押上げが時間・構成の押下げを上回る。

寄与の合計は丸め前の値で検算し、表の表示時に丸める。表示値だけを足し合わせた差を分解残差とは扱わない。

#### CY公表年平均との照合

本文で使用する毎月勤労統計の年平均は、公表月次値を前月末・本月末常用労働者数の平均で加重して再計算している。この再計算値の妥当性を確認するため、1993年、2000年、2015年、2025年について、就業形態計、一般労働者、パートタイム労働者の主要5指標を原表のCY公表年平均と照合した。

3就業形態×4年×5指標の60ケースを比較した結果、最大絶対差は次のとおりだった。

| 指標                 | CY公表値との差の最大絶対値 |
| -------------------- | -------------------------: |
| きまって支給する給与 |                    0.486円 |
| 総実労働時間         |                  0.076時間 |
| 所定内労働時間       |                  0.051時間 |
| 所定外労働時間       |                  0.058時間 |
| 出勤日数             |                    0.051日 |

すべての差はCY公表値の最小表示単位以内だった。所定外労働時間のように水準が小さい指標では相対差が大きく見える場合があるが、絶対差はいずれも小さい。

したがって、月次公表値から再計算した年平均はCY公表年平均と高い整合性を示した。本文の分析・分解では恒等関係と集計方法を統一するため再計算年平均を使用し、CY公表値は外部照合値として扱う。なお、両者の小さな差には公表値の丸め等が含まれ得るため、完全一致は前提としない。
