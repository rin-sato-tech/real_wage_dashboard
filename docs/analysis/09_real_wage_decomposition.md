# 実質賃金の名目賃金・物価要因分解

作成日：2026-09-04

位置づけ：`docs/analysis/09_real_wage_decomposition.md`

---

## 1. 目的

本分析では、

> 実質賃金の変化は、名目賃金の変化と物価の変化によってどのように構成されているか。特に、近年の実質賃金低下は名目賃金の弱さと物価上昇のどちらによるものか。

を検証する。

これまでの分析では、給与構成、労働投入、産業構成、労働需給、企業業績・生産性・労働分配、企業の賃金改定行動まで、名目賃金側の変化を分析してきた。本分析は、それらを物価側と接続し、実質購買力の変化を直接説明する役割を持つ。

---

## 2. 主な問い

1. 名目賃金上昇率が物価上昇率を上回った年・下回った年はいつか。
2. 2015年から2025年の累積的な実質賃金変化は、名目賃金要因と物価要因にどう分けられるか。
3. 2020年代の実質賃金低下では、物価上昇がどの程度重要だったか。
4. 自前計算した実質賃金指数は、公式実質賃金指数をどの程度再現できるか。
5. CPI系列を変えた場合、結果はどの程度変わるか。

---

## 5. 方法上の重要原則

毎月勤労統計では、ベンチマーク更新等により指数水準に断層が生じる場合がある。

探索段階では2024年について、

- 名目賃金指数から単純計算した前年比：約+5.5%
- 公表名目賃金前年比：+2.8%

と大きな差が確認された。

実質賃金でも、

- 指数から単純計算した前年比：約+2.3%
- 公表実質賃金前年比：-0.3%

となった。

したがって、分析では次のように役割を分ける。

| 用途                 | 使用系列                    |
| -------------------- | --------------------------- |
| 年ごとの名目賃金変化 | **公表前年比**              |
| 年ごとの実質賃金変化 | **公表前年比**              |
| CPI変化              | 年平均CPIから計算した前年比 |
| 長期累積名目変化     | **公表前年比を連鎖**        |
| 長期累積物価変化     | CPI前年比を連鎖             |
| 要因分解             | 公表前年比を対数化          |
| 指数水準             | 公式系列との照合・検証      |

**指数水準の単純な前年差・期間差を、ベンチマーク更新をまたぐ経済的な変化率として直接解釈しない。**

---

## 6. 実質賃金指数の検証

名目賃金指数を $W_t$、CPIを $P_t$ とする。

自前計算の実質賃金指数原系列を、$R_t^{raw} = \frac{W_t}{P_t} \times 100$とする。

これを2020年平均=100へ再基準化し、$R_t^{calc} = \frac{R_t^{raw}}{R_{2020}^{raw}} \times 100$とする。

これを公式実質賃金指数と比較する。

探索段階では2015～2025年について、公式指数との最大絶対差は約0.06ポイントだった。したがって、名目賃金指数とCPIを用いた実質化ロジックは妥当と判断する。

---

## 7. 年次変化率

### 7.1 名目賃金前年比

長期時系列表に掲載された公表前年比、$g_{W,t}$を使用する。

### 7.2 CPI前年比

CPI年平均を $P_t$ とすると、$g_{P,t} = \frac{P_t}{P_{t-1}} - 1$とする。

### 7.3 実質賃金前年比

公式長期時系列表に掲載された公表実質賃金前年比、$g_{R,t}$を使用する。

年次推移の説明では、この公表値を優先する。

---

## 8. 賃金－物価格差

説明用指標として、

$\text{賃金－物価格差} = g_{W,t} - g_{P,t}$

を計算する。

| 値    | 解釈                               |
| ----- | ---------------------------------- |
| 正    | 名目賃金上昇率が物価上昇率を上回る |
| 0付近 | 両者が概ね同程度                   |
| 負    | 物価上昇率が名目賃金上昇率を上回る |

これは直感的な説明指標であり、厳密な加法分解ではない。

---

## 9. 公表前年比を用いた対数分解

名目賃金前年比とCPI前年比を小数で表す。

### 名目賃金寄与

$C_{W,t} = 100 \ln(1 + g_{W,t})$

### 物価寄与

$C_{P,t} = -100\ln(1 + g_{P,t})$

### 機械的な実質賃金変化

$C^{*}_{R,t} = C_{W,t}+C_{P,t}$

とする。

したがって、

```text
機械的な実質賃金変化 = 名目賃金寄与 + 物価寄与
```

が厳密に成立する。

公表実質賃金前年比を対数化した値とは、丸め、指数改訂、統計上の調整等により小さな差が生じる可能性がある。

よって、

- 公表実質賃金前年比：公式の年次変化確認
- 名目賃金前年比＋CPI前年比：要因分解

として役割を分ける。

---

## 10. 公表前年比を連鎖した累積変化

2015年を起点として、2016～2025年の公表前年比を連鎖する。

### 10.1 名目賃金累積変化

$G_W = \prod_{t=2016}^{2025} (1 + g_{W,t}) - 1$

### 10.2 物価累積変化

$G_P = \prod_{t=2016}^{2025} (1 + g_{P,t}) - 1$

### 10.3 実質賃金の機械的累積変化

$G_R^{*} = \frac{1+G_W}{1+G_P} - 1$

とする。

指数水準の単純比ではなく、公表前年比を連鎖することでベンチマーク更新による断層を避ける。

---

## 11. 累積対数寄与

2015→2025について、

### 名目賃金累積寄与

$L_W = 100 \sum_{t=2016}^{2025} \ln(1 + g_{W,t})$

### 物価累積寄与

$L_P = -100 \sum_{t=2016}^{2025} \ln(1 + g_{P,t})$

### 実質賃金累積変化

$L_R = L_W + L_P$

とする。

---

## 17. 既存分析との接続

本分析では、名目賃金上昇の原因そのものを新たに推定しない。

これまでの分析で確認した、

- 所定内給与の上昇
- 時間当たり賃金の上昇
- 労働時間減少
- 産業内賃金上昇
- 労働需給逼迫
- 生産性・企業収益
- 賃金改定行動

を名目賃金側の背景として位置づけ、本分析ではその最終的な実質購買力への接続を行う。

- 個別世帯の生活費上昇率
- 個々の労働者の実質購買力変化
- 賃金分布の各層での実質賃金変化
- 為替、輸入物価、資源価格等の因果効果
- 春闘や最低賃金の因果効果

## 20. 分析上の注意点

### 20.1 集計値である

毎月勤労統計の集計値であり、同一人物の賃金変化を表すものではない。

### 20.2 CPIは個別世帯の生活費を直接表さない

CPIは平均的な消費構造に基づく物価指数である。

### 20.3 CPI系列によって結果が変わりうる

主系列を明示し、感度分析を行う。

### 20.4 ベンチマーク更新と指数断層

- 年次変化：公表前年比
- 長期累積変化：公表前年比を連鎖
- 指数水準：照合・検証用

と役割を分ける。

### 20.5 分解は因果関係を示さない

対数分解は恒等的・機械的分解であり、原因を示すものではない。
