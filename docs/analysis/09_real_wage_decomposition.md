# 実質賃金の名目賃金・物価要因分解

作成日：2026-09-04

位置づけ：`docs/analysis/09_real_wage_decomposition.md`

---

## 1. 問い

本分析では、

> 実質賃金の変化は、名目賃金の変化と物価の変化によってどのように構成されているか。特に、近年の実質賃金低下は名目賃金の弱さと物価上昇のどちらによるものか。

を検証する。

これまでの分析では、給与構成、労働投入、産業構成、労働需給、企業業績・生産性・労働分配、企業の賃金改定行動など、名目賃金側の変化を分析してきた。

本分析は、それらを物価側と接続し、名目賃金の上昇が実質購買力の改善につながったかを確認する。

---

## 2. 結論

2015年から2025年までの公表前年比を連鎖すると、

- 名目賃金：**+9.73%**
- CPI（持家の帰属家賃を除く総合）：**+16.59%**
- 機械的な実質賃金：**-5.88%**

となった。

対数分解では、

- 名目賃金寄与：**+9.29**
- 物価寄与：**-15.35**
- 実質賃金変化：**-6.06**

であった。

したがって、2015～2025年の実質賃金低下は、

> 名目賃金が全く伸びなかったためではなく、名目賃金上昇以上に物価が上昇したため

と整理できる。

特に2022～2025年は、名目賃金が毎年増加したにもかかわらず、CPI上昇率がそれを上回ったため、実質賃金は弱い状態が続いた。

## 4. 方法上の注意

毎月勤労統計では、ベンチマーク更新等により指数水準に断層が生じる場合がある。

実際に2024年について、

- 名目賃金指数から単純計算した前年比：約+5.5%
- 公表名目賃金前年比：+2.8%

となり、大きな差が確認された。

実質賃金でも、

- 指数水準から単純計算した前年比：約+2.3%
- 公表実質賃金前年比：-0.3%

となった。

したがって、本分析では次のように役割を分けた。

| 用途                 | 使用系列           |
| -------------------- | ------------------ |
| 年ごとの名目賃金変化 | 公表前年比         |
| 年ごとの実質賃金変化 | 公表前年比         |
| CPI変化              | 年平均CPIから算出  |
| 長期累積名目変化     | 公表前年比を連鎖   |
| 長期累積物価変化     | CPI前年比を連鎖    |
| 要因分解             | 公表前年比を対数化 |
| 指数水準             | 検証・照合用       |

指数水準の単純な前年差・期間差を、ベンチマーク更新をまたぐ経済的な変化率として直接解釈しない。

---

## 5. 実質賃金指数の再現確認

名目賃金指数を $W_t$、CPIを $P_t$ とする。

自前計算の実質賃金指数原系列を、$R_t^{raw} = \frac{W_t}{P_t} \times 100$とし、2020年平均=100へ再基準化した。

その結果、2015～2025年における自前計算実質賃金指数と公式実質賃金指数の最大絶対差は、

```text
0.059ポイント
```

であった。

したがって、名目賃金指数とCPIから実質賃金指数を再計算するロジックは、公式系列をほぼ再現している。

### 6.2 2015～2021年

2015～2021年は、実質賃金が改善する年と低下する年が混在していた。

2016年と2021年ではCPIが低下したため、名目賃金の小幅上昇でも実質賃金はプラスとなった。

一方、

- 2015年
- 2017年
- 2019年
- 2020年

では、名目賃金の伸び不足または低下により実質賃金がマイナスとなった。

この時期は、近年ほど大きな物価上昇が継続していたわけではない。

---

## 7. 2022～2025年の特徴

2022年以降は構造が明確である。

| 年   | 名目賃金 |   CPI | 実質賃金 |
| ---- | -------: | ----: | -------: |
| 2022 |    +2.0% | +3.0% |    -1.0% |
| 2023 |    +1.2% | +3.8% |    -2.5% |
| 2024 |    +2.8% | +3.2% |    -0.3% |
| 2025 |    +2.3% | +3.7% |    -1.3% |

この4年間は、**名目賃金は毎年増加している**。

しかし同時に、CPI上昇率が毎年名目賃金上昇率を上回った。

したがって、

> 近年の実質賃金低下は、「賃金が上がっていない」よりも、「賃金は上がっているが物価上昇に追いついていない」と表現する方が正確

である。

特に2023年は、

- 名目賃金：+1.2%
- CPI：+3.8%
- 実質賃金：-2.5%

となり、物価上昇が名目賃金上昇を大きく上回った。

---

## 8. 2015→2025累積変化

2016～2025年の公表前年比を連鎖した。

### 8.1 累積変化率

| 指標           | 2015→2025 |
| -------------- | --------: |
| 名目賃金       |    +9.73% |
| CPI            |   +16.59% |
| 機械的実質賃金 |    -5.88% |

名目賃金は約1割上昇した一方、物価は約1.7割上昇した。

この差によって、実質購買力は約5.9%低下した計算になる。

---

### 8.2 対数要因分解

| 要因     | 対数寄与 |
| -------- | -------: |
| 名目賃金 |    +9.29 |
| 物価     |   -15.35 |
| 実質賃金 |    -6.06 |

この分解からも、

> 名目賃金の上昇は実質賃金を押し上げる方向に働いたが、物価上昇による押下げの方が大きかった

ことが分かる。

したがって、2015～2025年の実質賃金低下を「名目賃金停滞」だけで説明するのは不十分である。

## 9. 2024年の指数断層

2024年は、指数水準と公表前年比の違いが特に大きい。

### 名目賃金

```text
指数から単純計算した前年比：+5.507%
公表前年比：+2.800%
```

### 実質賃金

```text
指数から単純計算した前年比：+2.253%
公表前年比：-0.300%
```

この差は、ベンチマーク更新等に伴う指数水準の断層によるものである。

したがって、本分析では2024年を含む時系列比較に指数水準の単純前年差を用いず、公表前年比を使用した。


> 実質賃金の評価はデフレーターとしてどのCPI系列を使用するかに一定程度依存する

ことが確認できる。

ただし、2022～2025年全体として「物価上昇が名目賃金上昇を圧迫した」という大きな結論は変わらない。

## 11. 既存分析との接続

これまでの分析では、2015年以降の名目賃金上昇について、

- 所定内給与の上昇
- 時間当たり賃金の上昇
- 労働時間減少による一部相殺
- 産業内賃金上昇
- 労働需給逼迫との正の関連
- 企業の生産性・収益性改善
- 2023～2025年の賃金改定率上昇

などを確認してきた。

本分析によって、これらの名目賃金側の改善が、そのまま実質購買力改善にはつながっていないことが分かった。

構造としては、

```text
名目賃金を押し上げる要因
        ↓
名目賃金 +9.73%
        │
        ├─────────┐
        ↓         ↓
   賃金寄与 +9.29   物価寄与 -15.35
        └────┬────┘
             ↓
       実質賃金 -5.88%
```

と整理できる。

## 12. この分析から言えること

- 2015～2025年で名目賃金は上昇した。
- 同期間の物価上昇率は名目賃金上昇率を上回った。
- その結果、実質賃金は累積で低下した。
- 2022～2025年は名目賃金が毎年増加したが、物価上昇に追いつかなかった。
- 近年の実質賃金低下では、物価要因の押下げが大きかった。
- CPI系列を変えると実質賃金前年比は一定程度変化する。
- 自前計算した実質賃金指数は公式系列をほぼ再現できた。

---

## 13. この分析だけでは言えないこと

- なぜ物価が上昇したか
- なぜ名目賃金上昇が物価上昇に遅れたか
- 物価上昇が賃金改定を因果的に引き起こしたか
- 為替、輸入物価、資源価格等の物価への寄与
- 春闘や最低賃金の因果効果
- 個々の労働者の実質購買力変化
- 賃金分布ごとの実質賃金変化
- 個別世帯の生活費上昇率

## 14. 制約

### 14.1 集計平均である

毎月勤労統計の集計値であり、同一人物の賃金変化を追跡したものではない。

### 14.2 CPIは平均的な物価指数である

個々の世帯の消費構造とは異なる。

### 14.3 CPI系列によって結果が変わる

本分析では「持家の帰属家賃を除く総合」を主系列とし、「総合」を感度分析に用いた。

### 14.4 ベンチマーク更新がある

指数水準には断層が生じる場合があるため、長期累積変化には公表前年比を連鎖した。

### 14.5 要因分解は因果分析ではない

対数分解は恒等的・機械的な分解であり、物価上昇や賃金上昇の原因そのものを示さない。

## 17. 結論

2015～2025年では、名目賃金は約9.7%上昇したが、物価は約16.6%上昇した。

その結果、実質賃金は機械的に約5.9%低下した。

したがって、この10年間の実質賃金低下は、

> **賃金が全く上がらなかったことではなく、賃金上昇よりも物価上昇の方が大きかったこと**

によって説明される。

特に2022～2025年は、名目賃金が毎年増加していたにもかかわらず、物価上昇率がそれを上回ったため、実質賃金改善には至らなかった。

これまでの分析で確認してきた賃金上昇要因は、名目賃金の改善にはつながっている。しかし、実質購買力という観点では、その改善幅が近年の物価上昇を吸収するには不足していたと整理できる。
