## 1. 分析の目的

本分析の目的は、日本の労働投入が長期的にどのように変化してきたかを、単なる平均労働時間の増減ではなく、

1. **誰が働いているか**
2. **各労働者層がどれだけ働いているか**
3. **労働者構成の変化と各層内部の変化のどちらが平均値を動かしたか**
4. **労働者数と労働時間を合わせた総労働投入量がどう変化したか**
5. **人的資本等を考慮した労働投入の質がどう変化したか**

まで分解して明らかにすることである。

現在の毎月勤労統計を用いた分析では、常用労働者1人当たりの労働時間を、

```text
総実労働時間
├─ 所定内労働時間
│  ├─ 出勤日数
│  └─ 1出勤日当たり所定内労働時間
└─ 所定外労働時間
```

と分解している。

この分析は維持する一方、平均値だけでは、

- 高齢者など短時間就業者の労働参加増加による構成効果
- 現役世代そのものの労働時間短縮
- 就業者数の変化
- 短時間労働者と長時間労働者の分布変化

を区別できない。

そこで、毎月勤労統計、労働力調査、JIPデータベースを役割分担させ、日本の労働投入を「人数・時間・構成・質」の4側面から分析する。

## 2. 分析上の主要な問い

### 問1：1人当たり労働時間は長期的にどの程度変化したか

毎月勤労統計を用いて、

- 総実労働時間
- 所定内労働時間
- 所定外労働時間
- 出勤日数
- 1出勤日当たり所定内労働時間

について1990年以降の長期推移を確認する。

2015年から2025年だけではなく、1990年以降の推移を確認し、現在確認されている労働時間短縮がどの時期から生じた現象なのかを明らかにする。

---

### 問2：月額賃金の変化は、時間当たり給与と労働時間のどちらから生じたか

既存分析を維持し、

$$W_t=W^{hr}_tH_t$$

として、

$$\Delta\ln W = \Delta\ln W^{hr} + \Delta\ln H$$

により、

- 概算時間当たり給与
- 総実労働時間

へ分解する。

ただし、`きまって支給する給与 ÷ 総実労働時間` は企業が設定する純粋な賃金単価ではないため、文書上は一貫して**概算時間当たり給与**または**時間当たりでみた給与水準**と表現する。

---

### 問3：平均労働時間の低下は、どの年齢層で生じたか

労働力調査を用い、

- 15～24歳
- 25～34歳
- 35～44歳
- 45～54歳
- 55～64歳
- 65歳以上

について平均就業時間を比較する。

25～54歳については、

- 25～34歳
- 35～44歳
- 45～54歳

の3階級を中核年齢層として重点的に確認する。

現段階では25～54歳を単一系列へ再集計せず、年齢階級別の結果を主分析とする。

これにより、

> 平均労働時間が低下したのは、高齢者など短時間就業者の割合が増えたためなのか、それとも25～54歳を含む各年齢層内部でも労働時間が短縮したためなのか

を区別する。

年齢別の労働時間には、労働力調査の年平均表から取得した**平均週間就業時間**を使用する。

平均週間就業時間は「従業者」を対象とした指標であるため、年齢構成比についても就業者数をそのまま使用せず、

$$N^{work}_{g,t} = \frac{AggregateWeeklyHours_{g,t}}{AverageWeeklyHours_{g,t}}$$

により、年齢階級別の延週間就業時間と平均週間就業時間から従業者数を逆算する。

そのうえで、

$$s_{g,t} = \frac{N^{work}_{g,t}}{\sum_g N^{work}_{g,t}}$$

として、平均週間就業時間と整合する従業者構成比を作成する。

利用期間は2000～2025年である。ただし2011年は東日本大震災の影響により全国値が欠測しているため、補間せず欠測のまま扱う。

---

### 問4：平均労働時間低下のうち、労働者構成変化はどの程度を説明するか

年齢層 $g$ の就業者構成比を $s_{g,t}$、平均労働時間を $H_{g,t}$ とする。

全体平均は、

$$\bar H_t=\sum_g s_{g,t}H_{g,t}$$

で表される。

開始時点0と終了時点1との差を、対称分解により、

$$\Delta\bar H = \sum_g \frac{s_{g,1}+s_{g,0}}{2} (H_{g,1}-H_{g,0}) + \sum_g \frac{H_{g,1}+H_{g,0}}{2} (s_{g,1}-s_{g,0})$$

と分解する。

### 層内効果

$$Within = \sum_g \bar s_g \Delta H_g$$

各年齢層内部で労働時間が変化した効果。

### 構成効果

$$Composition = \sum_g \bar H_g\Delta s_g$$

各年齢層の就業者構成比が変化した効果。

したがって、

$$平均労働時間変化 = 層内効果 + 構成効果$$

が完全に成立するよう実装する。

2015～2025年について対称分解を行った結果、

| 指標                   |      結果 |
| ---------------------- | --------: |
| 2015年平均週間就業時間 | 39.04時間 |
| 2025年平均週間就業時間 | 35.87時間 |
| 合計変化               | -3.17時間 |
| 年齢層内効果           | -2.83時間 |
| 年齢構成効果           | -0.34時間 |

となった。

平均週間就業時間低下に占める割合では、

- 年齢層内効果：約89.3%
- 年齢構成効果：約10.7%

である。

したがって、2015～2025年の平均週間就業時間低下の大部分は、高齢化などによる年齢構成変化ではなく、**各年齢層の内部で平均就業時間が低下したこと**によって説明される。

また、15～24歳から65歳以上まで、すべての年齢階級で年齢層内効果はマイナスとなっている。

## 3. 労働者数の分析

### 3.1 就業者数

平均労働時間だけでなく、各年齢層の就業者数を確認する。

ただし、就業者数の増加だけから労働参加拡大とは判断しない。

例えば65歳以上の就業者数増加には、

- 65歳以上人口そのものの増加
- 65歳以上人口の就業率上昇

の双方が含まれるためである。

---

### 3.2 就業率

年齢層 $g$ について、

$$
EmploymentRate_g = \frac{Employed_g}{Population_g} \times 100
$$

を確認する。

特に、

- 25～34歳
- 35～44歳
- 45～54歳
- 55～64歳
- 65歳以上

を重点的に比較する。

これによって、

> 高齢者就業者が増えたのは高齢者人口が増加したためか、それとも高齢者自身の労働参加が進んだためか

を分離する。

---

### 3.3 就業者数変化の人口・就業率分解

就業者数は、

$$E_{g,t} = P_{g,t}r_{g,t}$$

と表せる。

ここで、

- $E$：就業者数
- $P$：当該年齢階級人口
- $r$：就業率

である。

開始時点0と終了時点1について対称分解し、

$$PopulationEffect = \frac{r_0+r_1}{2} (P_1-P_0)$$

$$EmploymentRateEffect = \frac{P_0+P_1}{2} (r_1-r_0)$$

とする。

2015～2025年では、65歳以上の就業者数は約211万人増加した。このうち人口要因は約61万人、就業率要因は約151万人であり、増加の約7割は就業率上昇と対応する。

55～64歳では就業者数増加のほぼ全てが就業率上昇による。

一方、35～44歳では就業率が上昇しているにもかかわらず、人口減少の影響が大きく、就業者数は減少した。

なお、年齢階級人口は公表就業者数と就業率から逆算しており、就業率が小数第1位までの公表値であるため、この分解は近似値である。

---

### 3.4 男女別分析

必要に応じて、$年齢 \times 性別$まで分解する。

ただし主分析は男女計とし、男女別は結果の異質性を確認する補助分析とする。

男女別に分析する目的は、

- 女性の労働参加増加
- 男女間の労働時間差
- 高齢男性・高齢女性の労働参加

などが全体平均へ及ぼす影響を確認することである。

---

## 4. 労働時間分布の分析

平均週間就業時間だけでは、

- 短時間就業者が増えたのか
- 長時間就業者が減ったのか
- 標準的な時間帯へ集中したのか

を区別できない。

そこで、労働力調査 基本集計 表3-3「月末1週間の就業時間（6区分），年齢階級別就業者数」（e-Stat統計表ID：`0003009700`）を使用する。

データはe-Stat APIから取得し、主分析は全国・男女計・全産業・従業者・従業上の地位計とする。

### 4.1 長期比較用3区分

2000～2025年について、週間就業時間を次の3区分に統一する。

| 区分     | 週間就業時間 |
| -------- | -----------: |
| 短時間   |    1～34時間 |
| 標準付近 |   35～48時間 |
| 長時間   |   49時間以上 |

原統計では上位区分と詳細区分の公表期間が異なる。

そのため、

$$1～34 = 1～14 + 15～29 + 30～34$$

$$35～48 = 35～39 + 40～48$$

$$49以上 = 49～59 + 60以上$$

として、上位区分が存在しない年のみ詳細区分から再構成する。

公式上位区分が存在する場合は、万人単位の丸め誤差を避けるため公式値を優先する。

1～34時間について、公式上位区分と詳細区分合計の差は最大2万人、35～48時間では最大1万人であり、再構成値との整合性は高い。

49時間以上については、公式上位区分が2017年まで、49～59時間・60時間以上の詳細区分が2018年以降であるため、両系列を同一年で直接照合することはできない。ただし分類定義上は両詳細区分の合計が49時間以上に一致する。

2011年を除く2000～2025年について、25年 × 7年齢区分 = 175観測を構成できた。

3区分の合計が従業者総数をカバーする割合は平均約99.3%である。

構成比は未分類者を除外せず、

$$Share_{g,k,t} = \frac{N_{g,k,t}}{PersonsAtWork_{g,t}}$$

として従業者総数を分母とする。

### 4.2 長期的な分布変化

15歳以上全体では、2000～2025年に、

| 区分       | 2000年 | 2025年 |     変化 |
| ---------- | -----: | -----: | -------: |
| 1～34時間  | 22.49% | 36.38% | +13.89pt |
| 35～48時間 | 48.38% | 49.33% |  +0.94pt |
| 49時間以上 | 28.79% | 13.72% | -15.08pt |

となった。

したがって、長期的には

> **49時間以上の長時間就業者の縮小と、
> 1～34時間の短時間就業者の拡大**

が主要な分布変化である。

長時間就業者比率の低下は2020年だけの現象ではない。

2000→2010年でも49時間以上は-5.15pt、2012→2019年でも-4.39ptであり、コロナ以前から長期的な低下傾向が確認できる。

一方、2019→2020年には49時間以上が約3.16pt低下しており、コロナ期には長期傾向に加えて一時的な大幅低下が生じた。

### 4.3 2015～2025年の年齢別変化

2015～2025年の15歳以上全体では、

- 1～34時間：+5.24pt
- 35～48時間：+2.63pt
- 49時間以上：-7.61pt

となった。

49時間以上の構成比はすべての年齢階級で低下している。

特に、

- 25～34歳：-9.01pt
- 35～44歳：-8.77pt
- 45～54歳：-7.56pt

と、中核年齢層で低下が大きい。

25～54歳では35～48時間の構成比が同時に上昇しているため、単純な短時間就業の増加だけではなく、

> **49時間以上の長時間就業から35～48時間程度への移動**

が進んだと解釈できる。

一方、15～24歳と65歳以上では1～34時間の増加が大きく、より明確な短時間化が確認できる。

### 4.4 詳細7区分

2018～2025年については、

- 1～14時間
- 15～29時間
- 30～34時間
- 35～39時間
- 40～48時間
- 49～59時間
- 60時間以上

の7区分を使用する。

15歳以上全体の2018→2025年変化では、

| 区分       |    変化 |
| ---------- | ------: |
| 1～14時間  | +1.94pt |
| 15～29時間 | +0.35pt |
| 30～34時間 | +1.27pt |
| 35～39時間 | +0.56pt |
| 40～48時間 | +1.83pt |
| 49～59時間 | -3.04pt |
| 60時間以上 | -2.75pt |

となった。

したがって49時間以上の減少は、49～59時間だけではなく、**60時間以上の非常に長い就業時間帯の縮小**も伴っている。

25～54歳では49～59時間・60時間以上がともに減少し、40～48時間が増加している。

これらの結果は、年齢構成分解で確認された「平均週間就業時間低下の約89%が年齢層内効果」という結果と整合する。

- 非正規雇用

目的は、

## 6. 総労働投入量

日本経済全体で実際に投入された労働時間を評価するため、労働力調査の年齢階級別「延週間就業時間」を使用する。

年齢層 $g$ の総労働投入を、

$$
L_{g,t} = AggregateWeeklyHours_{g,t}
$$

とする。

また、

$$N^{work}_{g,t} = \frac{AggregateWeeklyHours_{g,t}}{AverageWeeklyHours_{g,t}}$$

とすれば、

$$L_{g,t} = N^{work}_{g,t}H_{g,t}$$

が成立する。

ここで、

- $N^{work}_{g,t}$：従業者数
- $H_{g,t}$：従業者1人当たり平均週間就業時間
- $L_{g,t}$：延週間就業時間

である。

就業者数には休業者が含まれる一方、平均週間就業時間は従業者を対象とするため、「就業者数 × 平均週間就業時間」は総労働投入の算出には使用しない。

全体の総労働投入は、

$$L_t=\sum_g L_{g,t}$$

とする。

---

## 7. 総労働投入の要因分解

総労働投入は、

$$L_t=N_t\bar H_t$$

と表せる。

ここで、

- $N_t$：従業者総数
- $\bar H_t$：従業者1人当たり平均週間就業時間

である。

開始時点0と終了時点1との差について、

$$\Delta L = \bar H \Delta N + \bar N \Delta \bar H$$

と対称分解する。

ここで、

$$\bar H=\frac{\bar H_0+\bar H_1}{2}$$

$$\bar N=\frac{N_0+N_1}{2}$$

である。

さらに平均週間就業時間の変化を、年齢階級 $g$ について、

$$\Delta \bar H = Within + Composition$$

と分解する。

したがって総労働投入変化は、

$$\Delta L = \underbrace{\bar H\Delta N}_{従業者総数効果} + \underbrace{\bar N \cdot Within}_{年齢層内時間効果} + \underbrace{\bar N \cdot Composition}_{年齢構成効果}$$

の3要因へ完全分解する。

### 7.1 2015～2025年

2015～2025年の延週間就業時間は、

| 指標   |             結果 |
| ------ | ---------------: |
| 2015年 | 241,272万時間/週 |
| 2025年 | 236,287万時間/週 |
| 変化   |  -4,985万時間/週 |
| 変化率 |           -2.07% |

となった。

要因分解では、

| 要因             |             寄与 |
| ---------------- | ---------------: |
| 従業者総数効果   | +15,255万時間/週 |
| 年齢層内時間効果 | -18,065万時間/週 |
| 年齢構成効果     |  -2,176万時間/週 |
| 合計             |  -4,985万時間/週 |

となった。

したがって、従業者総数の増加は総労働投入を大きく押し上げたものの、各年齢層内部の就業時間短縮と年齢構成変化による押下げを完全には相殺できず、総労働投入は約2%減少した。

減少要因の合計約20,240万時間に対し、従業者総数増加による押上げは約15,255万時間であり、減少要因の約75%が人数増加によって相殺された。

また、時間側の押下げ要因を見ると、年齢層内時間効果が約89.3%、年齢構成効果が約10.7%を占める。これは平均週間就業時間について行った年齢構成分解と整合する。

### 7.2 2000～2025年の長期変化

2000～2025年では、

| 指標   |             結果 |
| ------ | ---------------: |
| 2000年 | 270,293万時間/週 |
| 2025年 | 236,287万時間/週 |
| 変化   | -34,006万時間/週 |
| 変化率 |          -12.58% |

となった。

要因分解では、

- 従業者総数効果：+10,289万時間/週
- 年齢層内時間効果：-40,502万時間/週
- 年齢構成効果：-3,793万時間/週

である。

25年間では従業者総数は総労働投入を押し上げたものの、その効果は時間・構成による減少要因の約23%を相殺するにとどまった。

したがって長期的な総労働投入減少の中心は、**各年齢層内部における1人当たり就業時間の短縮**である。

### 7.3 時期による違い

総労働投入の構造は期間によって異なる。

| 期間      | 総労働投入変化率 | 従業者総数効果 | 年齢層内時間効果 | 年齢構成効果 |
| --------- | ---------------: | -------------: | ---------------: | -----------: |
| 2000→2010 |           -9.09% |         -9,436 |          -14,487 |         -646 |
| 2012→2019 |           +0.28% |        +15,361 |          -11,996 |       -2,686 |
| 2012→2025 |           -3.47% |        +18,371 |          -23,512 |       -3,359 |
| 2015→2025 |           -2.07% |        +15,255 |          -18,065 |       -2,176 |
| 2020→2025 |           +1.15% |         +7,810 |           -4,590 |         -530 |
| 2000→2025 |          -12.58% |        +10,289 |          -40,502 |       -3,793 |

寄与の単位は万時間/週である。

2000年代は従業者数と1人当たり時間の双方が減少した。

2010年代以降は、1人当たり就業時間が引き続き短縮する一方、従業者数の増加がその影響を大きく相殺する構造へ変化した。2012→2019年では両者がほぼ相殺され、総労働投入はほぼ横ばいとなった。

2020→2025年では従業者数増加の効果が時間短縮・年齢構成効果を上回り、総労働投入は1.15%増加した。

## 8. 毎月勤労統計による労働時間内部の分解

毎月勤労統計は、労働力調査とは混合せず、**雇用者1人当たり労働時間の内部構造を詳しく分析する統計**として使用する。

### 第1段階

$$月額給与 = 概算時間当たり給与 \times 総実労働時間$$

### 第2段階

$$総実労働時間 = 所定内労働時間 + 所定外労働時間$$

### 第3段階

$$所定内労働時間 = 出勤日数 \times 1出勤日当たり所定内労働時間$$

既存の分解手法を維持する。

---

## 9. 毎月勤労統計の長期分析

### 9.1 分析期間

基本的には、

```text
1990年 ～ 最新の完全な暦年
```

とする。

2026年のような年途中データは月次推移には利用できるが、年平均長期比較には含めない。

毎月勤労統計では1990年1月から5人以上事業所が主要系列となっているため、5人以上系列の長期分析開始点として1990年を採用する。

---

### 9.2 年平均の算出方法

現在の単純平均は改める。

毎月勤労統計の実数統計の公式年平均は、各月の常用労働者数を用いた加重平均である。

各月の系列値 $X_m$ に対するウェイトは、

$$w_m = \frac{N_{m-1,\mathrm{end}} + N_{m,\mathrm{end}}}{2}$$

とする。

ここで $N_{m,\mathrm{end}}$ は当月末常用労働者数である。

年平均は、

$$\bar X_y = \frac{\sum_m w_mX_m}{\sum_m w_m}$$

により算出する。

対象：

- きまって支給する給与
- 総実労働時間
- 所定内労働時間
- 所定外労働時間
- 出勤日数

そのうえで、

$$概算時間当たり給与 = \frac{\bar W}{\bar H}$$

$$1出勤日当たり所定内労働時間 = \frac{\overline{ScheduledHours}}{\overline{WorkingDays}}$$

として完全分解可能な形を維持する。

## 10. 長期比較方法

単一の基準年だけに依存しない。

以下の3種類を併用する。

### 10.1 直近10年比較

例：

```text
2015 → 2025
```

現在の結果との連続性を維持するため残す。

位置づけは、

> 最近10年間の詳細比較

とする。

---

### 10.2 全期間時系列

1990年以降について年次系列を描画する。

対象：

- 概算時間当たり給与
- 総実労働時間
- 所定内労働時間
- 所定外労働時間
- 出勤日数
- 1出勤日当たり所定内労働時間

必要に応じて基準年=100の指数も作成する。

---

### 10.3 ローリング10年比較

各年 $t$ について、

$$t-10 \rightarrow t$$

の変化を算出する。

例：

```text
1990 → 2000
1991 → 2001
...
2015 → 2025
```

これによって2015年という単一基準年への依存を避ける。

特に、

- 時間当たり給与寄与
- 総実労働時間寄与
- 出勤日数寄与
- 1出勤日当たり時間寄与

が時代によってどう変化したかを見る。

## 11. 毎月勤労統計の時系列断層への対応

毎月勤労統計では標本入替えやベンチマーク更新が行われる。

公式には時系列比較用の指数が作成されており、実数系列から独自計算した変化率と公式指数による変化率が一致しない場合がある。

したがって、

### 主分析

実数を使用して恒等式に基づく分解を行う。

### 頑健性確認結果

毎月勤労統計の公式労働時間指数と、実数系列から作成した長期変化を比較した。

1990→2025年では、

| 指標           | 実数系列 | 公式指数 |
| -------------- | -------: | -------: |
| 総実労働時間   |  -21.48% |  -21.32% |
| 所定内労働時間 |  -21.20% |  -20.65% |
| 所定外労働時間 |  -24.89% |  -27.73% |

となり、主要な長期方向性は一致した。

したがって、「長期的に1人当たり労働時間が減少した」という主結果は公式指数を用いても頑健である。

公式指数は独立に基準化された系列であるため、恒等式による要因分解には使用せず、頑健性確認に限定する。

## 12. 出勤日数減少の頑健性確認【未実装・補助分析】

所定内労働時間減少の主要因として出勤日数減少が確認された場合、暦要因を確認する。

具体的には各暦年について、

- 平日数
- 土日数
- 国民の祝日数

などから、勤務可能日数の概算値を作成する。

出勤日数減少が、

- 暦配置だけで説明可能か
- 暦を超えて減少しているか

を確認する。

ただし、

- 有給休暇取得
- 会社休日
- 勤務制度
- シフト構成

等の因果効果までは本分析では推定しない。

## 13. 労働力の未活用

労働時間が短いことを、それ自体で良い・悪いとは評価しない。

2018年以降について、労働力調査の未活用労働指標を補助的に用いる。

特に**追加就労希望就業者**を確認する。

追加就労希望就業者は、週35時間未満で働き、より長い時間働くことを希望し、実際に追加就労可能な就業者として定義されている。2025年平均についても公式集計が公表されている。

したがって、

```text
短時間就業者
├─ 追加就労希望なし
└─ 追加就労希望あり
```

を区別する。

これは、

> 短時間就業の増加が本人の選択によるものか、労働需要の不足等による不完全就業を含むのか

を考察するための補助材料とする。

因果関係は推定しない。

## 14. 労働の「質」

年齢・性別・雇用形態は**労働者構成**として扱い、それ自体を「労働の質」とは定義しない。

労働の質については、外部の人的資本調整済み指標を使用する。

JIPデータベース2026には、

- 従業者数
- マンアワー
- マンアワー指数
- 労働の質指数
- 質調整済み労働投入指数
- 女性比率
- パートタイム労働者比率
- 55歳以上従業者比率

などが収録されている。

JIPは本分析の基礎データへ直接結合するのではなく、

> 自前で算出した人数・マンアワーの変化と、人的資本等を考慮した質調整済み労働投入がどのように異なるか

を確認する**外部検証・補完分析**として使用する。

## 25. 結論

本分析では、「平均労働時間が減少した」という単一の平均値だけを結論としない。

分析の中心的な問いを、

> **誰が働くようになり、それぞれの労働者層がどれだけ働き、その構成変化と層内部の変化によって日本全体の労働投入がどのように変化したのか**

とする。

毎月勤労統計によって**1人当たり労働時間の内部構造**を詳細に分析し、労働力調査によって**労働者数・年齢構成・労働時間分布・総労働投入**へ分析範囲を拡張する。さらにJIPデータベースによって**労働の質を考慮した労働投入**を外部検証する。

この構成まで実施すれば、平均値の変化を表面的に論じるのではなく、労働者の「量・構成・時間・質」を区別したうえで日本の労働投入の変化を説明できるため、`03_labor_input.md` の労働投入分析は十分に完了したと判断する。
