# 日本経済の所得分配と制度部門別資金余剰の長期分析

作成日：2026-09-25

## 要約

本分析では、内閣府「国民経済計算（SNA）」を用いて、1994～2024年度の日本経済について、国内で生み出された所得がどのように分配され、その後、家計・企業・政府・海外のどの部門が資金余剰または資金不足となってきたかを分析した。

分析は、所得発生勘定、家計の第1次所得の配分勘定、所得の第2次分配勘定、可処分所得の使用勘定、制度部門別純貸出・純借入、非金融法人企業の資本勘定を接続して行った。名目金額は規模感を把握するために兆円単位で示し、長期的な構造変化については構成比・GDP比を主として評価した。

GDP所得面では、1994年度から2024年度にかけて、雇用者報酬のGDP比は49.99%から49.38%へほぼ横ばいであった。一方、営業余剰は36.53%から40.79%へ上昇し、混合所得は7.89%から2.12%へ大幅に低下した。したがって、長期変化を単純な「雇用者報酬から企業利益への移転」と捉えることはできず、混合所得の縮小を含む経済構造の変化を考慮する必要がある。

家計の純第1次所得では、雇用者報酬の構成比が76.90%から82.84%へ上昇した一方、営業余剰・混合所得は13.07%から9.09%、純財産所得は10.03%から8.07%へ低下した。家計部門全体については、長期的に労働所得から財産所得へ所得源が移行したという結果にはなっていない。

税・社会保障を通じた所得移転では、純社会負担の第1次所得比が16.72%から24.95%へ上昇した一方、社会給付も14.50%から22.92%へ上昇した。その結果、純可処分所得 / 第1次所得比率は1994年度87.31%、2024年度87.67%と長期の両端ではほぼ同水準であった。ただし、2015年度の90.45%から2024年度には87.67%へ低下しており、長期と直近では異なる動きがみられた。

家計貯蓄率は1994年度の12.02%から2024年度には0.80%へ低下した。2020年度には10.62%まで一時的に上昇したものの、その後再び低水準へ戻っている。

制度部門別では、1990年代には家計が主要な資金余剰部門であったが、2000年代以降は非金融法人企業が大幅な資金余剰部門となった。非金融法人企業の純貸出GDP比は1994年度の0.7%から2010年度には7.9%まで上昇したが、その後縮小し、2024年度には2.2%となった。

2015～2024年度に限ると、非金融法人企業の純貸出は36.5兆円から13.9兆円へ縮小し、GDP比では6.61%から2.16%へ4.46ポイント低下した。この変化を分解すると、純貯蓄が-4.04ポイント、純資本移転が+0.11ポイント、純資本形成が-0.53ポイント寄与しており、純貸出縮小の中心は純貯蓄比率の低下であった。ただし、2019～2020年度には投資減少によって純貸出が一時的に拡大し、2020～2024年度には純資本形成の回復が純貸出縮小の主要因となった。

以上から、1994～2024年度の日本経済は、「家計から企業へ所得と資金が一方向に移転し続けた」という単一の図式では説明できない。混合所得の縮小、家計所得における雇用者報酬依存度の上昇、社会負担と社会給付の双方の拡大、家計貯蓄率の低下、企業部門の資金余剰化とその後の縮小という複数の構造変化が重なっている。

## 1. 分析目的と問い

これまでの分析では、毎月勤労統計、労働力調査、法人企業統計等を用いて、賃金、労働時間、雇用構造、企業収益、生産性、労働分配率などを分析してきた。

特に `07_corporate_performance.md` では、2015～2024年度について企業の付加価値、労働生産性、人件費、1人当たり人件費、労働分配率、営業利益・経常利益を比較した。

しかし、法人企業統計は法人企業部門を対象とした企業会計ベースの統計であり、日本経済全体について、

- 生産された所得がどの所得項目へ分配されたか
- 家計所得が賃金以外を含めてどのように形成されたか
- 税・社会保障を経て家計にどの程度の所得が残ったか
- 所得が消費と貯蓄へどのように配分されたか
- 家計・企業・政府等のどの部門が資金余剰・資金不足となったか
- 企業部門の資金余剰が貯蓄と投資のどの変化に対応したか

を一貫した会計体系で把握することはできない。

そこで本分析では、内閣府「国民経済計算（SNA）」の制度部門別勘定を用い、分析対象を日本経済全体へ拡張する。

主な問いは次のとおりである。

1. GDPに占める雇用者報酬、営業余剰、混合所得等の割合は1994年度以降どのように変化したか。
2. 家計の第1次所得は、雇用者報酬、営業余剰・混合所得、財産所得によってどのように構成されてきたか。
3. 税・社会負担・社会給付を経て、家計の可処分所得は第1次所得に対してどのように変化したか。
4. 家計の消費・貯蓄構造はどのように変化したか。
5. 非金融法人企業、金融機関、一般政府、家計、海外部門の資金余剰・資金不足はどのように変化したか。
6. 非金融法人企業の純貸出は、純貯蓄・純資本移転・純資本形成のどの変化と対応しているか。
7. 2015～2024年度の変化は、1994年度以降の長期推移の中でどのような位置にあるか。

本分析では特定の結論を前提とせず、SNAの会計関係と時系列データから観測できる構造変化を記述する。

## 2. データと分析方法

### 2.1 使用データと対象範囲

内閣府「2024年度国民経済計算（2020年基準・2008SNA）」の年度系列を使用する。

主分析期間は、

```text
1994年度 ～ 2024年度
```

である。

また、既存の企業業績分析との接続のため、

```text
2015年度 → 2024年度
```

を直近の補助比較期間とする。

コロナ期を含む変化については、

```text
2015 → 2019
2019 → 2020
2020 → 2024
```

に分割して確認する。

使用する主な統計表は次のとおりである。

| 用途                              | 統計表                           | e-Stat統計表ID |
| --------------------------------- | -------------------------------- | -------------- |
| GDP所得面                         | 一国経済・所得の発生勘定・年度   | `0004049810`   |
| 家計第1次所得                     | 家計・第1次所得の配分勘定・年度  | `0004049854`   |
| 家計再分配                        | 家計・所得の第2次分配勘定・年度  | `0004049855`   |

年度系列と暦年系列は混在させない。

---

### 2.2 分析の基本的な流れ

本分析では、所得・支出・貯蓄・投資というフローを次の順序で接続する。

```text
国内で付加価値を生産
        ↓
所得の発生
├─ 雇用者報酬
├─ 営業余剰
├─ 混合所得
└─ 純生産・輸入税
        ↓
家計等への第1次所得配分
        ↓
税・社会負担・社会給付等
        ↓
可処分所得
        ↓
消費
        ↓
貯蓄
        ↓
実物投資・資本移転
        ↓
純貸出／純借入
```

企業の利益剰余金や家計金融資産などのストックは本分析の主対象とはしない。

したがって、純貸出がプラスであることを「現金を貯め込んでいる」とは解釈しない。純貸出は、所得・貯蓄等によって得た資金が実物投資等に必要な資金を上回るというフロー上の資金余剰を表す。

---

### 2.3 総概念と純概念

GDPの所得面構成では、GDPが総概念であるため、

- 雇用者報酬
- 総営業余剰
- 総混合所得
- 生産・輸入品に課される税
- 補助金

を使用する。

一方、第1次所得、可処分所得、貯蓄、資本勘定については原則として純概念を使用する。

固定資本減耗を含む「総」と控除した「純」を同一の恒等式内で混在させない。

---

### 2.4 GDP所得面構成

所得発生勘定について、

$$GDP_t = CE_t + GOS_t + GMI_t + T_t - S_t$$

を使用する。

ここで、

- \(CE\)：雇用者報酬
- \(GOS\)：総営業余剰
- \(GMI\)：総混合所得
- \(T\)：生産・輸入品に課される税
- \(S\)：補助金

である。

各項目についてGDP比を求める。

$$Share_{X,t} = \frac{X_t}{GDP_t} \times 100$$

混合所得には個人企業等における労働の対価と資本・企業活動による所得が混在する。そのため、

```text
雇用者報酬 = 労働所得
営業余剰 + 混合所得 = 資本所得
```

という単純な二分法は採用しない。

---

### 2.5 家計第1次所得

家計の純第1次所得は、

$$PI_t = CE^H_t + OSMI^H_t + PI^{rec}_t - PI^{pay}_t$$

として再構成する。

純財産所得は、

$$NetPropertyIncome_t = PI^{rec}_t-PI^{pay}_t$$

とする。

構成比は、

$$EmployeeCompensationRatio_t = \frac{CE^H_t}{PI_t} \times 100$$

$$OperatingMixedIncomeRatio_t = \frac{OSMI^H_t}{PI_t} \times 100$$

$$NetPropertyIncomeRatio_t = \frac{NetPropertyIncome_t}{PI_t} \times 100$$

として計算する。

受取財産所得だけではなく、支払財産所得を差し引いた純額を主指標とする。

---

### 2.6 家計可処分所得

家計の純可処分所得は概念的に、

$$DI_t = PI_t - CurrentTaxes_t - SocialContributions_t + SocialBenefits_t + OtherTransfers^{net}_t$$

と整理する。

補助指標として、

$$DisposableIncomeRatio_t = \frac{DI_t}{PI_t} \times 100$$

を使用する。

これは家計部門全体と他部門との所得移転を示す指標であり、高所得世帯から低所得世帯への所得再分配効果そのものを示すものではない。

---

### 2.7 家計貯蓄

家計の所得使用勘定について、

$$Saving_t = DI_t + PensionAdjustment_t - Consumption_t$$

を確認する。

家計貯蓄率は、

$$SavingRate_t = \frac{Saving_t}{DI_t+PensionAdjustment_t} \times 100$$

として再計算し、公表値と照合する。

ここでいう貯蓄は銀行預金への預入だけではなく、家計部門が所得のうち消費しなかった部分を表すSNA上のフロー概念である。

---

### 2.8 制度部門別純貸出・純借入

各制度部門について、

$$NetLendingRatio_{s,t} = \frac{NL_{s,t}}{GDP_t} \times 100$$

を使用する。

対象部門は、

- 非金融法人企業
- 金融機関
- 一般政府
- 家計
- 対家計民間非営利団体
- 海外部門

である。

\(NL>0\) は純貸出、\(NL<0\) は純借入を表す。

所得・貯蓄・投資との会計的な接続を重視し、**資本勘定側の純貸出・純借入を主系列**とする。金融勘定側は資金調達・運用面からの照合系列として用いる。

海外部門は海外側から見た符号である。したがって、海外部門の純借入は日本側から見れば対外的な純貸出に対応する。

GDP比の再計算では、公表表との整合を取るため支出側GDPを使用する。

---

### 2.9 非金融法人企業の資本勘定

非金融法人企業について、

$$NL_t = NetSaving_t + NetCapitalTransfers_t - NetCapitalFormation_t$$

を使用する。

純資本形成は、

$$NetCapitalFormation_t = (GFCF_t-CFC_t) +Inventories_t + LandPurchases_t$$

とする。

2015～2024年度の純貸出GDP比変化については、

$$\Delta NLRatio = \Delta SavingRatio + \Delta CapitalTransferRatio - \Delta CapitalFormationRatio$$

として恒等分解する。

この分解は純貸出の変化がどの会計項目と対応したかを示すものであり、各項目の変化原因を推定する因果分解ではない。

## 3. 分析結果

### 3.1 表記上の注意

金額は名目値を兆円単位で示す。

元データの単位は10億円であり、

$$1兆円 = 1000 \times 10億円$$

として換算する。

1994～2024年度の長期比較では物価水準や名目経済規模そのものが変化するため、名目額は規模感の把握に使用し、分配構造の評価では構成比・GDP比を主として使用する。

アプリでは、主要な時系列について「比率」と「名目額」を切り替えて確認できる。

---

### 3.2 GDP所得面構成

1994年度と2024年度を比較すると次のようになった。

| 項目           | 1994年度 名目額 | 1994年度 GDP比 | 2024年度 名目額 | 2024年度 GDP比 | 名目額変化 | 比率変化 |
| -------------- | --------------: | -------------: | --------------: | -------------: | ---------: | -------: |
| 雇用者報酬     |       262.8兆円 |         49.99% |       314.1兆円 |         49.38% |  +51.3兆円 |  -0.61pt |
| 営業余剰       |       192.1兆円 |         36.53% |       259.4兆円 |         40.79% |  +67.4兆円 |  +4.26pt |
| 混合所得       |        41.5兆円 |          7.89% |        13.5兆円 |          2.12% |  -28.0兆円 |  -5.78pt |
| 純生産・輸入税 |        29.4兆円 |          5.58% |        49.0兆円 |          7.71% |  +19.7兆円 |  +2.12pt |
| GDP            |       525.7兆円 |           100% |       636.0兆円 |           100% | +110.3兆円 |        — |

名目GDPは525.7兆円から636.0兆円へ増加した。

営業余剰は192.1兆円から259.4兆円へ増加し、GDP比も36.53%から40.79%へ4.26ポイント上昇した。

一方、雇用者報酬は名目額では51.3兆円増加したものの、GDP比は49.99%から49.38%へ0.61ポイント低下したにすぎず、30年間の両端ではほぼ同水準であった。

最も大きく変化したのは混合所得であり、41.5兆円から13.5兆円へ減少し、GDP比も7.89%から2.12%へ5.78ポイント低下した。

したがって、1994～2024年度の変化を単純に、

> 雇用者報酬が減り、その分が企業利益へ移った

とは解釈できない。

むしろ、

- 雇用者報酬比率はほぼ維持
- 営業余剰比率は上昇
- 混合所得比率は大幅低下
- 純生産・輸入税比率は上昇

という複数の変化が同時に生じている。

また、2015年度から2024年度では、営業余剰GDP比は41.27%から40.79%へわずかに低下し、雇用者報酬比率は47.42%から49.38%へ上昇した。

したがって、1994～2024年度の長期変化と2015年度以降の直近変化は区別する必要がある。

- 2015年度：90.45%

と、2015年度以降では低下している。

また、2020年度はその他経常移転等の影響が大きい特殊年度であり、通常時の長期構造と分けて解釈する必要がある。

### 3.5 家計の消費と貯蓄

代表年度の家計貯蓄率は次のとおりである。

| 年度 | 調整後可処分所得 |   純貯蓄 | 貯蓄率 |
| ---- | ---------------: | -------: | -----: |
| 1994 |        301.5兆円 | 36.2兆円 | 12.02% |
| 2000 |        302.4兆円 | 20.9兆円 |  6.91% |
| 2005 |        290.7兆円 |  4.9兆円 |  1.67% |
| 2010 |        289.0兆円 | 10.0兆円 |  3.47% |
| 2015 |        292.3兆円 | -1.0兆円 | -0.33% |
| 2019 |        303.8兆円 |  8.6兆円 |  2.84% |
| 2020 |        314.7兆円 | 33.4兆円 | 10.62% |
| 2023 |        317.9兆円 | -1.5兆円 | -0.46% |
| 2024 |        331.6兆円 |  2.6兆円 |  0.80% |

1994年度には36.2兆円であった純貯蓄は、2024年度には2.6兆円となった。貯蓄率も12.02%から0.80%へ低下している。

調整後可処分所得は301.5兆円から331.6兆円へ増加した一方、所得のうち貯蓄へ回る割合は大幅に低下した。

2020年度には純貯蓄33.4兆円、貯蓄率10.62%まで急上昇したが、その後、

- 2021年度：4.86%
- 2022年度：0.87%
- 2023年度：-0.46%
- 2024年度：0.80%

と再び低水準へ戻った。

したがって、2020年度の高貯蓄は一時的な現象として扱う必要がある。

### 3.6 制度部門別純貸出・純借入

1994年度と2024年度の比較は次のとおりである。

| 制度部門             | 1994年度 名目額 | GDP比 | 2024年度 名目額 | GDP比 | 名目額変化 | GDP比変化 |
| -------------------- | --------------: | ----: | --------------: | ----: | ---------: | --------: |
| 非金融法人企業       |        +3.9兆円 | +0.7% |       +13.9兆円 | +2.2% |  +10.0兆円 |    +1.5pt |
| 金融機関             |       +13.5兆円 | +2.6% |        +5.2兆円 | +0.8% |   -8.3兆円 |    -1.8pt |
| 一般政府             |       -20.7兆円 | -4.0% |        -8.9兆円 | -1.4% |  +11.8兆円 |    +2.6pt |
| 家計                 |       +20.2兆円 | +3.9% |       +12.9兆円 | +2.0% |   -7.3兆円 |    -1.9pt |
| 対家計民間非営利団体 |        -1.0兆円 | -0.2% |        -0.2兆円 |  0.0% |   +0.7兆円 |    +0.2pt |
| 海外部門             |       -12.2兆円 | -2.3% |       -29.2兆円 | -4.6% |  -17.0兆円 |    -2.3pt |

1994年度には家計が20.2兆円、金融機関が13.5兆円の資金余剰を持ち、非金融法人企業の純貸出は3.9兆円にとどまっていた。

その後、非金融法人企業の純貸出は、

- 2002年度：32.6兆円、GDP比6.1%
- 2010年度：40.4兆円、7.9%
- 2013年度：38.6兆円、7.4%
- 2015年度：36.5兆円、6.6%

まで拡大した。

一方、2024年度には13.9兆円、GDP比2.2%まで縮小している。

したがって、非金融法人企業については、

> 1990年代から2010年代前半にかけて大幅に資金余剰化し、その後余剰幅が縮小した

という二段階の変化として捉える必要がある。

家計は1994年度に20.2兆円、GDP比3.9%の純貸出であったが、2000年代以降はゼロ近辺となる年度が増えた。これは家計貯蓄率の長期低下とも整合する。

一般政府はほぼ全期間で純借入部門であり、1998年度、2009年度、2020年度などにはGDP比-10%前後まで資金不足が拡大した。

海外部門は多くの年度でマイナスである。これは海外部門側の純借入であり、日本側から見れば対外純貸出に対応する。

### 3.7 非金融法人企業の資金余剰

主要年度について、非金融法人企業の資本勘定を比較すると次のようになる。

| 年度 |   純貯蓄 | GDP比 | 純資本形成 |  GDP比 | 純資本移転 | GDP比 |   純貸出 | GDP比 |
| ---- | -------: | ----: | ---------: | -----: | ---------: | ----: | -------: | ----: |
| 1994 |  5.5兆円 | 1.05% |    6.2兆円 |  1.19% |    4.6兆円 | 0.88% |  3.9兆円 | 0.74% |
| 2010 | 30.8兆円 | 6.06% |   -6.1兆円 | -1.20% |    3.5兆円 | 0.68% | 40.4兆円 | 7.94% |
| 2015 | 43.4兆円 | 7.87% |    9.5兆円 |  1.73% |    2.6兆円 | 0.48% | 36.5兆円 | 6.61% |
| 2024 | 24.6兆円 | 3.83% |   14.5兆円 |  2.26% |    3.8兆円 | 0.59% | 13.9兆円 | 2.16% |

1994年度には純貯蓄が5.5兆円であったが、2015年度には43.4兆円まで拡大した。

また、2010年度には純資本形成が-6.1兆円であり、

$$30.8 + 3.5 - (-6.1) \approx 40.4兆円$$

の大幅な純貸出となった。

したがって、2000年代から2010年代前半の企業資金余剰拡大には、

- 純貯蓄の増加
- 一部年度における低い、または負の純資本形成

の双方が対応している。

2024年度には純貯蓄が24.6兆円へ低下し、純資本形成は14.5兆円へ増加したため、純貸出は13.9兆円へ縮小した。

---

### 3.8 2015～2024年度の純貸出変化分解

2015年度から2024年度にかけて、純貸出GDP比は6.61%から2.16%へ4.46ポイント低下した。

| 要因       |    寄与 |
| ---------- | ------: |
| 純貯蓄     | -4.04pt |
| 純資本移転 | +0.11pt |
| 純資本形成 | -0.53pt |
| 合計       | -4.46pt |

したがって、2015～2024年度全体では、純貯蓄GDP比の低下が企業の資金余剰縮小の最大の要因であった。

ただし、期間内部では構造が異なる。

#### 2015～2019年度

| 要因       |    寄与 |
| ---------- | ------: |
| 純貯蓄     | -2.87pt |
| 純資本移転 | -0.01pt |
| 純資本形成 | -0.43pt |
| 合計       | -3.30pt |

コロナ前から純貸出は縮小しており、その中心は純貯蓄の低下であった。

#### 2019～2020年度

| 要因       |    寄与 |
| ---------- | ------: |
| 純貯蓄     | -0.92pt |
| 純資本移転 | +0.37pt |
| 純資本形成 | +1.64pt |
| 合計       | +1.09pt |

純貯蓄は低下したものの、純資本形成が12.3兆円程度から2.9兆円程度まで急減したため、純貸出は一時的に拡大した。

したがって、2020年度の企業資金余剰拡大を「企業がより多く貯蓄した」と解釈することはできない。

#### 2020～2024年度

| 要因       |    寄与 |
| ---------- | ------: |
| 純貯蓄     | -0.25pt |
| 純資本移転 | -0.24pt |
| 純資本形成 | -1.74pt |
| 合計       | -2.24pt |

この期間では純資本形成の回復が純貸出縮小の最大の要因であった。

したがって、2015年度以降の企業資金余剰縮小は、期間によって、

```text
2015～2019：純貯蓄低下
2019～2020：投資急減による余剰拡大
2020～2024：投資回復による余剰縮小
```

という異なるメカニズムを持つ。

## 4. 結果の頑健性確認

### 4.1 会計恒等式の再構成

公表値をそのまま用いるだけでなく、主要な勘定について構成項目から再計算し、会計恒等式が成立することを確認した。

| 検証対象         | 主な再構成                                         |          最大差 |
| ---------------- | -------------------------------------------------- | --------------: |
| GDP所得面        | 雇用者報酬＋営業余剰＋混合所得＋税－補助金         | 約0.1（10億円） |
| 家計第1次所得    | 雇用者報酬＋営業余剰・混合所得＋財産所得受取－支払 | 約0.1（10億円） |
| 家計可処分所得   | 第1次所得－税－社会負担＋給付＋その他移転          | 約0.2（10億円） |
| 家計純貯蓄       | 可処分所得＋年金受給権調整－消費                   | 約0.1（10億円） |
| 非金融法人純貸出 | 純貯蓄＋純資本移転－純資本形成                     | 約0.1（10億円） |

差はいずれも公表値の丸めで説明できる範囲にとどまった。

---

### 4.2 家計貯蓄率の照合

家計貯蓄率について、公表値と、

$$\frac{純貯蓄}{純可処分所得+年金受給権の変動調整} \times 100$$

による再計算値を照合した。

最大差は約0.05ポイントであり、公表値の小数第1位への丸めと整合した。

---

### 4.3 制度部門別GDP比の再計算

制度部門別純貸出・純借入のGDP比について、金額系列とGDPから再計算した。

所得側GDPではなく、公表表と整合する支出側GDPを分母に使用した場合、公表GDP比との差は最大約0.05ポイントとなった。

このため、制度部門別純貸出のGDP比では支出側GDPを使用する。

---

### 4.4 部門間の会計整合性

非金融法人企業、金融機関、一般政府、家計、対家計民間非営利団体、海外部門を含む制度部門間の純貸出・純借入について、資本勘定側および金融勘定側の会計関係を確認した。

会計残差は設定した許容誤差内に収まった。

また、非金融法人企業の個別資本勘定から求めた純貸出と制度部門別純貸出表の値も照合し、全対象年度で整合することを確認した。

---

### 4.5 資本勘定と金融勘定

純貸出・純借入については、

- 資本勘定：貯蓄・資本移転・実物投資から求める
- 金融勘定：金融資産・負債の取引から求める

という二つの側面が存在する。

両者には統計上の不突合があり、完全一致を前提としない。

本分析では、所得→貯蓄→投資という分析目的との接続が明確なため資本勘定側を主系列とし、金融勘定側は検証系列として使用した。

---

### 4.6 比較期間への依存

本分析では1994年度と2024年度だけでなく、2010年度、2015年度、2019年度、2020年度なども確認した。

この結果、例えば非金融法人企業について、

- 1994→2024では純貸出GDP比が上昇
- 2015→2024では純貸出GDP比が大幅低下

という、一見反対方向の結果が同時に成立することが確認された。

したがって、比較開始年を明示せずに「企業余剰が増えた」「企業余剰が減った」と表現することは避ける。

---

### 4.7 特殊年度

2020年度には、

- 家計貯蓄率
- 家計純貸出
- 一般政府純借入
- 企業純資本形成

などが大きく変動した。

このため2020年度を通常時の構造変化と同一視せず、2015～2019、2019～2020、2020～2024へ分割して分析した。

ただし、本分析は新型コロナウイルス感染症の因果効果を推定するものではない。

## 5. 考察と限界

### 5.1 GDP所得面の変化は単純な労働対資本ではない

1994～2024年度では営業余剰比率が上昇したが、雇用者報酬比率は30年間の両端でほぼ同水準であった。

同時に、混合所得比率が5.8ポイント近く低下している。

したがって、営業余剰比率の上昇を、そのまま雇用者報酬から企業への所得移転とみなすことはできない。

混合所得の縮小には、個人企業の比重や法人化等の経済構造変化が含まれる可能性があるが、本分析ではその要因まで分解していない。

---

### 5.2 家計所得は雇用者報酬への依存を強めた

家計第1次所得に占める雇用者報酬比率は76.90%から82.84%へ上昇した。

純財産所得の構成比は長期では低下している。

この結果から、家計部門全体が資産所得中心へ移行したとはいえない。

一方、これは家計部門全体の平均的な集計であり、財産所得の偏在を捉えていない。

例えば、一部の資産保有世帯の配当・利子所得が大きく増加する一方、多くの世帯ではほとんど増加していない場合でも、SNAの家計部門集計だけではその違いを判断できない。

---

### 5.3 社会保障は負担・給付の双方が拡大した

1994～2024年度では純社会負担が大幅に増加したが、社会給付もほぼ同程度に拡大した。

そのため、可処分所得 / 第1次所得比率は長期の両端ではほぼ変化しなかった。

したがって、家計所得への社会保障の影響を評価する場合、保険料等の負担だけではなく給付側も含めて見る必要がある。

ただし、給付を受ける世帯と負担する世帯は同一ではないため、家計部門全体の純額から世帯間の再分配を評価することはできない。

---

### 5.4 家計貯蓄率の低下と企業資金余剰化

1990年代には家計が大きな資金余剰部門であったが、家計貯蓄率の低下とともにその余剰は縮小した。

一方、非金融法人企業は2000年代以降大幅な資金余剰部門となった。

これは日本経済の部門間資金構造に大きな変化が生じたことを示す。

ただし、家計の余剰縮小分がそのまま企業の余剰増加分へ直接移転したことを意味しない。

部門間の資金収支は政府・金融機関・海外部門も含む会計体系の中で決まるためである。

---

### 5.5 企業資金余剰は一方向に拡大していない

非金融法人企業の純貸出GDP比は1994年度の0.7%から2010年度には7.9%まで拡大した。

しかし、2015年度の6.6%から2024年度には2.2%へ縮小している。

したがって、日本企業が「現在まで資金余剰を拡大し続けている」という表現は適切ではない。

また、2015～2024年度の縮小についても、一貫して同じ要因が働いたわけではない。

コロナ前は純貯蓄低下、コロナ期には投資急減、コロナ後には投資回復という異なる動きが確認された。

---

### 5.6 純貯蓄は企業会計上の利益と同一ではない

SNAの純貯蓄は、企業会計上の営業利益・経常利益・内部留保と同一ではない。

したがって、

```text
純貯蓄が減った
=
企業利益が減った
```

とは解釈しない。

企業利益が配当、内部留保、設備投資等へどのように配分されたかについては、企業会計・法人企業統計等を用いた別分析が必要である。

---

### 5.7 名目額の長期比較

本分析で示す実額は名目値である。

したがって、例えば雇用者報酬が262.8兆円から314.1兆円へ増加したことを、そのまま実質的な購買力の増加とは解釈できない。

長期構造の評価では構成比・GDP比を主として使用する。

---

### 5.8 因果関係は推定していない

本分析は国民経済計算の会計関係と時系列変化を利用した記述分析・恒等分解である。

したがって、本分析だけから、

- 企業利益増加が家計所得低下を引き起こした
- 特定政策が企業資金余剰を生んだ
- 賃金抑制によって企業貯蓄が増加した
- コロナ禍が各指標を何ポイント変化させた

といった因果関係を判断することはできない。

---

## 6. 結論と今後の課題

### 6.1 結論

1994～2024年度の日本経済について、所得発生から家計所得、再分配、消費・貯蓄、制度部門別資金余剰までをSNAの会計体系に沿って分析した。

主な結果は次のとおりである。

1. **雇用者報酬のGDP比は長期の両端ではほぼ変化していない。**
   一方、営業余剰比率は上昇し、混合所得比率は大幅に低下した。

2. **家計所得では雇用者報酬への依存度が上昇した。**
   家計第1次所得に占める雇用者報酬比率は76.90%から82.84%へ上昇した。

3. **社会負担と社会給付は双方とも大幅に拡大した。**
   その結果、可処分所得 / 第1次所得比率は1994年度と2024年度ではほぼ同水準であった。

4. **家計貯蓄率は長期的に大幅に低下した。**
   1994年度の12.02%から2024年度には0.80%となった。

5. **1990年代から2010年代前半にかけて非金融法人企業が大幅に資金余剰化した。**
   純貸出GDP比は2010年度には7.9%まで上昇した。

6. **企業資金余剰は2010年代後半以降縮小している。**
   2015年度6.61%から2024年度2.16%へ低下した。

7. **2015～2024年度の企業純貸出縮小の最大要因は純貯蓄比率の低下であった。**
   ただし、コロナ期には投資急減、その後は投資回復が大きく影響した。

以上から、日本経済の所得・資金分配構造は、

> 家計から企業へ所得と資金が一方向に移転し続けた

という単一の説明では捉えられない。

より正確には、

```text
混合所得の縮小
        +
営業余剰比率の上昇
        +
家計所得の雇用者報酬依存度上昇
        +
社会負担・社会給付の双方の拡大
        +
家計貯蓄率の低下
        +
企業部門の資金余剰化
        +
2010年代後半以降の企業余剰縮小
```

という複数の変化を区別して理解する必要がある。

---

### 6.2 今後の課題

本分析では制度部門単位のマクロな所得・資金フローを扱った。

次に必要なのは、その内部で所得・資産がどのように配分されているかを確認することである。

#### 企業部門

`15_corporate_profit_allocation.md` では、

- 利益
- 配当
- 内部留保
- 設備投資
- 金融資産
- 負債

等を分析し、企業部門の純貯蓄・資金余剰が企業内部でどのように形成・配分されたかを検討する。

#### 家計部門

`16_household_income_wealth.md` では、

- 所得階層別所得
- 金融資産
- 負債
- 資産価格変動
- 所得分布
- 資産分布

を扱い、SNAの家計部門集計では把握できない家計間の分布を分析する。

これにより、

```text
マクロ所得分配
        ↓
企業内部の利益配分
        ↓
家計内部の所得・資産分布
```

という分析体系へ接続する。

## 付録

### A. 主要指標・計算式

#### A.1 GDP所得面

$$GDP = 雇用者報酬 + 総営業余剰 + 総混合所得 + 純生産・輸入税$$

#### A.2 家計第1次所得

$$純第1次所得 = 雇用者報酬 + 営業余剰・混合所得 + 純財産所得$$

$$純財産所得 = 財産所得受取 - 財産所得支払$$

#### A.3 家計可処分所得

$$純可処分所得 = 純第1次所得 - 経常税 - 純社会負担 + 社会給付 + その他経常移転（純）$$

#### A.4 家計貯蓄

$$純貯蓄 = 純可処分所得 + 年金受給権の変動調整 - 家計最終消費支出$$

$$貯蓄率 = \frac{純貯蓄}{純可処分所得+年金受給権の変動調整} \times 100$$

#### A.5 制度部門別純貸出

$$純貸出GDP比 = \frac{純貸出}{GDP} \times 100$$

#### A.6 非金融法人企業

$$純貸出 = 純貯蓄 + 純資本移転 - 純資本形成$$

$$純資本形成 = 純固定資本形成 + 在庫変動 + 土地純購入 $$

$$純固定資本形成 = 総固定資本形成 - 固定資本減耗$$

#### A.7 純貸出変化分解

$$\Delta NLRatio = \Delta SavingRatio + \Delta CapitalTransferRatio - \Delta CapitalFormationRatio$$
