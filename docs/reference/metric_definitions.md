# 指標・計算式の定義

## 1. この文書の目的

Real Wage Dashboardで使用する指標、計算式、単位を共通定義として整理する。

個別分析文書と本書で定義が異なる場合は、実装コードを確認したうえで本書を更新する。分析条件や解釈上の方針は`methodology.md`、入力データは`data_sources.md`で管理する。

---

## 2. 共通表記

| 表記          | 意味                                                 |
| ------------- | ---------------------------------------------------- |
| \(x_t\)       | 当月または当年の値                                   |
| \(x\_{t-1}\)  | 直前の比較時点の値。前月比では前月、年次比較では前年 |
| \(x\_{t-12}\) | 前年同月の値                                         |
| \(w\)         | 賃金                                                 |
| \(h\)         | 労働時間                                             |
| \(s\)         | 構成比                                               |
| \(\ln\)       | 自然対数                                             |

金額の単位は円、労働時間は時間、出勤日数は日、変化率は%、寄与度は原則としてパーセントポイント（pt）で表す。

---

## 3. 一般的な変化率

### 3.1 前月比

\[\text{前月比}_t = \left( \frac{x_t}{x_{t-1}} - 1 \right) \times 100 \]

### 3.2 前年同月比

\[\text{前年同月比}_t = \left( \frac{x_t}{x_{t-12}} - 1 \right) \times 100 \]

通常の前年比処理は、年月順に並べたデータの12観測前を前年同月として算出する。そのため、入力データが連続した月次系列であることを前提とする。

給与構成の寄与度では、12観測前との暦月差が12か月であることを明示的に検証する。12か月移動平均でも、対象区間が連続した12暦月であることを検証する。

### 3.3 年平均間の変化率

\[\text{変化率} = \left( \frac{\bar x*{終了年}}{\bar x*{開始年}} - 1 \right) \times 100 \]

主分析では、開始年・終了年ともに12か月分が揃っていることを確認する。

### 3.4 対数変化

\[\text{対数変化} = \ln \left( \frac{x*t}{x*{t-1}} \right) \times 100 \]

対数変化は通常の変化率に近い値になるが、同一ではない。要因分解の加法性を保つために使用する。

---

## 4. 12か月移動平均

\[MA*{12,t} = \frac{1}{12} \sum*{i=0}^{11} x\_{t-i} \]

単に12件の観測値があるだけでは算出せず、その12件が連続した12暦月であることを条件とする。

適用対象：

- 名目賃金額
- 実質賃金額
- 実質賃金指数
- 給与構成の各系列

前年比には移動平均を適用しない。

---

## 5. 消費者物価指数

### 5.1 CPI指数

e-Statから取得した2020年平均=100の指数を使用する。

| 列名          | 内容           | 単位           |
| ------------- | -------------- | -------------- |
| `index_value` | 消費者物価指数 | 2020年平均=100 |
| `mom_pct`     | CPI前月比      | %              |
| `yoy_pct`     | CPI前年同月比  | %              |

前月比と前年同月比は、取得した指数からアプリ内で計算する。

---

## 6. 名目賃金

### 6.1 名目賃金額

毎月勤労統計の各賃金系列の実額を使用する。

| 列名                   | 内容                   | 単位 |
| ---------------------- | ---------------------- | ---- |
| `nominal_wage_amount`  | 選択した賃金項目の月額 | 円   |
| `nominal_wage_mom_pct` | 名目賃金前月比         | %    |
| `nominal_wage_yoy_pct` | 名目賃金前年同月比     | %    |
| `nominal_wage_ma_12`   | 名目賃金12か月移動平均 | 円   |

使用する賃金項目は分析ごとに異なるため、現金給与総額、きまって支給する給与、所定内給与を区別する。

---

## 7. 実質賃金

### 7.1 実質賃金額

\[\text{実質賃金額} = \frac{\text{名目賃金額}}{\text{CPI}} \times 100 \]

| 列名                | 内容                   | 単位               |
| ------------------- | ---------------------- | ------------------ |
| `real_wage_amount`  | CPIで実質化した賃金額  | 2020年価格相当の円 |
| `real_wage_mom_pct` | 実質賃金前月比         | %                  |
| `real_wage_yoy_pct` | 実質賃金前年同月比     | %                  |
| `real_wage_ma_12`   | 実質賃金12か月移動平均 | 2020年価格相当の円 |

これは選択したCPIを用いてアプリ内で算出する指標であり、厚生労働省が公表する公式の実質賃金指数とは異なる場合がある。

### 7.2 名目賃金指数

\[\text{名目賃金指数}\_t = \frac{\text{名目賃金額}\_t}{\text{基準年12か月平均}} \times 100 \]

### 7.3 実質賃金指数

\[\text{実質賃金指数}\_t = \frac{\text{実質賃金額}\_t}{\text{基準年12か月平均}} \times 100 \]

基準年は2020年とし、12か月分のデータが揃っている場合だけ算出する。

---

## 8. 労働時間と概算時間当たり賃金

### 8.1 総実労働時間

\[\text{総実労働時間} = \text{所定内労働時間} + \text{所定外労働時間} \]

単位は、労働者1人当たりの月間時間である。

### 8.2 概算時間当たり賃金

\[\text{概算時間当たり賃金} = \frac{\text{きまって支給する給与}}{\text{総実労働時間}} \]

| 列名                      | 内容                              | 単位                    |
| ------------------------- | --------------------------------- | ----------------------- |
| `approx_hourly_wage`      | 概算時間当たり賃金                | 円/時間                 |
| `real_approx_hourly_wage` | CPIで実質化した概算時間当たり賃金 | 2020年価格相当の円/時間 |

公式の時間当たり賃金ではなく、月額賃金と月間労働時間から算出した分析用指標である。

### 8.3 1出勤日当たり所定内労働時間

\[\text{1出勤日当たり所定内労働時間} = \frac{\text{所定内労働時間}}{\text{出勤日数}} \]

単位は時間/日である。

---

## 9. 給与構成

### 9.1 給与項目の恒等関係

\[\text{現金給与総額} = \text{きまって支給する給与} + \text{特別給与} \]

\[\text{きまって支給する給与} = \text{所定内給与} + \text{所定外給与} \]

したがって、

\[\text{現金給与総額} = \text{所定内給与} + \text{所定外給与} + \text{特別給与} \]

となる。

### 9.2 給与構成比

\[\text{構成比} = \frac{\text{各給与項目}}{\text{現金給与総額}} \times 100 \]

### 9.3 給与項目別寄与度

\[\text{項目 } i \text{ の寄与度} = \frac{x*{i,t}-x*{i,t-12}}{\text{前年同月の現金給与総額}} \times 100 \]

所定内給与、所定外給与、特別給与の寄与度合計は、現金給与総額前年比に一致する。

長期比較では、前年同月値の代わりに開始年平均を分母として使用する。

---

## 10. 労働投入の要因分解

### 10.1 月額賃金の分解

概算時間当たり賃金の定義から、次の関係が成立する。

\[\text{月額賃金} = \text{概算時間当たり賃金} \times \text{総実労働時間} \]

対数変化は次のように分解する。

\[\Delta \ln(\text{月額賃金}) = \Delta \ln(\text{概算時間当たり賃金}) + \Delta \ln(\text{総実労働時間}) \]

各値は100を掛けて%近似値として表示する。

### 10.2 総実労働時間の分解

\[\Delta\text{総実労働時間} = \Delta\text{所定内労働時間} + \Delta\text{所定外労働時間} \]

所定内労働時間の寄与度は次のように算出する。

比較開始時点を0、終了時点を1とする。

\[\frac{\text{所定内労働時間}\_1 - \text{所定内労働時間}\_0}{\text{総実労働時間}\_0} \times 100 \]

所定外労働時間も同じ分母を用いる。

### 10.3 所定内労働時間の分解

\[\text{所定内労働時間} = \text{出勤日数} \times \text{1出勤日当たり所定内労働時間} \]

したがって、対数変化は次のように分解する。

\[\Delta\ln(\text{所定内労働時間}) = \Delta\ln(\text{出勤日数}) + \Delta\ln(\text{1出勤日当たり所定内労働時間}) \]

---

## 11. 産業構成効果

### 11.1 産業別雇用シェア

\[s\_{i,t} = \frac{\text{産業 } i \text{ の常用労働者数}}{\text{主要16産業の常用労働者数合計}} \]

月次の常用労働者数には、前月末労働者数と本月末労働者数の平均を使用する。

### 11.2 再構築平均賃金

\[\bar{w}_t = \sum_i s_{i,t} w\_{i,t} \]

主要16産業の賃金と雇用シェアから、全体の平均賃金を再構築する。

### 11.3 平均賃金変化の分解

開始時点を0、終了時点を1とする。

#### 産業内賃金効果

\[\sum*i s*{i,0}(w*{i,1} - w*{i,0}) \]

各産業内での賃金変化による効果を表す。

#### 産業構成効果

\[\sum*i w*{i,0}(s*{i,1} - s*{i,0}) \]

産業別雇用シェアの変化による効果を表す。

#### 交差効果

\[\sum*i (w*{i,1} - w*{i,0})(s*{i,1} - s\_{i,0}) \]

賃金変化と雇用シェア変化が同時に生じた部分を表す。

### 11.4 中心化した産業別構成寄与

産業ごとの構成効果を解釈する場合は、開始時点の平均賃金からの差を用いる。

\[(w*{i,0} - \bar{w}\_0)(s*{i,1} - s\_{i,0}) \]

これにより、高賃金産業または低賃金産業の雇用シェア変化が、平均賃金をどちらへ動かしたかを評価する。

## 12. 労働需給指標

### 12.1 逼迫方向への統一

値が大きいほど労働需給が逼迫する方向へ統一する。

| 指標                 | 変換       |
| -------------------- | ---------- |
| 有効求人倍率         | 変換しない |
| 新規求人倍率         | 変換しない |
| 完全失業率           | 符号を反転 |
| 短観・雇用人員判断DI | 符号を反転 |

短観の公表値は「過剰－不足」であるため、符号反転後は値が大きいほど人手不足感が強い。

### 12.2 同時点相関

労働需給指標と同月の所定内給与前年比について、Pearsonの相関係数を算出する。

### 12.3 ラグ相関

月次分析では、過去の労働需給指標と当月の所定内給与前年比を比較する。

\[\operatorname{corr} (\text{労働需給}\_{t-k}, \text{所定内給与前年比}\_t) \]

短観分析では同じ考え方を四半期単位で適用する。

相関係数と最大相関ラグは因果効果や企業の賃金決定期間を表すものではない。

---

## 13. 指数比較の注意

2020年平均=100の指数は、各系列をそれぞれ独立して指数化する。

そのため、指数の高さから次の内容を判断できない。

- 一般労働者とパートタイム労働者の絶対的な賃金格差
- 異なる賃金項目間の金額差
- 異なる産業間の賃金水準差

指数は、それぞれの系列が基準年からどの程度変化したかを比較するために使用する。

---

## 14. 寄与度と因果関係

寄与度分解は、観測された変化を構成要素に分けるものである。

寄与度が大きい要素を、経済的な原因または因果効果とみなさない。因果的な説明には、制度、外部要因、反実仮想、他の統計等を用いた追加検証が必要である。
