# 指標・計算式の定義

## 1. この文書の目的

Real Wage Dashboardで使用する指標、計算式、単位を共通定義として整理する。

個別分析文書と本書で定義が異なる場合は、実装コードを確認したうえで本書を更新する。分析条件や解釈上の方針は`methodology.md`、入力データは`data_sources.md`で管理する。

---

## 2. 共通表記

| 表記       | 意味                                                 |
| ---------- | ---------------------------------------------------- |
| $x_t$      | 当月または当年の値                                   |
| $x_{t-1}$  | 直前の比較時点の値。前月比では前月、年次比較では前年 |
| $x_{t-12}$ | 前年同月の値                                         |
| $w$        | 賃金                                                 |
| $h$        | 労働時間                                             |
| $s$        | 構成比                                               |
| $\ln$      | 自然対数                                             |

金額の単位は円、労働時間は時間、出勤日数は日、変化率は%、寄与度は原則としてパーセントポイント（pt）で表す。

---

## 3. 一般的な変化率

### 3.1 前月比

$$\text{前月比}_t = \left( \frac{x_t}{x_{t-1}} - 1 \right) \times 100$$

### 3.2 前年同月比

$$\text{前年同月比}_t = \left( \frac{x_t}{x_{t-12}} - 1 \right) \times 100$$

通常の前年比処理は、年月順に並べたデータの12観測前を前年同月として算出する。そのため、入力データが連続した月次系列であることを前提とする。

給与構成の寄与度では、12観測前との暦月差が12か月であることを明示的に検証する。12か月移動平均でも、対象区間が連続した12暦月であることを検証する。

### 3.3 年平均間の変化率

$$\text{変化率} = \left( \frac{\bar{x}_{終了年}}{\bar{x}_{開始年}} - 1 \right) \times 100$$

主分析では、開始年・終了年ともに12か月分が揃っていることを確認する。

### 3.4 対数変化

$$\text{対数変化} = \ln \left( \frac{x_t}{x_{t-1}} \right) \times 100$$

対数変化は通常の変化率に近い値になるが、同一ではない。要因分解の加法性を保つために使用する。

---

## 4. 12か月移動平均

$$MA_{12,t} = \frac{1}{12} \sum_{i=0}^{11} x_{t-i}$$

単に12件の観測値があるだけでは算出せず、その12件が連続した12暦月であることを条件とする。

適用対象：

- 名目賃金額
- 実質賃金額
- 実質賃金指数
- 給与構成の各系列

前年比には移動平均を適用しない。

### 5.1 CPI指数

| `yoy_pct`     | CPI前年同月比  | %              |

前月比と前年同月比は、取得した指数からアプリ内で計算する。

## 6. 名目賃金

### 6.1 名目賃金額

毎月勤労統計の各賃金系列の実額を使用する。

| 列名                   | 内容                   | 単位 |
| ---------------------- | ---------------------- | ---- |
| `nominal_wage_amount`  | 選択した賃金項目の月額 | 円   |
| `nominal_wage_mom_pct` | 名目賃金前月比         | %    |
| `nominal_wage_yoy_pct` | 名目賃金前年同月比     | %    |
| `nominal_wage_ma_12`   | 名目賃金12か月移動平均 | 円   |

使用する賃金項目は分析ごとに異なるため、現金給与総額、きまって支給する給与、所定内給与を区別する。

## 7. 実質賃金

### 7.1 実質賃金額

$$\text{実質賃金額} = \frac{\text{名目賃金額}}{\text{CPI}} \times 100$$

| 列名                | 内容                   | 単位               |
| ------------------- | ---------------------- | ------------------ |
| `real_wage_amount`  | CPIで実質化した賃金額  | 2020年価格相当の円 |
| `real_wage_mom_pct` | 実質賃金前月比         | %                  |
| `real_wage_yoy_pct` | 実質賃金前年同月比     | %                  |
| `real_wage_ma_12`   | 実質賃金12か月移動平均 | 2020年価格相当の円 |

これは選択したCPIを用いてアプリ内で算出する指標であり、厚生労働省が公表する公式の実質賃金指数とは異なる場合がある。

### 7.2 名目賃金指数

$$\text{名目賃金指数}_t = \frac{\text{名目賃金額}_t}{\text{基準年12か月平均}} \times 100$$

### 7.3 実質賃金指数

$$\text{実質賃金指数}_t = \frac{\text{実質賃金額}_t}{\text{基準年12か月平均}} \times 100$$

基準年は2020年とし、12か月分のデータが揃っている場合だけ算出する。

## 8. 労働時間と概算時間当たり賃金

### 8.1 総実労働時間

$$\text{総実労働時間} = \text{所定内労働時間} + \text{所定外労働時間}$$

単位は、労働者1人当たりの月間時間である。

### 8.2 概算時間当たり賃金

$$\text{概算時間当たり賃金} = \frac{\text{きまって支給する給与}}{\text{総実労働時間}}$$

| 列名                      | 内容                              | 単位                    |
| ------------------------- | --------------------------------- | ----------------------- |
| `approx_hourly_wage`      | 概算時間当たり賃金                | 円/時間                 |
| `real_approx_hourly_wage` | CPIで実質化した概算時間当たり賃金 | 2020年価格相当の円/時間 |

公式の時間当たり賃金ではなく、月額賃金と月間労働時間から算出した分析用指標である。

### 8.3 1出勤日当たり所定内労働時間

$$\text{1出勤日当たり所定内労働時間} = \frac{\text{所定内労働時間}}{\text{出勤日数}}$$

単位は時間/日である。

## 9. 給与構成

### 9.1 給与項目の恒等関係

$$\text{現金給与総額} = \text{きまって支給する給与} + \text{特別給与}$$

$$\text{きまって支給する給与} = \text{所定内給与} + \text{所定外給与}$$

したがって、

$$\text{現金給与総額} = \text{所定内給与} + \text{所定外給与} + \text{特別給与}$$

となる。

### 9.2 給与構成比

$$\text{構成比} = \frac{\text{各給与項目}}{\text{現金給与総額}} \times 100$$

### 9.3 給与項目別寄与度

$$\text{項目 } i \text{ の寄与度} = \frac{x_{i,t}-x_{i,t-12}}{\text{前年同月の現金給与総額}} \times 100$$

所定内給与、所定外給与、特別給与の寄与度合計は、現金給与総額前年比に一致する。

長期比較では、前年同月値の代わりに開始年平均を分母として使用する。

---

## 10. 労働投入の要因分解

### 10.1 月額賃金の分解

概算時間当たり賃金の定義から、次の関係が成立する。

$$\text{月額賃金} = \text{概算時間当たり賃金} \times \text{総実労働時間}$$

対数変化は次のように分解する。

$$\Delta \ln(\text{月額賃金}) = \Delta \ln(\text{概算時間当たり賃金}) + \Delta \ln(\text{総実労働時間})$$

各値は100を掛けて%近似値として表示する。

### 10.2 総実労働時間の分解

$$\Delta\text{総実労働時間} = \Delta\text{所定内労働時間} + \Delta\text{所定外労働時間}$$

所定内労働時間の寄与度は次のように算出する。

$$\frac{\text{所定内労働時間}_1-\text{所定内労働時間}_0}{\text{総実労働時間}_0} \times 100$$

所定外労働時間も同じ分母を用いる。

### 10.3 所定内労働時間の分解

$$\text{所定内労働時間} = \text{出勤日数} \times \text{1出勤日当たり所定内労働時間}$$

したがって、

$$\Delta\ln(\text{所定内労働時間}) = \Delta\ln(\text{出勤日数}) + \Delta\ln(\text{1出勤日当たり所定内労働時間})$$

## 11. 産業構成効果

### 11.1 産業別雇用シェア

$$s_{i,t} = \frac{\text{産業 } i \text{ の常用労働者数}} {\text{主要16産業の常用労働者数合計}}$$

月次の常用労働者数には、前月末労働者数と本月末労働者数の平均を使用する。

### 11.2 再構築平均賃金

$$\bar{w}_t = \sum_i s_{i,t}w_{i,t}$$

主要16産業の賃金と雇用シェアから、全体の平均賃金を再構築する。

### 11.3 平均賃金変化の分解

開始時点を0、終了時点を1とする。

#### 産業内賃金効果

$$\sum_i s_{i,0}(w_{i,1}-w_{i,0})$$

#### 産業構成効果

$$\sum_i w_{i,0}(s_{i,1}-s_{i,0})$$

#### 交差効果

$$\sum_i (w_{i,1}-w_{i,0})(s_{i,1}-s_{i,0})$$

### 11.4 中心化した産業別構成寄与

$$(w_{i,0}-\bar{w}_0)(s_{i,1}-s_{i,0})$$

これにより、高賃金産業または低賃金産業の雇用シェア変化が、平均賃金をどちらへ動かしたかを評価する。

## 12. 労働需給指標

### 12.1 逼迫方向への統一

値が大きいほど労働需給が逼迫する方向へ統一する。

| 指標                 | 変換       |
| -------------------- | ---------- |
| 有効求人倍率         | 変換しない |
| 新規求人倍率         | 変換しない |
| 完全失業率           | 符号を反転 |
| 短観・雇用人員判断DI | 符号を反転 |

### 12.2 同時点相関

労働需給指標と同月の所定内給与前年比について、Pearsonの相関係数を算出する。

### 12.3 ラグ相関

$$\operatorname{corr} (\text{労働需給}_{t-k}, \text{所定内給与前年比}_t)$$

相関係数と最大相関ラグは因果効果や企業の賃金決定期間を表すものではない。

## 13. 企業業績・生産性・分配指標

法人企業統計調査を用いて、企業側の付加価値創出力、収益性、人件費、労働への分配を分析する。

法人企業統計と毎月勤労統計では、対象企業・事業所、企業規模区分、集計単位が異なるため、両統計の金額水準を同一概念として直接比較しない。

### 13.1 売上高

| 列名    | 内容                 |
| ------- | -------------------- |
| `sales` | 法人企業統計の売上高 |

### 13.2 営業利益

| 列名               | 内容                   |
| ------------------ | ---------------------- |
| `operating_profit` | 法人企業統計の営業利益 |

### 13.3 経常利益

| 列名              | 内容                   |
| ----------------- | ---------------------- |
| `ordinary_profit` | 法人企業統計の経常利益 |

### 13.4 営業利益率

$$\text{営業利益率} = \frac{\text{営業利益}}{\text{売上高}} \times 100$$

分析用列：`operating_profit_margin`

前年差：

$$\Delta \text{営業利益率}_t = \text{営業利益率}_t - \text{営業利益率}_{t-1}$$

### 13.5 経常利益率

$$\text{経常利益率} = \frac{\text{経常利益}}{\text{売上高}} \times 100$$

分析用列：`ordinary_profit_margin`

### 13.6 付加価値額

| 列名          | 内容                     |
| ------------- | ------------------------ |
| `value_added` | 法人企業統計の付加価値額 |

### 13.7 付加価値率

$$\text{付加価値率} = \frac{\text{付加価値額}}{\text{売上高}} \times 100$$

分析用列：`value_added_ratio`

### 13.8 労働生産性

本分析では法人企業統計の「従業員1人当たり付加価値額」を使用する。

分析用列：`labor_productivity`

概念上は、

$$\text{労働生産性} = \frac{\text{付加価値額}}{\text{期中平均従業員数}}$$

である。

検証用再計算値：

$$\text{再計算労働生産性} = \frac{\text{付加価値額}}{\text{期中平均従業員数}} \times 100$$

分析用列：

```text
calculated_labor_productivity
labor_productivity_diff
```

通常の分析では公表された `labor_productivity` を使用する。

### 13.9 人件費

$$\text{人件費} = \text{役員給与} + \text{役員賞与} + \text{従業員給与} + \text{従業員賞与} + \text{福利厚生費}$$

分析用列：`personnel_expenses`

毎月勤労統計の賃金系列とは定義が異なるため、金額を直接比較しない。

### 13.10 1人当たり人件費

$$\text{1人当たり人件費} = \frac{\text{人件費}}{\text{期中平均従業員数}} \times 100$$

分析用列：`personnel_expenses_per_employee`

### 13.11 生産性・人件費伸び率ギャップ

$$\text{伸び率ギャップ} = \text{労働生産性伸び率} - \text{1人当たり人件費伸び率}$$

分析用列：`growth_gap_pct_point`

正の場合は労働生産性上昇率が1人当たり人件費上昇率を上回ったことを表すが、意図的な配分抑制を意味しない。

### 13.12 労働分配率

$$\text{労働分配率} = \frac{\text{人件費}}{\text{付加価値額}} \times 100$$

分析用列：`labor_share`

期間差：

$$\Delta \text{労働分配率} = \text{終了年度の労働分配率} - \text{開始年度の労働分配率}$$

分析用列：`labor_share_change_pct_point`

### 13.13 企業側指標の前年比

$$\text{前年比}_t = \left( \frac{x_t}{x_{t-1}}-1 \right) \times 100$$

分析用列：

```text
labor_productivity_yoy_pct
personnel_expenses_per_employee_yoy_pct
```

比率指標は前年差を使用する。

```text
ordinary_profit_margin_change_pct_point
operating_profit_margin_change_pct_point
```

### 13.14 年度ベースの賃金指標

年度平均月額賃金：

$$\text{年度平均月額賃金} = \frac{1}{12} \sum_{m=1}^{12}\text{月額賃金}_m$$

年度概算時間当たり賃金：

$$\text{年度概算時間当たり賃金} = \frac{\sum_{m=1}^{12}\text{月額賃金}_m}{\sum_{m=1}^{12}\text{総実労働時間}_m}$$

分析用列：

```text
monthly_wage
approx_hourly_wage
monthly_wage_yoy_pct
hourly_wage_yoy_pct
```

### 13.15 企業側指標と賃金のラグ相関

$$\operatorname{corr} (\text{企業指標}_t, \text{賃金指標}_{t+k})$$

`lag_years = 0` は同年度、`lag_years = 1` は翌年度の賃金との相関を表す。

### 13.16 相関分析の観測数

相関係数とともに、

```text
observation_count
```

を確認する。

## 14. 賃金改定行動指標

厚生労働省「賃金引上げ等の実態に関する調査」の公表値を使用する。

### 14.1 1人平均賃金改定額

企業が一定期間に実施した1人平均賃金の改定額を表す。

単位は円。

分析では公表値をそのまま使用し、毎月勤労統計の月額賃金差とは同一概念として扱わない。

### 14.2 1人平均賃金改定率

$$\text{1人平均賃金改定率} = \frac{\text{改定後賃金}-\text{改定前賃金}}{\text{改定前賃金}} \times 100$$

実際の分析では、公表された改定率を使用する。

単位は%。

### 14.3 賃金引上げ実施企業割合

$$\text{賃金引上げ実施企業割合} = \frac{\text{賃金を引き上げた企業数}}{\text{対象企業数}} \times 100$$

実装・分析では公表割合を使用する。

長期比較では、「引下げ」「変更なし」の回答区分が年によって異なるため、最も比較可能性が高い「引上げ実施企業割合」を中心に使用する。

### 14.4 賃金改定時に最も重視した要素

企業が賃金改定を決定する際に「最も重視した」と回答した要因の企業割合を使用する。

主な要因：

- 企業の業績
- 世間相場
- 雇用の維持
- 労働力の確保・定着
- 消費者物価の動向
- 最低賃金
- その他

単位は%。

これは企業の自己回答による行動・意識指標であり、因果効果を表さない。

## 15. 実質賃金の名目賃金・物価要因分解

### 15.1 基本関係

概念的には、

$$\text{実質賃金} = \frac{\text{名目賃金}}{\text{物価}}$$

と表す。

指数表記では、

$$R_t = \frac{N_t}{P_t}$$

とする。

ここで、

- $R_t$：実質賃金指数
- $N_t$：名目賃金指数
- $P_t$：CPI指数

である。

### 15.2 前年比からの連鎖指数

公表前年比 $g_t$ から、開始年を100とする分析用指数を再構築する。

$$I_t = I_{t-1} \left(1+\frac{g_t}{100} \right)$$

開始年では、

$$I_0=100$$

とする。

この方法で構築する指数は累積変化を比較するための分析用指数であり、公表指数の水準そのものではない。

### 15.3 累積変化率

開始年を0、終了年を1とする。

$$\text{累積変化率} = \left( \frac{I_1}{I_0}-1 \right) \times 100$$

名目賃金、CPI、再構築実質賃金について同じ方法で算出する。

### 15.4 機械的な実質賃金

名目賃金指数とCPI指数から、

$$R_t^{*} = \frac{N_t}{P_t} \times 100$$

として機械的な実質賃金指数を構築する。

ここでの100は基準化のための係数である。

### 15.5 対数分解

$$\ln R = \ln N - \ln P$$

したがって、開始時点0から終了時点1までの変化は、

$$\Delta\ln R = \Delta\ln N - \Delta\ln P$$

となる。

100を掛けて表示すると、

$$100\Delta\ln R = 100\Delta\ln N - 100\Delta\ln P$$

である。

分析上は、

- 名目賃金寄与：$100\Delta\ln N$
- 物価寄与：$-100\Delta\ln P$
- 実質賃金変化：$100\Delta\ln R$

として整理する。

通常の累積変化率と対数変化は一致しないため、同一の数値として扱わない。

### 15.6 公式実質賃金系列との整合確認

再構築した実質系列は、厚生労働省の公式実質賃金指数または公表前年比と比較する。

確認対象：

- 変化方向
- 年次変化の符号
- 累積変化の大きさ
- CPI系列の一致

完全一致しない場合は、賃金系列・CPI系列・基準化・丸め等の定義差を確認する。

## 16. 事業所規模別賃金指標

毎月勤労統計の5人以上系列と30人以上系列を比較する。

### 16.1 月額賃金比率

$$Q_w = \frac{\text{30人以上の月額賃金}}{\text{5人以上の月額賃金}}$$

$Q_w>1$ なら、30人以上系列の月額賃金が5人以上系列を上回る。

ただし、5人以上系列は30人以上事業所を含むため、独立二群の賃金格差ではない。

### 16.2 概算時間当たり賃金比率

$$Q_h = \frac{\text{30人以上の概算時間当たり賃金}}{\text{5人以上の概算時間当たり賃金}}$$

### 16.3 労働時間比率

$$Q_t = \frac{\text{30人以上の総実労働時間}}{\text{5人以上の総実労働時間}}$$

### 16.4 月額賃金比率の恒等関係

月額賃金が、

$$W = H\times T$$

で表されるため、規模間の比率についても、

$$Q_w = Q_h \times Q_t$$

が成立する。

### 16.5 規模差変化の対数分解

開始時点0、終了時点1とする。

$$\Delta\ln Q_w = \Delta\ln Q_h + \Delta\ln Q_t$$

100を掛けて、

$$100\Delta\ln Q_w = 100\Delta\ln Q_h + 100\Delta\ln Q_t$$

とする。

分析上は、

- 時間当たり賃金比率寄与
- 労働時間比率寄与
- 月額賃金比率変化

を区別する。

これは規模差の変化を構成要素に分解するものであり、各要因が変化した因果的理由を示さない。

### 16.6 就業形態別規模差

一般労働者・パートタイム労働者についても同様に、

- 月額賃金
- 概算時間当たり賃金
- 総実労働時間
- 30人以上 / 5人以上比率

を算出する。

就業形態間で絶対水準と変化方向を混同しない。

## 17. 指数比較の注意

2020年平均=100の指数は、各系列をそれぞれ独立して指数化する。

そのため、指数の高さから次の内容を判断できない。

- 一般労働者とパートタイム労働者の絶対的な賃金格差
- 異なる賃金項目間の金額差
- 異なる産業間の賃金水準差
- 異なる事業所規模系列の絶対的な水準差

指数は、それぞれの系列が基準年からどの程度変化したかを比較するために使用する。

前年比連鎖で再構築した指数も、累積変化を比較するための分析用指数であり、公表指数の水準比較には使用しない。

## 18. 寄与度・分解・相関と因果関係

寄与度分解や対数分解は、観測された変化を構成要素に分けるものである。

寄与度が大きい要素を、経済的な原因または因果効果とみなさない。

また、

- 同時点相関
- ラグ相関
- 産業横断相関
- 期間別相関
- 賃金改定理由の回答割合

についても、因果関係を直接示すものではない。

例えば、

```text
労働生産性上昇
↓
賃金上昇
```

という時間順序や正相関が観察されても、景気、物価、労働需給、産業構成、制度変更などの共通要因が両者を動かしている可能性がある。

同様に、

```text
物価寄与が大きい
```

という実質賃金分解の結果は、物価上昇が実質賃金低下を構成したことを示すが、

> なぜ物価が上昇したか

までは説明しない。

因果的な説明には、制度、外部要因、反実仮想、他の統計等を用いた追加検証が必要である。

## 19. 更新ルール

次の場合は本書を更新する。

- 新しい指標を分析で正式採用した場合
- 指標の計算式・単位・列名を変更した場合
- 公表統計の定義変更により既存指標の意味が変わった場合
- 新しい分解方法を採用した場合
- 個別分析文書と共通定義に差が生じた場合

個別分析だけで使用する一時的な補助指標は、共通化する必要が生じるまで個別分析文書で管理する。
