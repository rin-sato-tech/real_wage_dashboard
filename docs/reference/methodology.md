# 共通分析方法

## 1. この文書の目的

Real Wage Dashboardで実施する分析について、共通する対象範囲、比較期間、集計方法、証拠の区分、検証方針を定める。

入力データは[データ出典・取得方法](data_sources.md)、計算式と単位は[指標・計算式の定義](metric_definitions.md)、確定した結果は`docs/analysis/`の各文書で管理する。

本書には個別分析の結果を記載せず、複数分析に共通する方法だけを記載する。

---

## 2. 分析全体の問い

本プロジェクトでは、次の問いを階層的に検証する。

1. 名目賃金と実質賃金に何が起きたか。
2. 名目賃金の変化は、どの給与項目から生じたか。
3. 月額賃金の変化は、時間当たり賃金と労働時間のどちらから生じたか。
4. 労働時間の変化は、所定内時間、所定外時間、出勤日数のどこから生じたか。
5. 全国平均の変化は、雇用形態、産業、雇用構成によってどう異なるか。
6. 労働需給の逼迫と賃金上昇には、どのような関連があるか。
7. 企業の付加価値、生産性、収益、人件費、労働分配と賃金にはどのような関連があるか。
8. 企業に存在する賃上げ圧力・余力は、実際の賃金改定行動へどのようにつながるか。
9. 名目賃金の上昇は、物価を考慮した購買力の改善につながったか。

一つの回帰式で全体を説明せず、

- 定義上の関係
- 構成要素
- 属性差
- 経済環境
- 統計的関連

を段階的に検証する。

---

## 3. 証拠の区分

分析結果は、次の4種類を区別して記述する。

| 区分               | 内容                                   | 主張できること                       |
| ------------------ | -------------------------------------- | ------------------------------------ |
| 恒等的・機械的分解 | 定義上成立する関係を構成要素へ分解する | どの要素が観測された変化を構成したか |
| 記述的比較         | 雇用形態、産業、期間等を比較する       | 対象間にどのような差が観察されたか   |
| 統計的関連         | 相関、ラグ相関等を計算する             | 指標間にどの程度の線形関係があるか   |
| 因果的主張         | 反実仮想を用いて原因と結果を識別する   | ある要因が結果をどの程度変化させたか |

現在の分析は、主に恒等的・機械的分解、記述的比較、統計的関連を扱う。

因果推論に必要な研究設計を行っていない分析について、次のような表現を使用しない。

- 「AがBを引き起こした」
- 「Aの効果によってBが変化した」
- 「Aから何か月後にBが反応する」
- 「寄与度が最大なのでAが根本原因である」

---

## 4. 共通する主分析条件

名目賃金側の主要な長期分析では、原則として次の条件を使用する。

| 項目       | 条件                                         |
| ---------- | -------------------------------------------- |
| 比較期間   | 2015年平均から2025年平均                     |
| 事業所規模 | 5人以上                                      |
| 就業形態   | 就業形態計                                   |
| 産業       | 調査産業計、または比較可能な主要16産業       |
| 集計       | 1月から12月まで揃った暦年平均                |
| 賃金       | 分析目的に応じた賃金項目                     |
| 労働時間   | 総実労働時間、所定内労働時間、所定外労働時間 |

分析目的により条件を変更する場合は、個別分析文書と画面上で例外を明示する。

---

## 5. 2015年と2025年を比較する理由

2015年平均と2025年平均を使用する理由は次のとおりである。

1. 最新の完全な暦年までの10年間を比較できる。
2. 単月の季節性や一時的な変動を抑えられる。
3. コロナ前、コロナ期、回復期、近年の賃上げ局面を含められる。
4. 給与構成、労働投入、産業別分析の期間を統一できる。
5. 主要な対象系列で両年の12か月が揃っている。

2015年を唯一の正しい基準年とはみなさない。開始年を変更した場合に結論が大きく変わる可能性があるため、必要に応じて年次推移や時期別比較を併用する。

---

## 6. 主分析条件の例外

### 6.1 雇用形態比較

一般労働者とパートタイム労働者を分けて比較する。

実質値には選択したCPIを使用し、主結果ではCPI総合を基準とする。

### 6.2 産業別分析

調査産業計をベンチマークとし、分類階層を混在させず、主要産業分類CからRまでの16産業を比較する。

産業分類の変更や時系列断絶がある場合は、対象期間と対象産業を再検討する。

### 6.3 労働需給分析

月次分析では2000年1月から2025年12月、短観分析では2000年第1四半期から2025年第4四半期を使用する。

長期的な関係と局面差を確認するため、2015年から2025年までの比較条件とは分けて扱う。

### 6.4 企業業績・生産性・分配分析

法人企業統計は年度統計であり、毎月勤労統計を用いた2015年平均から2025年平均までの暦年比較とは集計単位が異なる。

企業業績分析では、目的に応じて次の期間を使い分ける。

#### 構造比較

```text
2015年度 ～ 2024年度
```

を主期間とする。

企業の付加価値、生産性、人件費、労働分配率、利益率が約10年間でどのように変化したかを確認する。

#### 長期時系列分析

```text
2000年度 ～ 2024年度
```

を基本期間とする。

ただし、人件費関連指標は必要な元系列の欠損により2007年度以降を使用する。

分析期間が指標ごとに異なる場合は、相関係数とともに観測数を必ず確認する。

#### 企業規模

法人企業統計では資本金区分を使用する。

毎月勤労統計の事業所規模とは定義が異なるため、両者を同一の規模区分として直接比較しない。

#### 産業

産業別比較では、法人企業統計と毎月勤労統計で対応可能な産業に対象を限定する。

両統計の産業分類・母集団は完全には一致しないため、産業横断比較は探索的分析として扱う。

---

## 7. 年平均・年度集計

原則として、1月から12月まで12か月分が揃った年だけを完全な年として使用する。

単純な年平均は次の条件で算出する。

- 同一年内に12か月存在する。
- 年月の重複がない。
- 対象指標に欠損値がない。
- 同じ産業、就業形態、事業所規模を比較する。

概算時間当たり賃金を年次集計する場合は、月次の概算値を単純平均する方法と、年間の賃金合計を労働時間合計で割る方法を区別する。

長期の労働投入分解では、次の加重概算時間当たり賃金を使用する。

```text
年間の月額賃金合計 ÷ 年間の総実労働時間合計
```

### 7.1 年度集計

年度統計との接続が必要な場合は、4月から翌年3月までを1年度とする。

```text
2024年度 = 2024年4月 ～ 2025年3月
```

毎月勤労統計を年度集計する場合は、12か月すべてが揃った年度だけを使用する。

年度平均月額賃金は、年度内12か月の単純平均とする。

概算時間当たり賃金は、

```text
年度内の月額賃金合計 ÷ 年度内の総実労働時間合計
```

として算出する。

月次の概算時間当たり賃金を単純平均する方法とは区別する。

年度化の目的は、月次統計と年度統計の頻度を揃えることであり、年度集計によって両統計の母集団や定義が一致するわけではない。

---

## 8. 指数化

指数は、対象系列ごとに独立して基準年平均=100へ変換する。

基準年には原則として2020年を使用し、12か月分が揃っていることを確認する。

指数は基準年からの相対変化を比較するために使用し、異なる系列間の絶対水準を比較するためには使用しない。

---

## 9. 分解分析の方針

### 9.1 恒等式の検証

分解を行う前に、元データで恒等関係が成立することを確認する。

主な検証対象：

- 現金給与総額と給与構成項目
- 総実労働時間と所定内・所定外労働時間
- 月額賃金と概算時間当たり賃金・総実労働時間
- 所定内労働時間と出勤日数・1出勤日当たり時間
- 産業別雇用シェアの合計

残差または丸め誤差がある場合は、その大きさと原因を確認してから分析を採用する。

### 9.2 加法分解

総額が構成項目の和として表される場合に使用する。

例：

```text
現金給与総額 = 所定内給与 + 所定外給与 + 特別給与
総実労働時間 = 所定内労働時間 + 所定外労働時間
```

構成項目の差額または寄与度の合計が、全体の変化と一致することを検証する。

### 9.3 対数分解

全体が要素の積として表される場合に使用する。

例：

```text
月額賃金 = 概算時間当たり賃金 × 総実労働時間
所定内労働時間 = 出勤日数 × 1出勤日当たり所定内労働時間
```

対数変化を使用する場合は、通常の変化率と混同しないよう、画面、CSV、文書で「対数変化」または「対数寄与」と明記する。

### 9.4 分解結果の解釈

分解によって分かるのは、観測された変化がどの要素から構成されたかである。

分解だけでは、次の原因を判断できない。

- 政策
- 景気循環
- 人手不足
- 生産性
- 企業行動
- 労働者の選好
- 制度変更

---

## 10. 記述的比較の方針

雇用形態別・産業別比較では、次を確認する。

1. 比較対象が同じ統計と定義に基づいている。
2. 比較期間が一致している。
3. 欠損月と重複月がない。
4. 指数と実額を混同していない。
5. 特徴的な対象だけでなく、対象全体の分布や範囲を確認する。
6. 補助分析と主分析を区別する。

特徴的な産業や期間を選ぶ場合は、選定基準を明示し、結果を見た後に都合のよい対象だけを選ばない。

---

## 11. 相関・ラグ相関の方針

### 11.1 同時点相関

労働需給指標と所定内給与前年比について、同じ時点のPearson相関係数を確認する。

相関係数とともに観測数を表示する。

### 11.2 方向の統一

労働需給指標は、値が大きいほど逼迫する方向へ統一する。

- 有効求人倍率：変換しない
- 新規求人倍率：変換しない
- 完全失業率：符号を反転
- 短観・雇用人員判断DI：符号を反転

### 11.3 ラグ相関

過去の労働需給指標と現在の所定内給与前年比を比較する。

最大相関となったラグだけでなく、次を確認する。

- 同時点相関との差
- 近接するラグの相関
- 分析期間を変更した場合の安定性
- 水準系列と前年差系列の違い
- 経済局面による違い
- ラグごとの観測数

最大相関ラグを企業の賃金決定期間とは解釈しない。

### 11.4 時系列相関の制約

単純相関とラグ相関には次の制約がある。

- 共通トレンドにより相関が高く見える場合がある。
- 各系列に自己相関が存在する場合がある。
- 第三の要因を統制していない。
- 多数のラグを比較すると偶然高い相関が得られる場合がある。
- 経済局面によって関係が変化する場合がある。

したがって、相関係数だけで賃金変動全体を説明しない。

### 11.5 期間別相関

長期全体の相関だけでは、経済局面による関係の変化が隠れる場合がある。そのため、必要に応じて分析期間を複数の局面へ分割し、同時点相関を比較する。期間区分は、分析前に経済的・制度的な意味を持つ区切りとして設定する。

企業業績分析では、

```text
2000～2012年度
2013～2019年度
2020～2024年度
```

を補助的な期間区分として使用する。

期間別相関では、次を確認する。

- 相関係数の符号
- 相関係数の大きさ
- 長期全体との違い
- 観測数
- 特定年度への依存
- 他の期間でも同じ関係が再現されるか

特に観測数が少ない期間では、強い相関係数が得られても一般化しない。

### 11.6 企業側指標のラグ相関

企業業績分析では、

```text
企業指標_t
と
賃金指標_t+k
```

の相関を確認する。

例えば `lag_years = 1` は、

```text
当年度の企業側指標
と
翌年度の賃金変化
```

との相関を表す。

この分析は、

> 企業側指標が賃金に先行する可能性があるか

を探索するためのものである。

最大相関となるラグを、

- 因果効果
- 賃金改定までの所要期間
- 利益が賃金へ波及する固定的な期間

とは解釈しない。

### 11.7 水準ではなく変化を比較する

長期的に上昇・下降する水準系列同士を単純相関すると、共通トレンドによって高い相関が得られる場合がある。

そのため企業業績と賃金の時系列比較では、原則として、

- 労働生産性：前年比
- 1人当たり人件費：前年比
- 月額賃金：前年比
- 概算時間当たり賃金：前年比
- 利益率：前年差

を用いる。

水準系列を使用する場合は、その目的と制約を個別分析文書で明示する。

## 12. 頑健性確認

主結果について、必要に応じて次の補助分析を行う。

- 開始年・終了年の変更
- 年次推移
- コロナ前・コロナ期・回復期の区分
- 事業所規模5人以上と30人以上の比較
- 就業形態計、一般労働者、パートタイム労働者の比較
- CPI系列の変更
- 水準系列と変化率系列の比較
- 月次値、年平均、12か月移動平均の比較

企業業績・産業横断・時系列相関を扱う場合は、さらに次を確認する。

- 分析期間を長期化した場合に相関の符号・大きさが維持されるか
- 経済局面ごとに相関が変化しないか
- 1観測を除外した場合に結果が大きく変わらないか
- 特定産業または特定年度が相関を支配していないか
- 指標ごとの利用可能期間と観測数
- 欠損値を除外した結果、比較対象期間が意図せず変化していないか

### Leave-One-Out

横断比較では、対象を1つずつ除外して相関を再計算する。

産業横断の場合は1産業ずつ、時系列の場合は1年度ずつ除外する。

```text
全データでの相関
↓
1対象ずつ除外
↓
相関の変動範囲を確認
```

特定対象を除外しただけで相関係数の符号や大きさが大幅に変化する場合、その関係は頑健とはみなさない。

Leave-One-Outは正式な因果推論や統計的有意性検定の代替ではなく、少数標本における感応度確認として使用する。

補助分析で主結果が大きく変わる場合は、結果の一般化を避け、条件依存性を明示する。

## 13. データ検証

分析前に最低限次を確認する。

### 13.1 単一データ

- 必須列
- データ型
- 年月の変換
- 重複年月
- 欠損値
- 対象期間
- 正の値を必要とする計算の分母
- 12か月の連続性
- 基準年の12か月完全性

### 13.2 データ結合

- 結合キー
- 結合前後の件数
- one-to-one等の期待する対応関係
- 結合後の欠損値
- 統計間の対象範囲
- 頻度の違い
- 産業分類等の定義差

### 13.3 分解結果

- 恒等式の誤差
- 寄与度合計と全体変化の差
- 雇用シェア合計
- 再構築平均と公表系列の差
- 対数分解の残差

### 13.4 年度統計・企業業績分析

- 年度が連続しているか
- 同一年度に複数行が存在しないか
- 指標ごとの利用可能開始年度
- 人件費構成項目の欠損
- 付加価値額・従業員数の分母異常
- 公表労働生産性と再計算値の差
- 企業規模区分の定義
- 産業分類の対応関係
- 年度化した毎月勤労統計が12か月完全であるか
- 時系列結合が `one-to-one` になっているか
- ラグごとの観測数

## 14. 分析結果の記述構成

個別分析文書とアプリ画面では、原則として次の順序で記述する。

1. 問い
2. 分析条件
3. 主な結果
4. 考察・解釈
5. 分析方法
6. 詳細結果
7. 言えること
8. 言えないこと
9. データ・実装・テスト

画面上部では、問い、条件、主要結果、考察が把握できるようにする。

分析全体を横断した結論は`docs/analysis/00_overview.md`、個別の数値と方法は各個別分析文書で管理する。

---

## 15. 新しい分析の採用手順

新しい分析ページを先に実装せず、次の順で検討する。

1. 問いと仮説を1文で定義する。
2. 必要な統計と指標を列挙する。
3. 統計定義、対象範囲、頻度、接続可能性を確認する。
4. スクリプトまたはNotebookで探索分析を行う。
5. 欠損、重複、時系列断絶を検証する。
6. 結果の説明力と限界を評価する。
7. 採用する場合だけ分析処理、テスト、UIを実装する。
8. 個別分析文書と全体概要を更新する。

採用の判断では、次を重視する。

- 既存分析では回答できない問いか。
- 結果が再現可能か。
- 対象期間と定義が比較可能か。
- 分析結果から何が言えて何が言えないか明示できるか。
- アプリへ追加する価値が実装・保守負担を上回るか。

---

## 16. 更新ルール

次の場合は本書を更新する。

- 主分析期間を変更した場合
- 共通する事業所規模、就業形態、産業範囲を変更した場合
- 年平均、指数化、分解、相関の方法を変更した場合
- 新しい証拠区分や頑健性確認を採用した場合
- 個別分析で共通化すべき方法が追加された場合

個別分析だけに固有の条件や結果は、本書ではなく対応する個別分析文書へ記載する。
