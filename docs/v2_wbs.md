# Real Wage Dashboard v2 WBS

## 1. 目的

v2では、v1で固定されていた賃金分析条件を選択可能にし、12か月移動平均を追加する。

対象となる主な拡張は以下。

- 賃金項目の切り替え
- 就業形態の切り替え
- 事業所規模の切り替え
- 12か月移動平均
- 名目賃金ページへの反映
- 実質賃金ページへの反映
- CSV出力への条件情報追加
- エラー処理・テスト拡張

### WBS 5：賃金分析ロジック拡張

対象：

```text
wage_analysis.py
```

#### 5-1. 既存変化率処理確認

以下を維持する。

- 前月比
- 前年同月比

#### 5-2. 12か月移動平均関数追加

汎用的な関数として実装する。

想定：

```python
add_moving_average(
    df,
    column,
    window=12,
)
```

#### 5-3. 連続12暦月判定

単純な、`rolling(12)`だけでは実装しない。

12個の観測値が存在するだけでなく、**その12件が連続する12暦月であること**を確認する。

#### 5-4. 欠損期間処理

以下の場合、移動平均を欠損値とする。

- 最初の11か月
- 途中に欠損月がある12か月区間

#### 5-5. 名目賃金MA列追加

想定列：

```text
nominal_wage_ma_12
```

#### 完了条件5

- 連続12暦月のみMAが算出される
- 欠損月をまたいだ計算が発生しない
- 前年同月比にはMAを適用しない

### WBS 6：実質賃金ロジック拡張

対象：

```text
real_wage_analysis.py
```

#### 6-1. 条件選択後の賃金データ対応

可変条件で作成された名目賃金DataFrameを既存のCPI処理と結合できるようにする。

#### 6-2. 月次実質賃金計算維持

以下の計算順序を固定する。

```text
月次名目賃金
↓
同月CPI
↓
月次実質賃金
```

#### 6-3. 実質賃金12か月移動平均追加

月次実質賃金算出後に、

```text
real_wage_ma_12
```

を追加する。

名目賃金MAを実質化してはならない。

#### 6-4. 指数化

以下を維持する。

- 名目賃金指数
- 実質賃金指数
- 2020年平均=100

#### 6-5. 実質賃金指数MA

グラフ表示に合わせて、`real_wage_index_ma_12`を作るか、`real_wage_amount`のMAから指数化するかを実装段階で一つに統一する。

原則として、月次実質賃金指数に対して12か月MAを適用する。

#### 6-6. 基準年不存在エラー

2020年の基準データが存在しない場合は処理を停止する。

#### 完了条件6

- 実質化→MAの順序が守られている
- 2020年基準指数を算出できる
- 基準データ不存在時にエラーになる
