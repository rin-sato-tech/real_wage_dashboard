# Real Wage Dashboard

e-Statの消費者物価指数と毎月勤労統計調査を用いて、
日本の物価・名目賃金・実質賃金を分析するStreamlitダッシュボードです。

賃金項目・就業形態・事業所規模・CPI系列を切り替えながら、
賃金と購買力の長期的な変化を確認できます。

---

## 主な機能

### 消費者物価指数

全国の消費者物価指数をe-Stat APIから取得し、時系列で表示します。

対応系列：

- 総合
- 生鮮食品を除く総合
- 生鮮食品及びエネルギーを除く総合
- 持家の帰属家賃を除く総合

最新値、前月比、前年同月比、時系列グラフ、CSV出力に対応しています。

---

### 名目賃金

毎月勤労統計調査の長期時系列データから名目賃金を分析します。

選択可能な条件：

- 賃金項目：現金給与総額 / きまって支給する給与
- 就業形態：就業形態計 / 一般労働者 / パートタイム労働者
- 事業所規模：5人以上 / 30人以上

月次値、12か月移動平均、前月比、前年同月比を表示します。

---

### 実質賃金

名目賃金を選択したCPIで実質化し、購買力の変化を分析します。

実質賃金額は次の式で計算しています。

```text
実質賃金額 = 名目賃金 ÷ CPI × 100
```

実質賃金の12か月移動平均は、

```text
月次名目賃金
↓
同月CPIで実質化
↓
月次実質賃金
↓
12か月移動平均
```

の順で算出します。

名目賃金指数・実質賃金指数は、それぞれ2020年平均=100として算出します。

---

### 雇用形態比較

一般労働者とパートタイム労働者について、
月額賃金・労働時間・概算時間当たり賃金・実質購買力の推移を比較します。

主分析では、2015年平均と2025年平均を比較し、

- 月額賃金
- 総実労働時間
- 概算時間当たり賃金
- 実質月額賃金
- 実質概算時間当たり賃金

の変化率を確認します。

また、月額賃金の前年同月変化を

- 時間当たり賃金要因
- 労働時間要因

に分解し、賃金変化の構造を確認します。

概算時間当たり賃金は、

```text
きまって支給する給与 ÷ 総実労働時間
```

で算出します。

一般労働者とパートタイム労働者の指数は、
それぞれ独立して2020年平均=100として指数化します。

分析結果はCSV出力でき、雇用形態比較ではTableau等での二次分析向けに全事業所規模・全CPI系列を含むCSVも出力できます。

詳細は `docs/employment_comparison_analysis.md` を参照してください。

---

### 給与構成分析

現金給与総額の変動を、

- 所定内給与
- 所定外給与
- 特別給与

に分解し、賃金上昇の中身を分析します。

2015年平均と2025年平均の比較では、現金給与総額は12.72%増加し、
所定内給与が+8.46pt、特別給与が+4.22pt、所定外給与が+0.04pt寄与しました。

また、月次・年次の寄与度を可視化し、2020年と近年で賃金変動の構造が異なることを確認できます。

詳細は `docs/analyzing/wage_composition_analysis.md` を参照してください。

## 使用データ

### 消費者物価指数

- 出典：政府統計の総合窓口 e-Stat
- 統計：消費者物価指数
- 地域：全国
- 基準：2020年=100
- 取得方法：e-Stat API

### 賃金・労働時間

- 出典：政府統計の総合窓口 e-Stat
- 統計：毎月勤労統計調査
- 産業：調査産業計
- 事業所規模：5人以上 / 30人以上
- 就業形態：就業形態計 / 一般労働者 / パートタイム労働者

使用ファイル：

```text
data/raw/hon-maikin-k-jissu.csv
```

## セットアップ

```bash
uv sync
```

`.streamlit/secrets.toml`を作成し、e-Stat APIのアプリケーションIDを設定します。

```toml
ESTAT_APP_ID = "your-app-id"
```

```bash
uv run streamlit run app.py
```

## データ更新

名目賃金データを更新する場合は、毎月勤労統計調査の長期時系列CSVを取得し、

```text
data/raw/hon-maikin-k-jissu.csv
```

を最新の毎月勤労統計調査の長期時系列CSVに置き換えます。

消費者物価指数はアプリ実行時にe-Stat APIから取得します。

---

## 注意事項

実質賃金・実質概算時間当たり賃金は、
選択したCPIを用いてアプリ内で算出しているため、
公表されている公式の実質賃金指数とは一致しない場合があります。

雇用形態比較の概算時間当たり賃金は分析用の概算値であり、公式の時給ではありません。

また、一般労働者とパートタイム労働者の指数はそれぞれ独立して
2020年平均=100としているため、指数の高さから絶対的な賃金格差を比較することはできません。
