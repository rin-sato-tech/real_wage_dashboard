# Real Wage Dashboard

消費者物価指数と毎月勤労統計調査を中心に、複数の公的統計を組み合わせて、日本の物価・賃金・労働時間と賃金変動の背景を分析するプロジェクトです。

Streamlitによる名目賃金・実質賃金の可視化に加え、給与構成、労働投入、雇用形態、産業構成、労働需給、企業業績・生産性・分配の観点から、賃金変化の構造を段階的に検証しています。

分析によっては、探索・検証・文書化までを成果物とし、すべてをStreamlitページとして実装するわけではありません。

> 分析条件、主要結果、解釈、限界を統合した文書は、[実質賃金関連分析：全体像と結論](docs/analysis/00_overview.md)を参照してください。

---

## このプロジェクトで扱う問い

- 名目賃金の上昇は、所定内給与、残業代、賞与のどこから生じたか。
- 月額賃金の変化は、時間当たり賃金と労働時間のどちらから生じたか。
- 全国平均の変化は各産業に広く共通するのか、産業構成変化によるものか。
- 労働需給の逼迫と所定内給与上昇には、どのような関連があるか。
- 企業の付加価値、生産性、収益、人件費、労働分配と賃金にはどのような関係があるか。
- 名目賃金の上昇は、物価を考慮した実質購買力の改善につながったか。

## 主な分析ページ

| ページ           | 主な内容                                                                             |
| ---------------- | ------------------------------------------------------------------------------------ |
| 消費者物価指数   | CPI4系列の最新値、前月比、前年同月比、時系列を表示                                   |
| 名目賃金         | 賃金項目、就業形態、事業所規模を切り替え、月次値・12か月移動平均・前年比を表示       |
| 実質賃金         | 選択したCPIで名目賃金を実質化し、2020年平均=100の指数と前年比を表示                  |
| 雇用形態比較     | 一般労働者とパートタイム労働者の月額賃金、労働時間、概算時間当たり賃金、実質値を比較 |
| 給与構成分析     | 現金給与総額の変化を所定内給与、所定外給与、特別給与に分解                           |
| 労働投入分析     | 月額賃金を概算時間当たり賃金と総実労働時間に分解し、労働時間を出勤日数まで掘り下げる |
| 産業別分析       | 主要16産業の月額賃金、概算時間当たり賃金、総実労働時間を比較・分解                   |
| 産業構成効果分析 | 平均賃金変化を産業内賃金効果、産業構成効果、交差効果に分解                           |
| 労働需給分析     | 求人倍率、完全失業率、短観の人手不足感と所定内給与前年比の相関・ラグ相関を分析       |

---

## 分析の到達点

2015年平均から2025年平均までの主分析では、次の構造を確認しました。

- 現金給与総額の上昇は、主として所定内給与の増加によって構成されていた。
- 概算時間当たり賃金の上昇を、総実労働時間の減少が一部相殺していた。
- 労働時間減少の中心は所定内労働時間であり、さらにその中心は出勤日数だった。
- 主要16産業すべてで概算時間当たり賃金が上昇し、総実労働時間が減少したが、変化幅には産業差があった。
- 平均賃金上昇の中心は産業構成変化ではなく、各産業内の賃金上昇だった。
- 労働需給の逼迫と所定内給与上昇には正の関連がみられたが、固定的な時間差や因果関係は確認できなかった。
- 名目賃金上昇が実質月額賃金の改善につながった程度は、就業形態によって異なった。
- 2015～2024年度では、企業の労働生産性は約12.7%上昇した一方、1人当たり人件費の上昇は約7.3%にとどまり、労働分配率は約3.3pt低下した。
- 企業規模別では、大企業ほど生産性・収益性の改善が大きく、中小企業では労働分配率が高い一方で、生産性と1人当たり人件費の水準が低かった。
- 長期時系列では労働生産性・1人当たり人件費と月額賃金に一定の正の関連がみられたが、その強さは時期によって大きく異なり、生産性上昇から賃金上昇への固定的な関係は確認できなかった。

詳細な数値、分析条件、各結果の証拠の強さ、分析から言えないことは、[分析全体の概要](docs/analysis/00_overview.md)に集約しています。

## 使用データ

| 分野                     | 統計・出典                           | 取得・保存方法                              |
| ------------------------ | ------------------------------------ | ------------------------------------------- |
| 物価                     | 総務省「消費者物価指数」             | e-Stat APIから取得                          |
| 賃金・労働時間・雇用者数 | 厚生労働省「毎月勤労統計調査」       | 長期時系列CSVを`data/raw/`に保存            |
| 求人倍率                 | 厚生労働省「一般職業紹介状況」       | Excelを`data/raw/labor_market/`に保存       |
| 完全失業率               | 総務省「労働力調査」                 | Excelを`data/raw/labor_market/`に保存       |
| 企業の雇用判断           | 日本銀行「全国企業短期経済観測調査」 | 整形済みCSVを`data/raw/labor_market/`に保存 |
| 企業業績・生産性・分配   | 財務省「法人企業統計調査」           | e-Stat APIから取得                          |

賃金・労働時間側の主分析では、毎月勤労統計の5人以上事業所を対象とし、主に2015年平均と2025年平均を比較しています。

企業業績分析では法人企業統計の年度データを使用し、2015年度から2024年度を主な構造比較期間、2000年度から2024年度を長期時系列分析期間としています。

統計ごとに対象範囲、集計単位、利用可能期間が異なるため、分析条件の例外は個別分析文書と `docs/reference/methodology.md` に記載しています。

## データ更新

賃金データを更新する場合は、毎月勤労統計調査の長期時系列CSVを取得し、`data/raw/hon-maikin-k-jissu.csv`を置き換えます。

消費者物価指数はアプリ実行時にe-Stat APIから取得します。労働需給分析のファイルは、各公表元の更新に合わせて`data/raw/labor_market/`内を更新します。

法人企業統計はe-Stat APIから取得します。統計表ID、分類コード、利用可能年度、主要系列の欠損状況が変わる可能性があるため、更新時は法人企業統計用の確認スクリプトと自動テストを実行します。

## 注意事項

- 実質賃金は、選択したCPIを用いてアプリ内で算出した値であり、公式の実質賃金指数と一致しない場合があります。
- 概算時間当たり賃金は、`きまって支給する給与 ÷ 総実労働時間`で算出した分析用指標であり、公式の時間当たり賃金ではありません。
- 雇用形態別の指数は、それぞれ独立して2020年平均=100としているため、指数の高さから絶対的な賃金格差を比較できません。
- 給与構成、労働投入、産業構成の分解は、変化を構成した要素を示すものであり、因果関係を示すものではありません。
- 労働需給分析の相関・ラグ相関から、賃上げの因果効果や固定的な賃金反応期間を判断することはできません。
- 法人企業統計と毎月勤労統計では、調査対象、集計単位、企業・事業所規模区分が異なるため、金額水準や規模区分を同一概念として直接比較しません。
- 企業業績・生産性と賃金の相関・ラグ相関は統計的関連を確認するためのものであり、生産性や利益の上昇が一定期間後の賃上げを引き起こすことを示すものではありません。
