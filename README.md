# Real Wage Dashboard

e-Statの消費者物価指数と厚生労働省「毎月勤労統計調査」を用いて、
日本の物価・賃金・労働時間の変化を分析するStreamlitダッシュボードです。

名目賃金・実質賃金の可視化に加え、雇用形態、給与構成、労働投入の観点から、
**賃金がどのような要因で変化しているか**を段階的に確認できます。

---

## 主な分析ページ

### 消費者物価指数

全国の消費者物価指数をe-Stat APIから取得し、時系列で表示します。

対応系列：

- 総合
- 生鮮食品を除く総合
- 生鮮食品及びエネルギーを除く総合
- 持家の帰属家賃を除く総合

最新値、前月比、前年同月比、時系列グラフ、CSV出力に対応しています。

---

### 名目賃金

毎月勤労統計調査の長期時系列データから名目賃金を分析します。

選択可能な主な条件：

- 賃金項目：現金給与総額 / きまって支給する給与
- 就業形態：就業形態計 / 一般労働者 / パートタイム労働者
- 事業所規模：5人以上 / 30人以上

月次値、12か月移動平均、前月比、前年同月比を確認できます。

---

### 実質賃金

名目賃金を選択したCPIで実質化し、購買力の変化を分析します。

```text
実質賃金額 = 名目賃金 ÷ CPI × 100
```

実質賃金の12か月移動平均は、

```text
月次名目賃金
↓
同月CPIで実質化
↓
月次実質賃金
↓
12か月移動平均
```

の順で算出します。

名目賃金指数・実質賃金指数は、それぞれ2020年平均=100として算出します。

---

### 雇用形態比較

一般労働者とパートタイム労働者について、

- 月額賃金
- 総実労働時間
- 1時間あたり賃金（概算）
- 実質月額賃金
- 実質1時間あたり賃金（概算）

を比較します。

また、月額賃金の変化を

```text
月額賃金
├─ 1時間あたり賃金（概算）
└─ 総実労働時間
```

に分解し、雇用形態による賃金変化の違いを確認します。

「1時間あたり賃金（概算）」は、`きまって支給する給与 ÷ 総実労働時間`で算出する分析用の派生指標です。

詳細は `docs/employment_comparison_analysis.md` を参照してください。

---

### 給与構成分析

現金給与総額の変動を、

- 所定内給与
- 所定外給与
- 特別給与

に分解し、賃金上昇の中身を分析します。

2015年平均から2025年平均では、現金給与総額は 12.72%増加し、

- 所定内給与：+8.46pt
- 所定外給与：+0.04pt
- 特別給与：+4.22pt

の寄与となりました。

月次・年次の寄与も確認でき、一時的な変動と長期的な変化を区別して分析できます。

詳細は `docs/analyzing/wage_composition_analysis.md` を参照してください。

---

### 労働投入分析

月額の「きまって支給する給与」の変化を、賃金単価と労働時間の両面から段階的に分解します。

```text
月額のきまって支給する給与
├─ 1時間あたり賃金（概算）
└─ 総実労働時間
   ├─ 所定内労働時間
   │  ├─ 出勤日数
   │  └─ 1出勤日あたり所定内労働時間
   └─ 所定外労働時間
```

主分析では2015年平均と2025年平均を比較します。

この期間では、

- 月額のきまって支給する給与：+10.30%
- 1時間あたり賃金（概算）：+17.95%
- 総実労働時間：-6.49%

となり、1時間あたり賃金の上昇を労働時間の減少が一部相殺していました。

さらに労働時間を分解すると、総実労働時間の減少は主に所定内労働時間から生じ、
所定内労働時間の減少は主として出勤日数の減少によって説明されます。

2015年からの累積変化、前年比、雇用形態別の補助分析に加え、
完全な年を対象として任意の比較期間も確認できます。

詳細は `docs/analyzing/labor_input_analysis.md` を参照してください。

---

### 産業別賃金分析

主要16産業について、2015年平均から2025年平均までの

- 月額賃金
- 1時間あたり賃金（概算）
- 総実労働時間

の変化を比較し、月額賃金の変化を「時間当たり賃金要因」と「労働時間要因」に分解します。

主要16産業すべてで月額賃金と概算時間当たり賃金が上昇する一方、総実労働時間は減少しており、上昇幅には大きな産業差が確認されました。

詳細は `docs/analyzing/industry_wage_analysis.md` を参照してください。

---

### 産業構成効果分析

2015年平均から2025年平均までの平均賃金変化を、

- 産業内賃金効果
- 産業構成効果
- 交差効果

に分解し、平均賃金上昇が各産業内部の賃金上昇によるものか、産業別の雇用シェア変化によるものかを確認します。

主要16産業から再構築した平均賃金は2015→2025年で約10.30%上昇し、

- 産業内賃金効果：+10.66pt
- 産業構成効果：-0.21pt
- 交差効果：-0.15pt

となりました。

平均賃金上昇の中心は各産業内部の賃金上昇であり、産業構成変化は10年間全体ではわずかな押し下げ要因でした。

また、産業別の雇用シェア変化と構成寄与、時期別分解、一般労働者・パートタイム労働者別の補助分析も確認できます。

詳細は `docs/analyzing/industry_composition_analysis.md` を参照してください。

## 使用データ

### 消費者物価指数

- 出典：政府統計の総合窓口 e-Stat
- 統計：消費者物価指数
- 地域：全国
- 基準：2020年=100
- 取得方法：e-Stat API

### 賃金・労働時間

- 出典：政府統計の総合窓口 e-Stat
- 統計：毎月勤労統計調査
- 産業：調査産業計 / 主要産業分類
- 事業所規模：5人以上 / 30人以上
- 就業形態：就業形態計 / 一般労働者 / パートタイム労働者

使用ファイル：`data/raw/hon-maikin-k-jissu.csv`

名目賃金データを更新する場合は、毎月勤労統計調査の長期時系列CSVを取得し、
`data/raw/hon-maikin-k-jissu.csv`を最新の毎月勤労統計調査の長期時系列CSVに置き換えます。

消費者物価指数はアプリ実行時にe-Stat APIから取得します。

## 注意事項

本ダッシュボードで算出する実質賃金は、選択したCPIを用いた独自計算値であり、
公表されている公式の実質賃金指数とは一致しない場合があります。

「1時間あたり賃金（概算）」は、`きまって支給する給与 ÷ 総実労働時間`
で算出した分析用の派生指標であり、公式の時間当たり賃金ではありません。

また、雇用形態比較で使用する指数は、
一般労働者とパートタイム労働者をそれぞれ独立して2020年平均=100としているため、
指数の高さから両者の絶対的な賃金格差を比較することはできません。
